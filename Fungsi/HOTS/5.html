No. 41
Diberikan fungsi $f$ terdefinisi untuk semua bilangan real $x$ selain $0$ dan $1$, memenuhi $$(x + 1)f(-x) + \frac{1 - x}{4x}f\left(\frac{1}{x}\right) = \frac{100(x^2 + 4)}{x}$$ Hitung nilai dari $f(2) + f(3) + f(4) + \cdots + f(400)$.
Sumber: OSK SMA 2021 (No. 3)
Pembahasan:

Substitusikan $x \mapsto -\frac{1}{x}$ ke persamaan:

$$-\frac{1 - x}{x}f\left(\frac{1}{x}\right) - \frac{x + 1}{4}f(-x) = -\frac{100(4x^2 + 1)}{x}$$

Kalikan dengan $-4$:

$$(x + 1)f(-x) + 16\left(\frac{1 - x}{4x}\right)f\left(\frac{1}{x}\right) = \frac{100(16x^2 + 4)}{x}$$

Kurangkan dengan persamaan awal untuk mengeliminasi $f(-x)$:

$$15\left(\frac{1 - x}{4x}\right)f\left(\frac{1}{x}\right) = \frac{100(15x^2)}{x} \implies f\left(\frac{1}{x}\right) = \frac{400x^2}{1 - x}$$

Ganti $\frac{1}{x} \mapsto x$, sehingga $f(x) = \frac{400}{x(x - 1)} = 400\left(\frac{1}{x - 1} - \frac{1}{x}\right)$. Dengan deret teleskopik:

$$\sum_{k=2}^{400} f(k) = 400\left(1 - \frac{1}{400}\right) = 399$$
Jadi, nilai jumlah tersebut adalah $399$.
No. 42
Misalkan $f(x) = a^2 x + 200$. Jika $f(20) + f^{-1}(22) = f^{-1}(20) + f(22)$, maka $f(1) = \cdots$
Sumber: OSK SMA 2022 (No. 1)
Pembahasan:

Karena $f(x) = a^2x + 200$ ($a \neq 0$), fungsi inversnya adalah $f^{-1}(x) = \frac{x - 200}{a^2}$.

$$f(20) - f(22) = f^{-1}(20) - f^{-1}(22) \implies a^2(20 - 22) = \frac{20 - 22}{a^2} \implies a^4 = 1 \implies a^2 = 1$$

Jadi $f(x) = x + 200$, sehingga $f(1) = 1 + 200 = 201$.

Jadi, nilai $f(1)$ adalah $201$.
No. 43
Tentukan semua fungsi $f : \mathbb{R} \to \mathbb{R}$ sehingga untuk setiap $x, y \in \mathbb{R}$ berlaku $$f(f(f(x)) + f(y)) = f(y) - f(x)$$
Sumber: OSN SMA 2022 (No. 1)
Pembahasan:

Misalkan $P(x, y)$ menyatakan persamaan fungsional $f(f(f(x)) + f(y)) = f(y) - f(x)$.

Substitusi $P(x, x)$ menunjukkan ada bilangan real $r = f(f(x)) + f(x)$ sehingga $f(r) = 0$. Kemudian $P(r, r)$ memberi $f(f(0)) = 0$.

Dari $P(0, y)$, diperoleh $f(f(f(0)) + f(y)) = f(y) - f(0)$, yaitu $f(f(y)) = f(y) - f(0)$ untuk semua $y \in \mathbb{R}$. Substitusikan kembali $f(f(x)) = f(x) - f(0)$ ke persamaan awal:

$$f(f(x) + f(y) - f(0)) = f(y) - f(x)$$

Menukar $x$ dan $y$ pada ruas kiri menghasilkan nilai yang sama, sehingga $f(y) - f(x) = f(x) - f(y) \implies f(x) = f(y)$ untuk semua $x, y$. Jadi $f$ fungsi konstan $f(x) \equiv c$; substitusi $c = c - c = 0$ memberi $f(x) \equiv 0$.

Jadi, satu-satunya fungsi yang memenuhi adalah $f(x) = 0$ untuk semua $x \in \mathbb{R}$.
No. 44
Sumber: OSN SMA 2023 (No. 2)

Tentukan semua fungsi $f : \mathbb{R} \to \mathbb{R}$ sedemikian sehingga untuk setiap bilangan real $x, y$ berlaku: $$f(f(x) + y) = \lfloor x + f(f(y)) \rfloor.$$

Pembahasan (Jawaban: $f(x) = \lfloor x \rfloor + k$, $k \in \mathbb{Z}$)

Karena ruas kanan selalu merupakan bilangan bulat, daerah hasil $f$ termuat di $\mathbb{Z}$ (sebab $y$ bebas mengambil sebarang nilai real, sehingga $f(x) + y$ dapat menjangkau seluruh $\mathbb{R}$). Jadi $f(t) \in \mathbb{Z}$ untuk semua $t \in \mathbb{R}$, dan akibatnya $f(f(y)) \in \mathbb{Z}$.

Oleh karena itu, $\lfloor x + f(f(y)) \rfloor = \lfloor x \rfloor + f(f(y))$, sehingga persamaan menjadi: $$f(f(x) + y) = \lfloor x \rfloor + f(f(y)).$$ Substitusi $x = 0$: $f(f(0) + y) = f(f(y))$ untuk semua $y \in \mathbb{R}$.
Jika $y \in [0, 1)$, maka $\lfloor y \rfloor = 0$. Ambil $x, y$ dengan $y = 0$: $$f(f(x)) = \lfloor x \rfloor + f(f(0)).$$ Misalkan $c = f(f(0)) \in \mathbb{Z}$. Maka $f(f(y)) = \lfloor y \rfloor + c$ untuk semua $y \in \mathbb{R}$.

Substitusi balik ke persamaan semula: $$f(f(x) + y) = \lfloor x \rfloor + \lfloor y \rfloor + c.$$ Ambil $x = 0$: $f(f(0) + y) = \lfloor y \rfloor + c$ untuk semua $y \in \mathbb{R}$.
Dengan mengganti $y \leftarrow y - f(0)$ (dan karena $f(0) \in \mathbb{Z}$), diperoleh: $$f(y) = \lfloor y - f(0) \rfloor + c = \lfloor y \rfloor + (c - f(0)).$$ Misalkan $k = c - f(0) \in \mathbb{Z}$, jadi $f(x) = \lfloor x \rfloor + k$.

Uji kembali: untuk $f(x) = \lfloor x \rfloor + k$ dengan $k \in \mathbb{Z}$: - Ruas kiri: $f(\lfloor x \rfloor + k + y) = \lfloor x \rfloor + k + \lfloor y \rfloor + k = \lfloor x \rfloor + \lfloor y \rfloor + 2k$. - Ruas kanan: $\lfloor x + \lfloor \lfloor y \rfloor + k \rfloor + k \rfloor = \lfloor x + \lfloor y \rfloor + 2k \rfloor = \lfloor x \rfloor + \lfloor y \rfloor + 2k$. Keduanya sama. Jadi semua solusinya adalah $f(x) = \lfloor x \rfloor + k$ untuk sebarang $k \in \mathbb{Z}$.
