No. 31
Barisan $x_0, x_1, x_2, \dots, x_n$ didefinisikan dengan $x_0 = 10$, $x_1 = 5$, dan $x_{k+1} = x_{k-1} - \dfrac{1}{x_k}$ untuk $k = 1, 2, 3, \dots, n - 1$ dan diperoleh $x_n = 0$. Nilai $n$ adalah $\cdots$
Sumber: OSP SMA 2016 (No. 18)
Pembahasan:

Kalikan relasi rekursif dengan $x_k$: $x_k x_{k+1} = x_{k-1} x_k - 1$.

Karena $x_0 x_1 = 10 \times 5 = 50$, dengan induksi diperoleh $x_{k-1} x_k = 51 - k$ untuk setiap $k \ge 1$.

Saat $x_n = 0$, $x_{n-1} x_n = 0 \implies 51 - n = 0 \implies n = 51$ (dan sebelum $k = 51$, semua $x_k \neq 0$ sehingga terdefinisi).

Jadi, nilai $n$ adalah $51$.
No. 32
Diberikan tripel bilangan asli berbeda $(x_0, y_0, z_0)$ yang memenuhi $x_0 + y_0 + z_0 = 2016$. Setiap jam ke-$i$, dengan $i \ge 1$, dibentuk tripel baru $$(x_i, y_i, z_i) = (y_{i-1} + z_{i-1} - x_{i-1},\; z_{i-1} + x_{i-1} - y_{i-1},\; x_{i-1} + y_{i-1} - z_{i-1})$$ Tentukan bilangan asli $n$ terkecil sehingga pada jam ke-$n$ pasti ditemukan minimal satu di antara $x_n, y_n,$ atau $z_n$ merupakan bilangan negatif.
Sumber: OSP SMA 2016 (No. 25)
Pembahasan:

Jumlah $x_i + y_i + z_i = 2016$ selalu tetap untuk setiap $i \ge 0$, sehingga $x_i = 2016 - 2x_{i-1}$, $y_i = 2016 - 2y_{i-1}$, dan $z_i = 2016 - 2z_{i-1}$.

Misalkan $a_i = \max\{x_i, y_i, z_i\}$ dan $b_i = \min\{x_i, y_i, z_i\}$. Maka $a_i = 2016 - 2b_{i-1}$ dan $b_i = 2016 - 2a_{i-1}$, sehingga untuk $i \ge 2$ berlaku:

$$a_i = 2016 - 2(2016 - 2a_{i-2}) = 4a_{i-2} - 2016 \implies (a_i - 672) = 4(a_{i-2} - 672)$$

Tulis $c_i = a_i - 672$, maka $c_{2k} = 4^k c_0$ dan $c_{2k+1} = 4^k c_1$. Karena $x_0, y_0, z_0$ bilangan asli berbeda yang berjumlah $2016 = 3 \times 672$, maka $a_0 \ge 673$ ($c_0 \ge 1$) dan $b_0 \le 671 \implies a_1 = 2016 - 2b_0 \ge 674$ ($c_1 \ge 2$).

Salah satu dari $(x_n, y_n, z_n)$ negatif jika dan hanya jika $b_n < 0 \iff 2016 - 2a_{n-1} < 0 \iff a_{n-1} \ge 1009 \iff c_{n-1} \ge 337$.

  • Untuk $n = 10$: $c_9 = 4^4 c_1 \ge 256 \times 2 = 512 > 337$ (dan $c_{10} \ge 4^5 \cdot 1 = 1024 > 337$), sehingga $n = 10$ pasti menghasilkan bilangan negatif!
  • Untuk $n = 9$ belum cukup: ambil $(x_0, y_0, z_0) = (671, 672, 673)$. Barisannya adalah $(674, 672, 670), (668, 672, 676), \dots, (416, 672, 928), (1184, 672, 160)$ pada jam ke-$9$, yang semuanya masih $\ge 0$ (dan baru menjadi negatif pada jam ke-$10$: $(-352, 672, 1696)$).
Jadi, bilangan asli $n$ terkecil adalah $10$.
No. 33
Misalkan $\{x_n\}$ adalah barisan bilangan bulat yang memenuhi $x_1 = x_2 = \dots = x_{12} = 0$, $x_{13} = 2$, dan untuk setiap bilangan asli $n$ berlaku $x_{n+13} = x_{n+4} + 2x_n$. Nilai $x_{143}$ adalah $\cdots$
Sumber: OSK SMA 2018 (No. 11)
Pembahasan:

Karena $x_{n+13} = x_{n+4} + 2x_n$, setiap suku tak nol bermula dari indeks $13$ dengan perpindahan indeks $+9$ (bobot $1$) atau $+13$ (bobot $2$). Agar mencapai $143 = 13 + 130$, kita butuh kombinasi $9p + 13q = 130$ dengan $p, q \ge 0$ bulat.

Persamaan $9p + 13q = 130 \implies 9p = 13(10 - q)$ memiliki dua solusi cacah: $(p, q) = (13, 1)$ (total $14$ langkah: $13$ kali $+9$ dan $1$ kali $+13$) dan $(p, q) = (0, 10)$ (total $10$ langkah: $10$ kali $+13$).

Dengan memperhatikan $x_{13} = 2$, banyaknya lintasan berbobot adalah:

$$x_{143} = 2 \cdot \left[\binom{14}{1} \cdot 1^{13} \cdot 2^1 + \binom{10}{10} \cdot 2^{10}\right] = 2\,(28 + 1024) = 2104$$
Jadi, nilai $x_{143}$ adalah $2104$.
No. 34
Barisan bilangan real $a_1, a_2, a_3, \dots$ memenuhi $$\frac{na_1 + (n - 1)a_2 + \cdots + 2a_{n-1} + a_n}{n^2} = 1$$ untuk setiap bilangan asli $n$. Nilai dari $a_1a_2a_3\cdots a_{2019}$ adalah $\cdots$
Sumber: OSP SMA 2019 (No. 8)
Pembahasan:

Misalkan $S_n = \sum_{k=1}^n (n + 1 - k)a_k = n^2$ dan $T_n = \sum_{k=1}^n a_k$. Untuk $n \ge 2$, $S_n - S_{n-1} = T_n$, sehingga:

$$T_n = n^2 - (n - 1)^2 = 2n - 1 \quad (n \ge 1)$$

Dengan demikian $a_1 = T_1 = 1$, dan untuk $n \ge 2$: $a_n = T_n - T_{n-1} = (2n - 1) - (2n - 3) = 2$.

$$a_1a_2\cdots a_{2019} = 1 \cdot 2^{2018} = 2^{2018}$$
Jadi, nilai dari $a_1a_2\cdots a_{2019}$ adalah $2^{2018}$.
No. 35
Suatu barisan bilangan real $a_1, a_2, a_3, \dots$ memenuhi $a_1 = 1$, $a_2 = \dfrac{3}{5}$ dan $$\frac{1}{a_n} = \frac{2}{a_{n-1}} - \frac{1}{a_{n-2}}$$ untuk setiap $n \ge 3$. Bilangan $a_{2020}$ dapat ditulis sebagai $\dfrac{p}{q}$ dengan $p$ dan $q$ bilangan asli relatif prima. Nilai $p + q$ adalah $\cdots$
Sumber: OSK SMA 2020 (No. 4)
Pembahasan:

Misalkan $b_n = \frac{1}{a_n}$. Relasi rekurensi menjadi $b_n - b_{n-1} = b_{n-1} - b_{n-2}$, sehingga $\{b_n\}$ adalah barisan aritmetika dengan $b_1 = 1$ dan $b_2 = \frac{5}{3}$ (beda $d = \frac{2}{3}$):

$$b_n = 1 + (n - 1)\frac{2}{3} = \frac{2n + 1}{3} \implies a_n = \frac{3}{2n + 1}$$

Untuk $n = 2020$:

$$a_{2020} = \frac{3}{4041} = \frac{1}{1347}$$

Maka $p = 1$, $q = 1347$, dan $p + q = 1348$.

Jadi, nilai $p + q$ adalah $1348$.
No. 36
Suatu barisan bilangan bulat $u_1, u_2, u_3, \dots$ memenuhi $$u_{n+1} - u_n = \begin{cases} 1, & \text{jika } n \text{ ganjil} \\ 2, & \text{jika } n \text{ genap} \end{cases}$$ Jika $u_1 + u_2 + \cdots + u_{20} = 360$, maka $u_1 = \cdots$
Sumber: OSP SMA 2020 (No. 7)
Pembahasan:

Kelompokkan suku berpasangan: $u_{2k-1} + u_{2k} = (u_1 + 3(k - 1)) + (u_1 + 3(k - 1) + 1) = 2u_1 + 6k - 5$ untuk $k = 1, \dots, 10$.

Jumlahkan untuk $k = 1, \dots, 10$:

$$\sum_{k=1}^{10} (2u_1 + 6k - 5) = 20u_1 + 6 \cdot 55 - 50 = 20u_1 + 280 = 360 \implies u_1 = 4$$
Jadi, nilai $u_1$ adalah $4$.
No. 37
Jika $$\sum_{k=1}^{\infty} \frac{2k + B}{3^{k+1}} = 20$$ maka $B$ adalah $\cdots$
Sumber: OSK SMA 2022 (No. 13)
Pembahasan:

Gunakan $\sum_{k=1}^\infty k x^{k-1} = \frac{1}{(1 - x)^2}$ dan $\sum_{k=1}^\infty x^{k-1} = \frac{1}{1 - x}$ pada $x = \frac{1}{3}$:

$$\sum_{k=1}^{\infty} \frac{2k + B}{3^{k+1}} = \frac{2}{9}\sum_{k=1}^{\infty} k\left(\frac{1}{3}\right)^{k-1} + \frac{B}{9}\sum_{k=1}^{\infty} \left(\frac{1}{3}\right)^{k-1} = \frac{2}{9}\left(\frac{3}{2}\right)^2 + \frac{B}{9}\left(\frac{3}{2}\right) = \frac{1}{2} + \frac{B}{6}$$ $$\frac{1}{2} + \frac{B}{6} = 20 \implies 3 + B = 120 \implies B = 117$$
Jadi, nilai $B$ adalah $117$.
No. 38
Definisikan barisan $\{a_n\}$ dengan $a_1 > 3$, dan untuk semua bilangan asli $n \ge 1$ berlaku $2a_{n+1} = a_n(-1 + \sqrt{4a_n - 3})$. Jika $|a_1 - a_{2022}| = 2023$, nilai dari $$\sum_{i=1}^{2023} \frac{a_i^3}{a_i^2 + a_i a_{i+1} + a_{i+1}^2} = \cdots$$
Sumber: OSP SMA 2022 (No. 10)
Pembahasan:

Tulis ulang relasi menjadi $2a_{n+1} + a_n = a_n\sqrt{4a_n - 3}$, lalu kuadratkan kedua ruas:

$$4a_{n+1}^2 + 4a_n a_{n+1} + a_n^2 = 4a_n^3 - 3a_n^2 \iff 4(a_n^2 + a_n a_{n+1} + a_{n+1}^2) = 4a_n^3$$ $$\implies \frac{a_n^3}{a_n^2 + a_n a_{n+1} + a_{n+1}^2} = 1 \quad \forall n \ge 1$$

Oleh karena itu, setiap suku pada deret tersebut bernilai $1$, dan jumlah $2023$ suku pertama adalah $2023$.

Jadi, nilai jumlah tersebut adalah $2023$.
No. 39
Sumber: OSK SMA 2023 (No. 13)

Barisan bilangan real $a_1, a_2, a_3, \dots$ memenuhi $a_1 = 1$, $a_2 = 2$, dan $a_{n+2} - a_{n+1} + a_n = \dfrac{n+1}{6}$ untuk setiap bilangan asli $n$. Nilai dari $a_{2023}$ adalah $\dots$

Pembahasan (Jawaban: $338$)

Tuliskan relasi rekurens untuk $n$ dan $n + 3$: $$a_{n+2} - a_{n+1} + a_n = \frac{n+1}{6}$$ $$a_{n+3} - a_{n+2} + a_{n+1} = \frac{n+2}{6}$$ Jumlahkan keduanya: $$a_{n+3} + a_n = \frac{2n + 3}{6}.$$ Ganti $n$ menjadi $n + 3$: $$a_{n+6} + a_{n+3} = \frac{2n + 9}{6}.$$ Kurangkan kedua persamaan terakhir: $$a_{n+6} - a_n = \frac{2n + 9}{6} - \frac{2n + 3}{6} = 1 \implies a_{n+6} = a_n + 1.$$ Karena $2023 = 6 \times 337 + 1$, maka: $$a_{2023} = a_1 + 337 = 1 + 337 = \mathbf{338}.$$
