Jika $\alpha, \beta$ dan $\gamma$ adalah akar-akar persamaan $x^3 - x - 1 = 0$, tentukan $$\frac{1 + \alpha}{1 - \alpha} + \frac{1 + \beta}{1 - \beta} + \frac{1 + \gamma}{1 - \gamma}$$
Sumber: OSP SMA 2005 (Bagian Kedua No. 3)
Pembahasan:

Misalkan $y = \dfrac{1 + x}{1 - x}$ (perhatikan $x = 1$ bukan akar karena $1^3 - 1 - 1 = -1 \ne 0$). Nyatakan $x$ dalam $y$:

$$y - xy = 1 + x \implies x(y + 1) = y - 1 \implies x = \frac{y - 1}{y + 1}$$

Substitusikan ke persamaan kubik $x^3 - x - 1 = 0$ lalu kalikan kedua ruas dengan $(y + 1)^3$:

$$(y - 1)^3 - (y - 1)(y + 1)^2 - (y + 1)^3 = 0$$ $$(y^3 - 3y^2 + 3y - 1) - (y^3 + y^2 - y - 1) - (y^3 + 3y^2 + 3y + 1) = 0$$ $$-y^3 - 7y^2 + y - 1 = 0 \iff y^3 + 7y^2 - y + 1 = 0$$

Akar-akar persamaan baru dalam $y$ ini adalah $y_1 = \dfrac{1+\alpha}{1-\alpha}$, $y_2 = \dfrac{1+\beta}{1-\beta}$, dan $y_3 = \dfrac{1+\gamma}{1-\gamma}$. Berdasarkan Teorema Vieta:

$$y_1 + y_2 + y_3 = -\frac{7}{1} = -7$$
Jadi, nilai dari $\dfrac{1 + \alpha}{1 - \alpha} + \dfrac{1 + \beta}{1 - \beta} + \dfrac{1 + \gamma}{1 - \gamma}$ adalah $-7$.
Jika $a$ dan $b$ adalah bilangan-bilangan bulat dan $x^2 - x - 1$ merupakan faktor dari $ax^3 + bx^2 + 1$, maka $b =$ $\cdots$
Sumber: OSK SMA 2008 (Bagian Kedua No. 17)
Pembahasan:

Karena $x^2 - x - 1$ membagi habis $ax^3 + bx^2 + 1$, dengan membandingkan koefisien $x^3$ (yaitu $a$) dan konstanta (yaitu $1$), hasil baginya harus berbentuk $(ax - 1)$:

$$ax^3 + bx^2 + 1 = (x^2 - x - 1)(ax - 1) = ax^3 - (a + 1)x^2 + (1 - a)x + 1$$

Samakan koefisien $x$ dan $x^2$ pada kedua ruas:

  • Koefisien $x$: $1 - a = 0 \implies a = 1$.
  • Koefisien $x^2$: $b = -(a + 1) = -(1 + 1) = -2$.
Jadi, nilai $b$ yang memenuhi adalah $-2$.
Misalkan $a, b, c$ dan $d$ bilangan rasional. Jika diketahui persamaan $x^4 + ax^3 + bx^2 + cx + d = 0$ mempunyai $4$ akar real, dua di antaranya adalah $\sqrt{2}$ dan $\sqrt{2008}$. Nilai dari $a + b + c + d$ adalah $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 11)
Pembahasan:

Karena $a, b, c, d \in \mathbb{Q}$, substitusi $x = \sqrt{2}$ dan $x = \sqrt{2008} = 2\sqrt{502}$ ke persamaan memberi:

  • $(2a + c)\sqrt{2} = -(2b + d + 4) \implies 2a + c = 0$ dan $2b + d + 4 = 0$.
  • $(2008a + c)\sqrt{2008} = -(2008b + d + 2008^2) \implies 2008a + c = 0$ dan $2008b + d + 2008^2 = 0$.

Dari $2a + c = 0$ dan $2008a + c = 0$ didapat $a = 0, c = 0$. Dari $2b + d = -4$ dan $2008b + d = -2008^2$ diperoleh $2006b = 4 - 2008^2 = -2006 \cdot 2010 \implies b = -2010$, dan $d = -4 - 2(-2010) = 4016$.

Jadi, nilai dari $a + b + c + d$ adalah $2006$.
Suatu polinom $f(x)$ memenuhi persamaan $f(x^2) - x^3 f(x) = 2(x^3 - 1)$ untuk setiap $x$ bilangan real. Derajat (pangkat tertinggi $x$) $f(x)$ adalah $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 15)
Pembahasan:

Misalkan $f(x)$ berderajat $n \ge 0$. Maka $f(x^2)$ berderajat $2n$ dan $x^3 f(x)$ berderajat $n + 3$.

  • Jika $n > 3$: maka $2n > n + 3$, sehingga $f(x^2) - x^3 f(x)$ berderajat $2n > 6$ (kontradiksi dengan ruas kanan berderajat $3$).
  • Jika $n = 3$: kedua suku berderajat $6$ dapat saling menghapuskan suku tertinggi. Misalnya $f(x) = x^3 - 2$ memberikan $(x^6 - 2) - x^3(x^3 - 2) = 2(x^3 - 1)$, sehingga $n = 3$ memenuhi.
  • Jika $n < 3$: maka $n + 3 = 3 \implies n = 0$ ($f(x) = c$), yang memberi $c - cx^3 = 2x^3 - 2 \implies c = -2$, sehingga $f(x) = -2$ juga memenuhi.
Jadi, derajat $f(x)$ yang memenuhi adalah $3$ (untuk $f(x) = x^3 - 2$) atau $0$ (untuk $f(x) = -2$).
Diberikan polinom real $P(x) = x^{2008} + a_1 x^{2007} + a_2 x^{2006} + \dots + a_{2007} x + a_{2008}$ dan $Q(x) = x^2 + 2x + 2008$. Misalkan persamaan $P(x) = 0$ mempunyai $2008$ selesaian real dan $P(2008) \le 1$. Tunjukkan bahwa persamaan $P(Q(x)) = 0$ mempunyai selesaian real.
Sumber: OSP SMA 2008 (Bagian Kedua No. 2)
Pembahasan:

Karena $P(x)$ berderajat $2008$, koefisien utamanya $1$, dan memiliki $2008$ akar real $x_1, x_2, \dots, x_{2008}$, maka $P(x) = \displaystyle\prod_{i=1}^{2008} (x - x_i)$.

Perhatikan bahwa $Q(x) = (x + 1)^2 + 2007$, sehingga $Q(x) = x_i$ memiliki selesaian real jika dan hanya jika ada minimal satu akar $x_k \ge 2007$.

Andaikan semua akar $x_i < 2007$ untuk $i = 1, \dots, 2008$. Maka $2008 - x_i > 1$ untuk setiap $i$, sehingga:

$$P(2008) = \prod_{i=1}^{2008} (2008 - x_i) > 1^{2008} = 1$$

Kontradiksi dengan $P(2008) \le 1$. Maka pasti ada sedikitnya satu akar $x_k \ge 2007$, yang membuat $Q(x) = x_k$ memiliki selesaian real.

Terbukti bahwa persamaan $P(Q(x)) = 0$ mempunyai selesaian real. $\blacksquare$
