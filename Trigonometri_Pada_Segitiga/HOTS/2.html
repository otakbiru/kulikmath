Pada $\triangle ABC$, titik $D$ terletak pada garis $BC$. Panjang $BC = 3$, besar sudut $\angle ABC = 30^\circ$, dan $\angle ADC = 45^\circ$. Panjang $AC = \cdots$
Sumber: OSP SMA 2012 (No. 12)
Pembahasan:

Misalkan $BD = x$ ($0 < x < 3$), sehingga $DC = 3 - x$. Karena $\angle ADC = 45^\circ$, maka $\angle ADB = 135^\circ$ dan $\angle BAD = 15^\circ$. Dengan Aturan Sinus pada $\triangle ABD$, $AD = \dfrac{x\sin 30^\circ}{\sin 15^\circ} = \dfrac{x}{2\sin 15^\circ}$.

Pada $\triangle ACD$, $AC^2 = AD^2 + (3 - x)^2 - 2\cdot AD\cdot (3 - x)\cos 45^\circ$ masih bergantung pada $x$, sehingga panjang $AC$ belum dapat ditentukan secara tunggal.

Jadi, panjang $AC$ belum dapat ditentukan secara tunggal dari informasi pada soal.
No. 12
Misalkan $M$ adalah titik tengah sisi $BC$ pada segitiga $\triangle ABC$ dan $\angle CAB = 45^\circ$, $\angle ABC = 30^\circ$, maka $\tan\angle AMC$ adalah $\cdots$
Sumber: OSP SMA 2013
Pembahasan:

Misalkan $BC = 2a$ (sehingga $BM = MC = a$) dan $AC = 2b$. Pada $\triangle ABC$, $\angle ACB = 180^\circ - 45^\circ - 30^\circ = 105^\circ$, dan dengan Aturan Sinus:

$$\frac{2a}{2b} = \frac{\sin 45^\circ}{\sin 30^\circ} = \sqrt{2} \implies \frac{a}{b} = \sqrt{2}$$

Misalkan $\angle AMC = y$, maka $\angle CAM = 180^\circ - 105^\circ - y = 75^\circ - y$. Dengan Aturan Sinus pada $\triangle AMC$:

$$\frac{a}{2b} = \frac{\sin(75^\circ - y)}{\sin y} \implies \frac{\sqrt{2}}{2}\sin y = \sin 75^\circ \cos y - \cos 75^\circ \sin y$$ $$\tan y = \frac{\sin y}{\cos y} = \frac{\sin 75^\circ}{\frac{\sqrt{2}}{2} + \cos 75^\circ} = \frac{\frac{\sqrt{6} + \sqrt{2}}{4}}{\frac{2\sqrt{2} + \sqrt{6} - \sqrt{2}}{4}} = \frac{\sqrt{6} + \sqrt{2}}{\sqrt{6} + \sqrt{2}} = 1$$
Jadi, nilai $\tan\angle AMC$ adalah $1$.
No. 13
Panjang sisi-sisi segitiga merupakan bilangan bulat berurutan, dan sudut terbesar dua kali sudut terkecil. Nilai cosinus sudut terkecil adalah $\cdots$
Sumber: OSP SMA 2015 (No. 8)
Pembahasan:

Misalkan sisi-sisinya $n - 1, n, n + 1$ ($n \ge 3$), sudut terkecil $\alpha$, dan sudut terbesar $2\alpha$. Dengan Aturan Sinus:

$$\frac{n + 1}{\sin 2\alpha} = \frac{n - 1}{\sin\alpha} \implies \cos\alpha = \frac{n + 1}{2(n - 1)}$$

Dengan Aturan Cosinus untuk sudut $\alpha$:

$$(n - 1)^2 = n^2 + (n + 1)^2 - 2n(n + 1)\left(\frac{n + 1}{2(n - 1)}\right) \implies (n + 1)^2 = (n + 4)(n - 1) \implies n = 5$$

Jadi segitiga bersisi $4, 5, 6$ dan $\cos\alpha = \dfrac{5 + 1}{2(5 - 1)} = \dfrac{3}{4}$.

Jadi, nilai cosinus sudut terkecil adalah $\dfrac{3}{4}$.
No. 14
Diberikan segitiga sama kaki $ABC$, dengan $AB = AC = b$, $BC = a$, dan $\angle BAC = 100^\circ$. Jika $BL$ garis bagi $\angle ABC$, maka nilai $AL + BL$ adalah $\cdots$
Sumber: OSP SMA 2015 (No. 20)
Pembahasan:

Karena $\triangle ABC$ sama kaki dengan $\angle A = 100^\circ$, maka $\angle B = \angle C = 40^\circ$, $\angle ABL = 20^\circ$, dan $\angle ALB = 60^\circ$. Dengan Aturan Sinus pada $\triangle ABC$ dan $\triangle ABL$:

$$b = \frac{a \sin 40^\circ}{\sin 100^\circ} = \frac{a \sin 40^\circ}{\cos 10^\circ}, \qquad AL = \frac{b \sin 20^\circ}{\sin 60^\circ}, \qquad BL = \frac{b \sin 100^\circ}{\sin 60^\circ}$$

Jumlahkan $AL + BL$ menggunakan identitas $\sin 20^\circ + \sin 100^\circ = 2\sin 60^\circ \cos 40^\circ$:

$$AL + BL = \frac{b(\sin 20^\circ + \sin 100^\circ)}{\sin 60^\circ} = 2b\cos 40^\circ = \frac{a \cdot 2\sin 40^\circ \cos 40^\circ}{\cos 10^\circ} = \frac{a\sin 80^\circ}{\cos 10^\circ} = a$$
Jadi, nilai $AL + BL$ adalah $a$.
