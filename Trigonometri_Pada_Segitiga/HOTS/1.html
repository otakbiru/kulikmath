Pada suatu $\triangle ABC$, besar sudut $C$ tiga kali besar sudut $A$ dan besar sudut $B$ dua kali besar sudut $A$. Berapakah perbandingan (rasio) antara panjang $AB$ dengan $BC$?
Sumber: OSK SMA 2002
Pembahasan:
Jumlah sudut dalam $\triangle ABC$ adalah $180^\circ$. Diketahui $\angle B = 2\angle A$ dan $\angle C = 3\angle A$, maka: $$\begin{aligned} \angle A + \angle B + \angle C &= 180^\circ\\ \angle A + 2\angle A + 3\angle A &= 180^\circ\\ 6\angle A &= 180^\circ\\ \angle A &= 30^\circ \end{aligned}$$ Sehingga besar sudut $C$ adalah: $$\begin{aligned} \angle C &= 3\angle A = 3(30^\circ) = 90^\circ \end{aligned}$$
Dengan menggunakan aturan sinus pada $\triangle ABC$: $$\begin{aligned} \frac{AB}{\sin \angle C} &= \frac{BC}{\sin \angle A}\\[4pt] \frac{AB}{\sin 90^\circ} &= \frac{BC}{\sin 30^\circ}\\[4pt] \frac{AB}{1} &= \frac{BC}{\frac{1}{2}}\\[4pt] \frac{AB}{BC} &= \frac{2}{1} \end{aligned}$$
Jadi, perbandingan (rasio) antara panjang $AB$ dengan $BC$ adalah $2 : 1$.

Sumber: matematikaidhamdaz
Pembahasan:
Dari segitiga siku-siku $\triangle ABD$ dan $\triangle ABC$, diperoleh: $$\tan \theta = \frac{x}{3} \quad \text{dan} \quad \tan(\theta + 45^\circ) = \frac{x + 5}{3}$$ Gunakan rumus jumlah tangen dua sudut: $$\begin{aligned} \tan\left(\theta + 45^\circ\right) &= \frac{\tan\theta + \tan 45^\circ}{1 - \tan\theta\tan 45^\circ}\\[4pt] \frac{x + 5}{3} &= \frac{\frac{x}{3} + 1}{1 - \frac{x}{3}\cdot 1}\\[4pt] \frac{x + 5}{3} &= \frac{x + 3}{3 - x}\\[4pt] (x + 5)(3 - x) &= 3(x + 3)\\ 3x - x^2 + 15 - 5x &= 3x + 9\\ x^2 + 5x - 6 &= 0\\ (x - 1)(x + 6) &= 0 \end{aligned}$$ Diperoleh $x = 1$ atau $x = -6$ (tidak memenuhi karena panjang sisi bernilai positif).
Jadi, nilai $x$ yang memenuhi adalah $x = 1$.
Diberikan segitiga $ABC$ siku-siku di $A$, titik $D$ pada $AC$ dan titik $F$ pada $BC$. Jika $AF \perp BC$ dan $BD = DC = FC = 1$, maka $AC = \cdots$
Sumber: OSP SMA 2007 (Bagian 1 • No. 18)
Pembahasan:

Misalkan $AC = x$ dan $\angle C = \theta$. Karena $DC = 1$, maka $AD = x - 1$.

Pada segitiga siku-siku $AFC$ (siku-siku di $F$):

$$\cos\theta = \frac{FC}{AC} = \frac{1}{x}$$

Karena $BD = DC = 1$, segitiga $BDC$ sama kaki sehingga $\angle DBC = \angle C = \theta$. Akibatnya sudut luar $\angle BDA = \angle DBC + \angle C = 2\theta$.

Pada segitiga siku-siku $BAD$ (siku-siku di $A$):

$$\cos 2\theta = \frac{AD}{BD} = \frac{x - 1}{1} = x - 1$$

Gunakan identitas $\cos 2\theta = 2\cos^2\theta - 1$:

$$2\left(\frac{1}{x}\right)^2 - 1 = x - 1 \implies \frac{2}{x^2} = x \implies x^3 = 2 \implies x = \sqrt[3]{2}$$
Jadi, panjang $AC$ adalah $\sqrt[3]{2}$.
Keliling suatu segitiga adalah $5$ dan jumlah kuadrat sisi-sisinya adalah $17$. Jika jari-jari lingkaran luar segitiga itu adalah $2$, maka jumlah ketiga tinggi segitiga itu adalah $\cdots$
Sumber: OSK SMA 2011 (No. 7)
Pembahasan:

Misalkan panjang sisi-sisi segitiga adalah $a, b, c$. Diketahui $a + b + c = 5$, $a^2 + b^2 + c^2 = 17$, dan $R = 2$.

Dari identitas $(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + bc + ca)$ diperoleh:

$$25 = 17 + 2(ab + bc + ca) \implies ab + bc + ca = 4$$

Dengan Aturan Sinus, $\sin A = \dfrac{a}{2R} = \dfrac{a}{4}$, $\sin B = \dfrac{b}{4}$, dan $\sin C = \dfrac{c}{4}$.

Tinggi terhadap sisi $a, b, c$ masing-masing adalah $t_a = b\sin C$, $t_b = c\sin A$, dan $t_c = a\sin B$. Maka jumlah ketiga tinggi segitiga tersebut adalah:

$$t_a + t_b + t_c = b \cdot \frac{c}{4} + c \cdot \frac{a}{4} + a \cdot \frac{b}{4} = \frac{ab + bc + ca}{4} = \frac{4}{4} = 1$$
Jadi, jumlah ketiga tinggi segitiga itu adalah $1$.
Pada suatu segitiga $ABC$, sudut $C$ tiga kali besar sudut $A$ dan sudut $B$ dua kali besar sudut $A$. Berapakah perbandingan (rasio) antara panjang $AB$ dengan $BC$?
Sumber: OSK SMA 2002 (No. 11)
Pembahasan:

Dari $\angle A + \angle B + \angle C = 180^\circ$ diperoleh $\angle A + 2\angle A + 3\angle A = 6\angle A = 180^\circ$, sehingga $\angle A = 30^\circ$, $\angle B = 60^\circ$, dan $\angle C = 90^\circ$.

Dengan Aturan Sinus (atau perbandingan segitiga siku-siku $30^\circ$-$60^\circ$-$90^\circ$):

$$\frac{AB}{BC} = \frac{\sin\angle C}{\sin\angle A} = \frac{\sin 90^\circ}{\sin 30^\circ} = \frac{1}{\frac{1}{2}} = 2$$
Jadi, rasio $AB : BC$ adalah $2$ (atau $2 : 1$).
Diberikan segitiga $ABC$ dengan sisi-sisi $a, b,$ dan $c$. Nilai $a^2 + b^2 + c^2$ sama dengan $16$ kali luas segitiga $ABC$. Besarnya nilai $\text{ctg }A + \text{ctg }B + \text{ctg }C$ adalah $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 12)
Pembahasan:

Dengan Aturan Cosinus dan rumus luas $[\triangle ABC] = \dfrac{1}{2}bc\sin A$, diperoleh:

$$\text{ctg }A = \frac{\cos A}{\sin A} = \frac{\frac{b^2 + c^2 - a^2}{2bc}}{\frac{2[\triangle ABC]}{bc}} = \frac{b^2 + c^2 - a^2}{4[\triangle ABC]}$$

Secara analog, $\text{ctg }B = \dfrac{a^2 + c^2 - b^2}{4[\triangle ABC]}$ dan $\text{ctg }C = \dfrac{a^2 + b^2 - c^2}{4[\triangle ABC]}$. Jumlahkan ketiganya:

$$\text{ctg }A + \text{ctg }B + \text{ctg }C = \frac{a^2 + b^2 + c^2}{4[\triangle ABC]} = \frac{16[\triangle ABC]}{4[\triangle ABC]} = 4$$
Jadi, nilai $\text{ctg }A + \text{ctg }B + \text{ctg }C$ adalah $4$.
