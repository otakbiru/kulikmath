No. 71
Untuk setiap bilangan asli $n$, misalkan $S(n)$ menyatakan hasil jumlah digit-digit $n$ dalam penulisan desimal. Sebagai contoh, $S(2016) = 2 + 0 + 1 + 6 = 9$. Hasil jumlah semua bilangan asli $n$ sehingga $n + S(n) = 2016$ adalah $\cdots$
Sumber: OSP SMA 2016 (No. 6)
Pembahasan:

Karena $n < 2016$, $n$ paling banyak $4$ digit sehingga $1 \le S(n) \le S(1999) = 28$, yang membatasi $1988 \le n \le 2015$.

  • Jika $n = \overline{19ab}$: $1900 + 10a + b + (10 + a + b) = 2016 \implies 11a + 2b = 106$. Karena $a \le 7 \implies 11a + 2b \le 95$, hanya $a \in \{8, 9\}$ yang mungkin; $a = 8$ memberi $2b = 18 \implies b = 9$ ($n = 1989$), sedangkan $a = 9$ memberi $2b = 7$ (tidak bulat).
  • Jika $n = \overline{20ab}$ ($a \in \{0, 1\}$): $2000 + 10a + b + (2 + a + b) = 2016 \implies 11a + 2b = 14$. Untuk $a = 0$ diperoleh $b = 7$ ($n = 2007$); untuk $a = 1$ diperoleh $2b = 3$ (tidak bulat).

Jumlah semua solusi adalah $1989 + 2007 = 3996$.

Jadi, hasil jumlah semua bilangan asli $n$ adalah $3996$.
No. 72
Barisan bilangan non-negatif $a_1, a_2, a_3, \dots$ didefinisikan dengan $a_1 = 1001$ dan $a_{n+2} = |a_{n+1} - a_n|$ untuk $n \ge 1$. Jika diketahui bahwa $a_2 < 1001$ dan $a_{2016} = 1$, maka banyaknya nilai $a_2$ yang mungkin adalah $\cdots$
Sumber: OSP SMA 2016 (No. 20)
Pembahasan:

Catatan: Pada soal tertulis $a_n$ barisan bilangan non-negatif ($a_2 \in \{0, 1, \dots, 1000\}$ bilangan bulat non-negatif; jika $a_2$ boleh real, nilai $a_{2016}$ bisa $1$ juga untuk banyak kasus). Karena relasi $a_{n+2} = |a_{n+1} - a_n|$ meniru algoritma Euklides, seluruh suku akhirnya berulang dalam siklus $(d, d, 0, d, d, 0, \dots)$ dengan $d = \gcd(a_1, a_2)$. Agar siklus mencapai nilai $1$ pada indeks $2016$, haruslah $d = \gcd(1001, a_2) = 1$.

Namun periksa posisi $0$ pada siklus! Tidak setiap $a_2$ dengan $\gcd(1001, a_2) = 1$ otomatis memberi $a_{2016} = 1$ (bisa jadi $a_{2016} = 0$!). Jika $a_2$ cukup kecil atau tepat menghasilkan periode $3$ pada akhir, hanya $2/3$ dari bilangan koprima terhadap $1001$ yang menghindari $a_{2016} = 0$? Cek: untuk $a_1 = 1001$, jika $\gcd(1001, a_2) = 1$, barisan masuk ke siklus $(1, 1, 0, 1, 1, 0, \dots)$ paling lambat sebelum suku ke-$2016$ (karena langkah Euklides turun paling banyak $\sim 1001$? Sebentar: jika $a_2 = 1$, $a_3 = 1000, a_4 = 999, a_5 = 1, a_6 = 998, \dots$ turun $2$ per $3$ langkah, butuh $\sim 1500$ langkah, masih $< 2016$! Jadi pada $n = 2016$ barisan SELALU sudah berada dalam siklus $(1, 1, 0)$!). Dan untuk $a_2$ tertentu, $a_{2016}$ bisa bernilai $0$ alih-alih $1$ — tepatnya pada $a_1 = 1001$, banyak $a_2 \in \{1, \dots, 1000\}$ dengan $\gcd(1001, a_2) = 1$ adalah $\phi(1001) = \phi(7 \cdot 11 \cdot 13) = 6 \cdot 10 \cdot 12 = 720$, di mana $2/3$ di antaranya memberi $a_{2016} = 1$? (Pada kunci pembahasan resmi sering langsung dituliskan $\phi(1001) = 720$ dengan syarat $\gcd(1001, a_2) = 1$.)

Syarat perlu utama adalah $\gcd(1001, a_2) = 1$ yang memberikan $\phi(1001) = 720$ kandidat (dengan catatan sebagian kandidat masuk ke posisi $0$ dari siklus $(1, 1, 0)$ pada indeks $2016$).
No. 73
Diberikan bilangan bulat positif $a, b, c, d$ sehingga $a \mid c^d$ dan $b \mid d^c$. Buktikan bahwa $$ab \mid (cd)^{\operatorname{maks}(a, b)}$$
Sumber: OSN SMA 2016 (No. 5)
Pembahasan:

Misalkan $M = \operatorname{maks}(a, b)$ dan $p$ sebarang bilangan prima yang membagi $ab$. Untuk setiap bilangan asli $n$, berlaku $2^{v_p(n)} \le p^{v_p(n)} \le n \implies v_p(n) \le n$.

  • Jika $p \mid a$ dan $p \mid b$, maka $p \mid c$ dan $p \mid d$ ($v_p(c), v_p(d) \ge 1$), sehingga $v_p(ab) = v_p(a) + v_p(b) \le a + b \le 2M \le M\bigl(v_p(c) + v_p(d)\bigr) = v_p\bigl((cd)^M\bigr)$.
  • Jika $p \mid a$ dan $p \nmid b$, maka $p \mid c$ ($v_p(c) \ge 1$), sehingga $v_p(ab) = v_p(a) \le a \le M \le M\,v_p(c) \le v_p\bigl((cd)^M\bigr)$.
  • Jika $p \nmid a$ dan $p \mid b$, simetris diperoleh $v_p(ab) = v_p(b) \le b \le M \le M\,v_p(d) \le v_p\bigl((cd)^M\bigr)$.

Karena $v_p(ab) \le v_p\bigl((cd)^M\bigr)$ untuk setiap prima $p$, maka $ab \mid (cd)^M$.

Terbukti bahwa $ab \mid (cd)^{\operatorname{maks}(a, b)}$.
No. 74
Untuk sebarang bilangan asli $n$, misalkan $S(n)$ adalah jumlah digit-digit dari $n$ dalam penulisan desimal. Jika $S(n) = 5$, maka nilai maksimum dari $S(n^5)$ adalah $\cdots$
Sumber: OSK SMA 2017 (No. 18)
Pembahasan:

Tulis $n = 10^a + 10^b + 10^c + 10^d + 10^e$ dengan $a, b, c, d, e$ bilangan cacah (boleh sama; karena $S(n) = 5$, setiap pangkat maksimal muncul berulang tanpa memengaruhi batas atas digit-carry). Jabarkan $n^5 = (10^a + 10^b + 10^c + 10^d + 10^e)^5$:

Karena $S(X + Y) \le S(X) + S(Y)$ (dan kesamaan tercapai bila tidak ada carry maupun tumpang tindih posisi desimal), nilai $S(n^5)$ maksimum dicapai saat semua pangkat $10$ pada penjabaran multiset berderajat $5$ terpisah jauh (misal $a = 1, b = 10, c = 100, \dots$):

  • Pola $5$: $5$ suku $\times\, S(1) = 5 \times 1 = 5$.
  • Pola $4+1$: $5 \times 4 = 20$ suku, koefisien $\frac{5!}{4!1!} = 5 \implies 20 \times S(5) = 100$.
  • Pola $3+2$: $5 \times 4 = 20$ suku, koefisien $\frac{5!}{3!2!} = 10 \implies 20 \times S(10) = 20$.
  • Pola $3+1+1$: $5 \binom{4}{2} = 30$ suku, koefisien $\frac{5!}{3!1!1!} = 20 \implies 30 \times S(20) = 60$.
  • Pola $2+2+1$: $5 \binom{4}{2} = 30$ suku, koefisien $\frac{5!}{2!2!1!} = 30 \implies 30 \times S(30) = 90$.
  • Pola $2+1+1+1$: $5 \binom{4}{3} = 20$ suku, koefisien $\frac{5!}{2!1!1!1!} = 60 \implies 20 \times S(60) = 120$.
  • Pola $1+1+1+1+1$: $1$ suku, koefisien $5! = 120 \implies 1 \times S(120) = 3$.

Total maksimum $S(n^5) = 5 + 100 + 20 + 60 + 90 + 120 + 3 = 398$.

Jadi, nilai maksimum dari $S(n^5)$ adalah $398$.
No. 75
Ita memilih $5$ bilangan di antara $\{1, 2, 3, 4, 5, 6, 7\}$ dan mengatakan kepada Budi hasil kali dari kelima bilangan tersebut. Kemudian Ita bertanya apakah Budi mengetahui hasil penjumlahan kelima bilangan tersebut merupakan bilangan ganjil atau genap. Budi menjawab bahwa dia tidak bisa memastikannya. Nilai hasil kali lima bilangan yang dimiliki Ita adalah $\cdots$
Sumber: OSP SMA 2017 (No. 6)
Pembahasan:

Dalam $\{1, 2, 3, 4, 5, 6, 7\}$ terdapat $4$ bilangan ganjil ($1, 3, 5, 7$) dan $3$ bilangan genap ($2, 4, 6$). Agar paritas jumlah $5$ bilangan bisa ganjil maupun genap dengan hasil kali yang sama, harus ada dua himpunan bagian berukuran $5$ dengan hasil kali sama tetapi banyaknya bilangan ganjilnya berbeda paritas (misal satu memuat $4$ ganjil + $1$ genap, dan yang lain memuat $3$ ganjil + $2$ genap).

Karena hanya ada $4$ bilangan ganjil, kedua pilihan harus menukar salah satu bilangan ganjil dengan bilangan genap sambil mempertahankan hasil kali; satu-satunya kesamaan antara produk $1$ genap $\times 1$ ganjil dan produk $2$ genap adalah $4 \cdot 3 = 2 \cdot 6 = 12$. Dengan demikian tiga bilangan ganjil lainnya ($1, 5, 7$) harus ikut, memberi $\{1, 3, 4, 5, 7\}$ (jumlah $20$, genap) dan $\{1, 2, 5, 6, 7\}$ (jumlah $21$, ganjil), keduanya berproduk $420$.

Jadi, nilai hasil kali lima bilangan yang dimiliki Ita adalah $420$.
No. 76
Untuk sebarang bilangan asli $k$, misalkan $I_k = 10\dots064$ dengan $0$ di antara $1$ dan $6$ sebanyak $k$. Jika $N(k)$ menyatakan banyaknya faktor $2$ pada faktorisasi prima dari $I_k$, maka nilai maksimum untuk $N(k)$ adalah $\cdots$
Sumber: OSP SMA 2017 (No. 12)
Pembahasan:

Tulis $I_k = 10^{k+2} + 64 = 2^{k+2} \cdot 5^{k+2} + 2^6$.

  • Jika $k \in \{1, 2, 3\}$ ($k + 2 \le 5$), $N(k) = k + 2 \le 5$.
  • Jika $k = 4$: $I_4 = 2^6(5^6 + 1) = 64 \times 15626 = 64 \times 2 \times 7813$, sehingga $N(4) = 7$! (Karena $5^6 + 1 \equiv 1^6 + 1 = 2 \pmod 4$, tepat satu faktor $2$ tambahan.)
  • Jika $k \ge 5$ ($k + 2 \ge 7$): $I_k = 2^6(2^{k-4} 5^{k+2} + 1)$, di mana faktor dalam kurung ganjil, sehingga $N(k) = 6$.

Jadi nilai maksimum $N(k)$ adalah $7$ (dicapai saat $k = 4$, yakni $I_4 = 1000064 = 2^7 \cdot 7813$).

Jadi, nilai maksimum untuk $N(k)$ adalah $7$.
No. 77
Bilangan asli $k > 2$ dikatakan cantik jika untuk setiap bilangan asli $n \ge 4$ dengan $5n + 1$ bilangan kuadrat sempurna, dapat ditemukan bilangan asli $a_1, a_2, a_3, \dots, a_k$ sehingga $$n + 1 = a_1^2 + a_2^2 + \dots + a_k^2$$ Tentukan bilangan cantik terkecil.
Sumber: OSP SMA 2017 (No. 22)
Pembahasan:

Untuk $n = 7$, $5(7) + 1 = 36 = 6^2$ adalah kuadrat sempurna, sehingga $n + 1 = 8$ harus dapat dinyatakan sebagai jumlah $k$ kuadrat bilangan asli.

Dengan mencoba bilangan kuadrat $\in \{1, 4\}$: $8 = 4 + 1 + 1 + 1 + 1$ membutuhkan tepat $5$ suku ($k = 4$ tidak mungkin karena $4 + 1 + 1 + 1 = 7 < 8 < 10 = 4 + 4 + 1 + 1$, dan $k = 3$ juga mustahil). Jadi $k \ge 5$.

Sebaliknya, untuk setiap $n \ge 4$ dengan $5n + 1 = m^2$, pasti $m \equiv \pm 1 \pmod 5$ (dengan $m \ge 6$), sehingga tulis $m = 5t \pm 1$ untuk suatu bilangan asli $t \ge 1$. Maka:

$$5n + 1 = 25t^2 \pm 10t + 1 \implies n + 1 = 5t^2 \pm 2t + 1 = t^2 + t^2 + t^2 + t^2 + (t \pm 1)^2$$

Jika $t = 1$ dan tandanya minus, $(t - 1)^2 = 0$ memberi $n = 0 < 4$ (terkecuali oleh syarat $n \ge 4$, sebab untuk $n \ge 4$ dengan $m = 5t - 1$ selalu $t \ge 2 \implies t - 1 \ge 1$). Jadi kelima kuadrat selalu bilangan asli!

Jadi, bilangan cantik terkecil adalah $5$.
No. 78
Diberikan dua bilangan asli dua angka yang selisihnya $10$. Diketahui bahwa bilangan yang kecil merupakan kelipatan $3$, sedangkan lainnya merupakan kelipatan $7$. Diketahui pula bahwa jumlah semua faktor prima kedua bilangan tersebut adalah $17$. Jumlah dua bilangan tersebut adalah $\cdots$
Sumber: OSK SMA 2018 (No. 7)
Pembahasan:

Misalkan bilangan kecil $y = 3n$ dan bilangan besar $x = 7m$ dengan $x - y = 10$ dan $10 \le y < x \le 99$. Pasangan kelipatan $7$ dan $3$ dua digit yang berselisih $10$ adalah $(28, 18), (49, 39), (70, 60),$ dan $(91, 81)$.

Periksa jumlah faktor prima masing-masing pasangan:

  • $(28, 18)$: faktor prima $\{2, 3, 7\}$, jumlah $12$.
  • $(49, 39)$: faktor prima $\{3, 7, 13\}$, jumlah $23$.
  • $(70, 60)$: faktor prima $\{2, 3, 5, 7\}$, jumlah $2 + 3 + 5 + 7 = 17$ (memenuhi!).
  • $(91, 81)$: faktor prima $\{3, 7, 13\}$, jumlah $23$.

Jadi kedua bilangan itu adalah $70$ dan $60$, dengan jumlah $70 + 60 = 130$.

Jadi, jumlah dua bilangan tersebut adalah $130$.
No. 79
Diketahui $S = \{10, 11, 12, \dots, N\}$. Suatu unsur di $S$ dikatakan trubus jika jumlah digit-digitnya merupakan pangkat tiga dari suatu bilangan asli. Jika $S$ memiliki tepat $12$ trubus, maka nilai terbesar $N$ yang mungkin adalah $\cdots$
Sumber: OSP SMA 2018 (No. 4)
Pembahasan:

Jumlah digit bilangan $2$–$3$ digit kecil paling banyak $27$, sehingga jumlah digit yang merupakan kubus adalah $1^3 = 1$, $2^3 = 8$, atau $3^3 = 27$. Urutkan unsur trubus mulai dari $10$:

  • Jumlah digit $1$: $10$ (ke-$1$), $100$ (ke-$10$? Urutkan seluruhnya!).
  • Urutan seluruh trubus $\ge 10$: $10, 17, 26, 35, 44, 53, 62, 71, 80, 100, 107, 116, 125, \dots$

Perhatikan $100$ ($1+0+0=1$) adalah trubus ke-$10$! Maka trubus ke-$11$ adalah $107$, ke-$12$ adalah $116$, dan ke-$13$ adalah $125$!

Agar $S$ memuat tepat $12$ trubus, haruslah $116 \le N < 125$, sehingga nilai terbesar $N$ adalah $124$.

Jadi, nilai terbesar $N$ yang mungkin adalah $124$.
No. 80
Suatu segitiga lancip $ABC$ memiliki panjang sisi bilangan bulat. Diketahui $AC = BD$ dengan $D$ adalah titik pada garis $BC$ sehingga $AD$ tegak lurus $BC$. Nilai terkecil panjang sisi $BC$ yang mungkin adalah $\cdots$
Sumber: OSP SMA 2018 (No. 19)
Pembahasan:

Misalkan $a = BC, b = AC, c = AB$. Karena $\triangle ABC$ lancip, $D$ terletak di antara $B$ dan $C$, sehingga $BD = b$ dan $CD = a - b > 0$. Dari Pythagoras pada $\triangle ABD$ dan $\triangle ACD$:

$$c^2 - b^2 = AD^2 = b^2 - (a - b)^2 \implies c^2 - b^2 = 2ab - a^2 \text{?}$$

Cek ulang: $AD^2 = c^2 - BD^2 = c^2 - b^2$, dan $AD^2 = AC^2 - CD^2 = b^2 - (a - b)^2 = 2ab - a^2$! Jadi $(c - b)(c + b) = \dots$ bukan $(a - b)^2$, melainkan $c^2 - b^2 = 2ab - a^2 \iff a^2 + c^2 = 2b^2 + 2ab \implies a(2b - a) = c^2 - b^2$?! Cek lagi: $b^2 - (a - b)^2 = b^2 - a^2 + 2ab - b^2 = 2ab - a^2$! Jadi $c^2 - b^2 = 2ab - a^2 \iff c^2 = b^2 + 2ab - a^2$! Bukan $c^2 - b^2 = (a - b)^2$ (di PDF tertulis $c^2 - b^2 = (a - b)^2$ yang salah tanda)! Mari selesaikan persamaan yang BENAR: $c^2 = b^2 + 2ab - a^2$, dengan syarat lancip $a^2 < b^2 + c^2$, $b^2 < a^2 + c^2$, $c^2 < a^2 + b^2$.

Perhatikan $c^2 < a^2 + b^2 \iff b^2 + 2ab - a^2 < a^2 + b^2 \iff 2ab < 2a^2 \iff b < a$ (sudah terpenuhi karena $CD = a - b > 0$!). Dan $a^2 < b^2 + c^2 \iff a^2 < 2b^2 + 2ab - a^2 \iff a^2 - ab - b^2 < 0 \iff \dfrac{a}{b} < \dfrac{1 + \sqrt{5}}{2}$! Jadi $b < a < 1{,}618b$.

Tulis $c^2 + 2a^2 = (a + b)^2 \implies (a + b - c)(a + b + c) = 2a^2$. Uji $a$ dari kecil ke besar dengan $b < a < 1{,}618b$:

  • $a = 5$: $b \in \{4\}$; $c^2 = 16 + 40 - 25 = 31$ (bukan kuadrat).
  • $a = 7$: $b \in \{5, 6\}$; $b=5 \implies c^2 = 25 + 70 - 49 = 46$; $b=6 \implies c^2 = 36 + 84 - 49 = 71$.
  • $a = 13$: $b \in \{9, 10, 11, 12\}$; $b = 12 \implies c^2 = 144 + 312 - 169 = 287$; $b = 9 \implies 81 + 234 - 169 = 146$.
  • $a = 17$: $b = 12 \implies 144 + 408 - 289 = 263$; $b = 15 \implies 225 + 510 - 289 = 446$.
  • Cek dengan rumus parametrik $(a + b)^2 - c^2 = 2a^2$: karena $(a+b-c)(a+b+c) = 2a^2$, misal $a = 12$: $2a^2 = 288 = 12 \cdot 24 \implies a+b = 18, c = 6$ ($b = 6$, cek $a < 1{,}618(6) = 9{,}7$, tumpul!). Atau $288 = 8 \cdot 36 \implies a+b = 22, b = 10, c = 14$! CEK $(a, b, c) = (12, 10, 14)$:
    $b < a$ ($10 < 12$)!
    $c^2 = 196$, $b^2 + 2ab - a^2 = 100 + 240 - 144 = 196$!
    Syarat lancip: $14^2 = 196 < 12^2 + 10^2 = 244$ (LANCIP!)!

Cek apakah ada $a < 12$ yang lancip: untuk $a ≤ 11$ ($b < a < 1{,}618b$), menguji $a = 1..11$ menunjukkan tidak ada tripel lancip $(a, b, c)$ bulat dengan $c^2 = b^2 + 2ab - a^2$ (misal $a = 7, b = 5$ bukan; $a = 10, 2a^2 = 200$: $(10, 20) \implies b = 5$, tumpul; $(4, 50)$ tak bisa; $a = 8, 2a^2 = 128$: $(8, 16) \implies b = 4$, tumpul; $a = 6, 2a^2 = 72$: $(6, 12) \implies b = 3$, tumpul; $a = 9, 2a^2 = 162$: $(6, 27)$ tak sama paritas; $a = 11, 2a^2 = 242$: $(2, 121)$ tak sama paritas). Jadi $BC_{\min} = 12$ (dengan $(a, b, c) = (12, 10, 14)$)!

Jadi, nilai terkecil panjang sisi $BC$ yang mungkin adalah $12$ (untuk segitiga $(12, 10, 14)$).
