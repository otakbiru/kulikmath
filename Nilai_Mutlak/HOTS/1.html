Nilai maksimum dari \({\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\) dengan x,y,z ∈ [0, 2021] adalah ....
  1. \(\sqrt{6063}\)
  2. \(2\sqrt{2021}\)
  3. \(\sqrt{4042}+\sqrt{2021}\)
  4. \(2\sqrt{2021}+\sqrt{4042}\)
  5. \(2021\sqrt{2}+2021\)
SUMBER
Pembahasan:
Misalkan x ≥ y ≥ z dan \({P=\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\). P bisa kita tulis menjadi,
\({P=\sqrt{x-y}+\sqrt{y-z}+\sqrt{x-z}}\)

Nilai P akan semakin besar jika nilai x semakin besar dan nilai z semakin kecil. Didapat x = 2021 dan z = 0. Substitusikan ke P menjadi
\({P=\sqrt{2021-y}+\sqrt{y}+\sqrt{2021}}\)

Dengan menggunakan ketaksamaan Cauchy-Schwarz didapat,
\(\begin{aligned} \left(\sqrt{2021-y}\cdot1+\sqrt{y}\cdot1\right)^2&\leq \left(\left(\sqrt{2021-y}\right)^2+\left(\sqrt{y}\right)^2\right)\left(1^2+1^2\right)\\ \left(\sqrt{2021-y}+\sqrt{y}\right)^2&\leq \left(2021-y+y\right)\left(2\right)\\ \left(\sqrt{2021-y}+\sqrt{y}\right)^2&\leq 4042\\ \sqrt{2021-y}+\sqrt{y}&\leq \sqrt{4042}\\ \sqrt{2021-y}+\sqrt{y}+\sqrt{2021}&\leq \sqrt{4042}+\sqrt{2021} \end{aligned}\)
Jadi, nilai maksimum dari \({\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\) dengan x,y,z ∈ [0, 2021] adalah \(\sqrt{4042}+\sqrt{2021}\).

Didefinisikan fungsi nilai mutlak
$|x|=\begin{cases}x,\ &x\geq0\\-x,\ &x\lt0\end{cases}$
Diberikan bilangan real x1 ≤ x2 ≤ x3 ≤ ⋯ ≤ x100 sehingga |x1| + |x2| + ⋯ + |x100| = 1 dan x1 + x2 + ⋯ + x100 = 0. Nilai maksimum dari x76 − x16 = $\dfrac{m}n$ dengan FPB(m, n) = 1. Nilai m + n = ....
Evaluasi GMOM September 2024
Pembahasan:
Agar nilai x76 − x16 maksimum, maka x76 harus terbesar dan x16 harus terkecil. Dengan kata lain,
x76 = x77 = ⋯ = x100
x1 = x2 = ⋯ = x16
Untuk x17 sampai x75 harus bernilai 0. Misal x76 = a > 0, dan x16 = b < 0. Substitusikan ke persamaan,
25a − 16b = 1
25a + 16b = 0
Didapat a = $\dfrac1{50}$ dan b = $-\dfrac1{32}$.

$\dfrac1{50}-\left(-\dfrac1{32}\right)=\dfrac{41}{800}$
41 + 800 = \(\boxed{841}\)
Jadi, m + n = 841.
Misalkan \(T\) adalah himpunan semua titik pada bidang-\(xy\) yang memenuhi \(|x| + |y| \le 4\). Luas daerah \(T\) adalah
  1. \(4\)
  2. \(8\)
  3. \(12\)
  4. \(16\)
  5. \(32\)
OSK SMA 2006 (Bagian I No. 7)
Pembahasan:

Batas daerah \(|x| + |y| = 4\) pada masing-masing kuadran berupa empat ruas garis yang menghubungkan titik-titik potong sumbu koordinat, yakni \((4, 0)\), \((0, 4)\), \((-4, 0)\), dan \((0, -4)\).

Keempat titik tersebut membentuk sebuah belah ketupat (sekaligus persegi miring) dengan panjang kedua diagonalnya sama dengan \(d_1 = 4 - (-4) = 8\) dan \(d_2 = 4 - (-4) = 8\).

Luas daerah \(T\) adalah:

\[L_T = \frac{1}{2} \cdot d_1 \cdot d_2 = \frac{1}{2} \times 8 \times 8 = 32\]
Jadi, luas daerah \(T\) adalah 32.
JAWAB: E
Tentukan semua bilangan real $x$ yang memenuhi $x^2 < |2x - 8|$.
Sumber: OSP SMA 2004 (Bagian Pertama - No. 10)
Pembahasan:

Bagi menjadi dua kasus berdasarkan tanda dari $2x - 8$:

  • Kasus 1 ($x \ge 4$): $x^2 < 2x - 8 \iff (x - 1)^2 + 7 < 0$, tidak ada solusi real.
  • Kasus 2 ($x < 4$): $x^2 < 8 - 2x \iff x^2 + 2x - 8 < 0 \iff (x + 4)(x - 2) < 0 \iff -4 < x < 2$ (seluruhnya memenuhi $x < 4$).
Jadi, semua bilangan real $x$ yang memenuhi adalah $-4 < x < 2$.
Jika $a$ bilangan real, maka $\sqrt{a^2} =$
  1. $-|a|$
  2. $-a$
  3. $\pm a$
  4. $a$
  5. $|a|$
Sumber: OSK SMA 2008 (Bagian Pertama No. 1)
Pembahasan:

Berdasarkan definisi akar kuadrat utama (principal square root), nilai $\sqrt{x}$ untuk $x \ge 0$ selalu bernilai tak negatif:

  • Jika $a \ge 0$, maka $\sqrt{a^2} = a$.
  • Jika $a < 0$, maka $-a > 0$ sehingga $\sqrt{a^2} = -a$.

Kedua kasus tersebut tepat dinyatakan oleh definisi nilai mutlak $|a|$.

Jadi, jawabannya adalah E. $|a|$.

Misalkan $M$ dan $m$ berturut-turut merupakan nilai $a$ terbesar dan terkecil sehingga berlaku $\left|x^2 - 2ax - a^2 - \dfrac{3}{4}\right| \le 1$ untuk setiap $x \in [0, 1]$. Nilai dari $M - m$ adalah $\cdots$
Sumber: OSP SMA 2015 (No. 17)
Pembahasan:

Misalkan $g(x) = x^2 - 2ax - a^2 - \frac{3}{4} = (x - a)^2 - 2a^2 - \frac{3}{4}$ pada $[0, 1]$.

  • Syarat di $x = 0$: $\left|-a^2 - \frac{3}{4}\right| \le 1 \implies a^2 \le \frac{1}{4} \implies -\frac{1}{2} \le a \le \frac{1}{2}$.
  • Syarat di $x = 1$: $\left|\frac{1}{4} - 2a - a^2\right| \le 1 \implies -\frac{3}{4} \le a^2 + 2a \le \frac{5}{4} \implies a \ge -\frac{1}{2}$ (pada $[-\frac{1}{2}, \frac{1}{2}]$).
  • Jika $a \in [0, \frac{1}{2}]$, puncak $x = a \in [0, 1]$ memberi nilai minimum $g(a) = -2a^2 - \frac{3}{4} \ge -1 \implies a^2 \le \frac{1}{8} \implies a \le \frac{1}{2\sqrt{2}}$.

Pemeriksaan menunjukkan seluruh $a \in \left[-\frac{1}{2}, \frac{1}{2\sqrt{2}}\right]$ memenuhi $|g(x)| \le 1$ pada $[0, 1]$. Jadi $M = \dfrac{1}{2\sqrt{2}}$ dan $m = -\dfrac{1}{2}$.

Jadi, nilai dari $M - m$ adalah $\dfrac{1}{2\sqrt{2}} + \dfrac{1}{2}$.
