Ringkasan dan penjelasan lengkap materi Nilai Mutlak

1. Pengertian dan Definisi Nilai Mutlak

Secara geometris, nilai mutlak (atau harga mutlak) dari suatu bilangan real \(x\), yang dilambangkan dengan \(|x|\), adalah jarak titik \(x\) ke titik nol \((0)\) pada garis bilangan real. Karena jarak selalu bernilai tak-negatif (\(\ge 0\)), maka \(|x| \ge 0\) untuk setiap \(x \in \mathbb{R}\).

Definisi Aljabar (Fungsi Sepotong-Sepotong / Piecewise): $$|x| = \begin{cases} x, & \text{jika } x \ge 0 \\ -x, & \text{jika } x < 0 \end{cases}$$ Secara lebih umum, untuk bentuk linear \(|ax + b|\) dengan titik pembuat nol \(x = -\frac{b}{a}\): $$|ax + b| = \begin{cases} ax + b, & \text{jika } ax + b \ge 0 \\ -(ax + b), & \text{jika } ax + b < 0 \end{cases}$$

  • Jarak Antara Dua Titik: Untuk sembarang dua bilangan real \(x\) dan \(a\) pada garis bilangan, ekspresi \(|x - a|\) menyatakan jarak antara titik \(x\) dan titik \(a\). Sebagai contoh, \(|x - 2| = 3\) berarti titik \(x\) berjarak \(3\) satuan dari angka \(2\) (yaitu \(x = 5\) atau \(x = -1\)).

2. Sifat-Sifat Aljabar Nilai Mutlak dan Ketaksamaan Segitiga

Untuk setiap bilangan real \(x, y \in \mathbb{R}\), berlaku sifat-sifat fundamental nilai mutlak berikut:

Nama Sifat Rumus Identitas / Ketaksamaan Catatan Penting
Sifat Non-Negatif & Simetri $$|x| \ge 0 \quad \text{dan} \quad |-x| = |x|$$ Akibatnya: \(|x - y| = |y - x|\).
Hubungan Kuadrat & Akar $$|x|^2 = x^2 \quad \text{dan} \quad \sqrt{x^2} = |x|$$ Dasar dari metode menguadratkan kedua ruas jika kedua ruas \(\ge 0\).
Perkalian & Pembagian $$|x \cdot y| = |x| \cdot |y| \quad \text{dan} \quad \left|\frac{x}{y}\right| = \frac{|x|}{|y|} \;\; (y \neq 0)$$ Nilai mutlak dapat dipecah pada operasi kali dan bagi.
Ketaksamaan Segitiga
(Triangle Inequality)		 $$\big||x| - |y|\big| \le |x + y| \le |x| + |y|$$ Kesamaan \(|x+y| = |x|+|y|\) tercapai jika dan hanya jika \(x \cdot y \ge 0\) (bertanda sama).

3. Grafik Fungsi Nilai Mutlak

Fungsi nilai mutlak bentuk baku memiliki persamaan umum: $$f(x) = a|x - h| + k \quad (a \neq 0)$$

  • Bentuk Kurva & Titik Puncak (Titik Belok Tajam): Grafik berbentuk huruf V yang simetris terhadap garis vertikal \(x = h\) dengan koordinat titik puncak (ujung lancip) di \(P(h, k)\).
    • Jika \(a > 0\), grafik membuka ke atas dengan nilai minimum \(y_{\min} = k\) dan daerah hasil \(R_f = [k, \infty)\).
    • Jika \(a < 0\), grafik membuka ke bawah dengan nilai maksimum \(y_{\text{maks}} = k\) dan daerah hasil \(R_f = (-\infty, k]\).
  • Transformasi Grafik \(y = |g(x)|\): Untuk menggambar grafik \(y = |g(x)|\) dari fungsi sembarang \(y = g(x)\), pertahankan bagian kurva \(g(x)\) yang berada di atas sumbu-\(X\) (\(g(x) \ge 0\)), lalu cerminkan bagian kurva yang berada di bawah sumbu-\(X\) terhadap sumbu-\(X\) ke atas.

4. Persamaan Nilai Mutlak

Terdapat tiga bentuk utama persamaan nilai mutlak beserta metode penyelesaiannya:

Bentuk Persamaan Syarat Berlaku Cara Penyelesaian
Bentuk 1: \(|f(x)| = c\) Konstanta \(c \ge 0\)
(Jika \(c < 0\), himpunan penyelesaian \(\emptyset\))		 $$f(x) = c \quad \text{atau} \quad f(x) = -c$$
Bentuk 2: \(|f(x)| = |g(x)|\) Kedua ruas sudah pasti \(\ge 0\) $$f(x) = g(x) \quad \text{atau} \quad f(x) = -g(x)$$
Ekuivalen selisih kuadrat: \(\big(f(x) + g(x)\big)\big(f(x) - g(x)\big) = 0\).
Bentuk 3: \(|f(x)| = g(x)\) Wajib syarat: \(g(x) \ge 0\) Cari solusi \(f(x) = g(x)\) atau \(f(x) = -g(x)\), lalu uji/iriskan dengan syarat \(g(x) \ge 0\).

Metode Analisis Interval (Untuk Penjumlahan Beberapa Nilai Mutlak, misal \(|x - a| + |x - b| = c\)):
1. Cari semua titik pembuat nol masing-masing nilai mutlak (\(x = a\) dan \(x = b\)).
2. Bagi garis bilangan menjadi beberapa interval (misalnya \(x < a\), \(a \le x < b\), dan \(x \ge b\)).
3. Buka tanda mutlak pada tiap interval sesuai tandanya, selesaikan persamaannya, dan pastikan solusinya berada di dalam interval tersebut.

5. Pertidaksamaan Nilai Mutlak

Penyelesaian pertidaksamaan nilai mutlak didasarkan pada sifat jarak terhadap titik asal (untuk konstanta \(c > 0\)):

Bentuk Pertidaksamaan Bentuk Ekuivalen (Tanpa Mutlak) Pola Daerah pada Garis Bilangan
$$|f(x)| < c \quad (\text{atau } \le c)$$ $$-c < f(x) < c$$ Irisan (Di antara): Daerah terkurung di tengah antara \(-c\) dan \(c\).
$$|f(x)| > c \quad (\text{atau } \ge c)$$ $$f(x) < -c \quad \text{atau} \quad f(x) > c$$ Gabungan (Menyebar): Daerah di sebelah kiri \(-c\) atau sebelah kanan \(c\).
$$|f(x)| < |g(x)|$$ $$\big(f(x) + g(x)\big)\big(f(x) - g(x)\big) < 0$$ Kuadratkan kedua ruas: \(f^2(x) - g^2(x) < 0\), lalu faktorkan dan uji garis bilangan.
$$a < |f(x)| < b \quad (a, b > 0)$$ $$a < f(x) < b \quad \text{atau} \quad -b < f(x) < -a$$ Gabungan dari dua interval simetris.
💡 Tips Penting Pertidaksamaan Rasional Nilai Mutlak:
• Jika terdapat bentuk pecahan \(\left|\frac{f(x)}{g(x)}\right| \le k\) dengan \(k > 0\), jangan lupa syarat penyebut \(g(x) \neq 0\)!
• Kalikan kedua ruas dengan \(|g(x)|\) menjadi \(|f(x)| \le k|g(x)|\), lalu gunakan pemfaktoran selisih kuadrat \(\big(f(x) + k\cdot g(x)\big)\big(f(x) - k\cdot g(x)\big) \le 0\).

6. Contoh Soal dan Pembahasan

Pelajari contoh soal berikut untuk menguasai persamaan nilai mutlak bersyarat, pertidaksamaan kuadrat nilai mutlak, serta metode pembagian interval. Klik tombol Lihat Penyelesaian untuk membuka pembahasannya.

Contoh 1
Tentukan himpunan penyelesaian dari persamaan nilai mutlak: $$|2x - 5| = x + 1$$
Penyelesaian:

Langkah 1: Tentukan syarat tak-negatif untuk ruas kanan.
Karena nilai mutlak di ruas kiri selalu \(\ge 0\), maka ruas kanan wajib memenuhi: $$x + 1 \ge 0 \implies x \ge -1$$

Langkah 2: Pecah menjadi dua kemungkinan persamaan linear.

  • Kemungkinan I (Positif): $$2x - 5 = x + 1 \implies x = 6$$ Cek syarat: karena \(6 \ge -1\) (memenuhi), maka \(x = 6\) adalah solusi yang sah.
  • Kemungkinan II (Negatif): $$2x - 5 = -(x + 1) \implies 2x - 5 = -x - 1 \implies 3x = 4 \implies x = \frac{4}{3}$$ Cek syarat: karena \(\frac{4}{3} \ge -1\) (memenuhi), maka \(x = \frac{4}{3}\) juga solusi yang sah.

Jadi, himpunan penyelesaian dari persamaan tersebut adalah \(\text{HP} = \left\{\frac{4}{3}, 6\right\}\).
Contoh 2
Tentukan himpunan semua nilai \(x \in \mathbb{R}\) yang memenuhi pertidaksamaan: $$\left|\frac{2x + 1}{x - 3}\right| \le 1$$
Penyelesaian:

Langkah 1: Catat syarat penyebut dan ubah bentuk pecahan.
Penyebut tidak boleh nol, sehingga \(x \neq 3\). Karena \(|x - 3| > 0\) untuk \(x \neq 3\), kita kalikan kedua ruas dengan \(|x - 3|\): $$|2x + 1| \le |x - 3|$$

Langkah 2: Gunakan sifat selisih kuadrat \(|f(x)| \le |g(x)| \iff (f + g)(f - g) \le 0\). $$(2x + 1)^2 - (x - 3)^2 \le 0$$ $$\big((2x + 1) + (x - 3)\big)\big((2x + 1) - (x - 3)\big) \le 0$$ $$(3x - 2)(x + 4) \le 0$$

Langkah 3: Tentukan titik pembuat nol dan uji garis bilangan.
Pembuat nol adalah \(x = -4\) dan \(x = \frac{2}{3}\). Karena koefisien \(x^2\) positif dan tanda pertidaksamaan \(\le 0\), maka daerah penyelesaiannya berada di antara kedua pembuat nol tersebut: $$-4 \le x \le \frac{2}{3}$$ Periksa syarat penyebut: nilai \(x = 3\) tidak berada di dalam interval \(\left[-4, \frac{2}{3}\right]\), sehingga seluruh interval tersebut aman.

Jadi, himpunan penyelesaian pertidaksamaan tersebut adalah \(\left\{x \in \mathbb{R} \;\middle|\; -4 \le x \le \frac{2}{3}\right\}\).
Contoh 3
Tentukan semua nilai \(x\) yang memenuhi persamaan \(|x + 1| + |2x - 4| = 9\), serta tentukan nilai minimum dari fungsi \(h(x) = |x + 1| + |x - 5|\)!
Penyelesaian:

Bagian A: Menyelesaikan \(|x + 1| + |2x - 4| = 9\) dengan Metode Interval.
Pembuat nol dari masing-masing mutlak adalah \(x + 1 = 0 \implies x = -1\) dan \(2x - 4 = 0 \implies x = 2\). Garis bilangan terbagi menjadi 3 kasus:

  • Kasus 1 (\(x < -1\)): Kedua mutlak bernilai negatif \(\implies -(x + 1) - (2x - 4) = 9\). $$-3x + 3 = 9 \implies -3x = 6 \implies x = -2$$ Karena \(-2 < -1\) (masuk dalam interval Kasus 1), maka \(x = -2\) memenuhi.
  • Kasus 2 (\(-1 \le x < 2\)): \(|x+1| = x+1\) dan \(|2x-4| = -(2x-4)\). $$(x + 1) - (2x - 4) = 9 \implies -x + 5 = 9 \implies x = -4$$ Karena \(-4\) tidak berada di dalam interval \([-1, 2)\), maka \(x = -4\) tidak memenuhi.
  • Kasus 3 (\(x \ge 2\)): Kedua mutlak bernilai positif \(\implies (x + 1) + (2x - 4) = 9\). $$3x - 3 = 9 \implies 3x = 12 \implies x = 4$$ Karena \(4 \ge 2\) (masuk dalam interval Kasus 3), maka \(x = 4\) memenuhi.

Bagian B: Nilai Minimum \(h(x) = |x + 1| + |x - 5|\) dengan Ketaksamaan Segitiga.
Berdasarkan Ketaksamaan Segitiga \(|A| + |B| \ge |A - B|\): $$h(x) = |x + 1| + |5 - x| \ge |(x + 1) + (5 - x)| = |6| = 6$$ Nilai minimum \(6\) ini tercapai untuk semua \(x\) di antara kedua titik pembuat nolnya, yaitu \(-1 \le x \le 5\).

Jadi, solusi persamaan adalah \(x \in \{-2, 4\}\), dan nilai minimum dari \(h(x) = |x + 1| + |x - 5|\) adalah \(6\).
