Berikut adalah soal tingkat ... materi Aljabar

Definisikan \(a * b = a + b + 1\) untuk semua bilangan bulat \(a, b\). Jika \(p\) memenuhi \(a * p = a\), untuk setiap bilangan bulat \(a\), maka \(p =\)
  1. \(-1\)
  2. \(0\)
  3. \(1\)
  4. \(2\)
  5. tidak ada yang memenuhi
OSK SMA 2006 (Bagian I No. 8)
Pembahasan:

Berdasarkan definisi operasi biner \(a * b = a + b + 1\), substitusikan \(b = p\):

\[a * p = a \iff a + p + 1 = a\]

Kurangkan kedua ruas dengan \(a\):

\[p + 1 = 0 \iff p = -1\]

Nilai \(p = -1\) tidak bergantung pada \(a\), sehingga memenuhi \(a * (-1) = a + (-1) + 1 = a\) untuk semua bilangan bulat \(a\) (\(p = -1\) adalah elemen identitas dari operasi \(*\)).

Jadi, nilai \(p\) adalah \(-1\).
