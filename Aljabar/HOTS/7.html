Definisikan \(a * b = a + b + 1\) untuk semua bilangan bulat \(a, b\). Jika \(p\) memenuhi \(a * p = a\), untuk setiap bilangan bulat \(a\), maka \(p =\)
  1. \(-1\)
  2. \(0\)
  3. \(1\)
  4. \(2\)
  5. tidak ada yang memenuhi
OSK SMA 2006 (Bagian I No. 8)
Pembahasan:

Berdasarkan definisi operasi biner \(a * b = a + b + 1\), substitusikan \(b = p\):

\[a * p = a \iff a + p + 1 = a\]

Kurangkan kedua ruas dengan \(a\):

\[p + 1 = 0 \iff p = -1\]

Nilai \(p = -1\) tidak bergantung pada \(a\), sehingga memenuhi \(a * (-1) = a + (-1) + 1 = a\) untuk semua bilangan bulat \(a\) (\(p = -1\) adalah elemen identitas dari operasi \(*\)).

Jadi, nilai \(p\) adalah \(-1\).

Bilangan \(\sqrt[3]{\sqrt{5} + 2} - \sqrt[3]{\sqrt{5} - 2}\) merupakan bilangan
  1. bulat negatif
  2. bulat positif
  3. pecahan
  4. irrasional positif
  5. irrasional negatif
Sumber: OSK SMA 2007 No. 2
Pembahasan:

Misalkan \(X = \sqrt[3]{\sqrt{5} + 2} - \sqrt[3]{\sqrt{5} - 2}\). Pangkat tigakan kedua ruas dengan identitas \((u - v)^3 = u^3 - v^3 - 3uv(u - v)\):

\[X^3 = (\sqrt{5} + 2) - (\sqrt{5} - 2) - 3\sqrt[3]{(\sqrt{5} + 2)(\sqrt{5} - 2)}\cdot X\]

Karena \((\sqrt{5} + 2)(\sqrt{5} - 2) = 5 - 4 = 1\), diperoleh:

\[X^3 = 4 - 3X \iff X^3 + 3X - 4 = 0\]

Faktorkan dengan memperhatikan \(X = 1\) adalah akar:

\[(X - 1)(X^2 + X + 4) = 0\]

Faktor kuadrat \(X^2 + X + 4\) memiliki diskriminan \(D = 1^2 - 4(1)(4) = -15 \lt 0\), sehingga tidak mempunyai akar real. Satu-satunya akar real adalah \(X = 1\).

Jadi, bilangan tersebut sama dengan \(1\), yaitu bilangan bulat positif.
JAWAB: B
Semua pasangan bilangan bulat \((x, y)\) yang memenuhi \(x + y = xy - 1\) dan \(x \le y\), adalah \(\cdots\)
Sumber: OSK SMA 2007 No. 13
Pembahasan:

Pindahkan suku ke satu ruas dan faktorkan (Simon's Favorite Factoring Trick):

\[xy - x - y - 1 = 0 \iff (x - 1)(y - 1) = 2\]

Karena \(x \le y\), maka \(x - 1 \le y - 1\). Pasangan faktor bulat dari \(2\) dengan urutan \(\le\) adalah:

  • \(x - 1 = -2,\; y - 1 = -1 \implies (x, y) = (-1, 0)\)
  • \(x - 1 = 1,\; y - 1 = 2 \implies (x, y) = (2, 3)\)
Jadi, semua pasangan \((x, y)\) yang memenuhi adalah \((-1, 0)\) dan \((2, 3)\).
Misalkan $x^{-n}$ sama dengan $\left(\dfrac{1}{x}\right)^n$ untuk setiap bilangan real $x$ (tak nol). Maka $a^3 - a^{-3}$ sama dengan $\cdots$
  1. $\left(a - \dfrac{1}{a}\right)\left(a^2 + 1 + \dfrac{1}{a^2}\right)$
  2. $\left(\dfrac{1}{a} - a\right)\left(a^2 - 1 + \dfrac{1}{a^2}\right)$
  3. $\left(a - \dfrac{1}{a}\right)\left(a^2 - 2 + \dfrac{1}{a^2}\right)$
  4. $\left(\dfrac{1}{a} - a\right)\left(\dfrac{1}{a^2} + 1 + a^2\right)$
  5. bukan di antara A, B, C, dan D
Sumber: OSK SMA 2002 (No. 5)
Pembahasan:

Gunakan identitas selisih dua pangkat tiga $u^3 - v^3 = (u - v)(u^2 + uv + v^2)$ dengan $u = a$ dan $v = \dfrac{1}{a}$:

$$a^3 - a^{-3} = a^3 - \left(\frac{1}{a}\right)^3 = \left(a - \frac{1}{a}\right)\left(a^2 + a \cdot \frac{1}{a} + \frac{1}{a^2}\right) = \left(a - \frac{1}{a}\right)\left(a^2 + 1 + \frac{1}{a^2}\right)$$
Jadi, jawabannya adalah A.
Banyaknya pasangan bilangan bulat $(x, y)$ yang memenuhi persamaan $2xy - 5x + y = 55$ adalah $\cdots$
Sumber: OSP SMA 2005 (Bagian Pertama No. 16)
Pembahasan:

Kalikan kedua ruas dengan $2$, lalu faktorkan menggunakan teknik Simon's Favorite Factoring Trick:

$$4xy - 10x + 2y = 110$$ $$2x(2y - 5) + (2y - 5) = 110 - 5$$ $$(2x + 1)(2y - 5) = 105$$

Faktorisasi prima $105 = 3^1 \cdot 5^1 \cdot 7^1$, sehingga banyaknya pembagi positif dari $105$ adalah $(1 + 1)(1 + 1)(1 + 1) = 8$, dan seluruh pembagi bulatnya (positif maupun negatif) ada $2 \times 8 = 16$.

Karena $105$ ganjil, setiap pembagi $d \mid 105$ bernilai ganjil, sehingga $2x + 1 = d \implies x = \dfrac{d - 1}{2} \in \mathbb{Z}$ dan $2y - 5 = \dfrac{105}{d} \implies y = \dfrac{\frac{105}{d} + 5}{2} \in \mathbb{Z}$ selalu menghasilkan pasangan bilangan bulat $(x, y)$ yang valid.

Jadi, banyaknya pasangan bilangan bulat $(x, y)$ yang memenuhi adalah $16$.
Jika $0 < b < a$ dan $a^2 + b^2 = 6ab$, maka $\dfrac{a + b}{a - b} =$ $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 3)
Pembahasan:

Karena $0 < b < a$, maka $a + b > 0$ dan $a - b > 0$, sehingga $\dfrac{a + b}{a - b} > 0$. Kuadratkan bentuk yang dicari dan substitusikan $a^2 + b^2 = 6ab$:

$$\left(\frac{a + b}{a - b}\right)^2 = \frac{a^2 + b^2 + 2ab}{a^2 + b^2 - 2ab} = \frac{6ab + 2ab}{6ab - 2ab} = \frac{8ab}{4ab} = 2$$

Karena $\dfrac{a + b}{a - b} > 0$, tarik akar kuadratnya untuk memperoleh $\dfrac{a + b}{a - b} = \sqrt{2}$.

Jadi, nilai $\dfrac{a + b}{a - b}$ adalah $\sqrt{2}$.
Banyaknya bilangan real $x$ yang memenuhi persamaan $x^4 - 2x^3 + 5x^2 - 176x + 2009 = 0$ adalah $\cdots$
Sumber: OSP SMA 2009 (Bagian Pertama No. 2)
Pembahasan:

Ubah ruas kiri menjadi jumlah kuadrat:

$$x^4 - 2x^3 + 5x^2 - 176x + 2009 = (x^2 - x)^2 + (2x - 44)^2 + 73 = 0$$

Karena $(x^2 - x)^2 \ge 0$ dan $(2x - 44)^2 \ge 0$ untuk setiap $x \in \mathbb{R}$, ruas kiri selalu $\ge 73 > 0$.

Jadi, banyaknya bilangan real $x$ yang memenuhi adalah $0$.
Bilangan bulat yang memenuhi pertidaksamaan $x^4 \le 8x^2 - 16$ sebanyak $\cdots$
Sumber: OSK SMA 2010 (No. 2)
Pembahasan:

Pindahkan seluruh suku ke ruas kiri dan faktorkan:

$$x^4 - 8x^2 + 16 \le 0 \implies (x^2 - 4)^2 \le 0$$

Karena kuadrat bilangan real tidak pernah negatif, satu-satunya kemungkinan adalah $x^2 - 4 = 0 \implies x = 2$ atau $x = -2$.

Jadi, banyaknya bilangan bulat $x$ yang memenuhi adalah $2$.
Misalkan $a, b,$ dan $c$ adalah bilangan-bilangan real positif dengan sifat $abc = 1$. Jika diketahui bahwa $$a^{2011} + b^{2011} + c^{2011} < \frac{1}{a^{2011}} + \frac{1}{b^{2011}} + \frac{1}{c^{2011}}$$ buktikan bahwa $$a + b + c < \frac{1}{a} + \frac{1}{b} + \frac{1}{c}$$
Sumber: OSN SMA 2011 (No. 3)
Pembahasan:

Untuk sebarang bilangan real $x, y, z$ dengan $xyz = 1$, perhatikan identitas:

$$(x - 1)(y - 1)(z - 1) = xyz - (xy + yz + zx) + (x + y + z) - 1 = (x + y + z) - \left(\frac{1}{x} + \frac{1}{y} + \frac{1}{z}\right)$$

Dengan $(x, y, z) = (a^{2011}, b^{2011}, c^{2011})$, kondisi soal ekuivalen dengan $(a^{2011} - 1)(b^{2011} - 1)(c^{2011} - 1) < 0$.

Karena $a, b, c > 0$, faktor $t^{2011} - 1 = (t - 1)(t^{2010} + \dots + 1)$ selalu bertanda sama dengan $t - 1$. Akibatnya:

$$(a - 1)(b - 1)(c - 1) < 0 \iff (a + b + c) - \left(\frac{1}{a} + \frac{1}{b} + \frac{1}{c}\right) < 0$$

Jadi $a + b + c < \dfrac{1}{a} + \dfrac{1}{b} + \dfrac{1}{c}$. Terbukti. $\blacksquare$

Tentukan semua nilai $b$ sehingga untuk semua $x$ paling tidak salah satu dari $f(x) = x^2 + 2012x + b$ atau $g(x) = x^2 - 2012x + b$ positif.
Sumber: OSK SMA 2012 (No. 10)
Pembahasan:

Jumlahkan kedua fungsi: $f(x) + g(x) = 2x^2 + 2b$.

  • Jika $b > 0$, maka $f(x) + g(x) = 2x^2 + 2b > 0$ untuk setiap $x \in \mathbb{R}$, sehingga pasti paling sedikit satu di antara $f(x)$ atau $g(x)$ bernilai positif.
  • Jika $b \le 0$, pilih $x = 0$; diperoleh $f(0) = g(0) = b \le 0$, sehingga syarat tidak terpenuhi.
Jadi, semua nilai $b$ yang memenuhi adalah $b > 0$.
