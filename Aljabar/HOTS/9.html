No. 81
Misalkan $a = 2\sqrt{2} - \sqrt{8 - 4\sqrt{2}}$ dan $b = 2\sqrt{2} + \sqrt{8 - 4\sqrt{2}}$. Jika $\dfrac{a}{b} + \dfrac{b}{a} = x + y\sqrt{2}$ dengan $x, y$ bulat, maka nilai $x + y$ adalah $\cdots$
Sumber: OSK SMA 2019 (No. 6)
Pembahasan:

Perhatikan bahwa $a + b = 4\sqrt{2}$ dan:

$$ab = (2\sqrt{2})^2 - (8 - 4\sqrt{2}) = 8 - (8 - 4\sqrt{2}) = 4\sqrt{2}$$

Maka:

$$\frac{a}{b} + \frac{b}{a} = \frac{a^2 + b^2}{ab} = \frac{(a + b)^2 - 2ab}{ab} = \frac{(4\sqrt{2})^2}{4\sqrt{2}} - 2 = 4\sqrt{2} - 2$$

Sehingga $x = -2$ dan $y = 4$, yang memberikan $x + y = -2 + 4 = 2$.

Jadi, nilai $x + y$ adalah $2$.
No. 82
Misalkan $$f(x) = \frac{3(x - 1)(x - 2)}{2} + \frac{(x - 2)(x - 3)}{2} - 2(x - 1)(x - 3)$$ Nilai dari $f(20)$ adalah $\cdots$
Sumber: OSK SMA 2020 (No. 1)
Pembahasan:

Jabarkan dan sederhanakan bentuk $f(x)$:

$$f(x) = \frac{3(x^2 - 3x + 2) + (x^2 - 5x + 6)}{2} - 2(x^2 - 4x + 3)$$ $$= \frac{4x^2 - 14x + 12}{2} - (2x^2 - 8x + 6) = (2x^2 - 7x + 6) - (2x^2 - 8x + 6) = x$$

Oleh karena itu, $f(20) = 20$.

Jadi, nilai dari $f(20)$ adalah $20$.
No. 83
Misalkan $x$ dan $y$ bilangan-bilangan real positif sehingga $$\left(\frac{x}{5} + \frac{y}{3}\right)\left(\frac{5}{x} + \frac{3}{y}\right) = 139$$ Jika nilai maksimal dan minimal dari $\dfrac{x + y}{\sqrt{xy}}$ berturut-turut adalah $M$ dan $m$, maka nilai dari $M - m$ adalah $\cdots$
Sumber: OSP SMA 2020 (No. 12)
Pembahasan:

Misalkan $a = \frac{x}{y} > 0$. Persamaan menjadi:

$$2 + \frac{3a}{5} + \frac{5}{3a} = 139 \implies 9a^2 - 2055a + 25 = 0$$

Akar-akar positifnya $a_1, a_2$ memenuhi $a_1 + a_2 = \frac{2055}{9}$ dan $a_1a_2 = \frac{25}{9}$, dengan $\frac{x+y}{\sqrt{xy}} = \sqrt{a} + \frac{1}{\sqrt{a}}$.

Kuadratkan selisih $M - m = \left(\sqrt{a_1} + \frac{1}{\sqrt{a_1}}\right) - \left(\sqrt{a_2} + \frac{1}{\sqrt{a_2}}\right)$:

$$(M - m)^2 = \frac{(\sqrt{a_1} - \sqrt{a_2})^2 (\sqrt{a_1a_2} - 1)^2}{a_1a_2} = \frac{\left(\frac{2055}{9} - 2 \cdot \frac{5}{3}\right)\left(\frac{5}{3} - 1\right)^2}{\frac{25}{9}} = \frac{\frac{2025}{9} \cdot \frac{4}{9}}{\frac{25}{9}} = 36$$

Karena $M \ge m$, maka $M - m = 6$.

Jadi, nilai dari $M - m$ adalah $6$.
No. 84
Koefisien $x^7$ pada penjabaran $$(1 + x)(2 + x^2)(3 + x^3)(4 + x^4)(5 + x^5)$$ adalah $\cdots$
Sumber: OSK SMA 2021 (No. 2)
Pembahasan:

Partisi $7$ menjadi bilangan berbeda dari $\{1, 2, 3, 4, 5\}$ hanya ada tiga kemungkinan:

  • $1 + 2 + 4$: suku $x \cdot x^2 \cdot 3 \cdot x^4 \cdot 5 = 15x^7$
  • $2 + 5$: suku $1 \cdot x^2 \cdot 3 \cdot 4 \cdot x^5 = 12x^7$
  • $3 + 4$: suku $1 \cdot 2 \cdot x^3 \cdot x^4 \cdot 5 = 10x^7$

Total koefisien $x^7$ adalah $15 + 12 + 10 = 37$.

Jadi, koefisien $x^7$ adalah $37$.
No. 85
Misalkan $x, y, z$ bilangan real positif dengan $x + y + z = 3$. Buktikan $$2\sqrt{x + \sqrt{y}} + 2\sqrt{y + \sqrt{z}} + 2\sqrt{z + \sqrt{x}} \le \sqrt{8 + x - y} + \sqrt{8 + y - z} + \sqrt{8 + z - x}$$
Sumber: OSN SMA 2021 (No. 4)
Pembahasan:

Dengan ketaksamaan AM-GM, $\sqrt{y} \le \frac{y + 1}{2}$, sehingga dengan Cauchy-Schwarz ($\sqrt{u} + \sqrt{v} \le \sqrt{2(u + v)}$):

$$2\sum_{\text{cyc}} \sqrt{x + \sqrt{y}} \le 2\sum_{\text{cyc}} \sqrt{x + \frac{y + 1}{2}} = \sum_{\text{cyc}} \left(\sqrt{x + \frac{y + 1}{2}} + \sqrt{y + \frac{z + 1}{2}}\right)$$ $$\le \sum_{\text{cyc}} \sqrt{2\left(x + y + \frac{y + z + 2}{2}\right)} = \sum_{\text{cyc}} \sqrt{2(x + y) + y + z + 2}$$

Karena $x + y = 3 - z$, substitusikan $2(x + y) + y + z + 2 = 6 - 2z + y + z + 2 = 8 + y - z$:

$$2\sum_{\text{cyc}} \sqrt{x + \sqrt{y}} \le \sum_{\text{cyc}} \sqrt{8 + y - z}$$
Terbukti pertidaksamaan tersebut berlaku.
No. 86
Diketahui $a, b, c, d$ bilangan real positif yang memenuhi $a > c$, $d > b$ dan $$3a^2 + 3b^2 = 3c^2 + 3d^2 = 4ac + 4bd$$ Nilai $\dfrac{12(ab + cd)}{ad + bc} = \cdots$
Sumber: OSK SMA 2022 (No. 17)
Pembahasan:

Misalkan $a = pc$ dan $d = qb$ dengan $p, q > 1$ (karena $a > c, d > b$). Maka $\frac{ab + cd}{ad + bc} = \frac{p + q}{pq + 1}$. Misalkan $k = 3a^2 + 3b^2$:

$$3p^2c^2 + 3b^2 = k, \qquad 3c^2 + 3q^2b^2 = k, \qquad 4pc^2 + 4qb^2 = k$$

Eliminasi $b^2$ dan $c^2$ dari dua persamaan pertama:

$$c^2 = \frac{k(q^2 - 1)}{3(p^2q^2 - 1)}, \qquad b^2 = \frac{k(p^2 - 1)}{3(p^2q^2 - 1)}$$

Substitusikan ke $4pc^2 + 4qb^2 = k$:

$$\frac{4(pq^2 - p + p^2q - q)}{3(p^2q^2 - 1)} = 1 \iff (pq - 1)\left(\frac{3}{4}pq - p - q + \frac{3}{4}\right) = 0$$

Karena $pq > 1$, maka $\frac{3}{4}(pq + 1) = p + q \implies \frac{p + q}{pq + 1} = \frac{3}{4}$, sehingga $\frac{12(ab + cd)}{ad + bc} = 12 \times \frac{3}{4} = 9$.

Jadi, nilainya adalah $9$.
No. 87
Tentukan bilangan real positif $K$ terkecil sehingga ketaksamaan $$K + \frac{a + b + c}{3} \ge (K + 1)\sqrt{\frac{a^2 + b^2 + c^2}{3}}$$ berlaku untuk setiap bilangan real $0 \le a, b, c \le 1$.
Sumber: OSN SMA 2022 (No. 8)
Pembahasan:

Substitusi $(a, b, c) = (1, 1, 0)$ memberikan $K + \frac{2}{3} \ge (K + 1)\sqrt{\frac{2}{3}} \implies K \ge \frac{\sqrt{6}}{3}$.

Kita buktikan $K = \frac{\sqrt{6}}{3}$ memenuhi. Pertidaksamaan menjadi:

$$\sqrt{a^2 + b^2 + c^2} \le \frac{a + b + c + \sqrt{6}}{\sqrt{2} + \sqrt{3}}$$

Untuk $a + b + c = k \in [0, 3]$ tetap ($1 \ge a \ge b \ge c \ge 0$), fungsi $a^2 + b^2 + c^2$ bersifat konveks sehingga maksimumnya tercapai di titik ekstrem:

  • Jika $0 \le k \le 1$: maksimum di $(k, 0, 0)$, dan $k \le \frac{k + \sqrt{6}}{1 + \sqrt{6}} < \frac{k + \sqrt{6}}{\sqrt{2} + \sqrt{3}}$ (karena $\sqrt{2} + \sqrt{3} < 1 + \sqrt{6}$).
  • Jika $1 \le k \le 2$: maksimum di $(1, k - 1, 0)$, dan $\sqrt{1 + (k - 1)^2} \le \sqrt{2}(k - 1)\text{?}$ (tepatnya untuk $1 \le k \le 2$, $\sqrt{1 + (k-1)^2} \le \frac{k + \sqrt{6}}{\sqrt{2} + \sqrt{3}}$ ekuivalen setelah pengkuadratan dengan fungsi kuadrat cekung atas yang bernilai $\le 0$ di $k = 1$ dan $k = 2$).
  • Jika $2 \le k \le 3$: maksimum di $(1, 1, k - 2)$, dan $\sqrt{2 + (k - 2)^2} \le \frac{k + \sqrt{6}}{\sqrt{2} + \sqrt{3}}$ ekuivalen dengan $-2(2 + \sqrt{6})(k - 2)(k - 3) \le 0$, benar untuk $k \in [2, 3]$.
Jadi, bilangan real positif $K$ terkecil adalah $\dfrac{\sqrt{6}}{3}$.
No. 88
Sumber: OSN SMA 2023 (No. 8)

Untuk setiap tiga bilangan bulat positif berbeda $a, b, c$, definisikan $S(a, b, c)$ sebagai himpunan semua bilangan rasional yang merupakan akar dari paling sedikit satu di antara enam persamaan kuadrat: $$ax^2 + bx + c = 0,\quad ax^2 + cx + b = 0,\quad bx^2 + ax + c = 0,$$ $$bx^2 + cx + a = 0,\quad cx^2 + ax + b = 0,\quad cx^2 + bx + a = 0.$$ Sebagai contoh, $S(1, 2, 3) = \left\{-1, -2, -\frac{1}{2}\right\}$. Tentukan nilai maksimum yang mungkin dari $|S(a, b, c)|$.

Pembahasan (Jawaban: $8$)

Tanpa kehilangan keumuman, misalkan $a < b < c$. Tinjau diskriminan dari dua persamaan kuadrat yang koefisien $x^2$-nya adalah $c$: $$\Delta_1 = b^2 - 4ac \quad \text{dan} \quad \Delta_2 = a^2 - 4bc.$$ Karena $a < b < c$ dan $a, b, c \ge 1$, maka: $$a^2 < ab < 4bc \implies \Delta_2 = a^2 - 4bc < 0.$$ Dengan demikian, persamaan $cx^2 + ax + b = 0$ tidak mempunyai akar real (apalagi rasional). Juga untuk persamaan $bx^2 + ax + c = 0$, diskriminannya $a^2 - 4bc < 0$, sehingga persamaan ini pun tidak mempunyai akar real!

Artinya, paling banyak hanya $4$ persamaan kuadrat yang dapat memiliki akar rasional, dan masing-masing mempunyai paling banyak $2$ akar, sehingga: $$|S(a, b, c)| \le 4 \times 2 = 8.$$ (Catatan: empat persamaan yang tersisa adalah $ax^2 + bx + c = 0$, $ax^2 + cx + b = 0$, $bx^2 + cx + a = 0$, dan $cx^2 + bx + a = 0$.)

Konstruksi mencapai $|S(a, b, c)| = 8$:
Kita cari $a < b < c$ sedemikian sehingga keempat persamaan tersebut memiliki akar rasional berbeda (dua persamaan pertama diskriminannya $b^2 - 4ac$ dan $c^2 - 4ab$ harus kuadrat sempurna, dan dua persamaan lainnya juga punya diskriminan yang sama!).
Ambil $a$ bilangan bulat positif apa pun ($a > 1$, misalnya $a = 2$), lalu pilih: $$b = 4a^2 + 1, \qquad c = 4a^3 + a + 1 \quad \text{(cek } a < b < c\text{)}.$$ Mari cek kedua diskriminan untuk $a = 2 \implies b = 17, c = 35$: - $b^2 - 4ac = 17^2 - 4(2)(35) = 289 - 280 = 9 = 3^2$! - $c^2 - 4ab = 35^2 - 4(2)(17) = 1225 - 136 = 1089 = 33^2$! Cek semua $8$ akarnya untuk $(a, b, c) = (2, 17, 35)$: 1. $2x^2 + 17x + 35 = 0 \implies x \in \left\{-5, -\frac{7}{2}\right\}$ 2. $2x^2 + 35x + 17 = 0 \implies x \in \left\{-17, -\frac{1}{2}\right\}$ 3. $17x^2 + 35x + 2 = 0 \implies x \in \left\{-2, -\frac{1}{17}\right\}$ 4. $35x^2 + 17x + 2 = 0 \implies x \in \left\{-\frac{2}{7}, -\frac{1}{5}\right\}$.

Kedelapan akar rasional tersebut semuanya berbeda! Jadi nilai maksimum dari $|S(a, b, c)|$ adalah $\mathbf{8}$.
