Jika $\dfrac{2}{x} - \dfrac{2}{y} = 1$ dan $y - x = 2$, maka $(x + y)^2 = \cdots$
Sumber: OSK SMA 2013 (No. 6)
Pembahasan:

Dari $\dfrac{2}{x} - \dfrac{2}{y} = 1$, diperoleh $\dfrac{2(y - x)}{xy} = 1 \implies xy = 4$.

Maka $(x + y)^2 = (y - x)^2 + 4xy = 2^2 + 4(4) = 20$.

Jadi, nilai $(x + y)^2$ adalah $20$.
Untuk $x > 0,\ y > 0$ didefinisikan $f(x, y)$ adalah nilai terkecil di antara $x$, $\dfrac{y}{2} + \dfrac{2}{x}$, dan $\dfrac{1}{y}$. Nilai terbesar yang mungkin dicapai oleh $f(x, y)$ adalah $\cdots$
Sumber: OSK SMA 2013 (No. 17)
Pembahasan:

Jika $x \le \frac{\sqrt{10}}{2}$ atau $\frac{1}{y} \le \frac{\sqrt{10}}{2}$, jelas $f(x, y) \le \frac{\sqrt{10}}{2}$. Jika $x > \frac{\sqrt{10}}{2}$ dan $\frac{1}{y} > \frac{\sqrt{10}}{2}$, maka $\frac{y}{2} + \frac{2}{x} < \frac{1}{\sqrt{10}} + \frac{4}{\sqrt{10}} = \frac{\sqrt{10}}{2}$. Kesamaan tercapai saat $x = \frac{1}{y} = \frac{\sqrt{10}}{2}$.

Jadi, nilai terbesar $f(x, y)$ adalah $\dfrac{\sqrt{10}}{2}$.

Misalkan $a, b$ adalah bilangan riil sedemikian sehingga $a + b = \dfrac{1}{a} + \dfrac{1}{b} = 6$. Nilai dari $\dfrac{a}{b} + \dfrac{b}{a} + 1980$ adalah $\cdots$
Sumber: OSK SMA 2014
Pembahasan:

Dari $\dfrac{1}{a} + \dfrac{1}{b} = 6$, diperoleh $\dfrac{a + b}{ab} = 6 \implies \dfrac{6}{ab} = 6 \implies ab = 1$.

Dengan demikian:

$$\frac{a}{b} + \frac{b}{a} + 1980 = \frac{a^2 + b^2}{ab} + 1980 = \frac{(a + b)^2 - 2ab}{ab} + 1980 = \frac{36 - 2}{1} + 1980 = 2014$$
Jadi, nilainya adalah $2014$.
No. 74
Untuk bilangan real $t$ dan bilangan real positif $a$ dan $b$ berlaku $$2a^2 - 3abt + b^2 = 2a^2 + abt - b^2 = 0$$ Nilai $t$ adalah $\cdots$
Sumber: OSP SMA 2014
Pembahasan:

Kurangkan persamaan pertama dari persamaan kedua:

$$(2a^2 + abt - b^2) - (2a^2 - 3abt + b^2) = 0 \implies 4abt - 2b^2 = 0 \implies b = 2at \quad (b > 0)$$

Substitusikan $b = 2at$ ke persamaan kedua:

$$2a^2 + at(2at) - (2at)^2 = 0 \implies 2a^2(1 - t^2) = 0 \implies t = \pm 1 \quad (a > 0)$$

Karena $a, b > 0$ dan $b = 2at$, maka $t > 0 \implies t = 1$.

Jadi, nilai $t$ adalah $1$.
No. 75
Diketahui bilangan real positif $a$ dan $b$ memenuhi persamaan $$a^4 + a^2b^2 + b^4 = 6 \quad \text{dan} \quad a^2 + ab + b^2 = 4$$ Nilai dari $a + b$ adalah $\cdots$
Sumber: OSK SMA 2015 (No. 9)
Pembahasan:

Dengan identitas Sophie Germain, $a^4 + a^2b^2 + b^4 = (a^2 + ab + b^2)(a^2 - ab + b^2)$, sehingga:

$$a^2 - ab + b^2 = \frac{6}{4} = \frac{3}{2}$$

Kurangkan dari $a^2 + ab + b^2 = 4$ untuk memperoleh $2ab = 4 - \dfrac{3}{2} = \dfrac{5}{2} \implies ab = \dfrac{5}{4}$.

Maka $(a + b)^2 = (a^2 + ab + b^2) + ab = 4 + \dfrac{5}{4} = \dfrac{21}{4}$, dan karena $a, b > 0$, $a + b = \dfrac{1}{2}\sqrt{21}$.

Jadi, nilai dari $a + b$ adalah $\dfrac{1}{2}\sqrt{21}$.
No. 76
Misalkan $a, b, c$ tiga bilangan asli yang memenuhi $2a + 2b + 2c = 100$. Nilai dari $a + b + c$ adalah $\cdots$
Sumber: OSP SMA 2016 (No. 1)
Pembahasan:

Faktorkan $2$ pada ruas kiri: $2(a + b + c) = 100 \implies a + b + c = 50$.

Jadi, nilai dari $a + b + c$ adalah $50$.
No. 77
Diketahui $x - y = 10$ dan $xy = 10$. Nilai $x^4 + y^4$ adalah $\cdots$
Sumber: OSK SMA 2017 (No. 1)
Pembahasan:

Hitung $x^2 + y^2 = (x - y)^2 + 2xy = 10^2 + 2(10) = 120$, lalu:

$$x^4 + y^4 = (x^2 + y^2)^2 - 2(xy)^2 = 120^2 - 2(10)^2 = 14400 - 200 = 14200$$
Jadi, nilai $x^4 + y^4$ adalah $14200$.
No. 78
Jika $\dfrac{(a - b)(c - d)}{(b - c)(d - a)} = -\dfrac{4}{7}$, maka nilai dari $\dfrac{(a - c)(b - d)}{(a - b)(c - d)}$ adalah $\cdots$
Sumber: OSK SMA 2017 (No. 5)
Pembahasan:

Gunakan identitas Euler untuk empat bilangan: $(a - b)(c - d) + (b - c)(d - a) = (a - c)(b - d)$? Cek tanda: $(a - b)(c - d) = ac - ad - bc + bd$, $(b - c)(d - a) = bd - ab - cd + ac$, selisihnya $(a - b)(c - d) - (b - c)(d - a) = ab + cd - ad - bc = (a - c)(b - d)$!

Bagi kedua ruas identitas $(a - b)(c - d) - (b - c)(d - a) = (a - c)(b - d)$ dengan $(a - b)(c - d)$:

$$\frac{(a - c)(b - d)}{(a - b)(c - d)} = 1 - \frac{(b - c)(d - a)}{(a - b)(c - d)} = 1 - \left(-\frac{7}{4}\right) = \frac{11}{4}$$
Jadi, nilainya adalah $\dfrac{11}{4}$.
No. 79
Dua bilangan real tidak nol $a$ dan $b$ memenuhi $ab = a - b$. Nilai $\dfrac{a}{b} + \dfrac{b}{a} - ab$ yang mungkin adalah $\cdots$
Sumber: OSP SMA 2017 (No. 1)
Pembahasan:

Kuadratkan $a - b = ab$ untuk memperoleh $a^2 + b^2 - 2ab = a^2 b^2 \implies a^2 + b^2 = a^2 b^2 + 2ab$. Maka:

$$\frac{a}{b} + \frac{b}{a} - ab = \frac{a^2 + b^2}{ab} - ab = \frac{a^2 b^2 + 2ab}{ab} - ab = ab + 2 - ab = 2$$
Jadi, nilai yang mungkin adalah $2$.
No. 80
Diketahui $a + 2b = 1$, $b + 2c = 2$, dan $b \neq 0$. Jika $a + nb + 2018c = 2019$ maka nilai $n$ adalah $\cdots$
Sumber: OSK SMA 2019 (No. 5)
Pembahasan:

Kalikan persamaan kedua dengan $1009$ untuk menyamakan koefisien $c$ menjadi $2018$:

$$1009b + 2018c = 2018$$

Jumlahkan dengan $a + 2b = 1$:

$$a + 1011b + 2018c = 2019$$

Kurangkan dengan $a + nb + 2018c = 2019$, diperoleh $(1011 - n)b = 0$. Karena $b \neq 0$, maka $n = 1011$.

Jadi, nilai $n$ adalah $1011$.
