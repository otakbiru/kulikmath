Berikut adalah soal tingkat ... materi Kuartil

Tujuh bilangan bulat telah diurutkan dari nilai terkecil hingga terbesar sebagai berikut: \[a, \; 2a - 3, \; 3a - 5, \; 4a - 6, \; 4a - 1, \; 5a + 2, \; 6a\] Jika jangkauan antarkuartil (\(Q_3 - Q_1\)) dari data tersebut adalah \(23\), maka nilai median dari data tersebut adalah ....

  1. \(14\)
  2. \(16\)
  3. \(18\)
  4. \(20\)
  5. \(22\)
SNBT / Penalaran Matematika
Pembahasan:

Langkah 1: Menentukan Letak Kuartil Data Tunggal

Banyak data adalah \(n = 7\) yang telah terurut dari terkecil ke terbesar: \[x_1 = a, \; x_2 = 2a - 3, \; x_3 = 3a - 5, \; x_4 = 4a - 6, \; x_5 = 4a - 1, \; x_6 = 5a + 2, \; x_7 = 6a\] Untuk \(n = 7\), letak masing-masing kuartil adalah:

  • Kuartil bawah (\(Q_1\)) terletak pada data ke-2: \[Q_1 = x_2 = 2a - 3\]
  • Median / Kuartil tengah (\(Q_2\)) terletak pada data ke-4: \[Q_2 = x_4 = 4a - 6\]
  • Kuartil atas (\(Q_3\)) terletak pada data ke-6: \[Q_3 = x_6 = 5a + 2\]

Langkah 2: Menghitung Nilai Parameter \(a\)

Jangkauan antarkuartil didefinisikan sebagai selisih kuartil atas dan kuartil bawah: \[\text{IQR} = Q_3 - Q_1\] Substitusikan nilai yang diketahui: \[(5a + 2) - (2a - 3) = 23\] \[5a + 2 - 2a + 3 = 23\] \[3a + 5 = 23\] \[3a = 18 \implies a = 6\]

Langkah 3: Menentukan Nilai Median (\(Q_2\))

Substitusikan nilai \(a = 6\) ke rumus median: \[\text{Median} = Q_2 = 4a - 6 = 4(6) - 6 = 24 - 6 = 18\]

Verifikasi Urutan Data:
Untuk \(a = 6\), kumpulan data tersebut adalah: \[6, \; 9, \; 13, \; 18, \; 23, \; 32, \; 36\] Data telah terurut naik dengan benar.

Jadi, nilai median data tersebut adalah \(18\) (Pilihan C).
