Misalkan $A = (-1)^{-1}$, $B = (-1)^1$, dan $C = 1^{-1}$. Berapakah $A + B + C$?
Sumber: OSP SMA 2002 (Bagian Pertama - No. 1)
Pembahasan:

Hitung masing-masing nilai:

$$A = (-1)^{-1} = \frac{1}{-1} = -1, \qquad B = (-1)^1 = -1, \qquad C = 1^{-1} = \frac{1}{1} = 1$$

Jumlahnya adalah $A + B + C = -1 + (-1) + 1 = -1$.

Jadi, nilai $A + B + C$ adalah $-1$.
