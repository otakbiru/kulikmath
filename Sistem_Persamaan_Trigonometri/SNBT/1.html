Berikut adalah soal tingkat ... materi Sistem Persamaan Trigonometri

Untuk sudut lancip $x$ dan $y$ ($0^\circ < x, y < 90^\circ$), diketahui sistem persamaan:
$$\begin{cases} \tan x + \tan y = 4 \\ \cot x + \cot y = 6 \end{cases}$$
Nilai dari $\tan(x + y)$ adalah ....
  1. $6$
  2. $8$
  3. $10$
  4. $12$
  5. $16$
Pembahasan:
Ubah persamaan kedua ke dalam bentuk tangen:
$$\cot x + \cot y = \frac{1}{\tan x} + \frac{1}{\tan y} = \frac{\tan x + \tan y}{\tan x \tan y} = 6$$ Substitusikan nilai $\tan x + \tan y = 4$:
$$\frac{4}{\tan x \tan y} = 6 \implies \tan x \tan y = \frac{4}{6} = \frac{2}{3}$$ Gunakan rumus tangen penjumlahan dua sudut:
$$\tan(x + y) = \frac{\tan x + \tan y}{1 - \tan x \tan y} = \frac{4}{1 - \frac{2}{3}} = \frac{4}{\frac{1}{3}} = 12$$
Jadi, nilai dari $\tan(x + y)$ adalah 12.
