Ringkasan dan penjelasan lengkap materi Sistem Persamaan Trigonometri

1. Pengertian & Karakteristik Sistem Persamaan Trigonometri

Sistem Persamaan Trigonometri adalah sekumpulan dua atau lebih persamaan matematika yang memuat fungsi-fungsi trigonometri (seperti $\sin, \cos, \tan$) dengan dua atau lebih variabel sudut (umumnya $x$ dan $y$).

Berbeda dengan sistem aljabar polinomial biasa, fungsi trigonometri memiliki sifat periodisitas (keperiodikan). Akibatnya, jika domain sudut tidak dibatasi, suatu sistem dapat memiliki tak hingga banyak solusi periodik dengan periode $2k\pi$ (untuk sinus dan cosinus) atau $k\pi$ (untuk tangen), $k \in \mathbb{Z}$. Umumnya, pencarian solusi dibatasi pada interval tertutup seperti $x, y \in [0, 2\pi]$ atau $[0^\circ, 360^\circ]$.

Prinsip Kunci Penyelesaian Sistem Trigonometri:
Tujuan utama adalah mentransformasikan sistem non-linear trigonometri menjadi sistem linear dalam kombinasi sudut $(x + y)$ dan $(x - y)$, atau mereduksinya menjadi persamaan aljabar simetris melalui substitusi variabel.

2. Tipe-Tipe Baku & Strategi Transformasi

A. Tipe 1: Sistem Jumlah Sudut & Penjumlahan Fungsi

Bentuk umum: $$\begin{cases} x + y = \alpha \\ \sin x + \sin y = C \end{cases} \quad \text{atau} \quad \begin{cases} x + y = \alpha \\ \cos x + \cos y = C \end{cases}$$ Gunakan formula konversi Jumlah ke Perkalian (Sum-to-Product): $$\sin x + \sin y = 2 \sin\left(\frac{x+y}{2}\right) \cos\left(\frac{x-y}{2}\right)$$ $$\cos x + \cos y = 2 \cos\left(\frac{x+y}{2}\right) \cos\left(\frac{x-y}{2}\right)$$ Karena nilai $x + y = \alpha$ sudah diketahui, nilai $\frac{x+y}{2} = \frac{\alpha}{2}$ konstan. Persamaan langsung tereduksi menjadi: $$\cos\left(\frac{x-y}{2}\right) = \frac{C}{2 \sin(\alpha/2)}$$ Setelah $(x - y)$ diperoleh, variabel $x$ dan $y$ dihitung via eliminasi SPLDV sederhana: $$x = \frac{(x+y) + (x-y)}{2}, \quad y = \frac{(x+y) - (x-y)}{2}$$

Gambar 1: Dekomposisi sudut pada lingkaran satuan — bisektor rata-rata $\frac{x+y}{2}$ dan simpangan sudut $\frac{x-y}{2}$.

B. Tipe 2: Sistem Perkalian Fungsi Trigonometri

Bentuk umum: $$\begin{cases} \cos x \cos y = A \\ \sin x \sin y = B \end{cases}$$ Terapkan rumus Perkalian ke Jumlah (Product-to-Sum) dengan menjumlahkan dan mengurangkan kedua persamaan: $$\cos(x - y) = \cos x \cos y + \sin x \sin y = A + B$$ $$\cos(x + y) = \cos x \cos y - \sin x \sin y = A - B$$ Sistem non-linear yang semula terikat terurai menjadi dua persamaan cosinus dasar yang saling bebas dalam variabel komposit $(x - y)$ dan $(x + y)$.

Gambar 2: Titik-titik potong solusi simultan pada bidang fase sudut $[0, \pi] \times [0, \pi]$.

C. Tipe 3: Sistem Tangen & Identitas Pecahan

Jika sistem memuat fungsi tangen, gunakan identitas fraksi: $$\tan x + \tan y = \frac{\sin x}{\cos x} + \frac{\sin y}{\cos y} = \frac{\sin(x + y)}{\cos x \cos y}$$ $$\tan x \tan y = \frac{\sin x \sin y}{\cos x \cos y}$$ Formula ini menghubungkan penjumlahan tangen dengan sinus jumlah sudut secara langsung tanpa perlu mengekspansi persamaan menjadi polinomial berderajat tinggi.

D. Tipe 4: Eliminasi Kuadratik via Identitas Pythagoras

Jika sistem berbentuk parameter sudut $t$: $$\begin{cases} x = r \cos t + h \\ y = r \sin t + k \end{cases} \iff \left(\frac{x - h}{r}\right)^2 + \left(\frac{y - k}{r}\right)^2 = \cos^2 t + \sin^2 t = 1$$ Metode penjumlahan kuadrat mengeliminasi variabel sudut $t$ secara seketika menghasilkan kurva lingkaran atau elips Kartesius.

Gambar 3: Penjumlahan dua vektor satuan $\vec{u} + \vec{v}$ menghasilkan resultan berpanjang $|\vec{R}| = 2\cos\left(\frac{x-y}{2}\right)$ pada arah sudut rata-rata $\frac{x+y}{2}$.

3. Tabel Identitas Kunci untuk Penyelesaian Sistem

Bentuk Operasi Identitas Transformasi Fungsi dalam Sistem
Jumlah Sinus $\sin x + \sin y = 2\sin\left(\frac{x+y}{2}\right)\cos\left(\frac{x-y}{2}\right)$ Mereduksi sistem ketika $(x+y)$ bernilai konstan.
Selisih Sinus $\sin x - \sin y = 2\cos\left(\frac{x+y}{2}\right)\sin\left(\frac{x-y}{2}\right)$ Mengekstrak nilai $(x-y)$ saat $(x+y)$ diketahui.
Jumlah Cosinus $\cos x + \cos y = 2\cos\left(\frac{x+y}{2}\right)\cos\left(\frac{x-y}{2}\right)$ Simetris, menghasilkan nilai perkalian cosinus.
Selisih Cosinus $\cos x - \cos y = -2\sin\left(\frac{x+y}{2}\right)\sin\left(\frac{x-y}{2}\right)$ Menghasilkan perkalian dua fungsi sinus.
Jumlah Tangen $\tan x + \tan y = \frac{\sin(x+y)}{\cos x \cos y}$ Menghubungkan penjumlahan tangen dan perkalian cosinus.

4. Contoh Soal & Pembahasan Bertingkat

Contoh 1: Tingkat Dasar — Sistem Jumlah Sudut & Transformasi Sinus

Tentukan seluruh pasangan sudut $(x, y)$ pada interval $0 \le x, y \le \pi$ yang memenuhi sistem persamaan trigonometri berikut: $$\begin{cases} x + y = \pi \quad \text{--- (1)} \\ \sin x + \sin y = 1 \quad \text{--- (2)} \end{cases}$$

Pembahasan:

Langkah 1: Mengaplikasikan Rumus Jumlah ke Perkalian
Gunakan formula konversi pada persamaan (2): $$\sin x + \sin y = 2 \sin\left(\frac{x + y}{2}\right) \cos\left(\frac{x - y}{2}\right) = 1$$ Dari persamaan (1), kita tahu bahwa $x + y = \pi$, sehingga: $$\frac{x + y}{2} = \frac{\pi}{2}$$ Substitusikan nilai sudut tengah ini: $$2 \sin\left(\frac{\pi}{2}\right) \cos\left(\frac{x - y}{2}\right) = 1$$ Karena $\sin\left(\frac{\pi}{2}\right) = 1$: $$2(1) \cos\left(\frac{x - y}{2}\right) = 1 \implies \cos\left(\frac{x - y}{2}\right) = \frac{1}{2}$$

Langkah 2: Menentukan Nilai $(x - y)$
Karena $0 \le x, y \le \pi$, maka $-\pi \le x - y \le \pi$, sehingga $-\frac{\pi}{2} \le \frac{x - y}{2} \le \frac{\pi}{2}$. Nilai sudut yang memiliki cosinus $\frac{1}{2}$ pada interval tersebut adalah: $$\frac{x - y}{2} = \frac{\pi}{3} \quad \text{atau} \quad \frac{x - y}{2} = -\frac{\pi}{3}$$ Kalikan dengan 2: $$x - y = \frac{2\pi}{3} \quad \text{atau} \quad x - y = -\frac{2\pi}{3}$$

Langkah 3: Menentukan Pasangan Solusi $(x, y)$

  • Kasus 1: $x - y = \frac{2\pi}{3}$
    Jumlahkan dengan $x + y = \pi$: $$2x = \pi + \frac{2\pi}{3} = \frac{5\pi}{3} \implies x = \frac{5\pi}{6}$$ $$y = \pi - \frac{5\pi}{6} = \frac{\pi}{6}$$ Diperoleh pasangan: $(x, y) = \left(\frac{5\pi}{6}, \frac{\pi}{6}\right)$.
  • Kasus 2: $x - y = -\frac{2\pi}{3}$
    Jumlahkan dengan $x + y = \pi$: $$2x = \pi - \frac{2\pi}{3} = \frac{\pi}{3} \implies x = \frac{\pi}{6}$$ $$y = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$$ Diperoleh pasangan: $(x, y) = \left(\frac{\pi}{6}, \frac{5\pi}{6}\right)$.

Kesimpulan: Himpunan penyelesaian sistem adalah $HP = \left\{\left(\frac{\pi}{6}, \frac{5\pi}{6}\right), \left(\frac{5\pi}{6}, \frac{\pi}{6}\right)\right\}$ atau dalam derajat: $\{(30^\circ, 150^\circ), (150^\circ, 30^\circ)\}$.

Contoh 2: Tingkat SNBT / UTBK — Sistem Perkalian Fungsi ke Jumlah Cosinus

Diberikan sistem persamaan trigonometri berikut: $$\begin{cases} \cos x \cos y = \frac{3}{4} \quad \text{--- (1)} \\ \sin x \sin y = \frac{1}{4} \quad \text{--- (2)} \end{cases}$$ untuk interval sudut $0 \le x, y \le \pi$.

  1. Tentukan nilai eksak dari $\cos(x - y)$ dan $\cos(x + y)$.
  2. Tentukan seluruh pasangan sudut $(x, y)$ yang memenuhi sistem tersebut.

Pembahasan:

(a) Menghitung Nilai $\cos(x - y)$ dan $\cos(x + y)$:
Berdasarkan rumus cosinus selisih dan jumlah sudut: $$\cos(x - y) = \cos x \cos y + \sin x \sin y$$ $$\cos(x + y) = \cos x \cos y - \sin x \sin y$$ Substitusikan persamaan (1) dan (2): $$\cos(x - y) = \frac{3}{4} + \frac{1}{4} = \frac{4}{4} = 1$$ $$\cos(x + y) = \frac{3}{4} - \frac{1}{4} = \frac{2}{4} = \frac{1}{2}$$

(b) Menentukan Pasangan Solusi $(x, y)$:
Karena $0 \le x, y \le \pi$, maka selisih $-\pi \le x - y \le \pi$. Nilai sudut yang memenuhi $\cos(x - y) = 1$ pada interval tersebut adalah: $$x - y = 0 \implies x = y$$ Selanjutnya, karena $x = y$, persamaan kedua $\cos(x + y) = \frac{1}{2}$ menjadi: $$\cos(2x) = \frac{1}{2}$$ Karena $0 \le x \le \pi$, maka $0 \le 2x \le 2\pi$. Sudut yang memenuhi adalah: $$2x = \frac{\pi}{3} \implies x = \frac{\pi}{6}$$ $$2x = \frac{5\pi}{3} \implies x = \frac{5\pi}{6}$$ Karena $y = x$, diperoleh dua pasangan solusi: $$(x, y) = \left(\frac{\pi}{6}, \frac{\pi}{6}\right) \quad \text{atau} \quad (x, y) = \left(\frac{5\pi}{6}, \frac{5\pi}{6}\right)$$ Verifikasi untuk $(30^\circ, 30^\circ)$: $$\cos(30^\circ)\cos(30^\circ) = \frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2} = \frac{3}{4} \quad (\text{benar})$$ $$\sin(30^\circ)\sin(30^\circ) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4} \quad (\text{benar})$$

Kesimpulan: Nilai $\cos(x - y) = 1$, $\cos(x + y) = \frac{1}{2}$, dan pasangan solusi adalah $HP = \left\{\left(\frac{\pi}{6}, \frac{\pi}{6}\right), \left(\frac{5\pi}{6}, \frac{5\pi}{6}\right)\right\}$.

Contoh 3: Tingkat HOTS (Olimpiade / Kompetisi) — Sistem Tangen-Cosinus Non-Linear Simetris

Tentukan seluruh pasangan sudut $(x, y)$ pada interval $-\frac{\pi}{2} < x, y < \frac{\pi}{2}$ yang memenuhi sistem persamaan non-linear berikut: $$\begin{cases} \tan x + \tan y = 2 \\ \cos x \cos y = \frac{1}{2} \end{cases}$$

Pembahasan:

Langkah 1: Menggunakan Identitas Penjumlahan Tangen
Tuliskan bentuk penjumlahan tangen ke bentuk pecahan sinus-cosinus: $$\tan x + \tan y = \frac{\sin x}{\cos x} + \frac{\sin y}{\cos y} = \frac{\sin x \cos y + \cos x \sin y}{\cos x \cos y} = \frac{\sin(x + y)}{\cos x \cos y}$$ Substitusikan nilai $\tan x + \tan y = 2$ dan $\cos x \cos y = \frac{1}{2}$: $$\frac{\sin(x + y)}{\frac{1}{2}} = 2 \implies \sin(x + y) = 2 \times \frac{1}{2} = 1$$

Langkah 2: Menentukan Sudut Jumlah $(x + y)$
Karena $-\frac{\pi}{2} < x < \frac{\pi}{2}$ dan $-\frac{\pi}{2} < y < \frac{\pi}{2}$, maka interval jumlah sudutnya adalah: $$-\pi < x + y < \pi$$ Satu-satunya sudut dalam selang $(-\pi, \pi)$ yang memiliki nilai sinus sama dengan 1 adalah: $$x + y = \frac{\pi}{2} \quad \text{--- (3)}$$

Langkah 3: Menentukan Nilai $\cos(x - y)$
Gunakan identitas perkalian cosinus: $$2 \cos x \cos y = \cos(x + y) + \cos(x - y)$$ Karena $x + y = \frac{\pi}{2}$, maka $\cos(x + y) = \cos\left(\frac{\pi}{2}\right) = 0$. Substitusikan ke persamaan: $$2 \left(\frac{1}{2}\right) = 0 + \cos(x - y) \implies 1 = \cos(x - y)$$ Karena $-\pi < x - y < \pi$, nilai sudut yang memenuhi $\cos(x - y) = 1$ hanyalah: $$x - y = 0 \implies x = y \quad \text{--- (4)}$$

Langkah 4: Menentukan Solusi Akhir $(x, y)$
Gabungkan persamaan (3) dan (4): $$x + x = \frac{\pi}{2} \implies 2x = \frac{\pi}{2} \implies x = \frac{\pi}{4}$$ Karena $y = x$, maka $y = \frac{\pi}{4}$.
Verifikasi: $$\tan\left(\frac{\pi}{4}\right) + \tan\left(\frac{\pi}{4}\right) = 1 + 1 = 2 \quad (\text{memenuhi})$$ $$\cos\left(\frac{\pi}{4}\right) \cos\left(\frac{\pi}{4}\right) = \frac{\sqrt{2}}{2} \times \frac{\sqrt{2}}{2} = \frac{2}{4} = \frac{1}{2} \quad (\text{memenuhi})$$

Kesimpulan: Solusi tunggal sistem tersebut adalah $(x, y) = \left(\frac{\pi}{4}, \frac{\pi}{4}\right)$ atau dalam derajat: $(45^\circ, 45^\circ)$.
