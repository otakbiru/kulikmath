Diberikan bilangan real non-negatif \(l, m, n, a,\) dan \(s\) yang memenuhi: \[l + m + n + a + s = 28\] Misalkan \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\}\). Nilai terkecil yang mungkin dari \(x\) adalah ....
  1. 28
  2. 20
  3. 24
  4. 14
  5. 27
LMNAS Ke-28 SMA
Pembahasan:
Perhatikan jumlah dari dua suku di dalam ekspresi maksimum: \[ \begin{aligned} (l + m + n) + (n + a + s) &= (l + m + n + a + s) + n \\ &= 28 + n \end{aligned} \] Karena \(n\) adalah bilangan real non-negatif (\(n \ge 0\)), maka: \[(l + m + n) + (n + a + s) \ge 28\] Berdasarkan sifat nilai maksimum dari dua bilangan real: \[ \max\{l + m + n,\; n + a + s\} \ge \dfrac{(l + m + n) + (n + a + s)}{2} \ge \dfrac{28}{2} = 14 \] Karena \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\} \ge \max\{l + m + n,\; n + a + s\}\), maka haruslah: \[x \ge 14\] Nilai minimum \(x = 14\) dapat dicapai ketika kita memilih: \[n = 0,\quad m = 0,\quad a = 0,\quad l = 14,\quad s = 14\] Pemeriksaan kondisi:
  • \(l + m + n + a + s = 14 + 0 + 0 + 0 + 14 = 28\) (memenuhi)
  • \(l + m + n = 14 + 0 + 0 = 14\)
  • \(m + n + a = 0 + 0 + 0 = 0\)
  • \(n + a + s = 0 + 0 + 14 = 14\)
  • \(x = \max\{14, 0, 14\} = 14\)
Jadi, nilai terkecil yang mungkin dari \(x\) adalah 14.

Pernyataan manakah yang benar?
  1. Jika $x < 0$ maka $x^2 > x$
  2. Jika $x^2 > 0$ maka $x > 0$
  3. Jika $x^2 > x$ maka $x > 0$
  4. Jika $x^2 > x$ maka $x < 0$
  5. Jika $x < 1$ maka $x^2 < x$
Sumber: OSK SMA 2002 (No. 4)
Pembahasan:

Tinjau tanda $x^2 - x = x(x - 1)$ untuk setiap bilangan real $x$:

  • Jika $x < 0$, maka $x < 0$ dan $x - 1 < 0$, sehingga hasil kalinya $x(x - 1) > 0 \iff x^2 > x$ (Pernyataan A benar).
  • Untuk B, C, D, dan E masing-masing dapat dibantah dengan contoh penyangkal: $x = -1$ membantah B, C, E; sedangkan $x = 2$ membantah D.
Jadi, pernyataan yang benar adalah A. Jika $x < 0$ maka $x^2 > x$.
Jika $a$ sebuah bilangan rasional dan $b$ adalah sebuah bilangan tak rasional, maka $a + b$ adalah bilangan $\cdots$
Sumber: OSP SMA 2005 (Bagian Pertama No. 1)
Pembahasan:

Andaikan $a + b$ merupakan bilangan rasional, misalkan $a + b = r$ dengan $r \in \mathbb{Q}$. Karena $a \in \mathbb{Q}$ dan himpunan bilangan rasional tertutup terhadap pengurangan, maka:

$$b = r - a \in \mathbb{Q}$$

Hal ini kontradiksi dengan keterangan bahwa $b$ adalah bilangan tak rasional (irasional). Oleh karena itu, pengandaian salah.

Jadi, $a + b$ adalah bilangan tak rasional.
Misalkan $k$ dan $m$ bilangan-bilangan asli sehingga $\dfrac{1}{2}\left(\sqrt{k + 4\sqrt{m}} - \sqrt{k}\right)$ adalah bilangan bulat.
  1. Buktikan bahwa $\sqrt{k}$ bilangan rasional.
  2. Buktikan bahwa $\sqrt{k}$ bilangan asli.
Sumber: OSN SMA 2005 (Hari Pertama No. 3)
Pembahasan:

a. Membuktikan $\sqrt{k}$ bilangan rasional:

Misalkan $n = \dfrac{1}{2}\left(\sqrt{k + 4\sqrt{m}} - \sqrt{k}\right)$ adalah bilangan bulat. Karena $m \ge 1$, maka $\sqrt{k + 4\sqrt{m}} > \sqrt{k}$, sehingga $n \ge 1$ (khususnya $n \ne 0$).

Susun ulang dan kuadratkan kedua ruas:

$$\sqrt{k + 4\sqrt{m}} = 2n + \sqrt{k}$$ $$k + 4\sqrt{m} = 4n^2 + 4n\sqrt{k} + k \implies \sqrt{m} = n^2 + n\sqrt{k}$$

Kuadratkan sekali lagi kedua ruas:

$$m = n^4 + 2n^3\sqrt{k} + kn^2 \implies \sqrt{k} = \frac{m - n^4 - kn^2}{2n^3}$$

Karena $k, m, n$ semuanya bilangan bulat dengan $n \ne 0$, ruas kanan merupakan hasil bagi dua bilangan bulat dengan penyebut tak nol, sehingga $\sqrt{k} \in \mathbb{Q}$. $\blacksquare$

b. Membuktikan $\sqrt{k}$ bilangan asli:

Dari bagian (a), tulis $\sqrt{k} = \dfrac{p}{q}$ dalam bentuk pecahan paling sederhana, dengan $p, q \in \mathbb{N}$ dan $\text{FPB}(p, q) = 1$. Kuadratkan kedua ruas:

$$k = \frac{p^2}{q^2} \implies kq^2 = p^2$$

Karena $\text{FPB}(p, q) = 1$, maka $\text{FPB}(p^2, q^2) = 1$. Agar $\dfrac{p^2}{q^2} = k$ berupa bilangan bulat, penyebutnya haruslah $q^2 = 1$, yang berarti $q = 1$. Akibatnya $\sqrt{k} = p$, suatu bilangan asli. $\blacksquare$

Terbukti bahwa $\sqrt{k}$ merupakan bilangan rasional sekaligus bilangan asli.
