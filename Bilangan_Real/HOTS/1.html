Diberikan bilangan real non-negatif \(l, m, n, a,\) dan \(s\) yang memenuhi: \[l + m + n + a + s = 28\] Misalkan \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\}\). Nilai terkecil yang mungkin dari \(x\) adalah ....
  1. 28
  2. 20
  3. 24
  4. 14
  5. 27
LMNAS Ke-28 SMA
Pembahasan:
Perhatikan jumlah dari dua suku di dalam ekspresi maksimum: \[ \begin{aligned} (l + m + n) + (n + a + s) &= (l + m + n + a + s) + n \\ &= 28 + n \end{aligned} \] Karena \(n\) adalah bilangan real non-negatif (\(n \ge 0\)), maka: \[(l + m + n) + (n + a + s) \ge 28\] Berdasarkan sifat nilai maksimum dari dua bilangan real: \[ \max\{l + m + n,\; n + a + s\} \ge \dfrac{(l + m + n) + (n + a + s)}{2} \ge \dfrac{28}{2} = 14 \] Karena \(x = \max\{l + m + n,\; m + n + a,\; n + a + s\} \ge \max\{l + m + n,\; n + a + s\}\), maka haruslah: \[x \ge 14\] Nilai minimum \(x = 14\) dapat dicapai ketika kita memilih: \[n = 0,\quad m = 0,\quad a = 0,\quad l = 14,\quad s = 14\] Pemeriksaan kondisi:
  • \(l + m + n + a + s = 14 + 0 + 0 + 0 + 14 = 28\) (memenuhi)
  • \(l + m + n = 14 + 0 + 0 = 14\)
  • \(m + n + a = 0 + 0 + 0 = 0\)
  • \(n + a + s = 0 + 0 + 14 = 14\)
  • \(x = \max\{14, 0, 14\} = 14\)
Jadi, nilai terkecil yang mungkin dari \(x\) adalah 14.

Pernyataan manakah yang benar?
  1. Jika $x < 0$ maka $x^2 > x$
  2. Jika $x^2 > 0$ maka $x > 0$
  3. Jika $x^2 > x$ maka $x > 0$
  4. Jika $x^2 > x$ maka $x < 0$
  5. Jika $x < 1$ maka $x^2 < x$
Sumber: OSK SMA 2002 (No. 4)
Pembahasan:

Tinjau tanda $x^2 - x = x(x - 1)$ untuk setiap bilangan real $x$:

  • Jika $x < 0$, maka $x < 0$ dan $x - 1 < 0$, sehingga hasil kalinya $x(x - 1) > 0 \iff x^2 > x$ (Pernyataan A benar).
  • Untuk B, C, D, dan E masing-masing dapat dibantah dengan contoh penyangkal: $x = -1$ membantah B, C, E; sedangkan $x = 2$ membantah D.
Jadi, pernyataan yang benar adalah A. Jika $x < 0$ maka $x^2 > x$.
Jika $a$ sebuah bilangan rasional dan $b$ adalah sebuah bilangan tak rasional, maka $a + b$ adalah bilangan $\cdots$
Sumber: OSP SMA 2005 (Bagian Pertama No. 1)
Pembahasan:

Andaikan $a + b$ merupakan bilangan rasional, misalkan $a + b = r$ dengan $r \in \mathbb{Q}$. Karena $a \in \mathbb{Q}$ dan himpunan bilangan rasional tertutup terhadap pengurangan, maka:

$$b = r - a \in \mathbb{Q}$$

Hal ini kontradiksi dengan keterangan bahwa $b$ adalah bilangan tak rasional (irasional). Oleh karena itu, pengandaian salah.

Jadi, $a + b$ adalah bilangan tak rasional.
Misalkan $k$ dan $m$ bilangan-bilangan asli sehingga $\dfrac{1}{2}\left(\sqrt{k + 4\sqrt{m}} - \sqrt{k}\right)$ adalah bilangan bulat.
  1. Buktikan bahwa $\sqrt{k}$ bilangan rasional.
  2. Buktikan bahwa $\sqrt{k}$ bilangan asli.
Sumber: OSN SMA 2005 (Hari Pertama No. 3)
Pembahasan:

a. Membuktikan $\sqrt{k}$ bilangan rasional:

Misalkan $n = \dfrac{1}{2}\left(\sqrt{k + 4\sqrt{m}} - \sqrt{k}\right)$ adalah bilangan bulat. Karena $m \ge 1$, maka $\sqrt{k + 4\sqrt{m}} > \sqrt{k}$, sehingga $n \ge 1$ (khususnya $n \ne 0$).

Susun ulang dan kuadratkan kedua ruas:

$$\sqrt{k + 4\sqrt{m}} = 2n + \sqrt{k}$$ $$k + 4\sqrt{m} = 4n^2 + 4n\sqrt{k} + k \implies \sqrt{m} = n^2 + n\sqrt{k}$$

Kuadratkan sekali lagi kedua ruas:

$$m = n^4 + 2n^3\sqrt{k} + kn^2 \implies \sqrt{k} = \frac{m - n^4 - kn^2}{2n^3}$$

Karena $k, m, n$ semuanya bilangan bulat dengan $n \ne 0$, ruas kanan merupakan hasil bagi dua bilangan bulat dengan penyebut tak nol, sehingga $\sqrt{k} \in \mathbb{Q}$. $\blacksquare$

b. Membuktikan $\sqrt{k}$ bilangan asli:

Dari bagian (a), tulis $\sqrt{k} = \dfrac{p}{q}$ dalam bentuk pecahan paling sederhana, dengan $p, q \in \mathbb{N}$ dan $\text{FPB}(p, q) = 1$. Kuadratkan kedua ruas:

$$k = \frac{p^2}{q^2} \implies kq^2 = p^2$$

Karena $\text{FPB}(p, q) = 1$, maka $\text{FPB}(p^2, q^2) = 1$. Agar $\dfrac{p^2}{q^2} = k$ berupa bilangan bulat, penyebutnya haruslah $q^2 = 1$, yang berarti $q = 1$. Akibatnya $\sqrt{k} = p$, suatu bilangan asli. $\blacksquare$

Terbukti bahwa $\sqrt{k}$ merupakan bilangan rasional sekaligus bilangan asli.
Diberikan $n$ adalah bilangan asli. Misalkan $x = 6 + 2009\sqrt{n}$. Jika $\dfrac{x^{2009} - x}{x^3 - x}$ merupakan bilangan rasional, tunjukkan bahwa $n$ merupakan kuadrat dari suatu bilangan asli.
Sumber: OSP SMA 2009 (Bagian Kedua No. 2)
Pembahasan:

Sederhanakan menjadi $\dfrac{x^{2008} - 1}{x^2 - 1} = \dfrac{a}{b} \in \mathbb{Q}$. Tulis $x^k = p_k + q_k\sqrt{n}$ dengan $p_k, q_k \in \mathbb{N}$ ($q_k > 0$).

Maka $b(p_{2008} - 1) - a(p_2 - 1) = (aq_2 - bq_{2008})\sqrt{n}$. Karena rasio $(p_{2008} - 1)/(p_2 - 1)$ tidak sama dengan $q_{2008}/q_2$, maka $\sqrt{n}$ harus rasional. Karena $n \in \mathbb{N}$ dan $\sqrt{n} \in \mathbb{Q}$, maka $n$ adalah kuadrat bilangan asli. $\blacksquare$

Terbukti bahwa $n$ merupakan kuadrat dari suatu bilangan asli.
Jika $(\sqrt{2012} + \sqrt{2011})^2 = n + r$ dengan $n$ merupakan bilangan asli dan $0 \le r < 1$, maka $r = \cdots$
Sumber: OSK SMA 2012 (No. 9)
Pembahasan:

Jabarkan kuadratnya: $(\sqrt{2012} + \sqrt{2011})^2 = 4023 + 2\sqrt{2011 \cdot 2012}$.

Perhatikan ketaksamaan:

$$2011^2 < 2011 \cdot 2012 < 2011 \cdot 2012 + \frac{1}{4} = \left(2011 + \frac{1}{2}\right)^2$$

Dengan mengambil akar kuadrat lalu mengalikan dengan $2$, diperoleh $4022 < 2\sqrt{2011 \cdot 2012} < 4023$, sehingga bagian bulatnya adalah $n = 4023 + 4022 = 8045$.

Jadi, $r = \mathbf{(\sqrt{2012} + \sqrt{2011})^2 - 8045}$.
Diketahui $H$ adalah himpunan semua bilangan asli kurang dari $2012$ yang faktor primanya tidak lebih dari $3$. Selanjutnya didefinisikan himpunan $$S = \left\{\frac{1}{n} \;\middle|\; n \in H\right\}$$ Jika $x$ merupakan hasil penjumlahan dari semua anggota $S$ dan $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang kurang dari atau sama dengan $x$, maka $\lfloor x \rfloor = \cdots$
Sumber: OSP SMA 2012 (No. 14)
Pembahasan:

Karena $x < \sum_{a=0}^\infty \sum_{b=0}^\infty \frac{1}{2^a 3^b} = 2 \cdot \frac{3}{2} = 3$ dan jumlah suku dengan $b \in \{0, 1\}$ saja sudah melebihi $2$, maka $2 < x < 3 \implies \lfloor x \rfloor = 2$.

Jadi, nilai $\lfloor x \rfloor$ adalah $2$.

Diketahui $a$ dan $b$ adalah bilangan riil positif sehingga $a + \sqrt{ab}$ dan $b + \sqrt{ab}$ rasional. Buktikan bahwa $a$ dan $b$ rasional.
Sumber: OSP SMA 2016 (No. 21)
Pembahasan:

Karena $a, b > 0$ dan $a + \sqrt{ab}, b + \sqrt{ab} \in \mathbb{Q}^+$, hasil baginya juga bilangan rasional positif:

$$p = \frac{a + \sqrt{ab}}{b + \sqrt{ab}} = \frac{\sqrt{a}(\sqrt{a} + \sqrt{b})}{\sqrt{b}(\sqrt{b} + \sqrt{a})} = \frac{\sqrt{a}}{\sqrt{b}} \in \mathbb{Q}^+$$

Maka $\sqrt{a} = p\sqrt{b}$, sehingga $\sqrt{ab} = p b$. Substitusikan ke $b + \sqrt{ab} \in \mathbb{Q}$:

$$b + pb = b(1 + p) \in \mathbb{Q} \implies b = \frac{b + \sqrt{ab}}{1 + p} \in \mathbb{Q}$$

Karena $b \in \mathbb{Q}$ dan $p \in \mathbb{Q}$, maka $a = p^2 b \in \mathbb{Q}$ juga.

Terbukti bahwa $a$ dan $b$ merupakan bilangan rasional.

Misalkan $x$ dan $y$ adalah bilangan-bilangan real yang memenuhi persamaan $$x^2 y^2 + 4x^2 + y^2 + 1 = 6xy$$ Jika $M$ dan $m$ berturut-turut menyatakan nilai terbesar dan nilai terkecil yang mungkin dari $x - y$, maka nilai dari $M - m$ adalah $\cdots$
Sumber: OSP SMA 2017 (No. 9)
Pembahasan:

Pindahkan $6xy$ ke ruas kiri dan kelompokkan menjadi dua kuadrat sempurna:

$$(x^2 y^2 - 2xy + 1) + (4x^2 - 4xy + y^2) = 0 \iff (xy - 1)^2 + (2x - y)^2 = 0$$

Diperoleh $xy = 1$ dan $y = 2x$, sehingga $2x^2 = 1 \implies x = \pm \dfrac{1}{\sqrt{2}}$ dan $y = \pm \sqrt{2}$.

Maka $x - y = \pm\left(\dfrac{1}{\sqrt{2}} - \sqrt{2}\right) = \mp \dfrac{1}{\sqrt{2}}$, sehingga $M = \dfrac{1}{\sqrt{2}}$ dan $m = -\dfrac{1}{\sqrt{2}}$, dan $M - m = \dfrac{2}{\sqrt{2}} = \sqrt{2}$.

Jadi, nilai dari $M - m$ adalah $\sqrt{2}$.
