Ringkasan dan penjelasan lengkap materi Pertidaksamaan Bentuk Aljabar

1. Pengertian & Sifat-Sifat Dasar Pertidaksamaan Aljabar

Pertidaksamaan Aljabar adalah kalimat terbuka matematika yang menyatakan hubungan ketaksamaan antara dua ekspresi aljabar dengan menggunakan lambang-lambang relasi: kurang dari ($<$), kurang dari atau sama dengan ($\le$), lebih dari ($>$), atau lebih dari atau sama dengan ($\ge$).

Himpunan semua nilai pengganti variabel yang menjadikan pertidaksamaan bernilai benar disebut Himpunan Penyelesaian (HP).

Sifat-Sifat Utama Relasi Ketaksamaan

Untuk setiap bilangan real $a, b, c, d \in \mathbb{R}$, berlaku kaidah-kaidah aljabar berikut:

  1. Sifat Trikotomi: Untuk setiap dua bilangan real $a$ dan $b$, tepat satu relasi berikut yang benar: $a < b$, $a = b$, atau $a > b$.
  2. Sifat Transitif: Jika $a < b$ dan $b < c$, maka $a < c$.
  3. Penjumlahan & Pengurangan: Menambahkan atau mengurangkan kedua ruas dengan bilangan real yang sama tidak akan pernah mengubah arah tanda ketaksamaan: $$a < b \iff a + c < b + c \quad \text{dan} \quad a - c < b - c$$
  4. Perkalian & Pembagian dengan Bilangan Positif: Jika kedua ruas dikalikan atau dibagi dengan bilangan positif ($c > 0$), tanda ketaksamaan tetap: $$a < b \quad \text{dan} \quad c > 0 \implies ac < bc \quad \text{dan} \quad \frac{a}{c} < \frac{b}{c}$$
  5. Perkalian & Pembagian dengan Bilangan Negatif: Jika kedua ruas dikalikan atau dibagi dengan bilangan negatif ($c < 0$), tanda ketaksamaan wajib dibalik: $$a < b \quad \text{dan} \quad c < 0 \implies ac > bc \quad \text{dan} \quad \frac{a}{c} > \frac{b}{c}$$
  6. Sifat Pembalikan (Inversi Pecahan): Jika $a$ dan $b$ mempunyai tanda yang sama (keduanya positif atau keduanya negatif) dan $a < b$, maka: $$\frac{1}{a} > \frac{1}{b}$$ Perhatian: Jika $a$ dan $b$ berlawanan tanda ($a < 0 < b$), maka $\frac{1}{a} < 0 < \frac{1}{b}$ sehingga arah tanda ketaksamaan tidak berbalik.

Peringatan Fatal dalam Aljabar: Jangan pernah mengalikan silang pertidaksamaan dengan suatu variabel atau ekspresi yang tandanya belum dipastikan (apakah positif atau negatif). Perkalian silang variabel tanpa analisis tanda dapat menghilangkan solusi atau membalik arah ketaksamaan secara keliru.

Notasi Interval (Selang) & Representasi Garis Bilangan

Solusi pertidaksamaan umumnya direpresentasikan dalam bentuk interval himpunan bilangan real:

  • Interval Terbuka $(a, b)$: $\{x \in \mathbb{R} \mid a < x < b\}$. Pada garis bilangan digambarkan dengan bulatan kosong ($\circ$) di kedua ujungnya.
  • Interval Tertutup $[a, b]$: $\{x \in \mathbb{R} \mid a \le x \le b\}$. Pada garis bilangan digambarkan dengan bulatan penuh ($\bullet$) di kedua ujungnya.
  • Interval Setengah Terbuka $[a, b)$ atau $(a, b]$: Salah satu batas bersifat inklusif ($\bullet$) dan batas lainnya eksklusif ($\circ$).
  • Interval Tak Hingga: $(-\infty, b] = \{x \mid x \le b\}$ atau $(a, \infty) = \{x \mid x > a\}$. Simbol $\pm \infty$ selalu berpasangan dengan kurung biasa.

2. Pertidaksamaan Kuadrat Satu Variabel (PtKV)

Bentuk baku pertidaksamaan kuadrat dalam variabel $x$ adalah: $$ax^2 + bx + c \gtrless 0 \quad (a \neq 0)$$

Prosedur standar penentuan himpunan penyelesaian:

  1. Nol-kan ruas kanan sehingga seluruh suku berada di ruas kiri.
  2. Pastikan koefisien $a > 0$ (jika negatif, kalikan kedua ruas dengan $-1$ dan balikkan tanda ketaksamaan).
  3. Tentukan pembuat nol fungsi kuadrat melalui pemfaktoran atau rumus kuadrat: $$ax^2 + bx + c = 0 \implies x_1, x_2$$
  4. Plot nilai $x_1$ dan $x_2$ pada garis bilangan real, membagi garis menjadi 3 interval.
  5. Lakukan uji tanda (test point) pada salah satu selang, atau gunakan kaidah pola tanda parabola:
    • Untuk $a > 0$, tanda selang di sebelah luar pembuat nol bertanda positif $(+)$, dan selang di antara pembuat nol bertanda negatif $(-)$.
    • Bentuk $ax^2 + bx + c \le 0 \implies x_1 \le x \le x_2$ (selang di antara dua pembuat nol).
    • Bentuk $ax^2 + bx + c \ge 0 \implies x \le x_1 \text{ atau } x \ge x_2$ (dua selang di luar pembuat nol).

Visualisasi Garis Bilangan PtKV

Perhatikan contoh pertidaksamaan kuadrat: $$(x + 2)(x - 3) \le 0$$ Pembuat nol berada pada $x_1 = -2$ dan $x_2 = 3$. Karena tanda ketaksamaan memuat tanda sama dengan ($\le$), kedua titik ujung diberi bulatan penuh.

Uji titik $x = 0$: $(0 + 2)(0 - 3) = -6 < 0$ (daerah tengah bernilai negatif).

Karena yang diminta adalah $\le 0$ (daerah bertanda negatif atau nol), maka daerah penyelesaian adalah interval tertutup di antara $-2$ dan $3$: $$\text{HP} = [-2, 3] = \{x \in \mathbb{R} \mid -2 \le x \le 3\}$$

Konsep Definit: Diskriminan $D < 0$

Jika suatu bentuk kuadrat $ax^2 + bx + c$ memiliki diskriminan $D = b^2 - 4ac < 0$, maka bentuk kuadrat tersebut tidak memiliki pembuat nol real (kurva parabolanya tidak pernah memotong sumbu-$X$). Kondisi ini dinamakan definit:

  • Definit Positif ($a > 0 \land D < 0$): Nilai $ax^2 + bx + c > 0$ selalu positif untuk setiap $x \in \mathbb{R}$. Bentuk definit positif dapat langsung dieliminasi/dibagi dari kedua ruas pertidaksamaan tanpa membalik arah tanda.
  • Definit Negatif ($a < 0 \land D < 0$): Nilai $ax^2 + bx + c < 0$ selalu negatif untuk setiap $x \in \mathbb{R}$. Bentuk ini dapat dieliminasi asalkan arah tanda ketaksamaan dibalik.

3. Pertidaksamaan Polinomial & Kaidah Multiplisitas Akar

Untuk pertidaksamaan berderajat tinggi yang telah difaktorkan menjadi faktor-faktor linear: $$P(x) = (x - r_1)^{k_1}(x - r_2)^{k_2}\dots(x - r_m)^{k_m} \gtrless 0$$ Arah perubahan tanda pada garis bilangan ditentukan oleh derajat multiplisitas (pangkat) dari masing-masing faktor:

  • Faktor Berpangkat Ganjil ($k_i = 1, 3, 5, \dots$): Kurva nilai fungsi menembus sumbu-$X$, sehingga tanda daerah pada garis bilangan berganti ($+ \longleftrightarrow -$) saat melewati titik kritis $r_i$.
  • Faktor Berpangkat Genap ($k_i = 2, 4, 6, \dots$): Karena $(x - r)^{2k} \ge 0$ untuk setiap $x \in \mathbb{R}$, kurva hanya menyinggung / memantul pada sumbu-$X$. Akibatnya, tanda daerah di sebelah kiri dan kanan titik kritis $r_i$ tetap sama ($+ \longrightarrow +$ atau $- \longrightarrow -$).

Perhatian pada Akar Berpangkat Genap: Jika pertidaksamaan bertanda $\le 0$ atau $\ge 0$, pembuat nol berpangkat genap tetap merupakan penyelesaian yang sah ($0 = 0$). Jangan sampai titik kritis terisolasi tersebut terhapus dari himpunan penyelesaian!

4. Pertidaksamaan Rasional (Bentuk Pecahan Aljabar)

Pertidaksamaan rasional adalah pertidaksamaan di mana variabel aljabar berada di dalam penyebut: $$\frac{P(x)}{Q(x)} \gtrless 0$$

Aturan Baku Penyelesaian Pertidaksamaan Rasional

  1. Jadikan ruas kanan sama dengan $0$: Jika ruas kanan berupa konstanta $C$, pindahkan ke ruas kiri: $\frac{P(x)}{Q(x)} - C \gtrless 0$, lalu samakan penyebut.
  2. Faktorkan pembilang dan penyebut secara tuntas hingga menjadi faktor-faktor linear atau kuadrat definit.
  3. Syarat Mutlak Penyebut ($Q(x) \neq 0$): Penyebut pecahan tidak boleh sama dengan nol karena pembagian dengan nol tidak terdefinisi. Oleh karena itu, semua pembuat nol dari penyebut selalu berupa bulatan kosong ($\circ$) pada garis bilangan, meskipun pertidaksamaan awal bertanda $\le$ atau $\ge$.
  4. Plot semua titik kritis pembilang dan penyebut pada satu garis bilangan terpadu, lalu tentukan tanda tiap daerah selang.

5. Pertidaksamaan Irasional (Bentuk Akar)

Pertidaksamaan irasional memuat variabel di bawah tanda radikal/akar: $\sqrt{f(x)}$. Karena akar pangkat dua dalam sistem bilangan real hanya terdefinisi untuk bilangan non-negatif, langkah awal wajib adalah memeriksa syarat terdefinisi (syarat numerus/radikan): $$f(x) \ge 0$$

Tiga Tipe Pokok Pertidaksamaan Irasional

  1. Tipe $\sqrt{f(x)} < \sqrt{g(x)}$: Kedua ruas bernilai non-negatif. Kuadratkan kedua ruas dengan mempertahankan syarat numerus: $$\begin{cases} f(x) \ge 0 \\ g(x) \ge 0 \\ f(x) < g(x) \end{cases} \iff \begin{cases} f(x) \ge 0 \\ f(x) < g(x) \end{cases} \quad (\text{karena } g(x) > f(x) \ge 0)$$
  2. Tipe $\sqrt{f(x)} < g(x)$: Karena ruas kiri $\ge 0$, maka ruas kanan $g(x)$ wajib bernilai positif ($g(x) > 0$). Kuadratkan kedua ruas: $$\begin{cases} f(x) \ge 0 \\ g(x) > 0 \\ f(x) < [g(x)]^2 \end{cases}$$ Himpunan penyelesaian adalah irisan ($\cap$) dari ketiga syarat tersebut.
  3. Tipe $\sqrt{f(x)} > g(x)$: Tipe ini harus dianalisis melalui dua cabang terpisah (gabungan / union $\cup$):
    • Kasus A ($g(x) < 0$): Ruas kanan negatif. Selama $f(x) \ge 0$, ruas kiri yang bernilai non-negatif selalu lebih besar daripada ruas kanan yang negatif. $$\text{HP}_A = \{x \mid f(x) \ge 0 \land g(x) < 0\}$$
    • Kasus B ($g(x) \ge 0$): Kedua ruas non-negatif, sehingga sah untuk dikuadratkan: $$\text{HP}_B = \{x \mid g(x) \ge 0 \land f(x) > [g(x)]^2\}$$
    Himpunan penyelesaian total adalah: $\text{HP} = \text{HP}_A \cup \text{HP}_B$.

6. Interpretasi Geometris Solusi Aljabar

Menyelesaikan pertidaksamaan aljabar $f(x) \le g(x)$ secara geometri ekuivalen dengan mencari interval absis $x$ di mana grafik kurva $y = f(x)$ berada di bawah atau berpotongan dengan grafik $y = g(x)$.

Contoh grafis pada gambar di samping: $$x^2 - 2x - 3 \le x + 1$$ Ekuivalen dengan $x^2 - 3x - 4 \le 0 \implies (x - 4)(x + 1) \le 0$.

Kedua kurva berpotongan pada absis $x = -1$ dan $x = 4$. Di antara kedua titik tersebut, kurva parabola biru $y = x^2 - 2x - 3$ terletak di bawah garis hijau $y = x + 1$.

Proyeksi daerah tersebut ke sumbu-$X$ menghasilkan interval solusi: $$\text{HP} = [-1, 4] = \{x \in \mathbb{R} \mid -1 \le x \le 4\}$$

7. Contoh Soal Berjenjang & Pembahasan Lengkap

Contoh 1: Pertidaksamaan Kuadrat (Tingkat Dasar)
Tentukan himpunan penyelesaian dari pertidaksamaan kuadrat berikut: $$2x^2 - 5x - 3 \ge 0$$
Pembahasan:
Langkah 1: Menentukan Pembuat Nol
Faktorkan persamaan kuadrat $2x^2 - 5x - 3 = 0$: $$\begin{aligned} 2x^2 - 5x - 3 &= 0 \\ (2x + 1)(x - 3) &= 0 \end{aligned}$$ Diperoleh dua pembuat nol: $$2x + 1 = 0 \implies x_1 = -\frac{1}{2}$$ $$x - 3 = 0 \implies x_2 = 3$$
Langkah 2: Uji Titik pada Garis Bilangan
Titik $x_1 = -\frac{1}{2}$ dan $x_2 = 3$ membagi sumbu bilangan real menjadi tiga interval:
  • Interval $x < -\frac{1}{2}$ (misal $x = -1$): $(2(-1) + 1)(-1 - 3) = (-1)(-4) = +4 > 0$ (Positif).
  • Interval $-\frac{1}{2} < x < 3$ (misal $x = 0$): $(2(0) + 1)(0 - 3) = (1)(-3) = -3 < 0$ (Negatif).
  • Interval $x > 3$ (misal $x = 4$): $(2(4) + 1)(4 - 3) = (9)(1) = +9 > 0$ (Positif).

Langkah 3: Menentukan Daerah Penyelesaian
Karena tanda pertidaksamaan adalah $\ge 0$ (positif atau nol), maka daerah yang memenuhi adalah interval di mana nilai fungsi bertanda positif, termasuk titik-titik pembuat nolnya: $$x \le -\frac{1}{2} \quad \text{atau} \quad x \ge 3$$
Jadi, himpunan penyelesaiannya adalah: $$\text{HP} = \left\{x \in \mathbb{R} \;\middle|\; x \le -\frac{1}{2} \text{ atau } x \ge 3\right\} = \left(-\infty, -\frac{1}{2}\right] \cup [3, \infty)$$
Contoh 2: Pertidaksamaan Pecahan Rasional (Tingkat SNBT)
Tentukan himpunan penyelesaian dari pertidaksamaan pecahan berikut: $$\frac{3x - 2}{x - 3} \le 2$$ Berapa banyak bilangan bulat non-negatif $x$ yang memenuhi pertidaksamaan tersebut?
Pembahasan:
Langkah 1: Pindahkan Semua Suku ke Ruas Kiri
Ingat: Jangan pernah kali silang dengan $(x - 3)$ karena tandanya dapat bernilai positif atau negatif tergantung nilai $x$! $$\begin{aligned} \frac{3x - 2}{x - 3} - 2 &\le 0 \\ \frac{3x - 2 - 2(x - 3)}{x - 3} &\le 0 \\ \frac{3x - 2 - 2x + 6}{x - 3} &\le 0 \\ \frac{x + 4}{x - 3} &\le 0 \end{aligned}$$
Langkah 2: Tentukan Titik Kritis & Syarat Penyebut
  • Pembuat nol pembilang: $x + 4 = 0 \implies x = -4$. Karena pertidaksamaan bertanda $\le$, titik $x = -4$ masuk ke dalam penyelesaian (bulatan penuh $\bullet$).
  • Pembuat nol penyebut: $x - 3 = 0 \implies x = 3$. Syarat mutlak pecahan adalah penyebut tidak boleh nol ($x - 3 \neq 0 \implies x \neq 3$), sehingga titik $x = 3$ tidak boleh masuk ke dalam penyelesaian (bulatan kosong $\circ$).

Langkah 3: Uji Tanda Interval
Titik $x = -4$ dan $x = 3$ membagi garis bilangan menjadi tiga daerah:
  • Untuk $x < -4$ (misal $x = -5$): $\frac{-5 + 4}{-5 - 3} = \frac{-1}{-8} = +\frac{1}{8} > 0$ (+).
  • Untuk $-4 < x < 3$ (misal $x = 0$): $\frac{0 + 4}{0 - 3} = -\frac{4}{3} < 0$ (–).
  • Untuk $x > 3$ (misal $x = 4$): $\frac{4 + 4}{4 - 3} = \frac{8}{1} = +8 > 0$ (+).
Karena diminta $\le 0$, maka interval penyelesaiannya adalah: $$-4 \le x < 3$$
Langkah 4: Menghitung Banyak Bilangan Bulat Non-Negatif
Bilangan bulat non-negatif adalah bilangan bulat yang nilainya $\ge 0$.
Bilangan bulat pada interval $[-4, 3)$ adalah: $\{-4, -3, -2, -1, 0, 1, 2\}$.
Di antara bilangan-bilangan tersebut, yang bernilai non-negatif adalah: $$x \in \{0, 1, 2\}$$ Terdapat $3$ bilangan bulat non-negatif.
Himpunan penyelesaian: $\text{HP} = \{x \in \mathbb{R} \mid -4 \le x < 3\} = [-4, 3)$.
Banyak bilangan bulat non-negatif yang memenuhi adalah 3 bilangan ($0, 1, 2$).
Contoh 3: Pertidaksamaan Irasional Bercabang (Tingkat HOTS)
Tentukan seluruh nilai bilangan real $x$ yang memenuhi pertidaksamaan irasional berikut: $$\sqrt{2x + 6} > x + 1$$
Pembahasan:
Langkah 1: Syarat Numerus (Bentuk di Bawah Akar)
Bentuk akar $\sqrt{2x + 6}$ harus terdefinisi pada bilangan real: $$2x + 6 \ge 0 \implies 2x \ge -6 \implies x \ge -3 \quad \text{--- (Syarat Utama)}$$
Langkah 2: Analisis Dua Kasus Ruas Kanan
Karena tanda ketaksamaan adalah $>$, kita membagi persoalan menjadi dua kemungkinan berdasarkan tanda dari ruas kanan $x + 1$:

KASUS A: Ruas kanan bernilai negatif ($x + 1 < 0 \implies x < -1$)
Jika $x < -1$ dan memenuhi syarat utama $x \ge -3$, maka:
  • Ruas kiri $\sqrt{2x + 6} \ge 0$ (bernilai non-negatif).
  • Ruas kanan $x + 1 < 0$ (bernilai negatif).
Suatu bilangan non-negatif selalu lebih besar daripada bilangan negatif untuk sembarang nilai $x$ yang memenuhi syarat numerus.
Maka penyelesaian Kasus A adalah irisan dari $x \ge -3$ dan $x < -1$: $$\text{HP}_A = [-3, -1) = \{x \in \mathbb{R} \mid -3 \le x < -1\}$$
KASUS B: Ruas kanan bernilai non-negatif ($x + 1 \ge 0 \implies x \ge -1$)
Karena kedua ruas sudah dipastikan bernilai non-negatif, kita dapat menguadratkan kedua ruas tanpa mengubah arah tanda: $$\begin{aligned} \left(\sqrt{2x + 6}\right)^2 &> (x + 1)^2 \\ 2x + 6 &> x^2 + 2x + 1 \\ 0 &> x^2 - 5 \iff x^2 - 5 < 0 \\ (x + \sqrt{5})(x - \sqrt{5}) &< 0 \end{aligned}$$ Pembuat nol adalah $x = -\sqrt{5}$ dan $x = \sqrt{5}$. Karena koefisien $x^2 > 0$ dan tandanya $< 0$, interval penyelesaian kuadratnya adalah: $$-\sqrt{5} < x < \sqrt{5}$$ Iriskan hasil kuadrat tersebut dengan syarat Kasus B ($x \ge -1$):
Karena $-\sqrt{5} \approx -2,236 < -1$, maka irisan antara $x \ge -1$ dan $-\sqrt{5} < x < \sqrt{5}$ adalah: $$\text{HP}_B = [-1, \sqrt{5}) = \{x \in \mathbb{R} \mid -1 \le x < \sqrt{5}\}$$
Langkah 3: Menggabungkan Kasus A dan Kasus B ($\text{HP} = \text{HP}_A \cup \text{HP}_B$)
Gabungan dari interval $[-3, -1)$ dan $[-1, \sqrt{5})$ bersambung tepat di titik $x = -1$: $$\text{HP} = [-3, -1) \cup [-1, \sqrt{5}) = [-3, \sqrt{5})$$
Jadi, semua nilai bilangan real $x$ yang memenuhi pertidaksamaan tersebut adalah: $$\text{HP} = \{x \in \mathbb{R} \mid -3 \le x < \sqrt{5}\} = [-3, \sqrt{5})$$
