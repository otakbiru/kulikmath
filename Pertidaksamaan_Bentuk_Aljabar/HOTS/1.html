Buktikan bahwa jika \(x\) dan \(y\) adalah bilangan positif dan \(xy = 1\), maka \(x + y \ge 2\).
Grup WhatsApp
Pembahasan:
Karena setiap bilangan real yang dikuadratkan selalu bernilai non-negatif, maka: \[\begin{aligned} \left(\sqrt{x}-\sqrt{y}\right)^2&\geq0\\[4pt] x-2\sqrt{xy}+y&\geq0\\[4pt] x+y&\geq2\sqrt{xy}\\[4pt] x+y&\geq2\sqrt{1}\\[4pt] x+y&\geq2(1)\\[4pt] x+y&\geq2 \end{aligned}\]
Jadi, terbukti bahwa jika \(x\) dan \(y\) adalah bilangan positif dan \(xy = 1\), maka \(x + y \ge 2\).
Buktikan bahwa: \[\dfrac1{10\sqrt2}\lt\dfrac12\times\dfrac34\times\dfrac56\times\cdots\times\dfrac{99}{100}\lt\dfrac1{10}\]
Grup WhatsApp
Pembahasan:
Misal \(a = \dfrac12\times\dfrac34\times\dfrac56\times\cdots\times\dfrac{99}{100}\).

Bagian 1: Membuktikan \(a \gt \dfrac1{10\sqrt2}\)
\(\begin{aligned} a^2&=\dfrac{1^2}{2^2}\times\dfrac{3^2}{4^2}\times\dfrac{5^2}{6^2}\times\cdots\times\dfrac{99^2}{100^2}\\[8pt] &=\dfrac1{2\cdot2}\times\dfrac{3^2}{4\cdot4}\times\dfrac{5^2}{6\cdot6}\times\cdots\times\dfrac{99^2}{100\cdot100}\\[8pt] &=\dfrac12\times\dfrac{3^2}{2\cdot4}\times\dfrac{5^2}{4\cdot6}\times\cdots\times\dfrac{99^2}{98\cdot100}\times\dfrac1{100} \end{aligned}\)

Perhatikan bahwa untuk setiap \(n \gt 1\): \[\dfrac{n^2}{(n-1)(n+1)}=\dfrac{n^2}{n^2-1}\gt1\] Sehingga: \(\begin{aligned} a^2&=\dfrac12\times\dfrac{3^2}{2\cdot4}\times\dfrac{5^2}{4\cdot6}\times\cdots\times\dfrac{99^2}{98\cdot100}\times\dfrac1{100}\\[8pt] &\gt\dfrac12\times1\times1\times\cdots\times1\times\dfrac1{100}\\[8pt] &\gt\dfrac1{200}\\[8pt] a&\gt\dfrac1{\sqrt{200}}=\dfrac1{10\sqrt2}\\[8pt] \dfrac1{10\sqrt2}&\lt a \qquad \color{red}{(1)} \end{aligned}\)

Bagian 2: Membuktikan \(a \lt \dfrac1{10}\)
\(\begin{aligned} a^2&=\dfrac{1^2}{2^2}\times\dfrac{3^2}{4^2}\times\dfrac{5^2}{6^2}\times\cdots\times\dfrac{99^2}{100^2}\\[8pt] &=\dfrac1{2^2}\times\dfrac{3\cdot3}{4^2}\times\dfrac{5\cdot5}{6^2}\times\cdots\times\dfrac{99\cdot99}{100^2}\\[8pt] &=\dfrac{1\cdot3}{2^2}\times\dfrac{3\cdot5}{4^2}\times\dfrac{5\cdot7}{6^2}\times\cdots\times\dfrac{97\cdot99}{98^2}\times\dfrac{99}{100}\cdot\dfrac1{100} \end{aligned}\)

Perhatikan bahwa \(\dfrac{(n-1)(n+1)}{n^2}=\dfrac{n^2-1}{n^2}\lt1\) dan \(\dfrac{99}{100}\lt1\). Maka: \(\begin{aligned} a^2&\lt1\times1\times1\times\cdots\times1\times1\cdot\dfrac1{100}\\[8pt] &\lt\dfrac1{100}\\[8pt] a&\lt\dfrac1{10} \qquad \color{red}{(2)} \end{aligned}\)

Dari pertidaksamaan (1) dan (2) diperoleh: \[\dfrac1{10\sqrt2}\lt a\lt\dfrac1{10}\]
Jadi, terbukti bahwa \(\dfrac1{10\sqrt2}\lt\dfrac12\times\dfrac34\times\dfrac56\times\cdots\times\dfrac{99}{100}\lt\dfrac1{10}\).
Buktikan bahwa \(999! \lt 500^{999}\).

[Catatan: \(n! = 1 \times 2 \times 3 \times \dots \times n\).]
OSP SMA 2003 (Bagian II No. 4)
Pembahasan:

Pasangkan faktor-faktor perkalian pada \(999!\) secara simetris terhadap suku tengah \(500\), yakni \((1 \cdot 999), (2 \cdot 998), \dots, (499 \cdot 501)\):

\[\begin{aligned} 999! &= 500 \cdot \prod_{k=1}^{499} (500 - k)(500 + k) \\ &= 500 \cdot (500^2 - 1^2)(500^2 - 2^2) \cdots (500^2 - 499^2) \end{aligned}\]

Untuk setiap \(k \in \{1, 2, \dots, 499\}\), karena \(1 \le k \lt 500\), berlaku ketaksamaan tegas bilangan positif:

\[0 \lt 500^2 - k^2 \lt 500^2\]

Kalikan seluruh \(499\) pertidaksamaan positif tersebut lalu kalikan dengan \(500 \gt 0\):

\[\begin{aligned} 999! &\lt 500 \cdot \underbrace{500^2 \cdot 500^2 \cdots 500^2}_{499\text{ faktor}} \\ &= 500 \cdot (500^2)^{499} \\ &= 500^{1 + 998} = 500^{999} \qquad \blacksquare \end{aligned}\]
Jadi, terbukti bahwa \(999! \lt 500^{999}\).
Untuk sebarang bilangan real \(a, b, c\) buktikan ketaksamaan \[5a^2 + 5b^2 + 5c^2 \ge 4ab + 4ac + 4bc\] dan tentukan kapan kesamaan berlaku.
OSN SMA 2003 (Hari II No. 5)
Pembahasan:

Pindahkan seluruh suku ke ruas kiri dan nyatakan selisihnya sebagai jumlah kuadrat-kuadrat bilangan real:

\[\begin{aligned} (5a^2 + 5b^2 + 5c^2) - (4ab + 4ac + 4bc) &= (a^2 + b^2 + c^2) + 2\big((2a^2 + 2b^2 + 2c^2) - 2ab - 2bc - 2ca\big) \\ &= a^2 + b^2 + c^2 + 2\big((a - b)^2 + (b - c)^2 + (c - a)^2\big) \end{aligned}\]

Karena kuadrat setiap bilangan real selalu tak negatif, yakni \(a^2 \ge 0\), \(b^2 \ge 0\), \(c^2 \ge 0\), \((a - b)^2 \ge 0\), \((b - c)^2 \ge 0\), dan \((c - a)^2 \ge 0\), maka ruas kanan selalu lebih besar atau sama dengan \(0\). Jadi:

\[5a^2 + 5b^2 + 5c^2 \ge 4ab + 4ac + 4bc\]

Syarat kesamaan:

Jumlah beberapa bilangan tak negatif bernilai nol jika dan hanya jika setiap sukunya bernilai nol, yaitu:

\[a^2 = b^2 = c^2 = 0 \quad \text{dan} \quad a - b = b - c = c - a = 0\]

Kondisi tersebut dipenuhi jika dan hanya jika \(a = b = c = 0\). \(\blacksquare\)

Jadi, ketaksamaan terbukti berlaku untuk semua bilangan real \(a, b, c\), dan kesamaan terjadi jika dan hanya jika \(a = b = c = 0\).
Misalkan $a, b, c$ bilangan-bilangan real positif yang memenuhi ketaksamaan $$5(a^2 + b^2 + c^2) < 6(ab + bc + ca).$$ Buktikan bahwa ketiga ketaksamaan berikut berlaku: $a + b > c$, $b + c > a$, dan $c + a > b$.
Sumber: OSN SMA 2007 (Hari Pertama - No. 3)
Pembahasan:

Karena ketaksamaan pada soal simetris terhadap $a, b, c$, tanpa mengurangi keumuman misalkan $c = \max(a, b, c)$. Karena $a, b > 0$ dan $c \ge a, b$, otomatis berlaku $b + c > a$ dan $c + a > b$. Kita tinggal membuktikan $a + b > c$.

Ubah bentuk $6(ab + bc + ca) - 5(a^2 + b^2 + c^2) > 0$:

$$\begin{aligned} 6ab + 6bc + 6ca - 5a^2 - 5b^2 - 5c^2 &> 0 \\ (5c - a - b)(a + b - c) - 4(a - b)^2 &> 0 \\ (5c - a - b)(a + b - c) &> (2a - 2b)^2 \ge 0 \end{aligned}$$

Karena $c \ge a$ dan $c \ge b$ serta $a, b, c > 0$, maka $5c - a - b \ge 3c > 0$. Mengingat hasil kali $(5c - a - b)(a + b - c)$ bernilai positif tegas, haruslah:

$$a + b - c > 0 \implies a + b > c$$
Terbukti bahwa ketiga ketaksamaan segitiga $a + b > c$, $b + c > a$, dan $c + a > b$ berlaku.
Didefinisikan $a * b = a + b + ab$ untuk semua bilangan real $a, b$. Jika $S = \{a \text{ bilangan real} \mid a * (-a) > a\}$, tuliskan $S$ sebagai sebuah selang (interval).
Sumber: OSP SMA 2002 (Bagian Pertama - No. 12)
Pembahasan:

Hitung $a * (-a) = a + (-a) + a(-a) = -a^2$. Pertidaksamaannya menjadi:

$$-a^2 > a \iff a^2 + a < 0 \iff a(a + 1) < 0 \iff -1 < a < 0$$
Jadi, $S$ sebagai selang adalah $(-1, 0)$ (yakni $\{a \in \mathbb{R} \mid -1 < a < 0\}$).
Tentukan semua bilangan real $x$ yang memenuhi $x^4 + \dfrac{1}{x^4} \le 2$.
Sumber: OSK SMA 2005 (Bagian Kedua - No. 16)
Pembahasan:

Untuk $x \ne 0$, pindahkan $2$ ke ruas kiri:

$$x^4 - 2 + \frac{1}{x^4} \le 0 \iff \left(x^2 - \frac{1}{x^2}\right)^2 \le 0$$

Karena kuadrat selalu $\ge 0$, wajiblah $x^2 - \dfrac{1}{x^2} = 0 \iff x^4 = 1 \iff x = 1$ atau $x = -1$.

Jadi, semua bilangan real $x$ yang memenuhi adalah $x = 1$ dan $x = -1$.
Diketahui bahwa $a, b, c$ dan $d$ adalah bilangan-bilangan asli yang memenuhi $\dfrac{a}{b} < \dfrac{c}{d}$ dan $c < a$. Jika $b \ne 1$ dan $c \ne d$, maka
  1. $\dfrac{a}{c} < \dfrac{b - a}{d - c}$
  2. $\dfrac{b - a}{d - c} < \dfrac{a}{c}$
  3. $\dfrac{a}{c} < \dfrac{b(d - 1)}{d(b - 1)}$
  4. $\dfrac{b(d - 1)}{d(b - 1)} < \dfrac{a}{c}$
  5. $\dfrac{a + b}{c + d} < \dfrac{a}{c}$
Sumber: OSK SMA 2008 (Bagian Pertama No. 10)
Pembahasan:

Karena $a, b, c, d$ bilangan asli dengan $\dfrac{a}{b} < \dfrac{c}{d}$ dan $c < a$, kita peroleh:

$$\frac{b}{d} > \frac{a}{c} > 1 \implies b > d \ge 1$$

Karena $b > d \ge 1$ dan $b \ne 1$ (sehingga $b \ge 2$), perhatikan bahwa fungsi $g(x) = 1 - \dfrac{1}{x} = \dfrac{x - 1}{x}$ naik monoton pada $x > 0$:

$$\frac{b - 1}{b} = 1 - \frac{1}{b} > 1 - \frac{1}{d} = \frac{d - 1}{d}$$

Bagi kedua ruas dengan $\dfrac{b - 1}{b} > 0$ (atau kalikan silang karena penyebutnya positif):

$$\frac{b(d - 1)}{d(b - 1)} < 1$$

Mengingat $a > c > 0 \implies \dfrac{a}{c} > 1$, diperoleh:

$$\frac{b(d - 1)}{d(b - 1)} < 1 < \frac{a}{c}$$
Jadi, jawabannya adalah D. $\dfrac{b(d - 1)}{d(b - 1)} < \dfrac{a}{c}$.
No. 9
Misalkan $a, b, c$ bilangan real positif. Buktikan ketaksamaan $$\sqrt{\frac{a}{b + c} + \frac{b}{c + a}} + \sqrt{\frac{b}{c + a} + \frac{c}{a + b}} + \sqrt{\frac{c}{a + b} + \frac{a}{b + c}} \ge 3$$
Sumber: OSN SMA 2015 (No. 7)
Pembahasan:

Untuk sebarang bilangan real positif $x, y, z$, kita buktikan ketaksamaan kunci:

$$\sqrt{\frac{y}{z + x} + \frac{z}{x + y}} \ge \frac{2(y + z)(z + 2x + y)}{(z + x)(2y + z + x) + (x + y)(2z + x + y)}$$

Kuadratkan dan kalikan kedua ruas; perhatikan identitas berikut:

$$\left(\frac{y}{z+x} + \frac{z}{x+y}\right)\frac{\bigl((z+x)(2y+z+x)+(x+y)(2z+x+y)\bigr)^2}{(y+z)^2(z+2x+y)^2} - 8\frac{y^2+z^2+xy+xz}{(y+z)(z+2x+y)} = \frac{(y^2+z^2+xy+xz)(2x^2-y^2-z^2)^2}{(z+x)(x+y)(y+z)^2(z+2x+y)^2} \ge 0$$

Padahal, $2\dfrac{y^2 + z^2 + xy + xz}{(y + z)(z + 2x + y)} - 1 = \dfrac{(y - z)^2}{(y + z)(z + 2x + y)} \ge 0$, sehingga suku pengurang $8\dfrac{y^2 + z^2 + xy + xz}{(y + z)(z + 2x + y)} \ge 4$. Ini membuktikan ketaksamaan kunci.

Selanjutnya, misalkan $N(x, y, z) = 2(y + z)(z + 2x + y)$ dan $D(x, y, z) = (z + x)(2y + z + x) + (x + y)(2z + x + y)$. Penjabaran langsung memberi $N(x, y, z) - D(x, y, z) = y^2 + z^2 - 2x^2$, sehingga:

$$\sum_{\text{siklik}} \frac{N(a, b, c)}{D(a, b, c)} = 3 + \sum_{\text{siklik}} \frac{b^2 + c^2 - 2a^2}{D(a, b, c)}$$

Karena $D(a, b, c) = 2a^2 + b^2 + c^2 + 4(ab + bc + ca)$, apabila $a \ge b \ge c$ maka baik $b^2 + c^2 - 2a^2$ maupun $\dfrac{1}{D(a, b, c)}$ terurut sama (menaik/membalik searah). Dengan Ketaksamaan Chebyshev:

$$\sum_{\text{siklik}} \frac{b^2 + c^2 - 2a^2}{D(a, b, c)} \ge \frac{1}{3}\left(\sum_{\text{siklik}} (b^2 + c^2 - 2a^2)\right)\left(\sum_{\text{siklik}} \frac{1}{D(a, b, c)}\right) = 0$$
Terbukti bahwa $\displaystyle \sum_{\text{siklik}} \sqrt{\frac{a}{b + c} + \frac{b}{c + a}} \ge 3$.
No. 10
Misalkan $a, b,$ dan $c$ adalah bilangan-bilangan real yang nilai mutlaknya tidak lebih besar dari $1$. Buktikan bahwa $$\sqrt{|a - b|} + \sqrt{|b - c|} + \sqrt{|c - a|} \le 2 + \sqrt{2}$$
Sumber: OSP SMA 2017 (No. 24)
Pembahasan:

Tanpa mengurangi keumuman, urutkan $-1 \le a \le b \le c \le 1$, dan misalkan $x = b - a \ge 0$ serta $y = c - b \ge 0$, sehingga $c - a = x + y \le 2$.

Dengan Ketaksamaan Cauchy-Schwarz: $\sqrt{x} + \sqrt{y} \le \sqrt{2(x + y)}$. Oleh karena itu:

$$\sqrt{|a - b|} + \sqrt{|b - c|} + \sqrt{|c - a|} = \sqrt{x} + \sqrt{y} + \sqrt{x + y} \le (\sqrt{2} + 1)\sqrt{x + y} \le (\sqrt{2} + 1)\sqrt{2} = 2 + \sqrt{2}$$

(Kesamaan tercapai saat $(a, b, c) = (-1, 0, 1)$.)

Terbukti bahwa $\sqrt{|a - b|} + \sqrt{|b - c|} + \sqrt{|c - a|} \le 2 + \sqrt{2}$.
