Berikut adalah soal tingkat ... materi Pertidaksamaan Bentuk Aljabar

Misalkan $a, b, c$ bilangan-bilangan real positif yang memenuhi ketaksamaan $$5(a^2 + b^2 + c^2) < 6(ab + bc + ca).$$ Buktikan bahwa ketiga ketaksamaan berikut berlaku: $a + b > c$, $b + c > a$, dan $c + a > b$.
Sumber: OSN SMA 2007 (Hari Pertama - No. 3)
Pembahasan:

Karena ketaksamaan pada soal simetris terhadap $a, b, c$, tanpa mengurangi keumuman misalkan $c = \max(a, b, c)$. Karena $a, b > 0$ dan $c \ge a, b$, otomatis berlaku $b + c > a$ dan $c + a > b$. Kita tinggal membuktikan $a + b > c$.

Ubah bentuk $6(ab + bc + ca) - 5(a^2 + b^2 + c^2) > 0$:

$$\begin{aligned} 6ab + 6bc + 6ca - 5a^2 - 5b^2 - 5c^2 &> 0 \\ (5c - a - b)(a + b - c) - 4(a - b)^2 &> 0 \\ (5c - a - b)(a + b - c) &> (2a - 2b)^2 \ge 0 \end{aligned}$$

Karena $c \ge a$ dan $c \ge b$ serta $a, b, c > 0$, maka $5c - a - b \ge 3c > 0$. Mengingat hasil kali $(5c - a - b)(a + b - c)$ bernilai positif tegas, haruslah:

$$a + b - c > 0 \implies a + b > c$$
Terbukti bahwa ketiga ketaksamaan segitiga $a + b > c$, $b + c > a$, dan $c + a > b$ berlaku.
