Jika $$\left(1 - \tan^2\frac{x}{2^{2011}}\right)\left(1 - \tan^2\frac{x}{2^{2010}}\right)\cdots\left(1 - \tan^2\frac{x}{2}\right) = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}}$$ maka $\sin 2x$ adalah $\cdots$
Sumber: OSP SMA 2011 (No. 8)
Pembahasan:

Dari identitas sudut ganda $\tan 2\theta = \dfrac{2\tan\theta}{1 - \tan^2\theta}$, diperoleh $1 - \tan^2\theta = \dfrac{2\tan\theta}{\tan 2\theta}$. Substitusikan ke setiap faktor pada ruas kiri:

$$\frac{2\tan\frac{x}{2^{2011}}}{\tan\frac{x}{2^{2010}}} \cdot \frac{2\tan\frac{x}{2^{2010}}}{\tan\frac{x}{2^{2009}}} \cdots \frac{2\tan\frac{x}{2}}{\tan x} = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}}$$

Secara teleskopik, ruas kiri menyusut menjadi:

$$\frac{2^{2011}\tan\frac{x}{2^{2011}}}{\tan x} = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}} \implies \tan x = \frac{1}{\sqrt{3}}$$

Gunakan identitas $\sin 2x = \dfrac{2\tan x}{1 + \tan^2 x}$:

$$\sin 2x = \frac{2 \cdot \frac{1}{\sqrt{3}}}{1 + \frac{1}{3}} = \frac{\frac{2}{\sqrt{3}}}{\frac{4}{3}} = \frac{\sqrt{3}}{2}$$
Jadi, nilai $\sin 2x$ adalah $\dfrac{1}{2}\sqrt{3}$.
Nilai $\sin^8 75^\circ - \cos^8 75^\circ = \cdots$
Sumber: OSK SMA 2005 (Bagian Kedua - No. 18)
Pembahasan:

Faktorkan dengan selisih kuadrat bertahap:

$$\sin^8 75^\circ - \cos^8 75^\circ = (\sin^4 75^\circ + \cos^4 75^\circ)(1)(-\cos 150^\circ) = \left(1 - \frac{1}{2}\sin^2 150^\circ\right)\left(\frac{\sqrt{3}}{2}\right) = \frac{7}{8} \cdot \frac{\sqrt{3}}{2} = \frac{7}{16}\sqrt{3}$$
Jadi, nilainya adalah $\dfrac{7}{16}\sqrt{3}$.
Diketahui bahwa $a$ dan $b$ adalah besar dua sudut pada sebuah segitiga. Jika $\sin a + \sin b = \dfrac{1}{2}\sqrt{2}$ dan $\cos a + \cos b = \dfrac{1}{2}\sqrt{6}$, maka $\sin(a + b) =$ $\cdots$
Sumber: OSK SMA 2008 (Bagian Kedua No. 20)
Pembahasan:

Kuadratkan dan jumlahkan kedua persamaan:

$$(\sin a + \sin b)^2 + (\cos a + \cos b)^2 = \left(\frac{1}{2}\sqrt{2}\right)^2 + \left(\frac{1}{2}\sqrt{6}\right)^2 = \frac{1}{2} + \frac{3}{2} = 2$$ $$2 + 2(\cos a \cos b + \sin a \sin b) = 2 \implies \cos(a - b) = 0$$

Selanjutnya, kalikan kedua persamaan yang diketahui:

$$(\sin a + \sin b)(\cos a + \cos b) = \frac{1}{2}\sqrt{2} \cdot \frac{1}{2}\sqrt{6} = \frac{1}{2}\sqrt{3}$$ $$\frac{1}{2}(\sin 2a + \sin 2b) + \sin(a + b) = \frac{1}{2}\sqrt{3}$$ $$\sin(a + b)\cos(a - b) + \sin(a + b) = \frac{1}{2}\sqrt{3}$$

Substitusikan $\cos(a - b) = 0$, sehingga diperoleh $\sin(a + b) = \dfrac{1}{2}\sqrt{3}$.

Jadi, nilai $\sin(a + b)$ adalah $\dfrac{1}{2}\sqrt{3}$.
Misalkan $f(y) = (\sqrt{3} + 1)\sin y + (\sqrt{3} - 1)\cos y$. Nilai maksimum untuk $(f(y))^2$ di mana $y$ bilangan real adalah $\cdots$
Sumber: OSK SMA 2009 (No. 14)
Pembahasan:

Untuk fungsi $f(y) = a\sin y + b\cos y$, nilai maksimum $(f(y))^2$ adalah $a^2 + b^2 = (\sqrt{3} + 1)^2 + (\sqrt{3} - 1)^2 = (4 + 2\sqrt{3}) + (4 - 2\sqrt{3}) = 8$.

Jadi, nilai maksimum untuk $(f(y))^2$ adalah $8$.
Jika $\tan x + \tan y = 25$ dan $\cot x + \cot y = 30$, maka nilai $\tan(x + y)$ adalah $\cdots$
Sumber: OSP SMA 2009 (Bagian Pertama No. 10)
Pembahasan:

Dari $\dfrac{1}{\tan x} + \dfrac{1}{\tan y} = \dfrac{\tan x + \tan y}{\tan x \tan y} = 30$ didapat $\tan x \tan y = \dfrac{25}{30} = \dfrac{5}{6}$.

$$\tan(x + y) = \frac{25}{1 - \frac{5}{6}} = 150$$
Jadi, nilai $\tan(x + y)$ adalah $150$.
Jika $x_1, x_2, \dots, x_{2009}$ bilangan real, maka nilai terkecil dari $$\cos x_1 \sin x_2 + \cos x_2 \sin x_3 + \dots + \cos x_{2009} \sin x_1$$ adalah $\cdots$
Sumber: OSP SMA 2009 (Bagian Pertama No. 15)
Pembahasan:

Misalkan jumlah tersebut adalah $K$. Dengan identitas $\cos^2 x_i + \sin^2 x_i = 1$:

$$2009 + 2K = \sum_{i=1}^{2009} (\cos x_i + \sin x_{i+1})^2 \ge 0 \quad (x_{2010} = x_1)$$

Sehingga $K \ge -\dfrac{2009}{2}$ (tercapai saat $x_i = \dfrac{3\pi}{4}$).

Jadi, nilai terkecilnya adalah $-\dfrac{2009}{2}$.
Nilai $x$ yang memenuhi $0 \le x \le \pi$ dan $$\frac{1}{\sin\left(\frac{x}{2^{2010}}\right)} = 2^{2010}\sqrt{2}\cos\left(\frac{x}{2}\right)\cos\left(\frac{x}{4}\right)\cdots\cos\left(\frac{x}{2^{2010}}\right)$$ adalah $\cdots$
Sumber: OSK SMA 2010 (No. 19)
Pembahasan:

Kalikan kedua ruas dengan $\sin\left(\dfrac{x}{2^{2010}}\right)$ dan terapkan berulang identitas $\sin 2\alpha = 2\sin\alpha\cos\alpha$:

$$1 = \sqrt{2} \cdot 2^{2010}\cos\left(\frac{x}{2}\right)\cdots\cos\left(\frac{x}{2^{2010}}\right)\sin\left(\frac{x}{2^{2010}}\right) = \sqrt{2}\sin x$$ $$\sin x = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

Untuk $0 \le x \le \pi$, solusinya adalah $x = \dfrac{\pi}{4}$ atau $x = \dfrac{3\pi}{4}$.

Jadi, nilai $x$ yang memenuhi adalah $\dfrac{\pi}{4}$ atau $\dfrac{3\pi}{4}$.
No. 18
Banyaknya nilai $\alpha$ dengan $0^\circ < \alpha < 90^\circ$ yang memenuhi persamaan $$(1 + \cos\alpha)(1 + \cos 2\alpha)(1 + \cos 4\alpha) = \frac{1}{8}$$ adalah $\cdots$
Sumber: OSK SMA 2013
Pembahasan:

Kalikan kedua ruas dengan $(1 - \cos\alpha) \neq 0$ dan gunakan $1 - \cos^2\theta = \frac{1}{2}(1 - \cos 2\theta)$ secara berulang:

$$(1 - \cos 2\alpha)(1 + \cos 2\alpha)(1 + \cos 4\alpha) = \frac{1}{4}(1 - \cos\alpha)$$ $$(1 - \cos 4\alpha)(1 + \cos 4\alpha) = \frac{1}{2}(1 - \cos\alpha) \implies 1 - \cos 8\alpha = 1 - \cos\alpha \implies \cos 8\alpha = \cos\alpha$$

Untuk $0^\circ < \alpha < 90^\circ$:

  • $8\alpha = \alpha + k\cdot 360^\circ \implies 7\alpha = k\cdot 360^\circ \implies \alpha = \dfrac{360^\circ}{7}$.
  • $8\alpha = -\alpha + k\cdot 360^\circ \implies \alpha = k\cdot 40^\circ \implies \alpha = 40^\circ,\ 80^\circ$.
Jadi, banyaknya nilai $\alpha$ yang memenuhi adalah $3$.
No. 19
Untuk $0 < x < \pi$, nilai minimum dari $\dfrac{16\sin^2 x + 9}{\sin x}$ adalah $\cdots$
Sumber: OSK SMA 2014
Pembahasan:

Karena $0 < x < \pi$, maka $\sin x > 0$. Dengan ketaksamaan AM-GM:

$$\frac{16\sin^2 x + 9}{\sin x} = 16\sin x + \frac{9}{\sin x} \ge 2\sqrt{16\sin x \cdot \frac{9}{\sin x}} = 2 \cdot 12 = 24$$

Kesamaan tercapai saat $16\sin x = \dfrac{9}{\sin x} \iff \sin x = \dfrac{3}{4}$ (yang memang ada pada interval $0 < x < \pi$).

Jadi, nilai minimumnya adalah $24$.
No. 20
Misalkan $0 < \alpha, \beta, \gamma < \dfrac{\pi}{2}$ dan $\alpha + \beta + \gamma = \dfrac{\pi}{4}$. Banyaknya tripel bilangan bulat positif $(a, b, c)$ sehingga $\tan\alpha = \dfrac{1}{a}$, $\tan\beta = \dfrac{1}{b},$ dan $\tan\gamma = \dfrac{1}{c}$ adalah $\cdots$
Sumber: OSP SMA 2014
Pembahasan:

Dari $\tan(\beta + \gamma) = \tan\left(\frac{\pi}{4} - \alpha\right)$, diperoleh $\dfrac{b + c}{bc - 1} = \dfrac{a - 1}{a + 1}$.

Dengan $a \le b \le c$ ($\alpha \ge \frac{\pi}{12} \implies \frac{1}{a} \ge 2 - \sqrt{3} > \frac{1}{4}$), didapat $a \in \{2, 3\}$:

  • $a = 2$: $(b - 3)(c - 3) = 10 \implies (b, c) \in \{(4, 13), (5, 8)\}$ ($2 \times 6 = 12$ permutasi).
  • $a = 3$: $(b - 2)(c - 2) = 5 \implies (b, c) = (3, 7)$ ($3$ permutasi).

Totalnya adalah $12 + 3 = 15$ tripel.

Jadi, banyaknya tripel $(a, b, c)$ adalah $15$.
