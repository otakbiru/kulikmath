Jika $$\left(1 - \tan^2\frac{x}{2^{2011}}\right)\left(1 - \tan^2\frac{x}{2^{2010}}\right)\cdots\left(1 - \tan^2\frac{x}{2}\right) = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}}$$ maka $\sin 2x$ adalah $\cdots$
Sumber: OSP SMA 2011 (No. 8)
Pembahasan:

Dari identitas sudut ganda $\tan 2\theta = \dfrac{2\tan\theta}{1 - \tan^2\theta}$, diperoleh $1 - \tan^2\theta = \dfrac{2\tan\theta}{\tan 2\theta}$. Substitusikan ke setiap faktor pada ruas kiri:

$$\frac{2\tan\frac{x}{2^{2011}}}{\tan\frac{x}{2^{2010}}} \cdot \frac{2\tan\frac{x}{2^{2010}}}{\tan\frac{x}{2^{2009}}} \cdots \frac{2\tan\frac{x}{2}}{\tan x} = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}}$$

Secara teleskopik, ruas kiri menyusut menjadi:

$$\frac{2^{2011}\tan\frac{x}{2^{2011}}}{\tan x} = 2^{2011}\sqrt{3}\tan\frac{x}{2^{2011}} \implies \tan x = \frac{1}{\sqrt{3}}$$

Gunakan identitas $\sin 2x = \dfrac{2\tan x}{1 + \tan^2 x}$:

$$\sin 2x = \frac{2 \cdot \frac{1}{\sqrt{3}}}{1 + \frac{1}{3}} = \frac{\frac{2}{\sqrt{3}}}{\frac{4}{3}} = \frac{\sqrt{3}}{2}$$
Jadi, nilai $\sin 2x$ adalah $\dfrac{1}{2}\sqrt{3}$.
Nilai $\sin^8 75^\circ - \cos^8 75^\circ = \cdots$
Sumber: OSK SMA 2005 (Bagian Kedua - No. 18)
Pembahasan:

Faktorkan dengan selisih kuadrat bertahap:

$$\sin^8 75^\circ - \cos^8 75^\circ = (\sin^4 75^\circ + \cos^4 75^\circ)(1)(-\cos 150^\circ) = \left(1 - \frac{1}{2}\sin^2 150^\circ\right)\left(\frac{\sqrt{3}}{2}\right) = \frac{7}{8} \cdot \frac{\sqrt{3}}{2} = \frac{7}{16}\sqrt{3}$$
Jadi, nilainya adalah $\dfrac{7}{16}\sqrt{3}$.
Diketahui bahwa $a$ dan $b$ adalah besar dua sudut pada sebuah segitiga. Jika $\sin a + \sin b = \dfrac{1}{2}\sqrt{2}$ dan $\cos a + \cos b = \dfrac{1}{2}\sqrt{6}$, maka $\sin(a + b) =$ $\cdots$
Sumber: OSK SMA 2008 (Bagian Kedua No. 20)
Pembahasan:

Kuadratkan dan jumlahkan kedua persamaan:

$$(\sin a + \sin b)^2 + (\cos a + \cos b)^2 = \left(\frac{1}{2}\sqrt{2}\right)^2 + \left(\frac{1}{2}\sqrt{6}\right)^2 = \frac{1}{2} + \frac{3}{2} = 2$$ $$2 + 2(\cos a \cos b + \sin a \sin b) = 2 \implies \cos(a - b) = 0$$

Selanjutnya, kalikan kedua persamaan yang diketahui:

$$(\sin a + \sin b)(\cos a + \cos b) = \frac{1}{2}\sqrt{2} \cdot \frac{1}{2}\sqrt{6} = \frac{1}{2}\sqrt{3}$$ $$\frac{1}{2}(\sin 2a + \sin 2b) + \sin(a + b) = \frac{1}{2}\sqrt{3}$$ $$\sin(a + b)\cos(a - b) + \sin(a + b) = \frac{1}{2}\sqrt{3}$$

Substitusikan $\cos(a - b) = 0$, sehingga diperoleh $\sin(a + b) = \dfrac{1}{2}\sqrt{3}$.

Jadi, nilai $\sin(a + b)$ adalah $\dfrac{1}{2}\sqrt{3}$.
Misalkan $f(y) = (\sqrt{3} + 1)\sin y + (\sqrt{3} - 1)\cos y$. Nilai maksimum untuk $(f(y))^2$ di mana $y$ bilangan real adalah $\cdots$
Sumber: OSK SMA 2009 (No. 14)
Pembahasan:

Untuk fungsi $f(y) = a\sin y + b\cos y$, nilai maksimum $(f(y))^2$ adalah $a^2 + b^2 = (\sqrt{3} + 1)^2 + (\sqrt{3} - 1)^2 = (4 + 2\sqrt{3}) + (4 - 2\sqrt{3}) = 8$.

Jadi, nilai maksimum untuk $(f(y))^2$ adalah $8$.
