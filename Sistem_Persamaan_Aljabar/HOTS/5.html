No. 41
Tuliskan semua pasangan bilangan real $(x, y)$ yang memenuhi sistem persamaan $$\begin{aligned} x^{100} - y^{100} &= 2^{99}(x - y) \\ x^{200} - y^{200} &= 2^{199}(x - y) \end{aligned}$$ dengan $x$ dan $y$ berbeda.
Sumber: OSN SMA 2017 (No. 4)
Pembahasan:

Substitusikan $x = 2a$ dan $y = 2b$ ($a \neq b$). Sistem menjadi:

$$a^{100} - b^{100} = a - b \qquad\text{dan}\qquad a^{200} - b^{200} = a - b$$

Karena $a \neq b$ ($a^{100} \neq b^{100}$), bagi persamaan kedua dengan persamaan pertama untuk memperoleh $a^{100} + b^{100} = 1$, sehingga $|a| \le 1$ dan $|b| \le 1$.

  • Jika $|a| = 1$ atau $|b| = 1$: maka salah satunya $0$ dan yang lain $\pm 1$. Menguji $(a, b) \in \{(\pm 1, 0), (0, \pm 1)\}$ pada $a^{100} - b^{100} = a - b$ menyisakan $(a, b) = (1, 0)$ dan $(0, 1)$, yakni $(x, y) = (2, 0)$ dan $(0, 2)$.
  • Jika $|a| < 1$ dan $|b| < 1$: dari $a^{100} - a = b^{100} - b$, apabila $ab = 0$ maka yang lain juga $0$ (melanggar $a \neq b$). Jika $ab \neq 0$, maka $\dfrac{a}{b} = \dfrac{b^{99} - 1}{a^{99} - 1} > 0$ (karena $a^{99} - 1, b^{99} - 1 < 0$), sehingga $a$ dan $b$ bertanda sama. Namun dari $\dfrac{a^{100} - b^{100}}{a - b} = 1$: $$1 = a^{99} + a^{98}b + \dots + b^{99} \implies a, b > 0 \quad\text{dan}\quad a^{99} + b^{99} < 1 = a^{100} + b^{100}$$ Mustahil karena $0 < a, b < 1 \implies a^{100} + b^{100} < a^{99} + b^{99}$.
Jadi, semua pasangan $(x, y)$ yang memenuhi adalah $(2, 0)$ dan $(0, 2)$.
No. 42
Cari semua tripel bilangan real $(x, y, z)$ yang memenuhi sistem persamaan $$\begin{aligned} \frac{1}{3}\min\{x, y\} + \frac{2}{3}\max\{x, y\} &= 2017 \\ \frac{1}{3}\min\{y, z\} + \frac{2}{3}\max\{y, z\} &= 2018 \\ \frac{1}{3}\min\{z, x\} + \frac{2}{3}\max\{z, x\} &= 2019 \end{aligned}$$
Sumber: OSN SMA 2018 (No. 4)
Pembahasan:

Untuk fungsi $f(p, q) = \frac{1}{3}\min\{p, q\} + \frac{2}{3}\max\{p, q\}$, apabila $a \le b \le c$ maka $f(a, b) \le f(a, c) \le f(b, c)$ (karena $f(a, c) - f(a, b) = \frac{2}{3}(c - b) \ge 0$ dan $f(b, c) - f(a, c) = \frac{1}{3}(b - a) \ge 0$).

Membandingkan nilai $2017 < 2018 < 2019$, pasangan terkecil haruslah $\{x, y\} = \{a, b\}$, pasangan tengah $\{y, z\} = \{a, c\}$, dan pasangan terbesar $\{z, x\} = \{b, c\}$! Ini memaksa urutan tunggal $y < x < z$ (sebab $\{x, y\} \cap \{y, z\} = \{y\}$ adalah nilai terkecil $a$, dan $\{y, z\} \cap \{z, x\} = \{z\}$ adalah nilai terbesar $c$).

Dengan $y < x < z$, sistem menjadi linear:

$$y + 2x = 3(2017), \qquad y + 2z = 3(2018), \qquad x + 2z = 3(2019)$$

Kurangkan persamaan ke-$2$ dan ke-$1$: $2(z - x) = 3 \implies z - x = \frac{3}{2}$. Kurangkan ke-$3$ dan ke-$2$: $x - y = 3$.

Substitusikan ke $y + 2x = 6051$: $(x - 3) + 2x = 6051 \implies 3x = 6054 \implies x = 2018$, lalu $y = 2015$ dan $z = 2018 + \dfrac{3}{2} = \dfrac{4039}{2}$.

Jadi, satu-satunya tripel $(x, y, z)$ yang memenuhi adalah $\left(2018,\; 2015,\; \dfrac{4039}{2}\right)$.
No. 43
Cari semua bilangan real $k$ sehingga sistem persamaan $$a^2 + ab = kb^2, \qquad b^2 + bc = kc^2, \qquad c^2 + ca = ka^2$$ memiliki solusi bilangan real positif $a, b, c$.
Sumber: OSP SMA 2019 (No. 17)
Pembahasan:

Misalkan $x = \frac{a}{b}, y = \frac{b}{c}, z = \frac{c}{a} > 0$. Membagi ketiga persamaan dengan $b^2, c^2, a^2$ menunjukkan $x, y, z$ adalah akar-akar positif dari $t^2 + t - k = 0$.

Karena hasil jumlah akar persamaan kuadrat tersebut bernilai $-1 < 0$, persamaan hanya dapat memiliki paling banyak satu akar positif. Oleh karena itu $x = y = z$.

Karena $xyz = 1$, maka $x^3 = 1 \implies x = y = z = 1$, sehingga $k = 1^2 + 1 = 2$ (dan tercapai saat $a = b = c > 0$).

Jadi, nilai $k$ yang memenuhi adalah $k = 2$.
No. 44
Tentukanlah semua pasangan bilangan real $(x, y)$ yang memenuhi sistem persamaan berikut: $$(x^2 + y + 1)(y^2 + x + 1) = 4$$ $$(x^2 + y)^2 + (y^2 + x)^2 = 2$$
Sumber: OSP SMA 2021 (No. 4)
Pembahasan:

Misalkan $a = x^2 + y$ dan $b = y^2 + x$, sehingga $(a + 1)(b + 1) = 4$ dan $a^2 + b^2 = 2$. Misalkan $m = a + b$, maka $ab = 3 - m$ dan:

$$m^2 = a^2 + b^2 + 2ab = 2 + 2(3 - m) \implies m^2 + 2m - 8 = 0 \implies m \in \{2, -4\}$$

Karena $(a - b)^2 = a^2 + b^2 - 2ab = 2 - (6 - 2m) = 2m - 4 \ge 0$, haruslah $m \ge 2 \implies m = 2$, dan $(a - b)^2 = 0 \implies a = b = 1$.

Sistem $x^2 + y = 1$ dan $y^2 + x = 1$ dikurangkan menjadi $(x - y)(x + y - 1) = 0$:

  • Jika $x = y$: $x^2 + x - 1 = 0 \implies x = y = \frac{-1 \pm \sqrt{5}}{2}$.
  • Jika $x + y = 1$: $x^2 + (1 - x) = 1 \implies x(x - 1) = 0 \implies (0, 1)$ atau $(1, 0)$.
Jadi, semua solusi $(x, y)$ adalah $\left(\frac{\sqrt{5}-1}{2}, \frac{\sqrt{5}-1}{2}\right)$, $\left(\frac{-\sqrt{5}-1}{2}, \frac{-\sqrt{5}-1}{2}\right)$, $(0, 1)$, dan $(1, 0)$.
