Misalkan $x, y,$ dan $z$ adalah bilangan real positif dengan sifat $xyz = 1$. Nilai terkecil dari $$(x + 2y)(y + 2z)(xz + 1)$$ tercapai saat $x + y + z$ bernilai $\cdots$
Sumber: OSP SMA 2011 (No. 10)
Pembahasan:

Terapkan ketaksamaan AM-GM pada masing-masing faktor:

$$x + 2y \ge 2\sqrt{2xy}, \qquad y + 2z \ge 2\sqrt{2yz}, \qquad xz + 1 \ge 2\sqrt{xz}$$

Kalikan ketiga ketaksamaan tersebut (karena semua suku positif):

$$(x + 2y)(y + 2z)(xz + 1) \ge 8\sqrt{4x^2 y^2 z^2} = 16xyz = 16$$

Nilai minimum $16$ tercapai jika dan hanya jika ketiga tanda kesamaan AM-GM berlaku serentak:

$$x = 2y, \qquad y = 2z, \qquad xz = 1$$

Dari $xz = 1$ dan $xyz = 1 \implies y = 1$, sehingga $x = 2(1) = 2$ dan $z = \dfrac{1}{2}$. Jadi $x + y + z = 2 + 1 + \dfrac{1}{2} = \dfrac{7}{2}$.

Jadi, nilai $x + y + z$ saat itu adalah $\dfrac{7}{2}$ (atau $3\dfrac{1}{2}$).
Diberikan $f(x) = x^2 + 4$. Misalkan $x$ dan $y$ adalah bilangan-bilangan real positif yang memenuhi $f(xy) + f(y - x) = f(y + x)$. Nilai minimum dari $x + y$ adalah $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 13)
Pembahasan:

Substitusikan definisi $f(t) = t^2 + 4$ ke persamaan yang diberikan:

$$(x^2y^2 + 4) + \bigl((y - x)^2 + 4\bigr) = (y + x)^2 + 4$$ $$x^2y^2 + 4 = (y + x)^2 - (y - x)^2 = 4xy$$ $$(xy - 2)^2 = 0 \implies xy = 2$$

Karena $x, y > 0$, berdasarkan ketaksamaan AM-GM:

$$x + y \ge 2\sqrt{xy} = 2\sqrt{2}$$

Kesamaan tercapai saat $x = y = \sqrt{2}$.

Jadi, nilai minimum dari $x + y$ adalah $2\sqrt{2}$.
Buktikan bahwa untuk $x$ dan $y$ bilangan real positif, berlaku $$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{2}{x + y + 2}$$
Sumber: OSN SMA 2008 (Hari Pertama No. 2)
Pembahasan:

Dengan ketaksamaan AM-GM pada $x$ dan $1$, berlaku $2\sqrt{x} \le x + 1$, sehingga $(1 + \sqrt{x})^2 = 1 + 2\sqrt{x} + x \le 2(x + 1)$ dan analog untuk $y$:

$$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{1}{2}\left(\frac{1}{x + 1} + \frac{1}{y + 1}\right)$$

Selanjutnya, dengan ketaksamaan AM-HM pada $x + 1$ dan $y + 1$:

$$\frac{1}{x + 1} + \frac{1}{y + 1} \ge \frac{4}{(x + 1) + (y + 1)} = \frac{4}{x + y + 2}$$

Sehingga $\dfrac{1}{(1 + \sqrt{x})^2} + \dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{1}{2} \cdot \dfrac{4}{x + y + 2} = \dfrac{2}{x + y + 2}$.

Terbukti bahwa $\dfrac{1}{(1 + \sqrt{x})^2} + \dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{2}{x + y + 2}$. $\blacksquare$
Bilangan rasional $a < b < c$ membentuk barisan hitung (aritmatika) dan $$\frac{a}{b} + \frac{b}{c} + \frac{c}{a} = 3$$ Banyaknya bilangan positif $a$ yang memenuhi adalah $\cdots$
Sumber: OSP SMA 2009 (Bagian Pertama No. 3)
Pembahasan:

Karena $a, b, c > 0$, menurut ketaksamaan AM-GM:

$$\frac{a}{b} + \frac{b}{c} + \frac{c}{a} \ge 3\sqrt[3]{\frac{a}{b} \cdot \frac{b}{c} \cdot \frac{c}{a}} = 3$$

Tanda kesamaan terjadi hanya jika $a = b = c$, yang kontradiksi dengan $a < b < c$.

Jadi, banyaknya bilangan positif $a$ yang memenuhi adalah $0$.
Nilai minimum dari $f(x) = \dfrac{9x^2 \sin^2 x + 4}{x \sin x}$ untuk $0 < x < \pi$ adalah $\cdots$
Sumber: OSP SMA 2009 (Bagian Pertama No. 6)
Pembahasan:

Untuk $0 < x < \pi$, berlaku $x \sin x > 0$. Dengan ketaksamaan AM-GM:

$$f(x) = 9x \sin x + \frac{4}{x \sin x} \ge 2\sqrt{9x \sin x \cdot \frac{4}{x \sin x}} = 12$$

Kesamaan tercapai saat $x \sin x = \dfrac{2}{3}$, yang memiliki solusi pada $(0, \pi)$.

Jadi, nilai minimum dari $f(x)$ adalah $12$.
Diketahui $x, y,$ dan $z$ adalah bilangan-bilangan real yang memenuhi sistem persamaan $$x + y + z = \frac{1}{x} + \frac{1}{y} + \frac{1}{z}, \qquad xyz = 1$$ Nilai terkecil $|x + y + z|$ adalah $\cdots$
Sumber: OSP SMA 2010 (Bagian Pertama No. 19)
Pembahasan:

Misalkan $s = x + y + z$. Karena $xyz = 1$, maka $xy + yz + zx = \dfrac{1}{x} + \dfrac{1}{y} + \dfrac{1}{z} = s$.

Akibatnya, $x^2 + y^2 + z^2 = s^2 - 2s$ dan $\dfrac{1}{x^2} + \dfrac{1}{y^2} + \dfrac{1}{z^2} = (xy + yz + zx)^2 - 2xyz(x + y + z) = s^2 - 2s$.

Dengan ketaksamaan AM-HM pada bilangan positif $x^2, y^2, z^2$:

$$\left(x^2 + y^2 + z^2\right)\left(\frac{1}{x^2} + \frac{1}{y^2} + \frac{1}{z^2}\right) \ge 9 \implies (s^2 - 2s)^2 \ge 9 \implies s^2 - 2s \ge 3$$ $$(s - 3)(s + 1) \ge 0 \implies s \ge 3 \text{ atau } s \le -1$$

Sehingga $|x + y + z| = |s| \ge 1$. Nilai $1$ tercapai saat $(x, y, z) = (1, -1, -1)$.

Jadi, nilai terkecil $|x + y + z|$ adalah $1$.
Suatu kompetisi matematika diikuti oleh $120$ peserta dari beberapa kontingen. Pada acara penutupan, setiap peserta memberikan $1$ souvenir pada setiap peserta dari kontingen yang sama dan $1$ souvenir pada salah seorang peserta dari tiap kontingen lainnya. Di akhir acara, diketahui terdapat $3840$ souvenir yang dipertukarkan. Berapa banyak kontingen maksimal sehingga kondisi di atas dapat terpenuhi?
Sumber: OSN SMA 2010 (Hari Pertama No. 3)
Pembahasan:

Misalkan ada $n$ kontingen dan kontingen ke-$i$ memiliki $x_i$ peserta, dengan $x_1 + x_2 + \dots + x_n = 120$.

Setiap peserta di kontingen ke-$i$ memberi $(x_i - 1)$ souvenir ke rekan sekontingennya dan $(n - 1)$ souvenir ke peserta kontingen lain, sehingga total souvenir adalah:

$$\sum_{i=1}^{n} x_i(x_i - 1) + 120(n - 1) = 3840 \implies \sum_{i=1}^{n} x_i^2 = 4080 - 120n$$

Dengan ketaksamaan QM-AM (atau Cauchy-Schwarz):

$$\frac{\sum_{i=1}^{n} x_i^2}{n} \ge \left(\frac{\sum_{i=1}^{n} x_i}{n}\right)^2 \implies \frac{4080 - 120n}{n} \ge \frac{120^2}{n^2}$$ $$n^2 - 34n + 120 \le 0 \implies (n - 4)(n - 30) \le 0 \implies 4 \le n \le 30$$

Nilai $n = 30$ tercapai apabila ke-$30$ kontingen masing-masing beranggotakan $4$ peserta ($30 \cdot 4(3) + 120(29) = 360 + 3480 = 3840$).

Jadi, banyaknya kontingen maksimal adalah $30$.
Untuk bilangan real positif $x$ dan $y$ dengan $xy = \dfrac{1}{3}$, nilai minimum dari $\dfrac{1}{9x^6} + \dfrac{1}{4y^6}$ adalah $\cdots$
Sumber: OSP SMA 2012 (No. 17)
Pembahasan:

Dengan ketaksamaan AM-GM dan substitusi $xy = \frac{1}{3}$:

$$\frac{1}{9x^6} + \frac{1}{4y^6} \ge 2\sqrt{\frac{1}{36(xy)^6}} = \frac{1}{3(xy)^3} = \frac{1}{3 \cdot \left(\frac{1}{3}\right)^3} = 9$$
Jadi, nilai minimumnya adalah $9$.
Diberikan bilangan asli $n$ dan bilangan-bilangan real positif $a_1, a_2, \dots, a_n$. Buktikan bahwa $$(1 + a_1)^2 (1 + a_2)^3 \cdots (1 + a_n)^{n+1} \ge (n + 1)^{n+1} a_1 a_2 \cdots a_n$$ dan tentukan kapan kesamaan berlaku.
Sumber: OSN SMA 2012 (No. 2)
Pembahasan:

Untuk setiap $k \in \{1, \dots, n\}$, terapkan AM-GM pada $k$ buah $\frac{1}{k}$ dan satu buah $a_k$:

$$\frac{1 + a_k}{k + 1} \ge \sqrt[k+1]{\frac{a_k}{k^k}} \implies (1 + a_k)^{k+1} \ge \frac{(k + 1)^{k+1}}{k^k} a_k$$

Kalikan untuk $k = 1, \dots, n$ (teleskopik): $\prod_{k=1}^{n} (1 + a_k)^{k+1} \ge (n + 1)^{n+1} a_1 a_2 \cdots a_n$. Kesamaan berlaku jika dan hanya jika $a_k = \dfrac{1}{k}$ untuk semua $k$. $\blacksquare$

No. 20
Buktikan bahwa untuk semua bilangan real positif $a, b, c$ dengan $a + b + c \le 6$ berlaku $$\frac{a + 2}{a(a + 4)} + \frac{b + 2}{b(b + 4)} + \frac{c + 2}{c(c + 4)} \ge 1$$
Sumber: OSP SMA 2013
Pembahasan:

Perhatikan identitas pecahan parsial berikut:

$$\frac{x + 2}{x(x + 4)} = \frac{1}{2}\left(\frac{1}{x} + \frac{1}{x + 4}\right) = \frac{1}{2x} + \frac{1}{2x + 8}$$

Dengan ketaksamaan AM-HM untuk $2a, 2b, 2c > 0$ dan $a + b + c \le 6$:

$$\frac{1}{2a} + \frac{1}{2b} + \frac{1}{2c} \ge \frac{9}{2(a + b + c)} \ge \frac{9}{12} = \frac{3}{4}$$

Dengan ketaksamaan AM-HM untuk $2a + 8, 2b + 8, 2c + 8 > 0$:

$$\frac{1}{2a + 8} + \frac{1}{2b + 8} + \frac{1}{2c + 8} \ge \frac{9}{2(a + b + c) + 24} \ge \frac{9}{36} = \frac{1}{4}$$

Jumlahkan kedua pertidaksamaan tersebut:

$$\frac{a + 2}{a(a + 4)} + \frac{b + 2}{b(b + 4)} + \frac{c + 2}{c(c + 4)} \ge \frac{3}{4} + \frac{1}{4} = 1$$
Terbukti bahwa $\dfrac{a + 2}{a(a + 4)} + \dfrac{b + 2}{b(b + 4)} + \dfrac{c + 2}{c(c + 4)} \ge 1$.
