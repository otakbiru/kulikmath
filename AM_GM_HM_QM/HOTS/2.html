Berikut adalah soal tingkat ... materi AM-GM-HM-QM

Misalkan $x, y,$ dan $z$ adalah bilangan real positif dengan sifat $xyz = 1$. Nilai terkecil dari $$(x + 2y)(y + 2z)(xz + 1)$$ tercapai saat $x + y + z$ bernilai $\cdots$
Sumber: OSP SMA 2011 (No. 10)
Pembahasan:

Terapkan ketaksamaan AM-GM pada masing-masing faktor:

$$x + 2y \ge 2\sqrt{2xy}, \qquad y + 2z \ge 2\sqrt{2yz}, \qquad xz + 1 \ge 2\sqrt{xz}$$

Kalikan ketiga ketaksamaan tersebut (karena semua suku positif):

$$(x + 2y)(y + 2z)(xz + 1) \ge 8\sqrt{4x^2 y^2 z^2} = 16xyz = 16$$

Nilai minimum $16$ tercapai jika dan hanya jika ketiga tanda kesamaan AM-GM berlaku serentak:

$$x = 2y, \qquad y = 2z, \qquad xz = 1$$

Dari $xz = 1$ dan $xyz = 1 \implies y = 1$, sehingga $x = 2(1) = 2$ dan $z = \dfrac{1}{2}$. Jadi $x + y + z = 2 + 1 + \dfrac{1}{2} = \dfrac{7}{2}$.

Jadi, nilai $x + y + z$ saat itu adalah $\dfrac{7}{2}$ (atau $3\dfrac{1}{2}$).
Diberikan $f(x) = x^2 + 4$. Misalkan $x$ dan $y$ adalah bilangan-bilangan real positif yang memenuhi $f(xy) + f(y - x) = f(y + x)$. Nilai minimum dari $x + y$ adalah $\cdots$
Sumber: OSP SMA 2008 (Bagian Pertama No. 13)
Pembahasan:

Substitusikan definisi $f(t) = t^2 + 4$ ke persamaan yang diberikan:

$$(x^2y^2 + 4) + \bigl((y - x)^2 + 4\bigr) = (y + x)^2 + 4$$ $$x^2y^2 + 4 = (y + x)^2 - (y - x)^2 = 4xy$$ $$(xy - 2)^2 = 0 \implies xy = 2$$

Karena $x, y > 0$, berdasarkan ketaksamaan AM-GM:

$$x + y \ge 2\sqrt{xy} = 2\sqrt{2}$$

Kesamaan tercapai saat $x = y = \sqrt{2}$.

Jadi, nilai minimum dari $x + y$ adalah $2\sqrt{2}$.
Buktikan bahwa untuk $x$ dan $y$ bilangan real positif, berlaku $$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{2}{x + y + 2}$$
Sumber: OSN SMA 2008 (Hari Pertama No. 2)
Pembahasan:

Dengan ketaksamaan AM-GM pada $x$ dan $1$, berlaku $2\sqrt{x} \le x + 1$, sehingga $(1 + \sqrt{x})^2 = 1 + 2\sqrt{x} + x \le 2(x + 1)$ dan analog untuk $y$:

$$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{1}{2}\left(\frac{1}{x + 1} + \frac{1}{y + 1}\right)$$

Selanjutnya, dengan ketaksamaan AM-HM pada $x + 1$ dan $y + 1$:

$$\frac{1}{x + 1} + \frac{1}{y + 1} \ge \frac{4}{(x + 1) + (y + 1)} = \frac{4}{x + y + 2}$$

Sehingga $\dfrac{1}{(1 + \sqrt{x})^2} + \dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{1}{2} \cdot \dfrac{4}{x + y + 2} = \dfrac{2}{x + y + 2}$.

Terbukti bahwa $\dfrac{1}{(1 + \sqrt{x})^2} + \dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{2}{x + y + 2}$. $\blacksquare$
