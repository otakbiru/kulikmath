No. 21
Tentukan semua bilangan real positif $M$ sedemikian sehingga untuk sebarang bilangan real positif $a, b, c$ paling sedikit satu di antara tiga bilangan berikut $$a + \frac{M}{ab}, \quad b + \frac{M}{bc}, \quad c + \frac{M}{ca}$$ bernilai lebih dari atau sama dengan $1 + M$.
Sumber: OSN SMA 2013
Pembahasan:

Pilih $a = b = c = x > 0$. Syarat perlu adalah $x + \dfrac{M}{x^2} \ge 1 + M$ untuk semua $x > 0$. Dengan AM-GM:

$$\frac{x}{2} + \frac{x}{2} + \frac{M}{x^2} \ge 3\sqrt[3]{\frac{M}{4}}$$

Kesamaan tercapai saat $x = \sqrt[3]{2M}$, sehingga wajib $3\sqrt[3]{\dfrac{M}{4}} \ge 1 + M$. Misalkan $t = \sqrt[3]{2M} > 0$ ($M = \dfrac{t^3}{2}$):

$$\frac{3t}{2} \ge 1 + \frac{t^3}{2} \iff t^3 - 3t + 2 \le 0 \iff (t - 1)^2(t + 2) \le 0$$

Karena $t > 0$, satu-satunya solusi adalah $t = 1 \implies M = \dfrac{1}{2}$.

Bukti cukup untuk $M = \dfrac{1}{2}$: Andaikan ketiga bilangan kurang dari $1 + \frac{1}{2} = \frac{3}{2}$. Jumlahkan ketiganya dan terapkan AM-GM $9$ suku:

$$\frac{9}{2} > \left(a + \frac{1}{2ab}\right) + \left(b + \frac{1}{2bc}\right) + \left(c + \frac{1}{2ca}\right) = \frac{a}{2} + \frac{a}{2} + \frac{1}{2ab} + \frac{b}{2} + \frac{b}{2} + \frac{1}{2bc} + \frac{c}{2} + \frac{c}{2} + \frac{1}{2ca} \ge 9\sqrt[9]{\frac{1}{2^9}} = \frac{9}{2}$$

Kontradiksi! Jadi untuk $M = \dfrac{1}{2}$, paling sedikit satu dari ketiga bilangan tersebut bernilai $\ge \dfrac{3}{2}$.

Jadi, satu-satunya bilangan real positif $M$ yang memenuhi adalah $M = \dfrac{1}{2}$.
No. 22
Misalkan $a, b, c$ bilangan real positif yang memenuhi $a + b + c = 1$. Nilai minimum dari $\dfrac{a + b}{abc}$ adalah $\cdots$
Sumber: OSK SMA 2017 (No. 8)
Pembahasan:

Misalkan $d = a + b$, maka $d + c = 1$. Dengan Ketaksamaan AM-GM dua kali:

$$dc \le \left(\frac{d + c}{2}\right)^2 = \frac{1}{4} \qquad\text{dan}\qquad ab \le \left(\frac{a + b}{2}\right)^2 = \frac{d^2}{4}$$

Maka $abc \le \dfrac{d^2 c}{4} = \dfrac{d(dc)}{4}$? Lebih tajam: $\dfrac{a + b}{abc} = \dfrac{d}{ab \cdot c} \ge \dfrac{d}{\frac{d^2}{4} \cdot c} = \dfrac{4}{dc} \ge \dfrac{4}{1/4} = 16$.

Kesamaan tercapai saat $d = c = \frac{1}{2}$ dan $a = b = \frac{1}{4}$.

Jadi, nilai minimum dari $\dfrac{a + b}{abc}$ adalah $16$.
No. 23
Diberikan bilangan real tak negatif $a, b, c, d, e$ dengan $ab + bc + cd + de = 2018$. Nilai minimum dari $a + b + c + d + e$ adalah $\cdots$
Sumber: OSP SMA 2018 (No. 12)
Pembahasan:

Misalkan $X = a + c + e$ dan $Y = b + d$. Karena $a, b, c, d, e \ge 0$:

$$XY = (a + c + e)(b + d) = (ab + bc + cd + de) + ad + eb \ge 2018$$

Dengan AM-GM: $a + b + c + d + e = X + Y \ge 2\sqrt{XY} \ge 2\sqrt{2018}$.

Kesamaan tercapai saat $a = e = 0$, $c = b + d = \sqrt{2018}$ (misal $b = \sqrt{2018}, d = 0$).

Jadi, nilai minimumnya adalah $2\sqrt{2018}$.

No. 24
Bilangan real terbesar $M$ sehingga untuk setiap $x$ positif berlaku $$(x + 1)(x + 3)(x + 5)(x + 11) \ge Mx$$ adalah $\cdots$
Sumber: OSK SMA 2019 (No. 18)
Pembahasan:

Jabarkan ruas kiri:

$$(x + 1)(x + 3)(x + 5)(x + 11) = x^4 + 20x^3 + 122x^2 + 268x + 165$$

Untuk mengeliminasi pangkat $x$ menjadi $x^1$ melalui AM-GM, perhatikan saat $x = 1$, nilai ruas kiri adalah $(2)(4)(6)(12) = 576$. Terapkan ketaksamaan AM-GM berbobot dengan $1 + 20 + 122 + 268 + 165 = 576$ suku:

$$\frac{x^4 + 20x^3 + 122x^2 + 268x + 165}{576} \ge \left( (x^4)^1 (x^3)^{20} (x^2)^{122} (x^1)^{268} (1)^{165} \right)^{1/576}$$

Hitung pangkat total $x$ di dalam akar: $4 + 60 + 244 + 268 = 576$, sehingga:

$$x^4 + 20x^3 + 122x^2 + 268x + 165 \ge 576(x^{576})^{1/576} = 576x$$

Kesamaan tercapai saat $x = 1$, maka nilai terbesar $M$ adalah $576$.

Jadi, bilangan real terbesar $M$ adalah $576$.
