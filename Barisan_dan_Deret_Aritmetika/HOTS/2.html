Masing-masing bilangan dari sekumpulan \(\{10, 11, 12, \dots, 20\}\) dikalikan dengan masing-masing bilangan dari \(\{21, 22, 23, \dots, 30\}\). Maka jumlah semua hasil kalinya adalah ....
  1. 44.505
  2. 42.075
  3. 37.855
  4. 35.555
Grup WhatsApp
Pembahasan:
Jumlah seluruh hasil perkalian dapat dinyatakan sebagai perkalian dari jumlah elemen masing-masing himpunan: \(\begin{aligned} \sum_{x=10}^{20} \sum_{y=21}^{30} xy &= \left(\sum_{x=10}^{20} x\right) \times \left(\sum_{y=21}^{30} y\right)\\[4pt] &= \left(\frac{11(10 + 20)}{2}\right) \times \left(\frac{10(21 + 30)}{2}\right)\\[4pt] &= 165 \times 255\\[4pt] &= \color{blue}\boxed{\boxed{\color{black}42075}} \end{aligned}\)
Jadi, jumlah semua hasil kalinya adalah 42.075.

Hasil dari operasi: \[2025 + \left(3 + \frac{1}{2020}\right) + \left(3 + \frac{3}{2020}\right) + \left(3 + \frac{5}{2020}\right) + \dots + \left(3 + \frac{4039}{2020}\right) = \dots.\]

Penyisihan OGM 10 Tingkat SMA
Pembahasan:
Banyak suku dalam tanda kurung dari pembilang ganjil 1 hingga 4039: \[n = \frac{4039 - 1}{2} + 1 = 2019 + 1 = 2020 \text{ suku}\] Jumlahkan seluruh bagian: \(\begin{aligned} &2025 + \left(3 + \frac{1}{2020}\right) + \left(3 + \frac{3}{2020}\right) + \dots + \left(3 + \frac{4039}{2020}\right)\\[4pt] &= 2025 + (2020 \times 3) + \frac{1 + 3 + 5 + \dots + 4039}{2020}\\[4pt] &= 2025 + 6060 + \frac{\frac{2020}{2}(1 + 4039)}{2020}\\[4pt] &= 8085 + \frac{4040}{2}\\[4pt] &= 8085 + 2020\\[4pt] &= \color{blue}\boxed{\boxed{\color{black}10105}} \end{aligned}\)
Jadi, hasil dari operasi tersebut adalah 10.105.

Diketahui \(a + (a + 1) + (a + 2) + \dots + 50 = 1139\). Jika \(a\) bilangan positif, maka \(a = \dots\)
OSK SMA 2006 (Bagian II No. 11)
Pembahasan:

Banyaknya suku pada penjumlahan bilangan bulat berurutan dari \(a\) hingga \(50\) adalah \(n = 50 - a + 1 = 51 - a\). Dengan rumus jumlah deret aritmetika:

\[\frac{n(a + 50)}{2} = 1139 \iff (51 - a)(a + 50) = 2278\] \[a^2 - a - 272 = 0 \iff (a - 17)(a + 16) = 0\]

Karena \(a\) bilangan positif, diperoleh \(a = 17\).
(Atau gunakan selisih jumlah: \(1 + 2 + \dots + 50 = \frac{50 \times 51}{2} = 1275\), sehingga \(1 + 2 + \dots + (a - 1) = 1275 - 1139 = 136 \implies \frac{(a - 1)a}{2} = 136 \implies a(a - 1) = 272 = 17 \times 16 \implies a = 17\).)

Jadi, nilai \(a\) adalah 17.
Pada sebuah barisan aritmatika, nilai suku ke-\(25\) tiga kali nilai suku ke-\(5\). Suku yang bernilai dua kali nilai suku pertama adalah suku ke \(\dots\)
OSK SMA 2006 (Bagian II No. 15)
Pembahasan:

Misalkan suku pertama adalah \(a\) dan beda barisan adalah \(b\) (\(b \neq 0\)), sehingga \(U_n = a + (n - 1)b\). Dari informasi \(U_{25} = 3 U_5\):

\[a + 24b = 3(a + 4b) \iff a + 24b = 3a + 12b \iff 2a = 12b \iff a = 6b\]

Kita cari indeks suku \(n\) sedemikian hingga \(U_n = 2 U_1 = 2a\):

\[a + (n - 1)b = 2a \iff (n - 1)b = a = 6b \implies n - 1 = 6 \iff n = 7\]

(Catatan: apabila \(b = 0\), maka barisan bernilai nol semua; pada soal ini yang dimaksud adalah barisan aritmetika tak konstan sehingga \(n\) tunggal.)

Jadi, suku tersebut adalah suku ke-7.
Diberikan berturut-turut (dari kiri ke kanan) gambar-gambar pertama, kedua dan ketiga dari suatu barisan gambar. Berapakah banyaknya bulatan hitam pada gambar ke-$n$?
Sumber: OSP SMA 2004 (Bagian Pertama - No. 6)
Pembahasan:

Perhatikan pola bulatan hitam pada masing-masing gambar segitiga:

  • Gambar ke-1 ($n = 1$, $3$ baris): $1 + 2 + 2 = 5$ bulatan hitam.
  • Gambar ke-2 ($n = 2$, $4$ baris): $1 + 2 + 2 + 2 = 7$ bulatan hitam.
  • Gambar ke-3 ($n = 3$, $5$ baris): $1 + 2 + 2 + 2 + 2 = 9$ bulatan hitam.

Gambar ke-$n$ memiliki $n + 2$ baris, di mana baris puncak memuat $1$ bulatan hitam dan setiap baris berikutnya hingga baris ke-$(n + 2)$ memuat tepat $2$ bulatan hitam:

$$U_n = 1 + 2(n + 1) = 2n + 3$$
Jadi, banyaknya bulatan hitam pada gambar ke-$n$ adalah $2n + 3$.
