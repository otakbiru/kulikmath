No. 11
Diketahui bahwa $$20! + 14! = 243290a0953b4931200$$ Nilai $a$ dan $b$ adalah $\cdots$
Sumber: OSK SMA 2014
Pembahasan:

Karena $20! + 14! = 14!(20\cdot 19\cdots 15 + 1)$ habis dibagi $14!$, bilangan ini pasti habis dibagi $9$ dan $11$:

  • Habis dibagi $9$: jumlah digitnya $56 + a + b \equiv 0 \pmod 9 \implies a + b \in \{7, 16\}$.
  • Habis dibagi $11$: selisih jumlah digit ganjil-genap $(2+3+9+a+9+3+4+3+2+0) - (4+2+0+0+5+b+9+1+0) = 14 + a - b$ habis dibagi $11$.

Uji $a + b = 7$: $14 + (7 - b) - b = 21 - 2b$ habis dibagi $11 \implies b = 5$ dan $a = 2$ (untuk $a + b = 16$, didapat $30 - 2b$ habis dibagi $11 \implies b = 4, a = 12$, mustahil).

Jadi, nilai $a = 2$ dan $b = 5$.
No. 12
Bilangan asli terbesar $n$ sehingga $n!$ dapat dinyatakan sebagai hasil perkalian $n - 4$ bilangan asli berurutan adalah $\cdots$
Sumber: OSK SMA 2017 (No. 14)
Pembahasan:

Agar $n!$ menjadi hasil kali $n - 4$ bilangan asli berurutan $(k + 1)(k + 2)\cdots(k + n - 4) = \dfrac{(k + n - 4)!}{k!}$, perhatikan bahwa jika $n$ ingin sebesar mungkin, $k$ harus sekecil mungkin? Tepatnya: untuk $k = 5$, $(k + n - 4)! / k!$ dengan $n$ yang digeser: jika kita mengambil $5! = 120$ sebagai faktor pengali di ujung kanan ($120 \cdot 119 \cdots 6$ memiliki $115 = 119 - 4$ faktor!), maka untuk $n = 119$ berlaku $119! = 6 \cdot 7 \cdots 119 \cdot 120$ ($115$ bilangan berurutan)!

Apakah $n \ge 120$ mungkin? Misalkan $n! = (m+1)\cdots(m+n-4)$ dengan $m \ge 5$ (kalau $m \le 4$ maka jumlah faktornya $\le n - 5$? Tidak, jika hasil kalinya dimulai dari $m + 1$ hingga $m + n - 4$, agar $\frac{(m+n-4)!}{m!} = n!$: jika $m \ge 1$, membandingkan pertumbuhan faktorial menunjukkan $(m + n - 4)! / n! = m!$. Karena $(m + n - 4)! / n! \ge n + m - 4$ untuk $m \ge 5$: untuk $m = 5$, $n + 1 = 5! \implies n = 119$; untuk $m = 6$, $(n+2)(n+1) = 6! = 720$, tak ada solusi bulat $n$; untuk $m \ge 7$, jika $m + n - 4 \ge n + 2$, $m! = \prod_{j=1}^{m-4}(n+j) > n^{m-4}$, padahal $n$ terbesar dicapai saat $m - 4 = 1 \implies m = 5 \implies n + 1 = 5! = 120 \implies n = 119$).

Jadi, bilangan asli terbesar $n$ adalah $119$.
