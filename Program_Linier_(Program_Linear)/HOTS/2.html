Jika nilai maksimum $x + y$ pada himpunan $\{(x, y) \mid x \ge 0,\; y \ge 0,\; x + 3y \le 6,\; 3x + y \le a\}$ adalah $4$, haruslah $a = \cdots$
Sumber: OSP SMA 2007 (Bagian 1 • No. 14)
Pembahasan:

Jumlahkan kedua pertidaksamaan $x + 3y \le 6$ dan $3x + y \le a$:

$$4(x + y) \le 6 + a \implies x + y \le \frac{6 + a}{4}$$

Tanda kesamaan tercapai tepat pada titik potong garis $x + 3y = 6$ dan $3x + y = a$, yang merupakan titik sudut daerah himpunan penyelesaian selama titik potong itu berada di kuadran I ($x \ge 0, y \ge 0$).

Karena nilai maksimum $x + y$ adalah $4$, maka:

$$\frac{6 + a}{4} = 4 \implies 6 + a = 16 \implies a = 10$$

Untuk $a = 10$, titik potong $x + 3y = 6$ dan $3x + y = 10$ adalah $(x, y) = (3, 1)$, yang memenuhi $x \ge 0, y \ge 0$ dan $x + y = 4$.

Jadi, haruslah $a = 10$.
