Banyaknya solusi pasangan bilangan bulat positif persamaan \(3x + 5y = 501\) adalah
  1. \(33\)
  2. \(34\)
  3. \(35\)
  4. \(36\)
  5. \(37\)
OSK SMA 2006 (Bagian I No. 10)
Pembahasan:

Perhatikan bahwa \(501 = 3 \times 167\), sehingga persamaan \(3x + 5y = 501\) dapat ditulis sebagai:

\[5y = 501 - 3x = 3(167 - x)\]

Karena ruas kanan habis dibagi \(3\) dan \(\gcd(3, 5) = 1\), maka \(y\) haruslah kelipatan \(3\). Misalkan \(y = 3k\) dengan \(k \in \mathbb{Z}^+\) (sebab \(y \gt 0\)). Substitusikan ke persamaan awal:

\[3x + 5(3k) = 501 \iff x + 5k = 167 \iff x = 167 - 5k\]

Agar pasangan \((x, y)\) sama-sama bilangan bulat positif, syaratnya:

  • \(y = 3k \ge 1 \implies k \ge 1\)
  • \(x = 167 - 5k \ge 1 \iff 5k \le 166 \implies k \le \left\lfloor \dfrac{166}{5} \right\rfloor = 33\)

Jadi nilai \(k\) yang memenuhi adalah \(1, 2, 3, \dots, 33\), sehingga terdapat tepat \(33\) pasangan solusi.

Jadi, banyaknya solusi pasangan bilangan bulat positif adalah 33.
JAWAB: A
Nanang mencari semua bilangan empat-angka yang selisihnya dengan jumlah keempat angkanya adalah \(2007\). Banyaknya bilangan yang ditemukan Nanang tidak akan lebih dari \(\dots\)
OSK SMA 2006 (Bagian II No. 17)
Pembahasan:

Misalkan bilangan empat-angka tersebut adalah \(N = \overline{abcd} = 1000a + 100b + 10c + d\) dengan \(a \in \{1, 2, \dots, 9\}\) dan \(b, c, d \in \{0, 1, \dots, 9\}\).

Jumlah keempat angkanya adalah \(S(N) = a + b + c + d \le 36 \lt 1000 \le N\), sehingga selisihnya pasti bernilai \(N - S(N) = 2007\):

\[\begin{aligned} N - S(N) &= (1000a + 100b + 10c + d) - (a + b + c + d) \\ &= 999a + 99b + 9c \\ &= 9(111a + 11b + c) = 2007 \end{aligned}\]

Bagi kedua ruas dengan \(9\) (karena \(2007 = 9 \times 223\)):

\[111a + 11b + c = 223\]

Perhatikan batas nilai \(11b + c \le 99 + 9 = 108\):

  • Jika \(a = 1\): \(11b + c = 223 - 111 = 112 \gt 108\) (tidak mungkin).
  • Jika \(a \ge 3\): \(111a \ge 333 \gt 223\) (tidak mungkin).
  • Jika \(a = 2\): \(11b + c = 223 - 222 = 1\). Karena \(b \ge 0\) dan \(0 \le c \le 9\), haruslah \(b = 0\) dan \(c = 1\).

Sementara itu, angka satuan \(d\) saling meniadakan dalam selisih \(N - S(N)\), sehingga \(d\) dapat dipilih bebas dari \(0\) sampai \(9\). Semua bilangan yang memenuhi ada tepat \(10\) bilangan, yakni \(2010, 2011, 2012, \dots, 2019\). Maka banyaknya bilangan yang dapat ditemukan Nanang paling banyak \(10\).

Jadi, banyaknya bilangan yang ditemukan Nanang tidak akan lebih dari 10.
