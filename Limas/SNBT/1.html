Berikut adalah soal tingkat ... materi Limas

Diketahui limas segiempat beraturan \(T.ABCD\) dengan panjang rusuk alas \(8\text{ cm}\) dan panjang rusuk tegak \(4\sqrt{6}\text{ cm}\). Jika \(\alpha\) menyatakan besar sudut antara bidang sisi tegak \(TAB\) dan bidang alas \(ABCD\), maka nilai dari \(\cos\alpha\) adalah ....

  1. \(\dfrac{1}{5}\sqrt{5}\)
  2. \(\dfrac{2}{5}\sqrt{5}\)
  3. \(\dfrac{1}{3}\sqrt{3}\)
  4. \(\dfrac{1}{2}\sqrt{2}\)
  5. \(\dfrac{1}{2}\sqrt{3}\)
SNBT / Geometri Ruang
Pembahasan:

Langkah 1: Mengidentifikasi Geometri Limas dan Menentukan Titik Bantu

Pada limas segiempat beraturan \(T.ABCD\):

  • Alas \(ABCD\) berbentuk persegi dengan panjang sisi \(s = 8\text{ cm}\).
  • Panjang rusuk tegak: \(TA = TB = TC = TD = 4\sqrt{6}\text{ cm}\).
  • Titik \(O\) adalah titik perpotongan diagonal alas \(AC\) dan \(BD\), sehingga ruas garis \(TO\) merupakan tinggi limas (\(TO \perp \text{alas } ABCD\)).
  • Titik \(P\) adalah titik tengah rusuk alas \(AB\).

Langkah 2: Menentukan Sudut antara Bidang \(TAB\) dan Bidang Alas \(ABCD\)

Garis persekutuan antara bidang \(TAB\) dan bidang alas \(ABCD\) adalah garis \(AB\):

  • Pada bidang alas, ruas garis \(OP \perp AB\) dengan panjang: \[OP = \frac{1}{2} s = \frac{1}{2} (8) = 4\text{ cm}\]
  • Pada bidang tegak \(TAB\), segitiga \(\triangle TAB\) merupakan segitiga sama kaki (\(TA = TB\)). Oleh karena itu, garis tinggi dari \(T\) jatuh tepat di titik tengah \(P\), sehingga ruas garis \(TP \perp AB\).
Sudut antara bidang \(TAB\) dan bidang alas \(ABCD\) diwakili oleh sudut antara dua garis yang tegak lurus terhadap garis persekutuan \(AB\), yaitu: \[\alpha = \angle TPO\]

Langkah 3: Menghitung Tinggi Limas (\(TO\))

Panjang diagonal bidang alas \(AC\) adalah: \[AC = s\sqrt{2} = 8\sqrt{2}\text{ cm}\] Jarak titik pusat \(O\) ke titik sudut \(A\) adalah: \[AO = \frac{1}{2} AC = 4\sqrt{2}\text{ cm}\] Tinjau segitiga siku-siku \(\triangle TOA\) (siku-siku di \(O\)): \[TO = \sqrt{TA^2 - AO^2} = \sqrt{(4\sqrt{6})^2 - (4\sqrt{2})^2}\] \[TO = \sqrt{96 - 32} = \sqrt{64} = 8\text{ cm}\]

Langkah 4: Menghitung Panjang Sisi Miring \(TP\)

Tinjau segitiga siku-siku \(\triangle TOP\) yang siku-siku di \(O\): \[TP = \sqrt{TO^2 + OP^2} = \sqrt{8^2 + 4^2} = \sqrt{64 + 16} = \sqrt{80} = 4\sqrt{5}\text{ cm}\]

Langkah 5: Menghitung Nilai \(\cos\alpha\)

Berdasarkan perbandingan trigonometri pada segitiga siku-siku \(\triangle TOP\): \[\cos\alpha = \frac{\text{sisi samping}}{\text{sisi miring}} = \frac{OP}{TP} = \frac{4}{4\sqrt{5}} = \frac{1}{\sqrt{5}} = \frac{1}{5}\sqrt{5}\]

Jadi, nilai dari \(\cos\alpha\) adalah \(\dfrac{1}{5}\sqrt{5}\) (Pilihan A).
