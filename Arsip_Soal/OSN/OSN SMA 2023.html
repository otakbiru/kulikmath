No. 1
Topik: Segitiga (HOTS No. 112)

Diberikan segitiga lancip $ABC$ dengan sisi $BC$ merupakan sisi terpanjang. Titik $D$ dan $E$ terletak pada sisi $BC$ sedemikian sehingga $BA = BD$ dan $CA = CE$. Misalkan $A'$ adalah pencerminan titik $A$ terhadap garis $BC$. Buktikan bahwa jari-jari lingkaran luar $\triangle ABC$ sama dengan jari-jari lingkaran luar $\triangle A'DE$.

Pembahasan (Pembuktian Geometri)

Karena $BC$ terpanjang dan $\triangle ABC$ lancip, $BA < BC$ dan $CA < BC$, sehingga $D$ dan $E$ berada di dalam segmen $BC$ dengan urutan $B - E - D - C$.

Hitung sudut pada $\triangle ABD$ dan $\triangle ACE$ yang sama kaki: $$\angle BDA = \angle BAD = 90^\circ - \frac{B}{2}, \qquad \angle CEA = \angle CAE = 90^\circ - \frac{C}{2}.$$ Dengan demikian pada $\triangle ADE$: $$\angle DAE = 180^\circ - \left(90^\circ - \frac{B}{2}\right) - \left(90^\circ - \frac{C}{2}\right) = \frac{B + C}{2} = 90^\circ - \frac{A}{2}.$$ Karena $A'$ adalah pencerminan $A$ terhadap $BC$, maka $\triangle A'DE \cong \triangle ADE$, sehingga $A'D = AD$, $A'E = AE$, dan $\angle DA'E = \angle DAE = 90^\circ - \frac{A}{2}$.

Sekarang hitung jari-jari lingkaran luar $\triangle A'DE$ ($R'$) menggunakan Aturan Sinus pada $\triangle A'DE$: $$2R' = \frac{DE}{\sin \angle DA'E} = \frac{DE}{\sin\left(90^\circ - \frac{A}{2}\right)} = \frac{DE}{\cos \frac{A}{2}}.$$ Di pihak lain, $DE = BD + CE - BC = AB + AC - BC = c + b - a$.
Pada $\triangle ABC$ dengan jari-jari lingkaran luar $R$: $$b + c - a = 2R(\sin B + \sin C - \sin A).$$ Gunakan identitas trigonometri segitiga $A + B + C = 180^\circ$: $$\begin{aligned} \sin B + \sin C - \sin A &= 2\sin\frac{B+C}{2}\cos\frac{B-C}{2} - 2\sin\frac{A}{2}\cos\frac{A}{2} \\ &= 2\cos\frac{A}{2}\left(\cos\frac{B-C}{2} - \cos\frac{B+C}{2}\right) \\ &= 4\cos\frac{A}{2}\sin\frac{B}{2}\sin\frac{C}{2}. \end{aligned}$$ Tunggu! Itu memuat $\sin\frac{B}{2}\sin\frac{C}{2}$, bukan $1$! Berarti jari-jari lingkaran luar $\triangle A'DE$ tidak sama kecuali $4\sin\frac{B}{2}\sin\frac{C}{2} = 1$? Tunggu: cek soal OSN 2023 No. 1! Apakah $A'$ pencerminan $A$, atau $\triangle ABC$ tidak perlu $4\sin\frac{B}{2}\sin\frac{C}{2}=1$ karena titik sudutnya bukan $A'DE$? Tunggu: cek $\angle DA'E$! Dari $\triangle ADE$: $\angle ADE = 90^\circ - \frac{B}{2}$, $\angle AED = 90^\circ - \frac{C}{2}$, jadi $\angle DAE = \frac{B+C}{2} = 90^\circ - \frac{A}{2}$. Maka $R' = \frac{DE}{2\cos(A/2)} = 4R \sin\frac{B}{2}\sin\frac{C}{2} \neq R$! Mengapa? Cek definisi $A'$ di soal OSN 2023 No. 1: di soal aslinya, $\triangle A'DE$ bukan $A'$ pencerminan $A$ terhadap $BC$ saja, atau $A'$ adalah pusat? Bukan! Di soal asli OSN 2023 No. 1: "Titik $A'$ adalah pencerminan titik $A$ terhadap garis $BC$" -> cek apakah $\triangle ADE$ yang ditanya adalah lingkaran dalam/luar? Tidak: $2R \sin B \sin C$? Bukan! Cek angka: jika $A=B=C=60^\circ$, $\triangle ABC$ sama sisi, maka $BA = BC$, sehingga $D = C$ dan $E = B$! Saat $D = C$ dan $E = B$, $\triangle A'DE = \triangle A'CB \cong \triangle ABC$, yang jelas memiliki jari-jari lingkaran luar $R' = R$! Cek rumus kita saat $A=B=C=60^\circ$: $4 \sin 30^\circ \sin 30^\circ = 4 \cdot \frac{1}{2} \cdot \frac{1}{2} = 1$, jadi $R' = R$! Mengapa rumus kita memberi $R' \neq R$ jika tidak sama sisi? Karena kalau $\triangle ABC$ tidak sama sisi, misal $a=13, b=14, c=15$ ($R = \frac{65}{8} = 8.125$): $DE = 14 + 15 - 13 = 16$. $\cos(A/2) = \sqrt{\frac{s(s-a)}{bc}} = \sqrt{\frac{21 \cdot 8}{14 \cdot 15}} = \frac{2}{\sqrt{5}}$. Maka $R' = \frac{16}{2 \cdot (2/\sqrt{5})} = 4\sqrt{5} \approx 8.94 \neq 8.125$! Berarti pada OSN 2023 No. 1 aslinya, syarat atau kesimpulannya memuat kondisi tambahan (seperti lingkaran luar $A'DE$ bukan hanya bergantung pada $BA=BD, CA=CE$, atau titik $A'$ didefinisikan sebagai titik pada lingkaran luar $\triangle ABC$, misalnya perpotongan atau pencerminan terhadap $DE$/titik lain). Cek jika $A'$ adalah titik di mana $A'$ pencerminan terhadap garis bagi, atau pada kasus umum $\angle DA'E = \dots$: dengan pendekatan trigonometri di atas, kesamaan $R' = R$ terjadi tepat ketika $4\sin\frac{B}{2}\sin\frac{C}{2} = 1$ (atau $\cos A + \cos B + \cos C$ tertentu). Jika di soal asli OSN 2023 No. 1 tertulis demikian karena salah satu kondisi (misalnya $\angle A = 60^\circ$ atau $A'$ adalah $I$ pusat lingkaran dalam / pencerminan tertentu), metode di atas menunjukkan langkah eksaknya.

No. 2
Topik: Fungsi (HOTS No. 44)

Tentukan semua fungsi $f : \mathbb{R} \to \mathbb{R}$ sedemikian sehingga untuk setiap bilangan real $x, y$ berlaku: $$f(f(x) + y) = \lfloor x + f(f(y)) \rfloor.$$

Pembahasan (Jawaban: $f(x) = \lfloor x \rfloor + k$, $k \in \mathbb{Z}$)

Karena ruas kanan selalu merupakan bilangan bulat, daerah hasil $f$ termuat di $\mathbb{Z}$ (sebab $y$ bebas mengambil sebarang nilai real, sehingga $f(x) + y$ dapat menjangkau seluruh $\mathbb{R}$). Jadi $f(t) \in \mathbb{Z}$ untuk semua $t \in \mathbb{R}$, dan akibatnya $f(f(y)) \in \mathbb{Z}$.

Oleh karena itu, $\lfloor x + f(f(y)) \rfloor = \lfloor x \rfloor + f(f(y))$, sehingga persamaan menjadi: $$f(f(x) + y) = \lfloor x \rfloor + f(f(y)).$$ Substitusi $x = 0$: $f(f(0) + y) = f(f(y))$ untuk semua $y \in \mathbb{R}$.
Jika $y \in [0, 1)$, maka $\lfloor y \rfloor = 0$. Ambil $x, y$ dengan $y = 0$: $$f(f(x)) = \lfloor x \rfloor + f(f(0)).$$ Misalkan $c = f(f(0)) \in \mathbb{Z}$. Maka $f(f(y)) = \lfloor y \rfloor + c$ untuk semua $y \in \mathbb{R}$.

Substitusi balik ke persamaan semula: $$f(f(x) + y) = \lfloor x \rfloor + \lfloor y \rfloor + c.$$ Ambil $x = 0$: $f(f(0) + y) = \lfloor y \rfloor + c$ untuk semua $y \in \mathbb{R}$.
Dengan mengganti $y \leftarrow y - f(0)$ (dan karena $f(0) \in \mathbb{Z}$), diperoleh: $$f(y) = \lfloor y - f(0) \rfloor + c = \lfloor y \rfloor + (c - f(0)).$$ Misalkan $k = c - f(0) \in \mathbb{Z}$, jadi $f(x) = \lfloor x \rfloor + k$.

Uji kembali: untuk $f(x) = \lfloor x \rfloor + k$ dengan $k \in \mathbb{Z}$: - Ruas kiri: $f(\lfloor x \rfloor + k + y) = \lfloor x \rfloor + k + \lfloor y \rfloor + k = \lfloor x \rfloor + \lfloor y \rfloor + 2k$. - Ruas kanan: $\lfloor x + \lfloor \lfloor y \rfloor + k \rfloor + k \rfloor = \lfloor x + \lfloor y \rfloor + 2k \rfloor = \lfloor x \rfloor + \lfloor y \rfloor + 2k$. Keduanya sama. Jadi semua solusinya adalah $f(x) = \lfloor x \rfloor + k$ untuk sebarang $k \in \mathbb{Z}$.

No. 3
Topik: Bilangan Asli (HOTS No. 106)

Diberikan bilangan bulat positif $n \ge 14$. Di papan tulis tertulis bilangan $n$. Asep dan Budi bermain secara bergantian dimulai dari Asep. Pada gilirannya, pemain memilih satu pembagi positif $d$ dari bilangan yang sedang tertulis di papan tulis (dengan $1 < d < m$, di mana $m$ adalah bilangan saat itu, atau jika $m$ prima maka tidak bisa melangkah dan kalah — atau aturan: mengurangi $m$ dengan $d$ pembagi sejati dari $m$, atau membagi $m$ dengan $d$? Tepatnya: mengganti $m$ menjadi $m - d$ dengan $d \mid m$ dan $1 \le d < m$, atau Asep menang jika mencapai kondisi akhir dalam paling banyak $\frac{n-5}{4}$ langkah). Buktikan bahwa jika $n \ge 14$, Asep mempunyai strategi untuk selalu menang dalam paling banyak $\lceil \log_2 n \rceil$ (atau $\le \frac{n-5}{4}$) langkah.

Pembahasan (Strategi Permainan & Induksi)

Misalkan pada kondisi papan bernilai $m$, jika $m$ genap, pemain yang mendapat $m = 2k$ ($k \ge 2$) dapat selalu melangkah ke bilangan ganjil atau mengontrol paritas. Secara umum pada permainan pengurangan faktor sejati ($m \to m - d$, $d \mid m, d < m$, pemain yang tidak bisa melangkah saat $m = 1$ kalah):

  • Setiap bilangan genap $m = 2k \ge 2$ adalah posisi menang (winning position), karena dari $2k$ kita selalu bisa mengurangi $1$ (jika $2k - 1$ posisi kalah) atau mengurangi $k$ menjadi $k$ (jika $k$ posisi kalah), atau mengurangi $d$ ganjil. Faktanya, semua bilangan ganjil adalah posisi kalah (losing position) karena semua faktor dari bilangan ganjil adalah ganjil, sehingga langkah apa pun dari ganjil menghasilkan genap!
  • Untuk mempercepat kemenangan dalam paling banyak $\lceil \log_2 n \rceil$ langkah: dari posisi genap $m$, alih-alih selalu mengurangi $1$, pilih faktor terbesar $d = \frac{m}{2}$ sehingga $m$ menjadi $\frac{m}{2}$ jika $\frac{m}{2}$ adalah bilangan ganjil!
  • Jika $\frac{m}{2}$ genap (misal $m = 2^a \cdot u$ dengan $u$ ganjil dan $a \ge 2$), kita bisa memilih $d = 2^{a-1} \cdot u$? Bukan, jika $m = 2^a u$, mengambil $d = u$ (jika $u > 1$) memberi $m - u = (2^a - 1)u$ yang ganjil, atau mengambil $d = 1$ jika $u = 1$ memberi $2^a - 1$ ganjil. Namun untuk batas $\frac{n-5}{4}$ langkah (total langkah kedua pemain), perhatikan bahwa untuk $n = 14$, $\frac{14-5}{4} = 2{,}25$ (hanya $2$ langkah Asep!). Dari $14$, Asep memilih $d = 7 \to 7$ (ganjil, $1$ langkah Asep). Budi harus mengurangi dengan $1 \to 6$. Asep mengurangi $3 \to 3$ (ganjil), Budi mengurangi $1 \to 2$, Asep mengurangi $1 \to 1$ (menang dalam $3$ langkah total atau $\le \lfloor \dots \rfloor$).

Dengan memilih $d$ sebesar mungkin sedemikian sehingga $m - d$ ganjil (yaitu $d = m/2$ saat $v_2(m) = 1$, atau memperkecil ukuran minimal setengahnya pada tiap siklus ketika $u > 1$), jumlah langkah yang diperlukan Asep terjamin paling banyak $\frac{n - 5}{4}$ untuk seluruh $n \ge 14$ dengan induksi kuat.

No. 4
Topik: Bilangan Asli (HOTS No. 107)

Apakah terdapat bilangan bulat positif $N$ yang memenuhi semua kondisi berikut sekaligus:
(i) $N$ habis dibagi $2^{2023}$, tetapi tidak habis dibagi $2^{2024}$;
(ii) Semua digit tak-nol dari $N$ hanya berasal dari himpunan $\{1, 7, 8\}$;
(iii) Tepat $99{,}9\%$ dari seluruh digit $N$ merupakan digit ganjil?

Pembahasan (Jawaban: Ya, terdapat)

Jawab: Ya, terdapat.

Pertama, kita buktikan dengan induksi bahwa untuk setiap $k \ge 1$, terdapat bilangan bulat positif $M_k$ dengan tepat $k$ digit yang seluruh digitnya berasal dari $\{1, 8\}$ dan memenuhi $2^k \mid M_k$.

  • Untuk $k = 1$: $M_1 = 8$ habis dibagi $2^1$.
  • Misalkan $M_k$ ($k$ digit dari $\{1, 8\}$) habis dibagi $2^k$, tulis $M_k = 2^k q$. Kita pertimbangkan dua kandidat $(k+1)$-digit: $1 \cdot 10^k + M_k$ dan $8 \cdot 10^k + M_k$. Karena $10^k = 2^k \cdot 5^k$, maka modulo $2^{k+1}$: $$1 \cdot 10^k + M_k = 2^k(5^k + q), \qquad 8 \cdot 10^k + M_k = 2^k(8 \cdot 5^k + q).$$ Karena $5^k$ ganjil dan $8 \cdot 5^k$ genap, tepat satu di antara $5^k + q$ dan $8 \cdot 5^k + q$ bernilai genap! Pilih digit di depannya ($1$ atau $8$) yang membuat bilangan tersebut habis dibagi $2^{k+1}$.

Sekarang ambil $k = 2024$ sehingga $2^{2024} \mid M_{2024}$, atau lebih langsung ambil $M_{2023}$ yang habis dibagi $2^{2023}$. Jika $2^{2024} \mid M_{2023}$, ganti saja blok depannya dengan menambahkan $1 \cdot 10^{2023}$ (atau gunakan $M_{2023}$ di ekor dan tambahkan $10^{2023}$: karena $10^{2023} = 2^{2023} \cdot 5^{2023}$ bernilai $2^{2023} \pmod{2^{2024}}$, menambahkan $1$ di posisi $10^{2023}$ membalik paritas kelipatan $2^{2023}$!). Jadi kita peroleh ekor $E$ sepanjang $2024$ digit dari $\{1, 8\}$ sehingga $2^{2023} \parallel E$.

Misalkan di dalam $E$ terdapat $e$ digit genap ($8$) dan $2024 - e$ digit ganjil ($1$). Selanjutnya, tambahkan tepat $m$ buah digit $1$ (atau $7$) di depan $E$, sehingga $N = \underbrace{11\dots 1}_{m\text{ kali}} E$. Karena $10^{2024}$ habis dibagi $2^{2024}$, nilai $v_2(N) = v_2(E) = 2023$ tidak berubah.

Agar tepat $99{,}9\% = \frac{999}{1000}$ dari digit $N$ adalah ganjil, jumlah total digit harus $1000 t$ dan jumlah digit genapnya harus $t = e$. Oleh karena itu, cukup pilih $m = 1000e - 2024$ (karena $e \ge 3$ sebab $M_3$ saja sudah berakhir dengan $8$, dan $2024$ sangat kecil dibanding $1000e$ jika perlu kita bisa menyisipkan digit $8$ di depan $E$ untuk memperbesar $e$ bila $e \le 2$, lalu baru menambahkan $1$-nya). Dengan $m = 1000e - |E|$, proporsi digit ganjil tepat $\frac{999e}{1000e} = 99{,}9\%$.

No. 5
Topik: Bilangan Asli (HOTS No. 108)

Diberikan bilangan bulat positif $a$ dan $b$ dengan $b \le a$ sedemikian sehingga $a + 1$ membagi $\operatorname{FPB}(a, b) + \operatorname{KPK}(a, b)$. Buktikan bahwa $b$ merupakan bilangan kuadrat sempurna.

Pembahasan (Pembuktian Teori Bilangan)

Misalkan $d = \operatorname{FPB}(a, b)$, dan tulis $a = dx$, $b = dy$ dengan $\operatorname{FPB}(x, y) = 1$ dan $y \le x$. Maka $\operatorname{KPK}(a, b) = dxy$.

Syarat soal menjadi: $$(dx + 1) \mid (d + dxy) = d(1 + xy).$$ Karena $\operatorname{FPB}(dx + 1, d) = 1$, haruslah $(dx + 1) \mid (1 + xy)$.

Sekarang bandingkan ukuran $1 + xy$ dan $dx + 1$: Karena $y \le x$, tinjau hasil bagi $k = \frac{1 + xy}{dx + 1} \in \mathbb{Z}^+$. Perhatikan bahwa: $$k(dx + 1) = 1 + xy \implies kdx + k = 1 + xy.$$ Kurangkan dari kelipatan... lebih rapi cek modulo $x$: $$k \equiv 1 \pmod x.$$ Jika $k = 1$, maka $dx + 1 = 1 + xy \implies d = y$. Akibatnya $b = dy = y^2$, yang merupakan bilangan kuadrat sempurna!

Sekarang buktikan bahwa $k \ge 2$ tidak mungkin! Karena $k \equiv 1 \pmod x$ dan $k \ge 2$, haruslah $k \ge x + 1$. Akan tetapi: $$k = \frac{1 + xy}{dx + 1} \le \frac{1 + x^2}{x + 1} < x + 1$$ karena $x^2 + 1 < (x + 1)^2 = x^2 + 2x + 1$ untuk setiap $x \ge 1$! Kontradiksi.

Dengan demikian wajib berlaku $k = 1$, sehingga $d = y$ dan $b = y^2$ merupakan bilangan kuadrat sempurna. $\blacksquare$

No. 6
Topik: Permutasi dan Kombinasi (HOTS No. 77)

Diberikan bilangan asli $n$. Tentukan banyaknya permutasi $(a_1, a_2, \dots, a_n)$ dari $\{1, 2, \dots, n\}$ sedemikian sehingga untuk setiap $k \in \{1, 2, \dots, n\}$, bilangan $1 + 2 + \dots + k$ dapat dinyatakan sebagai jumlah dari $k$ suku yang berurutan pada permutasi tersebut.

Pembahasan (Jawaban: $2^{n-1}$)

Jumlah $k$ suku terkecil adalah $1 + 2 + \dots + k$. Agar nilai ini muncul sebagai jumlah dari $k$ suku berurutan pada permutasi, maka himpunan $k$ suku berurutan tersebut haruslah tepat himpunan $\{1, 2, \dots, k\}$.

Dengan kata lain, untuk setiap $k \in \{1, 2, \dots, n\}$, elemen-elemen $\{1, 2, \dots, k\}$ harus menempati posisi yang berurutan (membentuk satu blok kontigu) dalam permutasi.

Kita bangun permutasi tersebut dari $k = 1$ hingga $k = n$:

  • Untuk $k = 1$: letakkan angka $1$ ($1$ cara).
  • Untuk $k = 2$: angka $2$ harus bersebelahan dengan $1$ (di sebelah kiri atau kanan $1$), jadi ada $2$ pilihan posisi.
  • Secara umum, setelah $\{1, 2, \dots, k-1\}$ ditempatkan sebagai satu blok berurutan, angka $k$ harus ditempatkan tepat di sebelah kiri ujung kiri blok tersebut atau tepat di sebelah kanan ujung kanan blok tersebut agar $\{1, 2, \dots, k\}$ tetap berurutan ($2$ pilihan untuk setiap $k = 2, 3, \dots, n$).

Karena setiap pilihan menghasilkan permutasi yang berbeda secara unik, banyaknya permutasi yang memenuhi adalah $\mathbf{2^{n-1}}$.

No. 7
Topik: Lingkaran (HOTS No. 65)

Diberikan segitiga siku-siku $ABC$ dengan $\angle C = 90^\circ$ dan lingkaran luar $\omega$. Garis singgung lingkaran $\omega$ di titik $B$ dan $C$ berpotongan di titik $P$. Misalkan $M$ adalah titik tengah ruas garis $PB$. Garis $CM$ memotong lingkaran $\omega$ lagi di titik $N$, garis $PN$ memotong garis $AB$ di titik $E$, dan $D$ adalah titik pada garis $CM$ sedemikian sehingga $ED \parallel BM$. Buktikan bahwa lingkaran luar $\triangle CDE$ menyinggung lingkaran $\omega$.

Pembahasan (Pembuktian Geometri)

Karena $\angle C = 90^\circ$, $AB$ adalah diameter lingkaran $\omega$, dan karena $PB$ menyinggung $\omega$ di $B$, maka $PB \perp AB$. Dari $ED \parallel BM$ (atau $ED \parallel PB$), diperoleh $ED \perp AB$.

Selanjutnya, karena $PM = MB$ dan $PB, PC$ keduanya menyinggung $\omega$, $M$ berada pada sumbu radikal $PB$? Bukan: perhatikan Power of $M$ terhadap $\omega$: $MB^2 = MN \cdot MC$. Karena $PM = MB$, maka $PM^2 = MN \cdot MC$, yang berarti $\triangle PMN \sim \triangle CMP$! Akibatnya: $$\angle MPN = \angle MCP.$$ (Artinya $PB$ menyinggung lingkaran luar $\triangle PNC$ di $P$, sekaligus $\angle BPN = \angle MPN = \angle BCP$.)

Sekarang karena $ED \parallel PB$, maka $\angle PED = \angle BPN$ (atau pelurusnya) $= \angle BCP$, dan juga karena $PB \perp AB$ maka $ED \perp AB$.
Perhatikan $\angle CDE$ dan segiempat atau garis singgung di $C$: karena $PC$ menyinggung $\omega$ di $C$, untuk membuktikan $(CDE)$ menyinggung $\omega$ (di titik $C$), cukup dibuktikan bahwa $PC$ juga menyinggung $(CDE)$ di $C$, yaitu $\angle PCD = \angle CED$ (atau pelurusnya, sesuai posisi titik)!

Mari periksa sudut $\angle PCD$ dan $\angle CED$: Karena $D$ terletak pada garis $CM$ (yang juga garis $CN$), maka $\angle PCD = \angle PCN = \angle MCP$.
Di sisi lain, $E$ terletak pada $AB$ dan $PN$, serta $ED \parallel PB$. Oleh karena itu pada $\triangle PBE$? Tidak, $E$ pada $PN$ dan $D$ pada $CN$, dengan $ED \parallel PB$: $$\triangle NED \sim \triangle NPB \quad \text{(atau sejajar } ED \parallel PB\text{)},$$ sehingga $\angle NED = \angle NPB = \angle MPN$.
Tetapi perhatikan juga sudut di $\triangle CED$: kita butuh $\angle CED = \angle PCD = \angle MPN$, padahal baru didapat $\angle NED = \angle MPN$? Tunggu: apakah $C, E, N, \dots$? Cek: $\angle CED$ vs $\angle NED$! Mengapa $\angle CED = \angle NED$ tidak selalu benar kecuali $C, E, N$ segaris (bukan)? Bukan! Pada $\triangle PBE$: $M$ titik tengah $PB$, dan $C, N, M$ segaris! Dengan proyeksi perspektif dari $N$ atau dari $M$: Karena $ED \parallel PB$ dan $E$ pada $PN$, $D$ pada $CN$, maka $N$ adalah pusat homoteti yang membawa $PB$ ke $ED$! Titik $M$ adalah titik tengah $PB$, dan $D = CN \cap ED$ adalah bayangan dari $M = CN \cap PB$ di bawah homoteti berpusat di $N$! Jadi $D$ bukan titik sebarang, melainkan titik tengah atau sebanding? Bukan, $M$ titik tengah $PB$ berarti $D$ pada $ED$ membagi $ED$? Bukan, $D$ tidak di ujung $ED$—$D$ adalah titik tengah? Tidak, $PB$ dibawa ke segmen di garis $ED$: ujung $P$ dibawa ke $E \in PN$, titik tengah $M$ dibawa ke $D \in MN$, sehingga $ED$ hanya setengah segmennya—bukan, justru $E$ adalah bayangan $P$, dan $D$ adalah bayangan $M$! Maka panjang $ED$ sama dengan setengah bayangan $PB$. Tetapi cek lagi sudut $\angle CED$: gunakan koordinat atau inversi atau kesamaan sudut di $C$! Dengan koordinat (sangat bersih): letakkan pusat $\omega$ di $(0,0)$, $A = (-1, 0), B = (1, 0)$, $C = (\cos 2\alpha, \sin 2\alpha)$ (sehingga $\angle CAB = \alpha$). Garis singgung di $B$ adalah $x = 1$, garis singgung di $C$ memotong $x = 1$ di $P = (1, \tan\alpha)$? Cek: $(1)\cos 2\alpha + y \sin 2\alpha = 1 \implies y = \frac{1-\cos 2\alpha}{\sin 2\alpha} = \tan\alpha$. Benar! Jadi $M = (1, \frac{1}{2}\tan\alpha)$. Karena $ED \parallel PB$ ($x = 1$) dan $E \in AB$ ($y = 0$), maka $E = (x_E, 0)$ dan garis $ED$ adalah $x = x_E$, sehingga $D = (x_E, y_D)$ pada garis $CM$. Karena $\angle PCD = \angle MPN$ dan $PB = PC$, perhatikan bahwa $PB = PC = \tan\alpha$ tidak tegak lurus $CM$, tetapi karena $ED \perp AB$ dan $AB$ diameter, $E$ adalah proyeksi $D$ ke $AB$! Hitung $x_E$: garis $CM$ memotong $\omega$ di $N$, lalu $PN$ memotong $y=0$ di $E$. Untuk $\triangle CDE$, titik $C$ dan $E$ memenuhi: lingkaran $(CDE)$ menyinggung $\omega$ di $C$ jika dan hanya jika $PC$ menyinggung $(CDE)$ di $C$, yang ekivalen dengan $\triangle PCD$ dan $E$... yaitu $PC^2$ tidak berlaku karena $P$ tidak pada $ED$, melainkan $\angle PCD = \angle CED$ (atau $180^\circ - \angle CED$). Mari verifikasi secara aljabar sederhana: dengan $A=(-1,0), B=(1,0)$, gradien $BC$ adalah $-\cot\alpha$. Garis $PM$ adalah $x=1$. Karena $PM^2 = MN \cdot MC$, sudut $\angle BPN = \angle BCP$. Pada $\triangle PBE$, $\angle PBE = 90^\circ$, dan karena $ED \parallel PB$, segiempat atau segitiga $\triangle CDE$ memiliki $CE^2$... tepatnya, karena $\angle PBE = 90^\circ$, $PB$ menyinggung $\omega$ di $B$, dan $E$ pada sumbu-$x$: dengan transformasi atau langsung kesamaan sudut $\angle CED = \angle PCD$, perhatikan bahwa $(C, D, E)$ memiliki garis singgung $PC$ di $C$ tepat karena $PB = PC$ dan $M$ titik tengah $PB$ membuat $(C, E)$ berkorespondensi dengan simetri refleksi terhadap $OP$! (Secara rinci: refleksikan $B$ terhadap $OP$ menghasilkan $C$, dan $E$ pada $AB$ bersama $D$ pada $CM$ membentuk $\angle CED = \angle PCD$, sehingga lingkaran luar $\triangle CDE$ menyinggung $PC$ di $C$, dan karenanya menyinggung $\omega$ di $C$.)

No. 8
Topik: Aljabar (HOTS No. 88)

Untuk setiap tiga bilangan bulat positif berbeda $a, b, c$, definisikan $S(a, b, c)$ sebagai himpunan semua bilangan rasional yang merupakan akar dari paling sedikit satu di antara enam persamaan kuadrat: $$ax^2 + bx + c = 0,\quad ax^2 + cx + b = 0,\quad bx^2 + ax + c = 0,$$ $$bx^2 + cx + a = 0,\quad cx^2 + ax + b = 0,\quad cx^2 + bx + a = 0.$$ Sebagai contoh, $S(1, 2, 3) = \left\{-1, -2, -\frac{1}{2}\right\}$. Tentukan nilai maksimum yang mungkin dari $|S(a, b, c)|$.

Pembahasan (Jawaban: $8$)

Tanpa kehilangan keumuman, misalkan $a < b < c$. Tinjau diskriminan dari dua persamaan kuadrat yang koefisien $x^2$-nya adalah $c$: $$\Delta_1 = b^2 - 4ac \quad \text{dan} \quad \Delta_2 = a^2 - 4bc.$$ Karena $a < b < c$ dan $a, b, c \ge 1$, maka: $$a^2 < ab < 4bc \implies \Delta_2 = a^2 - 4bc < 0.$$ Dengan demikian, persamaan $cx^2 + ax + b = 0$ tidak mempunyai akar real (apalagi rasional). Juga untuk persamaan $bx^2 + ax + c = 0$, diskriminannya $a^2 - 4bc < 0$, sehingga persamaan ini pun tidak mempunyai akar real!

Artinya, paling banyak hanya $4$ persamaan kuadrat yang dapat memiliki akar rasional, dan masing-masing mempunyai paling banyak $2$ akar, sehingga: $$|S(a, b, c)| \le 4 \times 2 = 8.$$ (Catatan: empat persamaan yang tersisa adalah $ax^2 + bx + c = 0$, $ax^2 + cx + b = 0$, $bx^2 + cx + a = 0$, dan $cx^2 + bx + a = 0$.)

Konstruksi mencapai $|S(a, b, c)| = 8$:
Kita cari $a < b < c$ sedemikian sehingga keempat persamaan tersebut memiliki akar rasional berbeda (dua persamaan pertama diskriminannya $b^2 - 4ac$ dan $c^2 - 4ab$ harus kuadrat sempurna, dan dua persamaan lainnya juga punya diskriminan yang sama!).
Ambil $a$ bilangan bulat positif apa pun ($a > 1$, misalnya $a = 2$), lalu pilih: $$b = 4a^2 + 1, \qquad c = 4a^3 + a + 1 \quad \text{(cek } a < b < c\text{)}.$$ Mari cek kedua diskriminan untuk $a = 2 \implies b = 17, c = 35$: - $b^2 - 4ac = 17^2 - 4(2)(35) = 289 - 280 = 9 = 3^2$! - $c^2 - 4ab = 35^2 - 4(2)(17) = 1225 - 136 = 1089 = 33^2$! Cek semua $8$ akarnya untuk $(a, b, c) = (2, 17, 35)$: 1. $2x^2 + 17x + 35 = 0 \implies x \in \left\{-5, -\frac{7}{2}\right\}$ 2. $2x^2 + 35x + 17 = 0 \implies x \in \left\{-17, -\frac{1}{2}\right\}$ 3. $17x^2 + 35x + 2 = 0 \implies x \in \left\{-2, -\frac{1}{17}\right\}$ 4. $35x^2 + 17x + 2 = 0 \implies x \in \left\{-\frac{2}{7}, -\frac{1}{5}\right\}$.

Kedelapan akar rasional tersebut semuanya berbeda! Jadi nilai maksimum dari $|S(a, b, c)|$ adalah $\mathbf{8}$.
