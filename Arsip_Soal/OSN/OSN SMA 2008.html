Hari Pertama (Nomor 1–4)

Hari Pertama - No. 1
Diberikan segitiga $ABC$. Titik-titik $D$, $E$, dan $F$ di luar segitiga $ABC$ sedemikian sehingga segitiga $ABD$, segitiga $BCE$, dan segitiga $CAF$ adalah segitiga sama sisi. Buktikan bahwa ketiga lingkaran luar segitiga tersebut berpotongan di satu titik.
Topik: Lingkaran
Pembahasan:

Misalkan lingkaran luar $\triangle ACF$ dan lingkaran luar $\triangle BCE$ berpotongan di titik $C$ dan titik kedua $K$.

Dengan menggunakan sudut berarah modulo $180^\circ$ (yang berlaku umum baik ketika $K$ berada di dalam maupun di luar $\triangle ABC$):

  • Karena $A, K, C, F$ terletak pada satu lingkaran dan $\triangle CAF$ sama sisi, maka $\measuredangle AKC = \measuredangle AFC = \pm 60^\circ$ (dalam konfigurasi standar di dalam segitiga, $\angle AKC = 180^\circ - \angle AFC = 120^\circ$).
  • Karena $B, K, C, E$ terletak pada satu lingkaran dan $\triangle BCE$ sama sisi, maka $\measuredangle CKB = \measuredangle CEB = \pm 60^\circ$ ($\angle BKC = 180^\circ - \angle BEC = 120^\circ$).

Akibatnya, sudut $\angle AKB = 360^\circ - 120^\circ - 120^\circ = 120^\circ$ (atau secara sudut berarah $\measuredangle AKB = \measuredangle AKC + \measuredangle CKB \equiv \measuredangle ADB \pmod{180^\circ}$).

Karena $\angle AKB + \angle ADB = 120^\circ + 60^\circ = 180^\circ$, segiempat $AKBD$ merupakan segiempat tali busur, yang berarti titik $K$ juga terletak pada lingkaran luar $\triangle ABD$.

Terbukti bahwa ketiga lingkaran luar $\triangle ABD$, $\triangle BCE$, dan $\triangle CAF$ berpotongan di satu titik (titik $K$). $\blacksquare$
Hari Pertama - No. 2
Buktikan bahwa untuk $x$ dan $y$ bilangan real positif, berlaku $$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{2}{x + y + 2}$$
Topik: AM GM HM QM
Pembahasan:

Dengan ketaksamaan AM-GM pada $x$ dan $1$ (atau dari $(\sqrt{x} - 1)^2 \ge 0$), berlaku $2\sqrt{x} \le x + 1$, sehingga:

$$(1 + \sqrt{x})^2 = 1 + 2\sqrt{x} + x \le 2(x + 1) \implies \frac{1}{(1 + \sqrt{x})^2} \ge \frac{1}{2(x + 1)}$$

Secara identik untuk $y$, diperoleh $\dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{1}{2(y + 1)}$. Jumlahkan keduanya:

$$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{1}{2}\left(\frac{1}{x + 1} + \frac{1}{y + 1}\right)$$

Selanjutnya, terapkan ketaksamaan AM-HM pada $x + 1$ dan $y + 1$:

$$\frac{1}{x + 1} + \frac{1}{y + 1} \ge \frac{4}{(x + 1) + (y + 1)} = \frac{4}{x + y + 2}$$

Substitusikan ke pertidaksamaan sebelumnya:

$$\frac{1}{(1 + \sqrt{x})^2} + \frac{1}{(1 + \sqrt{y})^2} \ge \frac{1}{2} \cdot \frac{4}{x + y + 2} = \frac{2}{x + y + 2}$$

Kesamaan terjadi jika dan hanya jika $x = y = 1$.

Terbukti bahwa $\dfrac{1}{(1 + \sqrt{x})^2} + \dfrac{1}{(1 + \sqrt{y})^2} \ge \dfrac{2}{x + y + 2}$ untuk semua $x, y > 0$. $\blacksquare$
Hari Pertama - No. 3
Carilah semua bilangan asli yang dapat dinyatakan dalam bentuk $$\frac{a + b}{c} + \frac{b + c}{a} + \frac{c + a}{b}$$ untuk suatu $a$, $b$, dan $c$ bilangan asli dengan $\text{FPB}(a, b) = \text{FPB}(b, c) = \text{FPB}(c, a) = 1$.
Topik: Bilangan Asli
Pembahasan:

Misalkan jumlah tersebut bernilai bilangan asli $k$. Samakan penyebutnya:

$$\frac{ab(a + b) + ac(a + c) + bc(b + c)}{abc} = k$$

Karena $c$ membagi $abc$ sekaligus $ac(a + c) + bc(b + c)$, maka $c \mid ab(a + b)$. Mengingat $\text{FPB}(c, a) = \text{FPB}(c, b) = 1$, diperoleh $c \mid (a + b)$. Secara simetris berlaku pula $b \mid (a + c)$ dan $a \mid (b + c)$.

Tanpa mengurangi keumuman, misalkan $a = \max(a, b, c)$. Karena $a \le b + c \le 2a$ dan $a \mid (b + c)$, hanya ada dua kemungkinan:

  • Kasus 1 ($b + c = 2a$): Karena $b \le a$ dan $c \le a$, haruslah $a = b = c$. Dari $\text{FPB}(a, b) = 1$, didapat $a = b = c = 1$, menghasilkan $k = 2 + 2 + 2 = 6$.
  • Kasus 2 ($b + c = a$): Karena $b \mid (a + c) = (2a - b)$, maka $b \mid 2a$. Mengingat $\text{FPB}(b, a) = 1$, haruslah $b \mid 2 \implies b \in \{1, 2\}$. Secara identik $c \in \{1, 2\}$. Mengingat $\text{FPB}(b, c) = 1$:
    • $(b, c) = (1, 1) \implies a = 2 \implies k = \dfrac{3}{1} + \dfrac{2}{2} + \dfrac{3}{1} = 7$.
    • $(b, c) = (1, 2)$ atau $(2, 1) \implies a = 3 \implies k = \dfrac{4}{2} + \dfrac{3}{3} + \dfrac{5}{1} = 8$.
Jadi, semua bilangan asli yang dapat dinyatakan dalam bentuk tersebut adalah $6$, $7$, dan $8$.
Hari Pertama - No. 4
Misalkan $A = \{1, 2, \dots, 2008\}$.
  1. Tentukan cacah subhimpunan dari $A$ yang hasil kali semua anggotanya habis dibagi $7$.
  2. Misalkan $N(i)$ menyatakan cacah subhimpunan dari $A$ yang jumlah semua anggotanya bersisa $i$ jika dibagi $7$. Buktikan bahwa $\displaystyle\sum_{i=0}^{7} (-1)^i N(i) = 0$.
Topik: Himpunan
Pembahasan:

a. Banyaknya seluruh subhimpunan dari $A$ adalah $2^{2008}$. Hasil kali anggota suatu subhimpunan $S \subseteq A$ tidak habis dibagi $7$ jika dan hanya jika $S$ tidak memuat satu pun bilangan kelipatan $7$.

Banyaknya bilangan kelipatan $7$ di dalam $A$ adalah $\left\lfloor \dfrac{2008}{7} \right\rfloor = 286$, sehingga ada $2008 - 286 = 1722$ anggota yang bukan kelipatan $7$. Banyaknya subhimpunan tanpa kelipatan $7$ adalah $2^{1722}$.

Jadi, cacah subhimpunan yang hasil kali anggotanya habis dibagi $7$ adalah $2^{2008} - 2^{1722}$.

b. Definisikan pemetaan komplemen $f : \mathcal{P}(A) \to \mathcal{P}(A)$ dengan $f(S) = \{2009 - x : x \in S\}$. Karena $2009 = 7 \times 287$ habis dibagi $7$, untuk setiap subhimpunan $S = \{x_1, \dots, x_k\}$ dengan jumlah anggota $s(S) \equiv i \pmod 7$:

$$s(f(S)) = \sum_{j=1}^{k} (2009 - x_j) = 2009k - s(S) \equiv -i \equiv 7 - i \pmod 7$$

Karena $f$ merupakan bijeksi ($f(f(S)) = S$), diperoleh $N(i) = N(7 - i)$ untuk setiap $i \in \{1, 2, 3, 4, 5, 6\}$. Akibatnya:

$$\sum_{i=1}^{6} (-1)^i N(i) = \bigl(N(6) - N(1)\bigr) + \bigl(N(2) - N(5)\bigr) + \bigl(N(4) - N(3)\bigr) = 0$$

Catatan: Pada penulisan naskah resmi jika indeks dimulai dari $i = 0$ sampai $7$, secara definisi sisa bagi oleh $7$ bernilai di $\{0, \dots, 6\}$ sehingga $N(7) = 0$ sedangkan $N(0) > 0$; identitas bernilai tepat $0$ pada rentang indeks sisa tak nol $i = 1, \dots, 6$.

Jadi, jawaban bagian (a) adalah $2^{2008} - 2^{1722}$, dan pada bagian (b) terbukti $N(i) = N(7 - i)$ untuk $i \in \{1, \dots, 6\}$ sehingga jumlah selang-selingnya bernilai $0$. $\blacksquare$

Hari Kedua (Nomor 5–8)

Hari Kedua - No. 5
Misalkan $m, n > 1$ bilangan-bilangan bulat sedemikian hingga $n$ membagi $4^m - 1$ dan $2^m$ membagi $n - 1$. Haruskah $n = 2^m + 1$? Jelaskan.
Topik: Bilangan Bulat
Pembahasan:

Karena $2^m \mid (n - 1)$ dan $n > 1$, dapat ditulis $n = k \cdot 2^m + 1$ untuk suatu bilangan asli $k \ge 1$. Karena $n \mid (4^m - 1)$, diperoleh:

$$k \cdot 2^m + 1 = n \le 4^m - 1 < 4^m + 1 \implies k < 2^m$$

Selanjutnya, karena $n \mid (4^m - 1)$, maka $n$ juga membagi $k^2(4^m - 1)$:

$$k^2(4^m - 1) = (k \cdot 2^m)^2 - k^2 = (n - 1)^2 - k^2 = (n^2 - 2n) + (1 - k^2)$$

Karena $n \mid (n^2 - 2n)$, haruslah $n \mid (k^2 - 1)$. Andaikan $k > 1$, maka $k^2 - 1 > 0$ sehingga:

$$n \le k^2 - 1 < k^2 < k \cdot 2^m < k \cdot 2^m + 1 = n$$

Terjadi kontradiksi. Oleh karena itu, haruslah $k = 1$, yang memberikan $n = 2^m + 1$ (yang memang memenuhi $2^m \mid 2^m$ dan $2^m + 1 \mid (2^m + 1)(2^m - 1) = 4^m - 1$).

Jadi, ya, haruslah $n = 2^m + 1$. $\blacksquare$
Hari Kedua - No. 6
Ada $21$ orang berhubungan secara rahasia dengan menggunakan frekuensi gelombang radio yang berbeda. Ada pasangan dua orang yang dapat berhubungan, mungkin ada yang tidak dapat. Setiap pasang yang berhubungan hanya menggunakan satu frekuensi tertentu yang berbeda dengan frekuensi yang digunakan pasangan lain. Setiap tiga orang selalu ada dua orang di antaranya yang tidak dapat berhubungan. Tentukan banyak maksimum frekuensi berbeda yang diperlukan dan jelaskan.
Topik: Aturan Pencacahan
Pembahasan:

Modelkan ke-$21$ orang sebagai simpul graf sederhana $G$ dengan $21$ simpul, dan setiap frekuensi yang digunakan sepasang orang sebagai satu sisi. Syarat "setiap tiga orang selalu ada dua orang yang tidak berhubungan" berarti graf $G$ tidak memuat segitiga ($K_3$).

Batas atas (Teorema Mantel): Misalkan $v$ adalah simpul dengan derajat maksimum $d$ pada $G$, dan $N(v)$ adalah himpunan $d$ tetangga dari $v$. Karena $G$ bebas segitiga, tidak ada satu pun sisi yang menghubungkan dua simpul di dalam $N(v)$. Artinya, setiap sisi di $G$ sedikitnya memiliki satu ujung di himpunan $V \setminus N(v)$ yang beranggotakan $21 - d$ simpul.

Karena setiap simpul di $V \setminus N(v)$ berderajat paling banyak $d$, banyaknya sisi (frekuensi) pada $G$ memenuhi:

$$|E(G)| \le \sum_{u \in V \setminus N(v)} \deg(u) \le d(21 - d) = \frac{441}{4} - \left(d - \frac{21}{2}\right)^2$$

Karena $d$ bilangan bulat, nilai maksimum $d(21 - d)$ tercapai saat $d = 10$ atau $d = 11$, yakni $10 \times 11 = 110$.

Konstruksi: Bagi ke-$21$ orang menjadi dua kelompok berisi $10$ orang dan $11$ orang, lalu hubungkan setiap orang di kelompok pertama dengan setiap orang di kelompok kedua (graf bipartit lengkap $K_{10, 11}$). Tidak ada segitiga karena setiap himpunan $3$ orang pasti memiliki $2$ orang di kelompok yang sama, dan banyaknya frekuensi tepat $10 \times 11 = 110$.

Jadi, banyak maksimum frekuensi berbeda yang diperlukan adalah $110$.
Hari Kedua - No. 7
Diberikan segitiga $ABC$ dengan panjang sisi-sisinya $a$, $b$, dan $c$. Garis-garis singgung lingkaran dalam segitiga $ABC$ yang sejajar dengan sisi-sisi segitiga $ABC$ membentuk tiga segitiga kecil. Pada masing-masing segitiga kecil dibuat lingkaran dalam. Buktikan bahwa jumlah luas dari lingkaran dalam segitiga $ABC$ dan ketiga lingkaran dalam segitiga kecil adalah $$\frac{\pi(a^2 + b^2 + c^2)(b + c - a)(c + a - b)(a + b - c)}{(a + b + c)^3}$$
Topik: Lingkaran
Pembahasan:

Misalkan $s = \dfrac{a + b + c}{2}$ dan $r$ adalah jari-jari lingkaran dalam $\triangle ABC$. Dari rumus luas $[\triangle ABC] = rs = \sqrt{s(s - a)(s - b)(s - c)}$ diperoleh:

$$r^2 = \frac{(s - a)(s - b)(s - c)}{s} = \frac{(b + c - a)(c + a - b)(a + b - c)}{4(a + b + c)}$$

Misalkan $t_A$ adalah tinggi $\triangle ABC$ dari $A$ ke $BC$, sehingga $[\triangle ABC] = \dfrac{1}{2}at_A = \dfrac{1}{2}r(a + b + c) \implies \dfrac{r}{t_A} = \dfrac{a}{a + b + c}$.

Garis singgung lingkaran dalam yang sejajar $BC$ memotong $AB$ di $D$ dan $AC$ di $E$. Karena garis singgung tersebut berjarak $2r$ dari $BC$, tinggi $\triangle ADE$ dari $A$ adalah $t_1 = t_A - 2r$. Karena $\triangle ADE \sim \triangle ABC$, jari-jari lingkaran dalam $\triangle ADE$ ($r_1$) memenuhi:

$$\frac{r_1}{r} = \frac{t_1}{t_A} = 1 - \frac{2r}{t_A} = 1 - \frac{2a}{a + b + c} = \frac{b + c - a}{a + b + c}$$

Dengan cara yang sama, jari-jari lingkaran dalam dua segitiga kecil lainnya ($r_2$ dan $r_3$) adalah:

$$r_2 = \frac{c + a - b}{a + b + c}\,r \quad \text{dan} \quad r_3 = \frac{a + b - c}{a + b + c}\,r$$

Jumlah luas keempat lingkaran dalam tersebut adalah $L = \pi(r^2 + r_1^2 + r_2^2 + r_3^2)$:

$$L = \pi r^2 \cdot \frac{(a + b + c)^2 + (b + c - a)^2 + (c + a - b)^2 + (a + b - c)^2}{(a + b + c)^2}$$

Dengan menjabarkan keempat kuadrat pada pembilang, seluruh suku silang $2ab, 2bc, 2ca$ saling meniadakan (masing-masing muncul dua kali positif dan dua kali negatif), menyisakan $4(a^2 + b^2 + c^2)$:

$$L = \pi \cdot \frac{(b + c - a)(c + a - b)(a + b - c)}{4(a + b + c)} \cdot \frac{4(a^2 + b^2 + c^2)}{(a + b + c)^2} = \frac{\pi(a^2 + b^2 + c^2)(b + c - a)(c + a - b)(a + b - c)}{(a + b + c)^3}$$
Terbukti bahwa jumlah luas keempat lingkaran dalam tersebut adalah $\dfrac{\pi(a^2 + b^2 + c^2)(b + c - a)(c + a - b)(a + b - c)}{(a + b + c)^3}$. $\blacksquare$
Hari Kedua - No. 8
Tentukan semua fungsi $f : \mathbb{N} \to \mathbb{N}$ yang memenuhi $$f(mn) + f(m + n) = f(m)f(n) + 1$$ untuk semua $m, n \in \mathbb{N}$.
Topik: Fungsi
Pembahasan:

Substitusikan beberapa nilai kecil untuk $(m, n)$:

  • $(1, 1) \implies f(1) + f(2) = f(1)^2 + 1$.
  • $(1, 2) \implies f(2) + f(3) = f(1)f(2) + 1$.
  • $(2, 2) \implies 2f(4) = f(2)^2 + 1$.
  • $(1, 3) \implies f(3) + f(4) = f(1)f(3) + 1$.

Misalkan $a = f(1)$ dan $b = f(2)$, sehingga $b = a^2 - a + 1$ dan $f(3) = ab - b + 1$, serta $f(4) = \dfrac{b^2 + 1}{2}$. Substitusi ke persamaan keempat:

$$(ab - b + 1) + \frac{b^2 + 1}{2} = a(ab - b + 1) + 1 \implies 2a^2b - b^2 - 4ab + 2a + 2b - 1 = 0$$

Substitusikan $b = a^2 - a + 1$ lalu sederhanakan:

$$a^4 - 4a^3 + 5a^2 - 2a = 0 \iff a(a - 1)^2(a - 2) = 0$$

Karena $a = f(1) \in \mathbb{N}$, nilai $f(1)$ yang mungkin hanyalah $1$ atau $2$:

  • Kasus $f(1) = 1$: Substitusi $n = 1$ memberi $f(m) + f(m + 1) = f(m) + 1 \implies f(m + 1) = 1$ untuk semua $m \in \mathbb{N}$. Jadi $f(x) = 1$ untuk semua $x \in \mathbb{N}$. Uji ke persamaan awal: $1 + 1 = 1 \cdot 1 + 1$ (memenuhi).
  • Kasus $f(1) = 2$: Substitusi $n = 1$ memberi $f(m) + f(m + 1) = 2f(m) + 1 \implies f(m + 1) = f(m) + 1$. Dengan induksi dari $f(1) = 2$, diperoleh $f(x) = x + 1$ untuk semua $x \in \mathbb{N}$. Uji ke persamaan awal: $(mn + 1) + (m + n + 1) = mn + m + n + 2 = (m + 1)(n + 1) + 1$ (memenuhi).
Jadi, semua fungsi $f : \mathbb{N} \to \mathbb{N}$ yang memenuhi adalah $f(x) = 1$ dan $f(x) = x + 1$.
