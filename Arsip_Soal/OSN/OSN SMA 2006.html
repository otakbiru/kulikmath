Hari Pertama (Nomor 1–4)

Hari Pertama - No. 1
Tentukan semua pasangan bilangan real \((x, y)\) yang memenuhi: \[ \begin{cases} x^3 - y^3 = 4(x - y) \\ x^3 + y^3 = 2(x + y) \end{cases} \]
Topik: Sistem Persamaan Aljabar
Pembahasan:

Pindahkan seluruh suku ke ruas kiri lalu faktorkan kedua persamaan:

  1. \(x^3 - y^3 = 4(x - y) \iff (x - y)(x^2 + xy + y^2 - 4) = 0\), sehingga: \[x = y \qquad \text{atau} \qquad x^2 + xy + y^2 = 4 \quad \text{...(i)}\]
  2. \(x^3 + y^3 = 2(x + y) \iff (x + y)(x^2 - xy + y^2 - 2) = 0\), sehingga: \[x = -y \qquad \text{atau} \qquad x^2 - xy + y^2 = 2 \quad \text{...(ii)}\]

Gabungkan syarat pada (i) dan (ii) menjadi empat kasus:

  • Kasus 1: \(x = y\) dan \(x = -y\).
    Diperoleh \(2x = 0 \implies x = 0,\; y = 0\), sehingga menghasilkan pasangan \((0, 0)\).
  • Kasus 2: \(x = y\) dan \(x^2 - xy + y^2 = 2\).
    Substitusikan \(y = x\): \[x^2 - x^2 + x^2 = 2 \iff x^2 = 2 \implies x = \pm\sqrt{2}\] Diperoleh pasangan \((\sqrt{2}, \sqrt{2})\) dan \((-\sqrt{2}, -\sqrt{2})\).
  • Kasus 3: \(x = -y\) dan \(x^2 + xy + y^2 = 4\).
    Substitusikan \(y = -x\): \[x^2 - x^2 + x^2 = 4 \iff x^2 = 4 \implies x = \pm 2\] Diperoleh pasangan \((2, -2)\) dan \((-2, 2)\).
  • Kasus 4: \(x^2 + xy + y^2 = 4\) dan \(x^2 - xy + y^2 = 2\).
    Kurangkan kedua persamaan: \[2xy = 2 \implies xy = 1\] Jumlahkan kedua persamaan: \[2(x^2 + y^2) = 6 \implies x^2 + y^2 = 3\] Maka \((x + y)^2 = x^2 + y^2 + 2xy = 3 + 2(1) = 5\), sehingga \(x + y = \pm\sqrt{5}\).
    Dengan \(s = x + y\) dan \(xy = 1\), bilangan \(x\) dan \(y\) merupakan akar-akar persamaan kuadrat \(t^2 - st + 1 = 0\): \[t = \frac{s \pm \sqrt{s^2 - 4}}{2} = \frac{s \pm \sqrt{5 - 4}}{2} = \frac{s \pm 1}{2}\]
    • Untuk \(s = \sqrt{5}\): diperoleh \(\left(\dfrac{\sqrt{5} + 1}{2},\; \dfrac{\sqrt{5} - 1}{2}\right)\) dan \(\left(\dfrac{\sqrt{5} - 1}{2},\; \dfrac{\sqrt{5} + 1}{2}\right)\).
    • Untuk \(s = -\sqrt{5}\): diperoleh \(\left(\dfrac{-\sqrt{5} + 1}{2},\; \dfrac{-\sqrt{5} - 1}{2}\right)\) dan \(\left(\dfrac{-\sqrt{5} - 1}{2},\; \dfrac{-\sqrt{5} + 1}{2}\right)\).

Keempat kasus di atas memberi tepat \(9\) pasangan real yang berbeda dan semuanya memenuhi faktorisasi awal kedua persamaan.

Jadi, ada \(9\) pasangan bilangan real \((x, y)\) yang memenuhi, yaitu:
\((0, 0),\; (\sqrt{2}, \sqrt{2}),\; (-\sqrt{2}, -\sqrt{2}),\; (2, -2),\; (-2, 2),\; \left(\dfrac{\sqrt{5} \pm 1}{2},\; \dfrac{\sqrt{5} \mp 1}{2}\right),\; \left(\dfrac{-\sqrt{5} \pm 1}{2},\; \dfrac{-\sqrt{5} \mp 1}{2}\right)\).
Hari Pertama - No. 2
Misalkan \(a, b, c\) adalah bilangan-bilangan asli. Jika \(30 \mid (a + b + c)\), buktikan bahwa \(30 \mid (a^5 + b^5 + c^5)\).

[Catatan: \(x \mid y\) menyatakan \(x\) habis membagi \(y\).]
Topik: Modulo
Pembahasan:

Untuk sebarang bilangan bulat \(n\), perhatikan identitas aljabar berikut:

\[n^5 - n = n(n^4 - 1) = n(n - 1)(n + 1)(n^2 + 1)\]

Tulis \(n^2 + 1 = (n^2 - 4) + 5 = (n - 2)(n + 2) + 5\), sehingga:

\[n^5 - n = (n - 2)(n - 1)n(n + 1)(n + 2) + 5(n - 1)n(n + 1)\]

Sekarang perhatikan keterbagian kedua suku oleh \(30\):

  • Suku pertama \((n - 2)(n - 1)n(n + 1)(n + 2)\) adalah hasil kali \(5\) bilangan bulat berurutan, sehingga pasti habis dibagi \(5! = 120\), dan khususnya habis dibagi \(30\).
  • Suku kedua memuat \((n - 1)n(n + 1)\), yaitu hasil kali \(3\) bilangan bulat berurutan, sehingga habis dibagi \(3! = 6\). Akibatnya, \(5(n - 1)n(n + 1)\) habis dibagi \(5 \times 6 = 30\).

(Sebagai alternatif, lewat Teorema Kecil Fermat untuk faktor prima \(30 = 2 \times 3 \times 5\): diperoleh \(n^5 \equiv n \pmod{2}\), \(n^5 = n^3 \cdot n^2 \equiv n \cdot n^2 = n^3 \equiv n \pmod{3}\), dan \(n^5 \equiv n \pmod{5}\), sehingga \(n^5 \equiv n \pmod{30}\).)

Dengan demikian, \(30 \mid (n^5 - n)\) untuk setiap \(n \in \mathbb{Z}\). Terapkan hasil ini pada \(n = a, b, c\) lalu jumlahkan:

\[(a^5 + b^5 + c^5) - (a + b + c) = (a^5 - a) + (b^5 - b) + (c^5 - c) \equiv 0 \pmod{30}\]

Karena diketahui \(30 \mid (a + b + c)\), yaitu \(a + b + c \equiv 0 \pmod{30}\), maka:

\[a^5 + b^5 + c^5 \equiv a + b + c \equiv 0 \pmod{30}\]

Jadi terbukti bahwa \(30 \mid (a^5 + b^5 + c^5)\). \(\blacksquare\)

Jadi, terbukti bahwa \(30 \mid (a^5 + b^5 + c^5)\).
Hari Pertama - No. 3
Misalkan \(S\) adalah himpunan semua segitiga \(ABC\) yang memenuhi sifat: \(\tan A\), \(\tan B\) dan \(\tan C\) adalah bilangan-bilangan asli. Buktikan bahwa semua segitiga anggota \(S\) sebangun.
Topik: Trigonometri Pada Segitiga
Pembahasan:

Misalkan \(x = \tan A\), \(y = \tan B\), dan \(z = \tan C\). Karena \(x, y, z \in \mathbb{N}\) bernilai positif (sedangkan tangen bernilai negatif untuk sudut tumpul dan tak terdefinisi di \(90^\circ\)), maka ketiga sudut \(A, B, C\) harus lancip (\(0^\circ \lt A, B, C \lt 90^\circ\)).

Dalam segitiga berlaku \(A + B + C = 180^\circ \implies A + B = 180^\circ - C\). Karena \(C \lt 90^\circ\), maka \(A + B \gt 90^\circ\) (terutama \(A + B \neq 90^\circ\)), sehingga identitas tangen dapat diterapkan:

\[\tan(A + B) = \tan(180^\circ - C) \implies \frac{\tan A + \tan B}{1 - \tan A \tan B} = -\tan C\]

Substitusikan \(x, y, z\):

\[\frac{x + y}{1 - xy} = -z \implies x + y = z(xy - 1) \implies x + y + z = xyz\]

Tanpa mengurangi perumuman, urutkan \(1 \le x \le y \le z\). Akibatnya:

\[xyz = x + y + z \le z + z + z = 3z\]

Karena \(z \ge 1 \gt 0\), bagi kedua ruas dengan \(z\):

\[xy \le 3\]

Karena \(1 \le x \le y\) adalah bilangan asli, hanya ada tiga kemungkinan pasangan \((x, y)\):

  • \((x, y) = (1, 1)\): \(1 + 1 + z = z \implies 2 = 0\) (tidak ada solusi).
  • \((x, y) = (1, 2)\): \(1 + 2 + z = 2z \implies z = 3\) (memenuhi \(1 \le 2 \le 3\)).
  • \((x, y) = (1, 3)\): \(1 + 3 + z = 3z \implies 2z = 4 \implies z = 2\) (melanggar \(y \le z\), dan menghasilkan multihimpunan yang sama dengan kasus sebelumnya).

Dengan demikian, untuk setiap \(\triangle ABC \in S\), multihimpunan nilai tangen sudut-sudutnya selalu unik, yakni:

\[\{\tan A, \tan B, \tan C\} = \{1, 2, 3\}\]

Karena fungsi \(f(\theta) = \tan \theta\) monoton naik sejati pada selang \((0^\circ, 90^\circ)\), nilai masing-masing sudut juga ditentukan secara tunggal, yaitu \(\{45^\circ, \arctan 2, \arctan 3\}\) (sekitar \(45^\circ\), \(63{,}43^\circ\), dan \(71{,}57^\circ\)).

Karena setiap dua segitiga dalam \(S\) memiliki ketiga pasang sudut bersesuaian yang sama besar (kriteria Sudut–Sudut–Sudut), maka semua segitiga anggota \(S\) sebangun. \(\blacksquare\)

Jadi, terbukti bahwa semua segitiga anggota \(S\) saling sebangun (dengan tangen sudut-sudutnya \(1, 2, 3\)).
Hari Pertama - No. 4
Misalkan \(n \gt 2\) sebuah bilangan asli tetap. Sebuah bidak hitam ditempatkan pada petak pertama dan sebuah bidak putih ditempatkan pada petak terakhir sebuah papan 'catur' berukuran \(1 \times n\). Wiwit dan Siti lalu melangkah bergantian. Wiwit memulai permainan dengan bidak putih. Pada setiap langkah, pemain memindahkan bidaknya sendiri satu atau dua petak ke kanan atau ke kiri tanpa melompati bidak lawan. Pemain yang tidak bisa melangkah dinyatakan kalah. Pemain manakah yang memiliki cara (strategi) untuk selalu memenangkan permainan, apa pun yang dilakukan lawannya? Jelaskan strategi pemain tersebut!
Topik: Matematika Terapan
Pembahasan:

Beri nomor petak papan \(1 \times n\) dari kiri ke kanan sebagai \(1, 2, \dots, n\). Misalkan posisi bidak hitam (milik Siti) adalah \(b\) dan posisi bidak putih (milik Wiwit) adalah \(w\). Karena kedua bidak tidak dapat melompati satu sama lain, selalu berlaku \(1 \le b \lt w \le n\).

Definisikan jarak kosong di antara kedua bidak:

\[d = w - b - 1 \ge 0\]

Pada posisi awal, \(b = 1\) dan \(w = n\), sehingga \(d_0 = n - 2 \ge 1\). Perhatikan bahwa Wiwit (putih) kalah hanya jika pada gilirannya bidak terjepit di ujung kanan dengan \((b, w) = (n - 1, n)\), sedangkan Siti (hitam) kalah hanya jika pada gilirannya bidak terjepit di ujung kiri dengan \((b, w) = (1, 2)\).

Pemenang ditentukan oleh sisa pembagian \(n\) oleh \(3\) (atau ekuivalennya sisa \(d_0 = n - 2\) modulo \(3\)):

  1. Kasus 1: \(n \equiv 2 \pmod{3}\) (misalnya \(n = 5, 8, 11, \dots\)). Maka Siti (pemain kedua) selalu menang.
    Pada awal permainan, \(d_0 = n - 2 \equiv 0 \pmod{3}\) dan \(d_0 \ge 3\).
    Strategi Siti: Setelah setiap langkah Wiwit, Siti selalu menjaga agar kondisi \(d \equiv 0 \pmod{3}\) kembali terpenuhi dengan cara selalu melangkah ke kanan:
    • Jika sebelum giliran Wiwit berlaku \(d = 0\) (kedua bidak berdampingan, \(w = b + 1\)), maka jika Wiwit belum terjepit di kanan (\(w \lt n\)), ia terpaksa menggeser bidak putih ke kanan sejauh \(r \in \{1, 2\}\) petak (membuat \(d = r\)). Siti membalas menggeser bidak hitam ke kanan sejauh \(r\) petak yang sama, sehingga \(d\) kembali menjadi \(0\).
    • Jika sebelum giliran Wiwit berlaku \(d \ge 3\) dengan \(3 \mid d\):
      • Bila Wiwit melangkah ke kiri sejauh \(r \in \{1, 2\}\) petak, jarak kosong menyusut menjadi \(d - r \ge 3 - r \ge 1\). Siti membalas melangkah ke kanan sejauh \(3 - r \in \{1, 2\}\) petak (selalu muat sebab tersedia \(d - r \ge 3 - r\) petak kosong), sehingga jarak kosong berkurang total \(r + (3 - r) = 3\) menjadi \(d - 3 \equiv 0 \pmod{3}\).
      • Bila Wiwit melangkah ke kanan sejauh \(r \in \{1, 2\}\) petak, jarak kosong menjadi \(d + r\). Siti membalas melangkah ke kanan sejauh \(r\) petak, sehingga jarak kosong kembali menjadi \(d \equiv 0 \pmod{3}\).
    Setiap kali Siti membalas, posisi \(b\) bertambah minimal \(1\) (karena Siti selalu bergerak ke kanan). Karena \(b \le n - 1\) terbatas di kanan, permainan pasti berakhir, dan Siti selalu memiliki langkah sah. Pada akhirnya kedua bidak terdorong sampai \((b, w) = (n - 1, n)\), di mana pada giliran Wiwit ia tidak dapat bergerak dan Siti menang.
  2. Kasus 2: \(n \equiv 0 \pmod{3}\) atau \(n \equiv 1 \pmod{3}\) (misalnya \(n = 3, 4, 6, 7, 9, \dots\)). Maka Wiwit (pemain pertama) selalu menang.
    Pada awal permainan, \(d_0 = n - 2\) bernilai sisa \(1\) atau \(2\) modulo \(3\).
    Langkah pembuka Wiwit:
    • Jika \(n \equiv 0 \pmod{3}\) (\(d_0 \equiv 1 \pmod{3}\)), Wiwit memindahkan bidak putih \(1\) petak ke kiri (dari \(n\) ke \(n - 1\)), sehingga \(d = d_0 - 1 \equiv 0 \pmod{3}\).
    • Jika \(n \equiv 1 \pmod{3}\) (\(d_0 \equiv 2 \pmod{3}\)), Wiwit memindahkan bidak putih \(2\) petak ke kiri (dari \(n\) ke \(n - 2\)), sehingga \(d = d_0 - 2 \equiv 0 \pmod{3}\).
    Setelah langkah pertama ini, giliran jatuh ke Siti dengan kondisi \(3 \mid d\), persis simetris dengan Kasus 1! Dari sini, Wiwit selalu melangkah ke kiri untuk memulihkan \(d \equiv 0 \pmod{3}\): jika Siti menjauh ke kiri \(r\) petak (atau terpaksa saat \(d = 0\)), Wiwit ikut ke kiri \(r\) petak; jika Siti mendekat ke kanan \(r\) petak saat \(d \ge 3\), Wiwit ke kiri \(3 - r\) petak.
    Karena \(w\) selalu berkurang minimal \(1\) setiap langkah Wiwit dan \(w \ge 2\), bidak hitam akhirnya terjepit pada \((b, w) = (1, 2)\), sehingga Siti kehabisan langkah dan Wiwit menang.
Jadi:
• Untuk \(n \equiv 2 \pmod{3}\) (\(n = 5, 8, 11, \dots\)), Siti (pemain kedua) selalu menang dengan selalu melangkah ke kanan untuk menjaga jarak kosong kelipatan \(3\).
• Untuk \(n \equiv 0 \text{ atau } 1 \pmod{3}\) (\(n = 3, 4, 6, 7, 9, \dots\)), Wiwit (pemain pertama) selalu menang dengan memotong jarak menjadi kelipatan \(3\) pada langkah pertama, lalu selalu melangkah ke kiri untuk mempertahankannya.

Hari Kedua (Nomor 5–8)

Hari Kedua - No. 5
Pada segitiga \(ABC\), \(M\) adalah titik tengah \(BC\) dan \(G\) adalah titik berat segitiga \(ABC\). Sebuah garis \(\ell\) melalui \(G\) memotong ruas garis \(AB\) di \(P\) dan ruas garis \(AC\) di \(Q\), di mana \(P \neq B\) dan \(Q \neq C\). Jika \([XYZ]\) menyatakan luas segitiga \(XYZ\), tunjukkan bahwa: \[\frac{[BGM]}{[PAG]} + \frac{[CMG]}{[QGA]} = \frac{3}{2}\]
Topik: Segitiga
Pembahasan:

Karena \([PAG]\) dan \([QGA]\) berada pada penyebut (tidak boleh nol), maka \(P \neq A\) dan \(Q \neq A\). Akibatnya \(P\) berada di bagian dalam ruas garis \(AB\) dan \(Q\) berada di bagian dalam ruas garis \(AC\). Misalkan:

\[p = \frac{AP}{AB} \in (0, 1) \qquad \text{dan} \qquad q = \frac{AQ}{AC} \in (0, 1)\]

Gunakan sifat titik berat \(G\) pada garis berat \(AM\) (dengan \(M\) titik tengah \(BC\) dan \(AG : GM = 2 : 1\)):

  1. Karena \(BM = MC\), diperoleh \([ABM] = [ACM] = \dfrac{1}{2}[ABC]\). Selanjutnya karena \(AG : GM = 2 : 1\): \[[BGM] = [CMG] = \frac{1}{3}[ABM] = \frac{1}{6}[ABC]\] \[[BAG] = \frac{2}{3}[ABM] = \frac{1}{3}[ABC], \qquad [CAG] = \frac{2}{3}[ACM] = \frac{1}{3}[ABC]\]
  2. Segitiga \(\triangle PAG\) dan \(\triangle BAG\) bertitik puncak sama \(G\) dengan alas segaris di \(AB\), sehingga: \[[PAG] = \frac{AP}{AB}[BAG] = \frac{p}{3}[ABC]\] Demikian pula pada sisi \(AC\): \[[QGA] = \frac{AQ}{AC}[CAG] = \frac{q}{3}[ABC]\]
  3. Karena \(G\) berada di antara \(P\) dan \(Q\) pada ruas garis \(PQ\), berlaku \([APQ] = [APG] + [AQG]\). Padahal \([APQ] = \dfrac{AP}{AB}\cdot\dfrac{AQ}{AC}[ABC] = pq\,[ABC]\), sehingga: \[pq\,[ABC] = \frac{p}{3}[ABC] + \frac{q}{3}[ABC]\] Bagi kedua ruas dengan \(pq\,[ABC] \gt 0\): \[1 = \frac{1}{3q} + \frac{1}{3p} \implies \frac{1}{p} + \frac{1}{q} = 3\]
  4. Substitusikan seluruh hubungan luas ke ruas kiri yang ditanyakan: \[\frac{[BGM]}{[PAG]} + \frac{[CMG]}{[QGA]} = \frac{\frac{1}{6}[ABC]}{\frac{p}{3}[ABC]} + \frac{\frac{1}{6}[ABC]}{\frac{q}{3}[ABC]} = \frac{1}{2}\left(\frac{1}{p} + \frac{1}{q}\right) = \frac{1}{2} \cdot 3 = \frac{3}{2}. \quad \blacksquare\]
Jadi, terbukti bahwa \(\dfrac{[BGM]}{[PAG]} + \dfrac{[CMG]}{[QGA]} = \dfrac{3}{2}\).
Hari Kedua - No. 6
Setiap nomor telepon di suatu daerah terdiri dari \(8\) angka dan diawali dengan angka \(8\). Pak Edy, yang baru pindah ke daerah itu, mengajukan pemasangan sebuah telepon baru. Berapakah peluang Pak Edy mendapatkan nomor telepon yang memuat tidak lebih dari \(5\) angka berbeda?
Topik: Peluang
Pembahasan:

Karena digit pertama selalu \(8\), tujuh digit berikutnya masing-masing dapat diisi dengan \(10\) pilihan angka \(\{0, 1, \dots, 9\}\), sehingga ukuran ruang sampel adalah:

\[n(S) = 10^7 = 10.000.000\]

Misalkan suatu nomor telepon memuat tepat \(k\) angka berbeda. Karena angka \(8\) sudah pasti muncul pada posisi pertama, harus muncul tepat \(r = k - 1\) angka berbeda selain \(8\) (dipilih dari \(9\) angka \(\{0,1,2,3,4,5,6,7,9\}\)) di antara \(7\) posisi terakhir, dengan syarat tiap-tiap dari \(r\) angka tersebut muncul minimal satu kali (sedangkan angka \(8\) sendiri boleh muncul lagi atau tidak pada \(7\) posisi terakhir).

Untuk setiap pilihan \(r\) angka selain \(8\) (sebanyak \(\binom{9}{r}\) cara), banyaknya cara mengisi \(7\) posisi terakhir memakai \(r + 1\) angka tersedia agar seluruh \(r\) angka non-\(8\) muncul minimal sekali dihitung dengan Prinsip Inklusi–Eksklusi (mengeluarkan susunan ketika \(j\) di antara \(r\) angka tersebut absen):

\[N(r) = \sum_{j=0}^{r} (-1)^j \binom{r}{j} (r + 1 - j)^7\]

Lebih efisien menghitung banyaknya kejadian komplemen \(A^c\), yaitu nomor telepon memuat lebih dari \(5\) angka berbeda (\(k \in \{6, 7, 8\}\), yaitu \(r \in \{5, 6, 7\}\)):

  • Kasus \(k = 6\) (\(r = 5\)): terdapat \(\binom{9}{5} = 126\) pilihan himpunan \(5\) angka selain \(8\), dan: \[N(5) = 6^7 - \binom{5}{1}5^7 + \binom{5}{2}4^7 - \binom{5}{3}3^7 + \binom{5}{4}2^7 - \binom{5}{5}1^7\] \[N(5) = 279.936 - 5(78.125) + 10(16.384) - 10(2.187) + 5(128) - 1 = 31.920\] Banyaknya nomor dengan tepat \(6\) angka berbeda: \(126 \times 31.920 = 4.021.920\).
  • Kasus \(k = 7\) (\(r = 6\)): terdapat \(\binom{9}{6} = 84\) pilihan himpunan \(6\) angka selain \(8\), dan: \[N(6) = 7^7 - \binom{6}{1}6^7 + \binom{6}{2}5^7 - \binom{6}{3}4^7 + \binom{6}{4}3^7 - \binom{6}{5}2^7 + \binom{6}{6}1^7\] \[N(6) = 823.543 - 6(279.936) + 15(78.125) - 20(16.384) + 15(2.187) - 6(128) + 1 = 20.160\] Banyaknya nomor dengan tepat \(7\) angka berbeda: \(84 \times 20.160 = 1.693.440\).
  • Kasus \(k = 8\) (\(r = 7\)): terdapat \(\binom{9}{7} = 36\) pilihan \(7\) angka selain \(8\), dan ketujuh posisi terakhir merupakan permutasi seluruh \(7\) angka tersebut, sehingga \(N(7) = 7! = 5.040\).
    Banyaknya nomor dengan tepat \(8\) angka berbeda: \(36 \times 5.040 = 181.440\).

Jumlah seluruh nomor dengan lebih dari \(5\) angka berbeda:

\[n(A^c) = 4.021.920 + 1.693.440 + 181.440 = 5.896.800\]

Maka banyaknya nomor dengan tidak lebih dari \(5\) angka berbeda adalah:

\[n(A) = n(S) - n(A^c) = 10.000.000 - 5.896.800 = 4.103.200\]

Dengan demikian, peluangnya adalah:

\[P(A) = \frac{4.103.200}{10.000.000} = \frac{5.129}{12.500} = 0{,}41032\]
Jadi, peluang Pak Edy mendapatkan nomor telepon dengan tidak lebih dari \(5\) angka berbeda adalah \(\dfrac{5.129}{12.500}\) (atau \(0{,}41032\)).
Hari Kedua - No. 7
Misalkan \(a, b, c\) bilangan-bilangan real sehingga \(ab, bc, ca\) bilangan-bilangan rasional. Buktikan bahwa ada bilangan-bilangan bulat \(x, y, z\) yang tidak semuanya nol, sehingga \(ax + by + cz = 0\).
Topik: Bilangan Real
Pembahasan:

Tinjau dua kemungkinan untuk nilai \(a, b, c \in \mathbb{R}\):

  • Kasus 1: Setidaknya satu di antara \(a, b, c\) bernilai nol.
    • Jika \(a = 0\), pilih \((x, y, z) = (1, 0, 0)\), maka \(ax + by + cz = 0(1) + b(0) + c(0) = 0\).
    • Jika \(b = 0\), pilih \((x, y, z) = (0, 1, 0)\), maka \(ax + by + cz = 0\).
    • Jika \(c = 0\), pilih \((x, y, z) = (0, 0, 1)\), maka \(ax + by + cz = 0\).
    Dalam ketiga keadaan ini, \(x, y, z \in \mathbb{Z}\) dan tidak semuanya nol.
  • Kasus 2: Ketiga bilangan tak nol (\(a \neq 0,\; b \neq 0,\; c \neq 0\)).
    Karena \(ca \in \mathbb{Q}\) dan \(bc \in \mathbb{Q}\) dengan \(bc \neq 0\), hasil bagi keduanya juga merupakan bilangan rasional: \[\frac{a}{b} = \frac{ca}{bc} \in \mathbb{Q}\] Oleh karena itu, terdapat bilangan-bilangan bulat \(p, q \in \mathbb{Z}\) dengan \(q \neq 0\) sehingga: \[\frac{a}{b} = \frac{p}{q} \iff aq - bp = 0\] Sekarang pilih \((x, y, z) = (q, -p, 0)\). Jelas bahwa \(x, y, z \in \mathbb{Z}\), tidak semuanya nol (sebab \(x = q \neq 0\)), dan memenuhi: \[ax + by + cz = a(q) + b(-p) + c(0) = aq - bp = 0\]

Dalam kedua kasus selalu dapat dikonstruksi bilangan-bilangan bulat \(x, y, z\) yang tidak semuanya nol sehingga \(ax + by + cz = 0\). \(\blacksquare\)

Jadi, terbukti bahwa selalu ada \((x, y, z) \in \mathbb{Z}^3 \setminus \{(0, 0, 0)\}\) yang memenuhi \(ax + by + cz = 0\).
Hari Kedua - No. 8
Tentukan bilangan bulat \(85\)-angka terbesar yang memenuhi sifat: jumlah semua angkanya sama dengan hasilkali semua angkanya.
Topik: Bilangan Bulat
Pembahasan:

Misalkan \(N\) adalah bilangan bulat positif \(85\)-angka yang memenuhi sifat tersebut. Tidak mungkin ada angka \(0\) di antara digit-digit \(N\), sebab jika ada satu saja angka \(0\) maka hasil kali semua angkanya menjadi \(0\), padahal jumlah semua angkanya minimal \(1\).

Jadi seluruh \(85\) digit berasal dari \(\{1, 2, \dots, 9\}\). Agar \(N\) bernilai terbesar, susunan digitnya harus terurut menurun dari kiri ke kanan. Misalkan terdapat \(k\) digit yang bernilai \(\ge 2\), yakni \(x_1 \ge x_2 \ge \dots \ge x_k \ge 2\), sedangkan \(85 - k\) digit sisanya adalah \(1\).

Syarat jumlah digit sama dengan hasil kali digit menghasilkan:

\[x_1 x_2 \cdots x_k = x_1 + x_2 + \dots + x_k + (85 - k)\]

Untuk \(k = 0\) diperoleh \(1 = 85\) (mustahil) dan untuk \(k = 1\) diperoleh \(x_1 = x_1 + 84\) (mustahil), sehingga haruslah \(k \ge 2\). Agar \(N\) sebesar mungkin, kita maksimalkan terlebih dahulu \(x_1\):

  1. Cek \(x_1 = 9\):
    Karena \(2 \le x_i \le 9\) untuk \(i \ge 2\), berlaku batas: \[9 \cdot 2^{k-1} \le 9 x_2 \cdots x_k = 9 + (x_2 + \dots + x_k) + (85 - k) \le 9 + 9(k - 1) + 85 - k = 8k + 85\]
    • Untuk \(k \ge 5\): \(9 \cdot 2^{k-1} \ge 144 \gt 125 = 8(5) + 85\), dan fungsi eksponensial \(9 \cdot 2^{k-1}\) terus melampaui \(8k + 85\), sehingga mustahil.
    • Untuk \(k = 2\): \(9x_2 = x_2 + 92 \iff 8x_2 = 92\), tidak ada solusi bulat.
    • Untuk \(k = 3\): \(9x_2x_3 = x_2 + x_3 + 91 \in [95, 109]\). Karena habis dibagi \(9\), \(9x_2x_3 \in \{99, 108\}\):
      • \(9x_2x_3 = 99 \implies x_2x_3 = 11\) (prima \(\gt 9\), mustahil).
      • \(9x_2x_3 = 108 \implies x_2x_3 = 12\) dan \(x_2 + x_3 = 17\) (mustahil, jumlah maksimum pasangan berturut-turut dengan hasil kali \(12\) adalah \(6 + 2 = 8 \lt 17\)).
    • Untuk \(k = 4\): \(9x_2x_3x_4 = x_2 + x_3 + x_4 + 90 \in [96, 117]\). Kelipatan \(9\) di selang tersebut adalah \(\{99, 108, 117\}\):
      • \(99 \implies x_2x_3x_4 = 11\) dan \(117 \implies x_2x_3x_4 = 13\), keduanya prima \(\gt 9\) (mustahil).
      • \(108 \implies x_2x_3x_4 = 12\) dan \(x_2 + x_3 + x_4 = 18\) (mustahil karena faktorisasi \(12 = 3 \cdot 2 \cdot 2\) memberi jumlah \(7 \neq 18\)).
    Jadi \(x_1 = 9\) tidak mungkin terjadi (\(x_1 \le 8\)).
  2. Cek \(x_1 = 8\):
    Dengan \(2 \le x_i \le 8\) untuk \(i \ge 2\): \[8 \cdot 2^{k-1} \le 8 x_2 \cdots x_k = 8 + (x_2 + \dots + x_k) + (85 - k) \le 8 + 8(k - 1) + 85 - k = 7k + 85\]
    • Untuk \(k \ge 5\): \(8 \cdot 2^{k-1} \ge 128 \gt 120 = 7(5) + 85\), sehingga mustahil.
    • Untuk \(k = 2\): \(8x_2 = x_2 + 91 \iff 7x_2 = 91 \implies x_2 = 13 \gt 9\) (mustahil).
    • Untuk \(k = 3\): \(8x_2x_3 = x_2 + x_3 + 90 \in [94, 106]\), sehingga \(8x_2x_3 \in \{96, 104\}\):
      • \(96 \implies x_2x_3 = 12\) dan \(x_2 + x_3 = 6\) (mustahil, jumlah minimalnya \(4 + 3 = 7 \gt 6\)).
      • \(104 \implies x_2x_3 = 13\) (prima \(\gt 9\), mustahil).
    • Untuk \(k = 4\): \(8x_2x_3x_4 = x_2 + x_3 + x_4 + 89 \in [95, 113]\), sehingga \(8x_2x_3x_4 \in \{96, 104, 112\}\):
      • \(104 \implies x_2x_3x_4 = 13\) (prima) dan \(112 \implies x_2x_3x_4 = 14 = 2 \cdot 7\) (hanya \(2\) faktor prima, tak bisa difaktorkan menjadi \(3\) bilangan \(\ge 2\)).
      • \(96 \implies x_2x_3x_4 = 12 = 2^2 \cdot 3\) dan \(x_2 + x_3 + x_4 = 96 - 89 = 7\). Satu-satunya tripel terurut \(\ge 2\) yang memenuhi adalah \((x_2, x_3, x_4) = (3, 2, 2)\), yang benar memberikan \(3 + 2 + 2 = 7\).

Satu-satunya solusi dengan \(x_1 = 8\) adalah multihimpunan digit \(\{8, 3, 2, 2\}\) ditambah \(85 - 4 = 81\) angka \(1\). Karena tidak ada solusi berangka depan \(9\), menyusun digit secara menurun menghasilkan bilangan terbesar:

\[N = 8322\underbrace{111\dots 1}_{81\text{ angka } 1}\]

(Pemeriksaan: banyak angka \(= 4 + 81 = 85\); jumlah angka \(= 8 + 3 + 2 + 2 + 81(1) = 96\); hasil kali angka \(= 8 \times 3 \times 2 \times 2 \times 1^{81} = 96\).)

Jadi, bilangan bulat \(85\)-angka terbesar yang dimaksud adalah \(8322\underbrace{111\dots 1}_{81\text{ angka }1}\).
