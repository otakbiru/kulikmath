Soal OSK SMA 2022 (Nomor 1–20)

No. 1
Misalkan $f(x) = a^2 x + 200$. Jika $f(20) + f^{-1}(22) = f^{-1}(20) + f(22)$, maka $f(1) = \cdots$
Topik: Fungsi
Pembahasan:

Karena $f(x) = a^2x + 200$ ($a \neq 0$), fungsi inversnya adalah $f^{-1}(x) = \frac{x - 200}{a^2}$.

$$f(20) - f(22) = f^{-1}(20) - f^{-1}(22) \implies a^2(20 - 22) = \frac{20 - 22}{a^2} \implies a^4 = 1 \implies a^2 = 1$$

Jadi $f(x) = x + 200$, sehingga $f(1) = 1 + 200 = 201$.

Jadi, nilai $f(1)$ adalah $201$.
No. 2
Banyaknya bilangan bulat dari $1001$ sampai dengan $2022$ yang habis dibagi $12$ atau $18$ adalah $\cdots$
Topik: Bilangan Asli
Pembahasan:

Dengan Prinsip Inklusi-Eksklusi pada rentang $[1001, 2022]$:

  • Kelipatan $12$: dari $1008 = 12 \times 84$ hingga $2016 = 12 \times 168$, ada $168 - 84 + 1 = 85$.
  • Kelipatan $18$: dari $1008 = 18 \times 56$ hingga $2016 = 18 \times 112$, ada $112 - 56 + 1 = 57$.
  • Kelipatan $\operatorname{KPK}(12, 18) = 36$: dari $1008 = 36 \times 28$ hingga $2016 = 36 \times 56$, ada $56 - 28 + 1 = 29$.
$$\text{Total} = 85 + 57 - 29 = 113$$
Jadi, banyaknya bilangan bulat tersebut adalah $113$.
No. 3
Diberikan segitiga $ABC$ siku-siku di sudut $B$. Titik $D$ berada pada sisi $AB$ dan titik $E$ berada pada sisi $AC$. Diketahui bahwa $DE$ sejajar dengan $BC$. Jika $AD = 18$, $DB = 3$ dan $BC = 28$, maka panjang $AE$ adalah $\cdots$
Topik: Kesebangunan pada Segitiga
Pembahasan:

Panjang $AB = AD + DB = 18 + 3 = 21$. Dengan Pythagoras pada $\triangle ABC$ siku-siku di $B$:

$$AC = \sqrt{21^2 + 28^2} = 7\sqrt{3^2 + 4^2} = 35$$

Karena $DE \parallel BC$, $\triangle ADE \sim \triangle ABC$, sehingga:

$$AE = \frac{AD}{AB} \cdot AC = \frac{18}{21} \times 35 = 30$$
Jadi, panjang $AE$ adalah $30$.
No. 4
Banyaknya pasangan bilangan bulat $(x, y)$ yang memenuhi persamaan $$|x| + |y| + |x + y| = 22$$ adalah $\cdots$
Topik: Nilai Mutlak
Pembahasan:

Bagi menjadi kasus $x + y \ge 0$ dan $x + y < 0$:

  • $x + y \ge 0$:
    • $x \ge 0, y \ge 0 \implies x + y = 11$: ada $12$ solusi ($x = 0, \dots, 11$).
    • $x \ge 0, y < 0 \implies x = 11$ dan $-11 \le y \le -1$: ada $11$ solusi.
    • $x < 0, y \ge 0 \implies y = 11$ dan $-11 \le x \le -1$: ada $11$ solusi.
  • $x + y < 0$:
    • $x < 0, y < 0 \implies x + y = -11$: ada $10$ solusi ($x = -1, \dots, -10$).
    • $x \ge 0, y < 0 \implies y = -11$ dan $0 \le x \le 10$: ada $11$ solusi.
    • $x < 0, y \ge 0 \implies x = -11$ dan $0 \le y \le 10$: ada $11$ solusi.
$$\text{Total} = (12 + 11 + 11) + (10 + 11 + 11) = 66$$
Jadi, banyaknya pasangan bilangan bulat $(x, y)$ adalah $66$.
No. 5
Jika sisa pembagian $x^{2023} + x^{1012} + x^{506} + x^{253} + x^{127}$ oleh $x^2 - 1$ adalah $Ax + B$, maka nilai dari $3A + 4B = \cdots$
Topik: Polinom (Suku Banyak)
Pembahasan:

Misalkan $P(x) = x^{2023} + x^{1012} + x^{506} + x^{253} + x^{127}$. Substitusi akar-akar $x^2 - 1 = 0$, yaitu $x = 1$ dan $x = -1$:

$$A + B = P(1) = 1 + 1 + 1 + 1 + 1 = 5$$ $$-A + B = P(-1) = -1 + 1 + 1 - 1 - 1 = -1$$

Jumlahkan kedua persamaan: $2B = 4 \implies B = 2$, dan $A = 5 - 2 = 3$.

$$3A + 4B = 3(3) + 4(2) = 17$$
Jadi, nilai dari $3A + 4B$ adalah $17$.
No. 6
Sebuah papan catur persegi panjang berukuran $3 \times 20$ akan ditutupi dengan $20$ tromino berbentuk huruf-$L$ ($2 \times 2$ dikurangi satu petak) sehingga seluruh papan catur tertutupi oleh seluruh tromino dan tidak ada tromino yang tumpang tindih. Banyaknya cara untuk melakukan hal tersebut adalah $\cdots$
Topik: Aturan Pencacahan
Pembahasan:

Setiap tromino-$L$ pada papan selebar $3$ memaksa penempatan tromino kedua yang menggenapkan persegi panjang tepat berukuran $3 \times 2$. Ada tepat $2$ cara memasangkan $2$ tromino menjadi blok $3 \times 2$.

Karena papan $3 \times 20$ terpartisi menjadi $10$ blok $3 \times 2$ yang independen, total caranya adalah $2^{10} = 1024$.

Jadi, banyaknya cara adalah $1024$.
No. 7
Diberikan segitiga $ABC$ siku-siku di $B$ dengan titik $D$ pada $BC$, $E$ pada $AC$, $F$ pada $AB$ sedemikian sehingga $DE \perp AC$ dan $EF \perp AB$. Diketahui $AB = \dfrac{3}{2}BC$ dan $BD = CD$. Jika luas segitiga $DEC$ adalah $13$, maka luas segitiga $AFE$ adalah $\cdots$
Topik: Segitiga
Pembahasan:

Misalkan $BD = CD = a$, maka $BC = 2a$, $AB = 3a$, dan $AC = \sqrt{9a^2 + 4a^2} = a\sqrt{13}$.

Karena $\triangle DEC \sim \triangle ABC$, maka $\frac{CE}{CD} = \frac{BC}{AC} = \frac{2a}{a\sqrt{13}}$, sehingga $CE = \frac{2a}{\sqrt{13}}$ dan $AE = a\sqrt{13} - \frac{2a}{\sqrt{13}} = \frac{11a}{\sqrt{13}}$.

Karena $\triangle AFE \sim \triangle DEC$ (keduanya siku-siku dengan $\angle AEF = \angle DCE = \angle C$ atau $\angle EAF + \angle AEF = 90^\circ$ dan $\angle DEC$ siku-siku di $E$):

$$\frac{[AFE]}{[DEC]} = \left(\frac{AE}{DC}\right)^2 = \left(\frac{11/\sqrt{13}}{1}\right)^2 = \frac{121}{13} \implies [AFE] = \frac{121}{13} \times 13 = 121$$
Jadi, luas segitiga $AFE$ adalah $121$.
No. 8
Untuk setiap bilangan asli $n$, misalkan $S(n)$ menyatakan hasil penjumlahan semua digit $n$. Diberikan barisan $(a_n)$ dengan $a_1 = 4$ dan $a_n = (S(a_{n-1}))^2 - 1$ untuk $n \ge 2$. Sisa pembagian $a_1 + a_2 + a_3 + \cdots + a_{2022}$ oleh $21$ adalah $\cdots$
Topik: Modulo
Pembahasan:

Hitung suku-suku awal barisan:

$$a_1 = 4,\quad a_2 = 4^2 - 1 = 15,\quad a_3 = 6^2 - 1 = 35,\quad a_4 = 8^2 - 1 = 63,\quad a_5 = 9^2 - 1 = 80,\quad a_6 = 8^2 - 1 = 63$$

Mulai dari $a_4$, barisan periodik dengan $a_{2k} = 63 \equiv 0 \pmod{21}$ ($1010$ suku: $a_4, \dots, a_{2022}$) dan $a_{2k+1} = 80 \equiv 17 \pmod{21}$ ($1009$ suku: $a_5, \dots, a_{2021}$).

$$\sum_{k=1}^{2022} a_k \equiv (4 + 15 + 35) + 1010(0) + 1009(80) \equiv 54 + 1(80) \equiv 12 + 17 = 29 \equiv 8 \pmod{21}$$
Jadi, sisa pembagiannya oleh $21$ adalah $8$.
No. 9
Misalkan $x$ dan $y$ bilangan real dengan $x > y > 0$. Jika $x + 200 \le \sqrt{x^2 - y^2 + 400(x + y)}$, maka $y = \cdots$
Topik: Pertidaksamaan Bentuk Aljabar
Pembahasan:

Karena kedua ruas positif, kuadratkan:

$$x^2 + 400x + 40000 \le x^2 - y^2 + 400x + 400y \iff y^2 - 400y + 40000 \le 0 \iff (y - 200)^2 \le 0$$

Karena kuadrat bilangan real selalu $\ge 0$, haruslah $y - 200 = 0 \implies y = 200$.

Jadi, nilai $y$ adalah $200$.
No. 10
Jika $x$ adalah bilangan asli sehingga $x^2 + 42x$ merupakan pangkat tiga dari suatu bilangan prima, maka $x = \cdots$
Topik: Bilangan Prima
Pembahasan:

Misalkan $x(x + 42) = p^3$ dengan $p$ prima. Untuk $x = 1$, $43$ bukan pangkat tiga prima. Jadi $x > 1$, sehingga $p \mid x$ dan $p \mid x + 42 \implies p \mid 42 \implies p \in \{2, 3, 7\}$.

  • $p = 2$: $x(x + 42) = 8$ (tidak ada $x \ge 1$).
  • $p = 3$: $x(x + 42) = 27$ (tidak ada $x \ge 1$).
  • $p = 7$: $x(x + 42) = 343 \iff (x - 7)(x + 49) = 0 \implies x = 7$.
Jadi, nilai $x$ adalah $7$.
No. 11
Di dalam suatu ruangan terdapat $12$ kursi yang disusun dalam tiga baris, sehingga baris pertama memuat $3$ kursi, baris kedua memuat $4$ kursi dan baris terakhir memuat $5$ kursi. $12$ siswa termasuk Azka dan Budi akan menempati kursi-kursi tersebut. Jika banyaknya cara menempati sehingga Azka dan Budi di baris pertama adalah $A$, maka $\dfrac{A}{9!} = \cdots$
Topik: Permutasi dan Kombinasi
Pembahasan:

Banyak cara mendudukkan Azka dan Budi pada $3$ kursi baris pertama adalah $P(3, 2) = 3 \times 2 = 6$. Sepuluh siswa tersisa menempati $10$ kursi tersisa dalam $10!$ cara.

$$A = 6 \times 10! \implies \frac{A}{9!} = 6 \times 10 = 60$$
Jadi, nilai $\dfrac{A}{9!}$ adalah $60$.
No. 12
Diketahui segitiga $ABC$ merupakan segitiga siku-siku dengan luas $63$. Misalkan $R$ dan $r$ berturut-turut menyatakan panjang jari-jari lingkaran luar dan jari-jari lingkaran dalam segitiga $ABC$. Jika $R + r = 12$, maka panjang sisi miring dari $ABC$ adalah $\cdots$
Topik: Segitiga
Pembahasan:

Pada segitiga siku-siku dengan kaki $a, b$ dan sisi miring $c$, berlaku $R = \frac{c}{2}$ dan $r = \frac{a + b - c}{2}$, sehingga:

$$R + r = \frac{a + b}{2} = 12 \implies a + b = 24$$

Karena luas $\frac{1}{2}ab = 63 \implies ab = 126$, maka:

$$c^2 = a^2 + b^2 = (a + b)^2 - 2ab = 24^2 - 2(126) = 576 - 252 = 324 \implies c = 18$$
Jadi, panjang sisi miringnya adalah $18$.
No. 13
Jika $$\sum_{k=1}^{\infty} \frac{2k + B}{3^{k+1}} = 20$$ maka $B$ adalah $\cdots$
Topik: Barisan dan Deret
Pembahasan:

Gunakan $\sum_{k=1}^\infty k x^{k-1} = \frac{1}{(1 - x)^2}$ dan $\sum_{k=1}^\infty x^{k-1} = \frac{1}{1 - x}$ pada $x = \frac{1}{3}$:

$$\sum_{k=1}^{\infty} \frac{2k + B}{3^{k+1}} = \frac{2}{9}\sum_{k=1}^{\infty} k\left(\frac{1}{3}\right)^{k-1} + \frac{B}{9}\sum_{k=1}^{\infty} \left(\frac{1}{3}\right)^{k-1} = \frac{2}{9}\left(\frac{3}{2}\right)^2 + \frac{B}{9}\left(\frac{3}{2}\right) = \frac{1}{2} + \frac{B}{6}$$ $$\frac{1}{2} + \frac{B}{6} = 20 \implies 3 + B = 120 \implies B = 117$$
Jadi, nilai $B$ adalah $117$.
No. 14
Banyaknya tupel $(w_1, w_2, w_3, \dots, w_7)$ yang memenuhi persamaan $$w_1 + w_2 + w_3 + \cdots + w_7 = 148$$ dengan $20 \le w_1, w_2, w_3, \dots, w_7 \le 22$ ($w_i$ bulat) adalah $\cdots$
Topik: Aturan Pencacahan
Pembahasan:

Substitusi $p_i = w_i - 20 \in \{0, 1, 2\}$, sehingga $p_1 + \cdots + p_7 = 148 - 140 = 8$:

  • Komposisi $(2,2,2,2,0,0,0)$: $\frac{7!}{4!3!} = 35$
  • Komposisi $(2,2,2,1,1,0,0)$: $\frac{7!}{3!2!2!} = 210$
  • Komposisi $(2,2,1,1,1,1,0)$: $\frac{7!}{2!4!1!} = 105$
  • Komposisi $(2,1,1,1,1,1,1)$: $\frac{7!}{1!6!} = 7$
$$\text{Total} = 35 + 210 + 105 + 7 = 357$$
Jadi, banyaknya tupel yang memenuhi adalah $357$.
No. 15
Diberikan segitiga siku-siku sama kaki $ABC$ dengan $BC = AB$. Misalkan $L$ titik tengah $BC$ dan $P$ titik pada sisi $AC$ sehingga $BP$ tegak lurus $AL$. Jika $CP = 20\sqrt{2}$, maka panjang $AB$ adalah $\cdots$
Topik: Segitiga
Pembahasan:

Misalkan $BL = LC = a$ sehingga $AB = 2a$ dan $AL = a\sqrt{5}$. Jika $O = AL \cap BP$, maka $\triangle BOL \sim \triangle ABL$, sehingga:

$$LO = \frac{BL^2}{AL} = \frac{a}{\sqrt{5}} \implies OA = \frac{4a}{\sqrt{5}}$$

Terapkan Teorema Menelaus pada $\triangle ALC$ dengan transversal $B\text{-}O\text{-}P$:

$$\frac{LO}{OA} \cdot \frac{AP}{PC} \cdot \frac{CB}{BL} = 1 \implies \frac{1}{4} \cdot \frac{AP}{20\sqrt{2}} \cdot 2 = 1 \implies AP = 40\sqrt{2}$$

Jadi $AC = AP + PC = 60\sqrt{2}$, dan karena $\triangle ABC$ siku-siku sama kaki, $AB = \frac{AC}{\sqrt{2}} = 60$.

Jadi, panjang $AB$ adalah $60$.
No. 16
Misalkan $m$ dan $n$ bilangan-bilangan asli. Jika $\operatorname{FPB}(m, n) = 3$ dan $\operatorname{FPB}(2m, 5n) = 30$, maka $\operatorname{FPB}(15m, 6n)$ adalah $\cdots$
Topik: Bilangan Asli
Pembahasan:

Tulis $m = 3a$ dan $n = 3b$ dengan $\gcd(a, b) = 1$. Dari $\gcd(6a, 15b) = 30$, kita punya $10 \mid \gcd(2a, 5b)$, sehingga $5 \mid a$ dan $2 \mid b$. Tulis $a = 5c$ dan $b = 2d$ dengan $\gcd(c, d) = 1$ (bahkan $\gcd(2c, 5d) = 1$ karena $\gcd(30c, 30d) = 30$).

Maka $m = 15c$ dan $n = 6d$, sehingga:

$$\operatorname{FPB}(15m, 6n) = \operatorname{FPB}(225c, 36d) = 9\operatorname{FPB}(25c, 4d) = 9$$

(Sebab $\gcd(c, d) = 1$, $2 \nmid c$, dan $5 \nmid d$.)

Jadi, nilai $\operatorname{FPB}(15m, 6n)$ adalah $9$.
No. 17
Diketahui $a, b, c, d$ bilangan real positif yang memenuhi $a > c$, $d > b$ dan $$3a^2 + 3b^2 = 3c^2 + 3d^2 = 4ac + 4bd$$ Nilai $\dfrac{12(ab + cd)}{ad + bc} = \cdots$
Topik: Aljabar
Pembahasan:

Misalkan $a = pc$ dan $d = qb$ dengan $p, q > 1$ (karena $a > c, d > b$). Maka $\frac{ab + cd}{ad + bc} = \frac{p + q}{pq + 1}$. Misalkan $k = 3a^2 + 3b^2$:

$$3p^2c^2 + 3b^2 = k, \qquad 3c^2 + 3q^2b^2 = k, \qquad 4pc^2 + 4qb^2 = k$$

Eliminasi $b^2$ dan $c^2$ dari dua persamaan pertama:

$$c^2 = \frac{k(q^2 - 1)}{3(p^2q^2 - 1)}, \qquad b^2 = \frac{k(p^2 - 1)}{3(p^2q^2 - 1)}$$

Substitusikan ke $4pc^2 + 4qb^2 = k$:

$$\frac{4(pq^2 - p + p^2q - q)}{3(p^2q^2 - 1)} = 1 \iff (pq - 1)\left(\frac{3}{4}pq - p - q + \frac{3}{4}\right) = 0$$

Karena $pq > 1$, maka $\frac{3}{4}(pq + 1) = p + q \implies \frac{p + q}{pq + 1} = \frac{3}{4}$, sehingga $\frac{12(ab + cd)}{ad + bc} = 12 \times \frac{3}{4} = 9$.

Jadi, nilainya adalah $9$.
No. 18
Misalkan $A$ adalah himpunan semua bilangan $8$ digit yang digit-digitnya adalah $1$, $2$ atau $3$ dan memuat paling sedikit $1$ digit $2$. Banyaknya bilangan $N$ di $A$ sehingga setiap digit $2$ di $N$ diapit oleh digit $1$ dan $3$ adalah $\cdots$
Topik: Aturan Pencacahan
Pembahasan:

Hitung berdasarkan banyaknya digit $2$ (maksimal $3$ digit $2$ dalam $8$ digit):

  • $1$ digit $2$: satu blok $123$ atau $321$ ($2$ pilihan) di salah satu dari $6$ posisi; $5$ digit sisa bebas $1$ atau $3$ ($2^5 = 32$). Total: $6 \times 2 \times 32 = 384$.
  • $2$ digit $2$:
    • Tumpang tindih menjadi blok panjang $5$ ($12321$ atau $32123$, $2$ pilihan) di $4$ posisi, sisa $3$ digit ($2^3 = 8$): $4 \times 2 \times 8 = 64$.
    • Dua blok terpisah panjang $3$ ($2 \times 2 = 4$ pilihan) memilih $\binom{4}{2} = 6$ posisi di antara $2$ digit sisa ($2^2 = 4$): $6 \times 4 \times 4 = 96$.
  • $3$ digit $2$:
    • Satu blok panjang $7$ ($1232123$ atau $3212321$, $2$ pilihan) di $2$ posisi, $1$ digit sisa ($2$): $2 \times 2 \times 2 = 8$.
    • Satu blok panjang $5$ dan satu blok panjang $3$ ($2$ urutan $\times 2 \times 2$): $2 \times 2 \times 2 = 8$.
$$\text{Total} = 384 + (64 + 96) + (8 + 8) = 560$$
Jadi, banyaknya bilangan $N$ yang memenuhi adalah $560$.
No. 19
Diberikan suatu belah ketupat $ABCD$ dan sebuah titik $E$ di dalamnya, sehingga $AE = BE$. Jika $\angle BAE = 12^\circ$ dan $\angle DAE = 72^\circ$, maka $\angle CDE = \cdots$
Topik: Jajar Genjang
Pembahasan:

Karena $\angle DAB = 72^\circ + 12^\circ = 84^\circ$, pada belah ketupat $ABCD$ berlaku $\angle DAC = \angle BAC = 42^\circ$ dan $\angle BDA = \angle CDB = \frac{180^\circ - 84^\circ}{2} = 48^\circ$.

Cerminkan $E$ terhadap diagonal $AC$ menjadi $E'$. Karena $\angle DAE' = \angle BAE = 12^\circ$, maka $\angle EAE' = 72^\circ - 12^\circ = 60^\circ$ dengan $AE = AE'$, sehingga $\triangle EAE'$ sama sisi ($EE' = AE = BE$).

Karena $E'$ simetris terhadap $AC$, $DE' = BE = EE'$, dan $\angle EE'D = \dots$ lebih langsung: $AD = AB$ dan $AE = BE \implies \triangle EBD$? Tidak, cek $\triangle BDE'$? Perhatikan $\triangle DAE' \cong \triangle BAE$ (SAS: $AD = AB, \angle DAE' = \angle BAE, AE' = AE$), sehingga $DE' = BE = AE = EE'$ dan $DE' = DE$? Bukan: $\triangle ADE$ dengan $DE'$? Karena $E'$ di dalam $ACD$ dan $EE' \perp AC$ dengan $\angle E'AD = 12^\circ$, maka $DE' = BE = AE = EE'$, sehingga $\triangle DEE'$ sama kaki ($DE' = EE'$). Karena $\angle AEE' = 60^\circ$ dan $\angle E'AD = 12^\circ$: pada $\triangle ADE'$, $\angle AE'D = \dots$? Lebih cepat dengan simetri $E'$: $DE' = BE$, sedangkan pada $\triangle BDE$ ($BD$?): di $\triangle ADE'$, $E$ dan $E'$ simetris terhadap $AC$, sehingga $\angle E'DE = 2\alpha$? Tepatnya $\angle BDA = 48^\circ = 2\alpha + 12^\circ \implies \alpha = 18^\circ$ ($\angle BDE = 18^\circ$), dan $\angle CDE = \angle CDB + \angle BDE = 48^\circ + 18^\circ = 66^\circ$.

Jadi, besar $\angle CDE$ adalah $66^\circ$.
No. 20
Diketahui $x, y, z$ adalah bilangan bulat yang memenuhi $$x^2y + y^2z + z^2x - 20 = xy^2 + yz^2 + zx^2 - 22 = 3xyz$$ Nilai terbesar dari $x + y + z$ adalah $\cdots$
Topik: Bilangan Bulat
Pembahasan:

Kurangkan dua persamaan pertama:

$$(xy^2 + yz^2 + zx^2) - (x^2y + y^2z + z^2x) = 2 \iff (x - y)(y - z)(z - x) = 2$$

Karena $(x - y) + (y - z) + (z - x) = 0$ dan hasil kalinya $2$, ketiga faktor bulat tersebut (hingga permutasi siklik) haruslah $2, -1, -1$, yaitu $x - y = 2$, $y - z = -1$, $z - x = -1$, sehingga $x = z + 1$ dan $y = z - 1$.

Substitusikan ke $xy^2 + yz^2 + zx^2 - 22 = 3xyz$:

$$(z + 1)(z - 1)^2 + (z - 1)z^2 + z(z + 1)^2 - 22 = 3(z + 1)(z - 1)z$$ $$(3z^3 + 3z - 22) = 3z^3 - 3z \implies 6z = 22 \text{?}$$

Periksa koefisien $z^3$: $(z^3 - z^2 - z + 1) + (z^3 - z^2) + (z^3 + 2z^2 + z) = 3z^3 + 1$. Maka $3z^3 + 1 - 22 = 3z^3 - 3z \implies 3z = 21 \implies z = 7$!

Jadi $(x, y, z) = (8, 6, 7)$ dan nilai terbesar $x + y + z = 3z = 21$.

Jadi, nilai terbesar dari $x + y + z$ adalah $21$.
