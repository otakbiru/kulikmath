Berikut adalah soal tingkat ... materi Koordinat Kutub

Luas daerah satu kelopak (loop) yang dibatasi oleh kurva mawar berkutub: \[r = 4\cos(2\theta)\] adalah .... satuan luas.

  1. \(\pi\)
  2. \(\dfrac{3}{2}\pi\)
  3. \(2\pi\)
  4. \(4\pi\)
  5. \(8\pi\)
HOTS / Kalkulus Lanjutan
Pembahasan:

Langkah 1: Menentukan Batas Sudut untuk Satu Kelopak

Kurva \(r = 4\cos(2\theta)\) merupakan kurva mawar berkutub bernoda empat kelopak. Satu kelopak terbentuk ketika nilai \(r\) bergerak dari titik asal (\(r = 0\)) mencapai nilai maksimum lalu kembali lagi ke titik asal (\(r = 0\)).

Cari pembuat nol untuk nilai \(r\): \[r = 0 \iff 4\cos(2\theta) = 0 \implies \cos(2\theta) = 0\] Penyelesaian nilai sudut di sekitar sumbu kutub positif (\(\theta = 0\)): \[2\theta = -\frac{\pi}{2} \implies \theta = -\frac{\pi}{4}\] \[2\theta = \frac{\pi}{2} \implies \theta = \frac{\pi}{4}\] Sehingga, satu kelopak yang memuat sumbu kutub terbentuk pada interval sudut: \[-\frac{\pi}{4} \le \theta \le \frac{\pi}{4}\]

Langkah 2: Menuliskan Rumus Integral Luas dalam Koordinat Kutub

Luas daerah yang dibatasi oleh kurva dalam koordinat kutub dirumuskan sebagai: \[L = \frac{1}{2} \int_{\alpha}^{\beta} r^2 \, d\theta\] Substitusikan \(r = 4\cos(2\theta)\) serta batas sudut \(\alpha = -\frac{\pi}{4}\) dan \(\beta = \frac{\pi}{4}\): \[L = \frac{1}{2} \int_{-\pi/4}^{\pi/4} \left(4\cos(2\theta)\right)^2 \, d\theta\] \[L = \frac{1}{2} \int_{-\pi/4}^{\pi/4} 16\cos^2(2\theta) \, d\theta = 8 \int_{-\pi/4}^{\pi/4} \cos^2(2\theta) \, d\theta\]

Langkah 3: Menggunakan Kesimetrian dan Identitas Trigonometri

Karena fungsi \(\cos^2(2\theta)\) merupakan fungsi genap (simetris terhadap sumbu polar \(\theta = 0\)): \[L = 8 \times 2 \int_{0}^{\pi/4} \cos^2(2\theta) \, d\theta = 16 \int_{0}^{\pi/4} \cos^2(2\theta) \, d\theta\] Gunakan identitas sudut rangkap kosinus \(\cos^2(u) = \dfrac{1 + \cos(2u)}{2}\): \[\cos^2(2\theta) = \frac{1 + \cos(4\theta)}{2}\] Sehingga integralnya menjadi: \[L = 16 \int_{0}^{\pi/4} \frac{1 + \cos(4\theta)}{2} \, d\theta = 8 \int_{0}^{\pi/4} \left(1 + \cos(4\theta)\right) \, d\theta\]

Langkah 4: Mengevaluasi Nilai Integral

Integralkan masing-masing suku terhadap \(\theta\): \[L = 8 \left[ \theta + \frac{\sin(4\theta)}{4} \right]_{0}^{\pi/4}\] Substitusikan batas atas \(\theta = \frac{\pi}{4}\) dan batas bawah \(\theta = 0\): \[L = 8 \left[ \left(\frac{\pi}{4} + \frac{\sin\left(4 \cdot \frac{\pi}{4}\right)}{4}\right) - \left(0 + \frac{\sin(0)}{4}\right) \right]\] \[L = 8 \left[ \left(\frac{\pi}{4} + \frac{\sin(\pi)}{4}\right) - 0 \right]\] Karena \(\sin(\pi) = 0\): \[L = 8 \left( \frac{\pi}{4} + 0 \right) = 2\pi\]

Jadi, luas daerah satu kelopak kurva tersebut adalah \(2\pi\) satuan luas (Pilihan C).
