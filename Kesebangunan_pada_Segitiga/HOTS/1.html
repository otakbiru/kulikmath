Berikut adalah soal tingkat ... materi Kesebangunan pada Segitiga

Diberikan segitiga \(ABC\). Titik \(D\) terletak pada sisi \(BC\) sedemikian sehingga besar sudut \(\angle BAD = \angle BCA\). Ruas garis \(DE\) ditarik sejajar dengan sisi \(AB\) (\(DE \parallel AB\)) dan memotong sisi \(AC\) di titik \(E\). Jika panjang \(BD = 4\text{ cm}\), panjang \(CD = 8\text{ cm}\), dan luas segitiga \(\triangle CDE\) adalah \(16\text{ cm}^2\), maka luas segitiga \(\triangle ABD\) adalah ....

  1. \(9\text{ cm}^2\)
  2. \(12\text{ cm}^2\)
  3. \(16\text{ cm}^2\)
  4. \(18\text{ cm}^2\)
  5. \(24\text{ cm}^2\)
HOTS / Olimpiade Matematika
Pembahasan:

Langkah 1: Menentukan Panjang Total Sisi \(BC\)

Titik \(D\) membagi ruas garis \(BC\) menjadi dua bagian: \[BC = BD + CD = 4 + 8 = 12\text{ cm}\]

Langkah 2: Menemukan Kesebangunan Pertama (\(\triangle CDE \sim \triangle CBA\))

Karena ruas garis \(DE\) sejajar dengan sisi \(AB\) (\(DE \parallel AB\)), maka:

  • \(\angle CDE = \angle CBA\) (sudut sehadap)
  • \(\angle CED = \angle CAB\) (sudut sehadap)
  • Sudut di \(C\) adalah sudut persekutuan (\(\angle DCE = \angle BCA\)).
Sehingga segitiga \(\triangle CDE\) sebangun dengan segitiga \(\triangle CBA\) (\(\triangle CDE \sim \triangle CBA\)).
Rasio kesebangunannya adalah: \[\frac{CD}{CB} = \frac{8}{12} = \frac{2}{3}\] Perbandingan luas dua segitiga yang sebangun sama dengan kuadrat dari rasio sisi-sisi yang bersesuaian: \[\frac{\text{Luas } \triangle CDE}{\text{Luas } \triangle CBA} = \left(\frac{CD}{CB}\right)^2 = \left(\frac{2}{3}\right)^2 = \frac{4}{9}\] Diketahui \(\text{Luas } \triangle CDE = 16\text{ cm}^2\), maka: \[\frac{16}{\text{Luas } \triangle CBA} = \frac{4}{9} \implies \text{Luas } \triangle CBA = \frac{9 \times 16}{4} = 36\text{ cm}^2\]

Langkah 3: Menemukan Kesebangunan Kedua (\(\triangle BAD \sim \triangle BCA\))

Tinjau segitiga \(\triangle BAD\) dan segitiga \(\triangle BCA\):

  • \(\angle BAD = \angle BCA\) (diketahui pada soal)
  • \(\angle ABD = \angle CBA\) (sudut persekutuan di titik \(B\))
  • Akibatnya, sudut ketiga juga sama besar: \(\angle BDA = \angle BAC\).
Dengan demikian, segitiga \(\triangle BAD\) sebangun dengan segitiga \(\triangle BCA\) (\(\triangle BAD \sim \triangle BCA\)).
Dari kesebangunan ini, perbandingan sisi-sisinya memenuhi: \[\frac{AB}{BC} = \frac{BD}{AB} \implies AB^2 = BD \times BC\] Substitusikan \(BD = 4\) dan \(BC = 12\): \[AB^2 = 4 \times 12 = 48\]

Langkah 4: Menghitung Luas Segitiga \(\triangle ABD\)

Metode Rasio Kuadrat Kesebangunan:
Karena \(\triangle BAD \sim \triangle BCA\), perbandingan luasnya adalah: \[\frac{\text{Luas } \triangle ABD}{\text{Luas } \triangle CBA} = \left(\frac{AB}{BC}\right)^2 = \frac{AB^2}{BC^2} = \frac{48}{12^2} = \frac{48}{144} = \frac{1}{3}\] Maka: \[\text{Luas } \triangle ABD = \frac{1}{3} \times \text{Luas } \triangle CBA = \frac{1}{3} \times 36 = 12\text{ cm}^2\]

Verifikasi dengan Perbandingan Garis Tinggi:
Perhatikan bahwa segitiga \(\triangle ABD\) dan segitiga \(\triangle CBA\) memiliki garis tinggi yang sama jika ditarik dari titik sudut \(A\) ke garis alas \(BC\). Oleh karena itu, rasio luas kedua segitiga sama dengan rasio alasnya: \[\frac{\text{Luas } \triangle ABD}{\text{Luas } \triangle CBA} = \frac{BD}{BC} = \frac{4}{12} = \frac{1}{3}\] \[\text{Luas } \triangle ABD = \frac{1}{3} \times 36 = 12\text{ cm}^2\] Kedua metode menghasilkan nilai yang konsisten.

Jadi, luas segitiga \(ABD\) adalah \(12\text{ cm}^2\) (Pilihan B).

Misalkan \(\triangle ABC\) adalah segitiga siku-siku dengan \(AB = 3\), \(BC = 4\) dan \(AC = 5\). Definisikan titik \(D_1\) sebagai titik pada \(AC\) sedemikian sehingga \(BD_1\) tegak lurus dengan \(AC\). Definisikan \(E_1\) sebagai titik pada \(BC\) sedemikian sehingga \(D_1E_1\) tegak lurus terhadap \(BC\).

Untuk semua \(n \ge 2\), definisikan \(D_n\) sebagai titik pada \(AC\) sedemikian sehingga \(E_{n-1}D_n\) tegak lurus terhadap \(AC\) dan \(E_n\) sebagai titik pada \(BC\) sehingga \(D_nE_n\) tegak lurus terhadap \(BC\).

Tentukan sisa pembagian dari \(25^{2026} \cdot D_{2026}E_{2026}\) saat dibagi oleh \(255\).

KTOM November 2026 (Bagian A No. 5)
Pembahasan:

Karena \(AB = 3\), \(BC = 4\), dan \(AC = 5\) memenuhi \(AB^2 + BC^2 = 3^2 + 4^2 = 5^2 = AC^2\), maka \(\triangle ABC\) siku-siku di \(B\) dengan:

\[\sin C = \dfrac{AB}{AC} = \dfrac{3}{5} \quad \text{dan} \quad \cos C = \dfrac{BC}{AC} = \dfrac{4}{5}\]

Perhatikan barisan segitiga siku-siku yang sebangun dengan \(\triangle ABC\) dan memiliki titik sudut lancip di \(C\):

  • Pada \(\triangle BCD_1\) yang siku-siku di \(D_1\), hipotenusanya adalah \(BC = 4\), sehingga: \[CD_1 = BC \cos C = 4 \cdot \dfrac{4}{5}\]
  • Pada \(\triangle CD_1E_1\) yang siku-siku di \(E_1\), hipotenusanya adalah \(CD_1\), sehingga: \[D_1E_1 = CD_1 \sin C = 4 \cdot \dfrac{4}{5} \cdot \dfrac{3}{5} = 3 \cdot \left(\dfrac{16}{25}\right)^1, \qquad CE_1 = CD_1 \cos C = 4 \cdot \left(\dfrac{4}{5}\right)^2\]
  • Untuk setiap \(n \ge 2\), karena \(\triangle CE_{n-1}D_n\) siku-siku di \(D_n\) dan \(\triangle CD_nE_n\) siku-siku di \(E_n\), setiap langkah dari \(n - 1\) ke \(n\) mengalikan ukuran segitiga dengan faktor \(\cos^2 C = \left(\dfrac{4}{5}\right)^2 = \dfrac{16}{25}\): \[CD_n = CE_{n-1} \cos C, \qquad CE_n = CD_n \cos C = \dfrac{16}{25}\,CE_{n-1}\] \[D_nE_n = CD_n \sin C = \dfrac{16}{25}\,D_{n-1}E_{n-1}\]

Dengan demikian, barisan panjang \(D_nE_n\) membentuk barisan geometri dengan suku pertama \(D_1E_1 = 3 \cdot \dfrac{16}{25}\) dan rasio \(r = \dfrac{16}{25}\), sehingga untuk setiap \(n \ge 1\):

\[D_nE_n = 3 \cdot \left(\dfrac{16}{25}\right)^n = \dfrac{3 \cdot 16^n}{25^n}\]

Untuk \(n = 2026\), diperoleh:

\[25^{2026} \cdot D_{2026}E_{2026} = 25^{2026} \cdot \dfrac{3 \cdot 16^{2026}}{25^{2026}} = 3 \cdot 16^{2026}\]

Sekarang kita hitung sisa pembagian \(3 \cdot 16^{2026}\) oleh \(255\). Perhatikan bahwa \(16^2 = 256 \equiv 1 \pmod{255}\), sehingga:

\[3 \cdot 16^{2026} = 3 \cdot \left(16^2\right)^{1013} \equiv 3 \cdot 1^{1013} = 3 \pmod{255}\]

Karena \(0 \le 3 < 255\), sisa pembagiannya adalah \(\color{blue}\boxed{\boxed{\color{black}3}}\).

Jadi, sisa pembagian dari \(25^{2026} \cdot D_{2026}E_{2026}\) saat dibagi oleh \(255\) adalah 3.
Dalam sebuah segitiga \(ABC\) siku-siku sama kaki, dibuat persegi \(PQRS\) sebagai berikut: Titik \(P\) pada sisi \(AB\), titik \(Q\) pada sisi \(AC\), sedangkan titik-titik \(R\) dan \(S\) pada sisi miring \(BC\). Jika luas segitiga \(ABC\) adalah \(x\), berapakah luas persegi \(PQRS\)?
OSP SMA 2003 (Bagian I No. 8)
Pembahasan:

Karena \(R\) dan \(S\) terletak pada sisi miring \(BC\), maka sudut siku-siku segitiga sama kaki \(\triangle ABC\) berada di titik \(A\), dengan \(\angle B = \angle C = 45^\circ\) dan panjang alas \(BC = c\). Tinggi segitiga terhadap sisi miring \(BC\) adalah \(t = \frac{1}{2}BC = \frac{c}{2}\), sehingga luasnya:

\[x = \frac{1}{2} \cdot c \cdot \frac{c}{2} = \frac{c^2}{4} \implies c^2 = 4x\]

Misalkan panjang sisi persegi \(PQRS\) adalah \(s\). Perhatikan dua segitiga kecil di kanan dan kiri persegi:

  • \(\triangle PBR\) siku-siku di \(R\) dengan \(\angle B = 45^\circ\), sehingga segitiga siku-siku sama kaki dan \(BR = PR = s\).
  • \(\triangle QCS\) siku-siku di \(S\) dengan \(\angle C = 45^\circ\), sehingga segitiga siku-siku sama kaki dan \(SC = QS = s\).

Karena titik \(B, R, S, C\) segaris pada sisi miring \(BC\), diperoleh:

\[BC = BR + RS + SC = s + s + s = 3s \implies s = \frac{c}{3}\]

Oleh karena itu, luas persegi \(PQRS\) adalah:

\[[PQRS] = s^2 = \left(\frac{c}{3}\right)^2 = \frac{c^2}{9} = \frac{4x}{9}\]
Jadi, luas persegi \(PQRS\) adalah \(\mathbf{\dfrac{4}{9}x}\).
