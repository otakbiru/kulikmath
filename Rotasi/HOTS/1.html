Berikut adalah soal tingkat ... materi Rotasi

Titik $P(a, b)$ dirotasikan sebesar $90^\circ$ berlawanan arah jarum jam dengan pusat rotasi $(1, 2)$ sehingga menghasilkan bayangan $P'(-2, 4)$. Nilai dari $a + b$ adalah ....
  1. $6$
  2. $7$
  3. $8$
  4. $9$
  5. $10$
Pembahasan:
Rumus rotasi $90^\circ$ berlawanan arah jarum jam terhadap pusat $(p, q)$:
$$\begin{pmatrix} x' - p \\ y' - q \end{pmatrix} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} \begin{pmatrix} x - p \\ y - q \end{pmatrix}$$ Dengan pusat $(p, q) = (1, 2)$ dan bayangan $(x', y') = (-2, 4)$:
1. Baris pertama:
$$x' - p = -(y - q) \implies -2 - 1 = -(b - 2) \implies -3 = -b + 2 \implies b = 5$$ 2. Baris kedua:
$$y' - q = x - p \implies 4 - 2 = a - 1 \implies 2 = a - 1 \implies a = 3$$ Maka nilai $a + b = 3 + 5 = 8$.
Jadi, nilai dari $a + b$ adalah 8.
JAWAB: C
Titik \(P\) terletak di dalam persegi \(ABCD\) demikian rupa, sehingga \(AP : BP : CP = 1 : 2 : 3\). Berapakah besar sudut \(APB\)?
OSP SMA 2003 (Bagian I No. 13)
Pembahasan:

Misalkan \(AP = k\), \(BP = 2k\), dan \(CP = 3k\) untuk suatu \(k > 0\).

Putar \(\triangle BPA\) sebesar \(90^\circ\) terhadap titik sudut \(B\) sedemikian sehingga sisi \(BA\) berimpit dengan sisi \(BC\) (yaitu bayangan titik \(A\) tepat jatuh di \(C\), dan bayangan titik \(P\) kita namakan \(P'\)).

Akibat sifat rotasi (\(\triangle BP'C \cong \triangle BPA\)), diperoleh:

  • \(BP' = BP = 2k\) dan \(CP' = AP = k\).
  • \(\angle PBP' = \angle ABC = 90^\circ\).
  • \(\angle APB = \angle CP'B\).

Perhatikan \(\triangle PBP'\): karena siku-siku sama kaki di \(B\) dengan \(BP = BP' = 2k\), maka:

\[\angle BP'P = 45^\circ \quad \text{dan} \quad PP' = 2k\sqrt{2}\]

Selanjutnya perhatikan \(\triangle CPP'\) yang memiliki panjang sisi \(CP' = k\), \(PP' = 2k\sqrt{2}\), dan \(CP = 3k\). Karena memenuhi hubungan Pythagoras:

\[(CP')^2 + (PP')^2 = k^2 + (2k\sqrt{2})^2 = k^2 + 8k^2 = 9k^2 = (CP)^2\]

maka \(\triangle CPP'\) siku-siku di \(P'\), sehingga \(\angle CP'P = 90^\circ\).

Dengan demikian, besar sudut yang dicari adalah:

\[\angle APB = \angle CP'B = \angle CP'P + \angle PP'B = 90^\circ + 45^\circ = 135^\circ\]
Jadi, besar sudut \(APB\) adalah \(\mathbf{135^\circ}\).
