Berikut adalah soal tingkat ... materi Turunan Fungsi Trigonometri

Turunan pertama dari fungsi $f(x) = \dfrac{\sin x}{1 + \cos x}$ adalah $f'(x)$. Nilai dari $f'\left(\dfrac{\pi}{3}\right)$ adalah ....
  1. $\dfrac{1}{3}$
  2. $\dfrac{1}{2}$
  3. $\dfrac{2}{3}$
  4. $\dfrac{3}{4}$
  5. $1$
Pembahasan:
Sederhanakan bentuk fungsi $f(x)$ menggunakan rumus sudut rangkap/setengah sudut:
$$f(x) = \frac{\sin x}{1 + \cos x} = \frac{2\sin(x/2)\cos(x/2)}{2\cos^2(x/2)} = \frac{\sin(x/2)}{\cos(x/2)} = \tan\left(\frac{x}{2}\right)$$ Tentukan turunan pertamanya:
$$f'(x) = \frac{1}{2} \sec^2\left(\frac{x}{2}\right)$$ Untuk $x = \frac{\pi}{3}$ ($60^\circ$), maka $\frac{x}{2} = \frac{\pi}{6}$ ($30^\circ$):
$$\cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2} \implies \sec\left(\frac{\pi}{6}\right) = \frac{2}{\sqrt{3}} \implies \sec^2\left(\frac{\pi}{6}\right) = \frac{4}{3}$$ Sehingga nilai turunannya:
$$f'\left(\frac{\pi}{3}\right) = \frac{1}{2} \times \frac{4}{3} = \frac{2}{3}$$
Jadi, nilai dari $f'\left(\dfrac{\pi}{3}\right)$ adalah $\dfrac{2}{3}$.
