Latihan Soal SNBT materi Persamaan Trigonometri
1.
Banyaknya nilai $x$ pada interval $0^\circ \le x \le 360^\circ$ yang memenuhi persamaan $$2\cos^2 x - 5\cos x - 3 = 0$$ adalah ...
A.
0
B.
1
C.
2
D.
3
E.
4
Kunci Jawaban & Pembahasan:

Kunci Jawaban: C

Diberikan persamaan trigonometri:

$$2\cos^2 x - 5\cos x - 3 = 0$$

Misalkan $u = \cos x$, dengan batasan nilai kosinus $-1 \le u \le 1$. Maka persamaan menjadi:

$$2u^2 - 5u - 3 = 0$$

Faktorkan persamaan kuadrat tersebut:

$$(2u + 1)(u - 3) = 0$$ $$u = -\frac{1}{2} \quad \text{atau} \quad u = 3$$

Evaluasi nilai $u$ terhadap rentang fungsi kosinus:

  • Untuk $u = \cos x = 3$: Tidak memenuhi karena nilai $\cos x$ berada pada interval $[-1, 1]$.
  • Untuk $u = \cos x = -\frac{1}{2}$: Memenuhi.

Cari nilai $x$ yang memenuhi $\cos x = -\frac{1}{2}$ pada interval $0^\circ \le x \le 360^\circ$:

Nilai kosinus bernilai negatif di Kuadran II dan Kuadran III dengan sudut relasi $60^\circ$ ($\cos 60^\circ = \frac{1}{2}$):

  • Kuadran II: $x = 180^\circ - 60^\circ = 120^\circ$
  • Kuadran III: $x = 180^\circ + 60^\circ = 240^\circ$

Kedua nilai berada dalam rentang $0^\circ \le x \le 360^\circ$.

Jadi, banyaknya nilai $x$ yang memenuhi persamaan tersebut adalah 2.
