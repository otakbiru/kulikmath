Ringkasan dan penjelasan lengkap materi Rata-Rata (Mean)

1. Pengertian & Makna Fisis Rata-Rata sebagai Titik Tumpu

Rata-Rata Hitung (Arithmetic Mean), yang lazim disimbolkan dengan $\bar{x}$ (dibaca x-bar), adalah ukuran pemusatan data (*measure of central tendency*) yang merepresentasikan nilai tunggal pembagi rata jumlahan seluruh nilai observasi.

Secara aljabar, rata-rata untuk $n$ buah data $x_1, x_2, \dots, x_n$ dirumuskan sebagai: $$\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n} = \frac{x_1 + x_2 + \dots + x_n}{n}$$

Sifat Keseimbangan Mekanis (Pusat Massa)

Secara fisika dan geometri, rata-rata bertindak sebagai titik tumpu keseimbangan (fulcrum / center of mass) dari suatu sistem partikel berbobot identik yang ditempatkan pada garis bilangan real.

Ciri khas fundamental rata-rata adalah jumlah aljabar dari deviasi (selisih) setiap data terhadap nilai rata-ratanya selalu tepat sama dengan nol: $$\sum_{i=1}^{n} (x_i - \bar{x}) = 0$$

Pada visualisasi di samping dengan data $\{2, 4, 9, 13\}$, nilai rata-ratanya adalah: $$\bar{x} = \frac{2 + 4 + 9 + 13}{4} = 7$$ Deviasi di sebelah kiri: $(2 - 7) + (4 - 7) = -5 + (-3) = -8$.
Deviasi di sebelah kanan: $(9 - 7) + (13 - 7) = +2 + (+6) = +8$.
Sistem berada dalam keseimbangan momen putar statis sempurna: $(-8) + (+8) = 0$.

2. Rata-Rata Tertimbang & Rata-Rata Gabungan

A. Rata-Rata Tertimbang (Weighted Mean)

Jika setiap nilai data $x_i$ memiliki bobot kepentingan atau frekuensi kemunculan sebesar $w_i$, maka rata-rata tertimbang didefinisikan sebagai: $$\bar{x}_w = \frac{\sum_{i=1}^{k} w_i x_i}{\sum_{i=1}^{k} w_i} = \frac{w_1 x_1 + w_2 x_2 + \dots + w_k x_k}{w_1 + w_2 + \dots + w_k}$$

B. Rata-Rata Gabungan (Combined Mean) & Kaidah Tuas

Jika terdapat $k$ kelompok data dengan banyak anggota masing-masing $n_1, n_2, \dots, n_k$ dan rata-rata $\bar{x}_1, \bar{x}_2, \dots, \bar{x}_k$, maka rata-rata seluruh anggota gabungan adalah: $$\bar{x}_{\text{gab}} = \frac{n_1 \bar{x}_1 + n_2 \bar{x}_2 + \dots + n_k \bar{x}_k}{n_1 + n_2 + \dots + n_k}$$

Kaidah Tuas Jungkat-Jungkit (Lever Rule):
Untuk dua kelompok data dengan $\bar{x}_1 < \bar{x}_{\text{gab}} < \bar{x}_2$, perbandingan jumlah anggota berbanding terbalik dengan selisih jarak rata-ratanya terhadap rata-rata gabungan: $$n_1 (\bar{x}_{\text{gab}} - \bar{x}_1) = n_2 (\bar{x}_2 - \bar{x}_{\text{gab}}) \iff \frac{n_1}{n_2} = \frac{\bar{x}_2 - \bar{x}_{\text{gab}}}{\bar{x}_{\text{gab}} - \bar{x}_1}$$

3. Rata-Rata Data Berkelompok (Tabel Distribusi Frekuensi)

Untuk data yang disajikan dalam bentuk interval kelas berkala, terdapat tiga metode komputasi yang menghasilkan nilai rata-rata yang sama:

  1. Metode Titik Tengah ($x_i$): $$\bar{x} = \frac{\sum_{i=1}^{k} f_i x_i}{\sum_{i=1}^{k} f_i} \quad \text{dengan } x_i = \frac{\text{Batas Bawah} + \text{Batas Atas}}{2}$$
  2. Metode Rata-Rata Sementara ($x_s$ / Assumed Mean): Memilih salah satu titik tengah kelas dengan frekuensi terbesar sebagai acuan $x_s$, lalu menghitung deviasi $d_i = x_i - x_s$: $$\bar{x} = x_s + \frac{\sum_{i=1}^{k} f_i d_i}{\sum_{i=1}^{k} f_i}$$
  3. Metode Koding (Pengkodean Sederhana $u_i$): Menyederhanakan deviasi dengan membaginya terhadap panjang interval kelas $c$: $u_i = \frac{x_i - x_s}{c}$: $$\bar{x} = x_s + \left(\frac{\sum_{i=1}^{k} f_i u_i}{\sum_{i=1}^{k} f_i}\right) \times c$$

4. Sifat-Sifat Transformasi Linear Data

Jika setiap nilai data awal $x_i$ dikenai transformasi aljabar linear menjadi data baru $y_i = a x_i + b$ (dengan $a$ faktor pengali dan $b$ konstanta pergeseran):

Teorema Transformasi Linear Rata-Rata:
$$\bar{y} = a \bar{x} + b$$ Rata-rata terpengaruh secara langsung oleh operasi perkalian/pembagian ($a$) maupun operasi penjumlahan/pengurangan ($b$).

Perbandingan Kritis: Ukuran pemusatan data (Rata-rata, Median, Modus) terpengaruh oleh operasi penjumlahan dan perkalian. Sebaliknya, ukuran penyebaran data (Jangkauan, Simpangan Kuartil, Simpangan Baku) hanya terpengaruh oleh perkalian $|a|$ dan kebal terhadap operasi penambahan konstanta $+ b$.

5. Hierarki Ketaksamaan Rata-Rata Klasik: QM $\ge$ AM $\ge$ GM $\ge$ HM

Untuk sekumpulan bilangan real positif $a, b > 0$, didefinisikan empat jenis rata-rata klasik:

  • Quadratic Mean (Rata-rata Kuadrat / RMS): $QM = \sqrt{\frac{a^2 + b^2}{2}}$
  • Arithmetic Mean (Rata-rata Hitung): $AM = \frac{a + b}{2}$
  • Geometric Mean (Rata-rata Ukur): $GM = \sqrt{ab}$
  • Harmonic Mean (Rata-rata Harmonik): $HM = \frac{2}{\frac{1}{a} + \frac{1}{b}} = \frac{2ab}{a + b}$

Teorema Rantai Ketaksamaan: $$QM \ge AM \ge GM \ge HM$$ Tanda kesamaan ($QM = AM = GM = HM$) berlaku jika dan hanya jika seluruh elemen bernilai sama ($a = b$).

6. Contoh Soal Berjenjang & Pembahasan Lengkap

Contoh 1: Transformasi Linear & Penambahan Data Baru (Tingkat Dasar)
Sekumpulan data yang terdiri dari 10 bilangan memiliki nilai rata-rata 45.
a) Jika ke dalam kelompok tersebut ditambahkan satu data baru yang bernilai 67, tentukan nilai rata-rata yang baru!
b) Jika setiap bilangan dari 10 data awal tersebut dikalikan 2 kemudian dikurangi 5, tentukan nilai rata-rata dari data baru tersebut!
Pembahasan:
a) Menghitung Rata-Rata Setelah Penambahan Data Baru
Jumlah total awal dari 10 data ($n_1 = 10, \bar{x}_1 = 45$): $$\sum x_{\text{awal}} = n_1 \times \bar{x}_1 = 10 \times 45 = 450$$ Setelah ditambahkan data baru $x_{11} = 67$, jumlah total baru menjadi: $$\sum x_{\text{baru}} = 450 + 67 = 517$$ Banyaknya data kini menjadi $n_{\text{baru}} = 10 + 1 = 11$.
Rata-rata yang baru adalah: $$\bar{x}_{\text{baru}} = \frac{\sum x_{\text{baru}}}{n_{\text{baru}}} = \frac{517}{11} = \mathbf{47}$$
b) Menerapkan Sifat Transformasi Linear
Setiap data dikenai operasi $y_i = 2x_i - 5$.
Berdasarkan teorema transformasi linear data: $$\bar{y} = 2\bar{x} - 5$$ Substitusikan rata-rata awal $\bar{x} = 45$: $$\bar{y} = 2(45) - 5 = 90 - 5 = \mathbf{85}$$
a) Rata-rata setelah penambahan satu data baru adalah 47.
b) Rata-rata setelah transformasi linear adalah 85.
Contoh 2: Rata-Rata Gabungan & Analisis Rasio Frekuensi (Tingkat SNBT)
Nilai rata-rata ujian matematika suatu kelas gabungan adalah 72. Diketahui nilai rata-rata siswa putra adalah 68, sedangkan nilai rata-rata siswa putri adalah 75. Jika jumlah seluruh siswa dalam kelas tersebut adalah 35 orang:
a) Tentukan perbandingan jumlah siswa putra dan siswa putri di kelas tersebut!
b) Hitunglah banyak masing-masing siswa putra dan siswa putri!
Pembahasan:
a) Menentukan Perbandingan Siswa (Kaidah Tuas / Selisih Jarak)
Diketahui:
  • Rata-rata siswa putra: $\bar{x}_1 = 68$
  • Rata-rata siswa putri: $\bar{x}_2 = 75$
  • Rata-rata gabungan kelas: $\bar{x}_{\text{gab}} = 72$
Gunakan rumus perbandingan rata-rata gabungan: $$\frac{n_1}{n_2} = \frac{\bar{x}_2 - \bar{x}_{\text{gab}}}{\bar{x}_{\text{gab}} - \bar{x}_1}$$ Substitusikan nilai yang diketahui: $$\frac{n_{\text{putra}}}{n_{\text{putri}}} = \frac{75 - 72}{72 - 68} = \frac{3}{4}$$ Jadi, perbandingan jumlah siswa putra dan siswa putri adalah $3 : 4$.

b) Menghitung Banyak Siswa Putra dan Putri
Total bagian rasio $= 3 + 4 = 7$ bagian.
Diketahui total siswa adalah 35 orang, maka nilai 1 bagian rasio adalah: $$\text{Nilai 1 Bagian} = \frac{35}{7} = 5 \text{ siswa}$$ Banyak siswa putra: $$n_{\text{putra}} = 3 \times 5 = \mathbf{15 \text{ orang}}$$ Banyak siswa putri: $$n_{\text{putri}} = 4 \times 5 = \mathbf{20 \text{ orang}}$$
a) Perbandingan banyak siswa putra dan putri adalah $3 : 4$.
b) Banyak siswa putra adalah 15 orang dan siswa putri adalah 20 orang.
Contoh 3: Optimasi Ketaksamaan AM-GM Pembobotan & Siklik (Tingkat HOTS)
a) Tiga bilangan real positif $a, b, c > 0$ memenuhi persamaan $a + b + c = 12$. Tentukan nilai maksimum yang mungkin dari perkalian bentuk berpangkat $a^2 b^3 c$!
b) Buktikan bahwa untuk sembarang bilangan real positif $x, y, z > 0$ selalu berlaku ketaksamaan: $$\frac{x}{y} + \frac{y}{z} + \frac{z}{x} \ge 3$$ serta tentukan syarat kapan kesamaan tepat terjadi!
Pembahasan:
a) Teknik Pembobotan Suku pada Ketaksamaan AM-GM
Kita ingin mencari nilai maksimum dari ekspresi $a^2 b^3 c^1$.
Eksponen dari masing-masing variabel adalah $2, 3,$ dan $1$, dengan total eksponen $2 + 3 + 1 = 6$.
Uraikan jumlahan $a + b + c$ menjadi 6 suku yang berbobot seimbang:
  • Pecah $a$ menjadi 2 suku bernilai $\frac{a}{2}$
  • Pecah $b$ menjadi 3 suku bernilai $\frac{b}{3}$
  • Suku $c$ tetap bernilai $c$ (1 suku)
Jumlah keenam suku tersebut tetap bernilai 12: $$\left(\frac{a}{2} + \frac{a}{2}\right) + \left(\frac{b}{3} + \frac{b}{3} + \frac{b}{3}\right) + c = a + b + c = 12$$ Terapkan Ketaksamaan Rata-Rata Aritmetika - Geometri (AM-GM) untuk 6 suku positif: $$\frac{\frac{a}{2} + \frac{a}{2} + \frac{b}{3} + \frac{b}{3} + \frac{b}{3} + c}{6} \ge \sqrt[6]{\left(\frac{a}{2}\right) \left(\frac{a}{2}\right) \left(\frac{b}{3}\right) \left(\frac{b}{3}\right) \left(\frac{b}{3}\right) c}$$ $$\frac{12}{6} \ge \sqrt[6]{\frac{a^2 b^3 c}{2^2 \times 3^3}} = \sqrt[6]{\frac{a^2 b^3 c}{4 \times 27}} = \sqrt[6]{\frac{a^2 b^3 c}{108}}$$ $$2 \ge \sqrt[6]{\frac{a^2 b^3 c}{108}}$$ Pangkatkan 6 pada kedua ruas ketaksamaan: $$2^6 \ge \frac{a^2 b^3 c}{108} \implies 64 \ge \frac{a^2 b^3 c}{108}$$ $$a^2 b^3 c \le 64 \times 108 = \mathbf{6.912}$$ Nilai maksimum $6.912$ tercapai saat kondisi kesamaan AM-GM terpenuhi, yaitu saat semua suku bernilai sama: $$\frac{a}{2} = \frac{b}{3} = c = 2 \implies a = 4, \quad b = 6, \quad c = 2$$ (Cek: $4 + 6 + 2 = 12$, memenuhi).

b) Pembuktian Ketaksamaan Siklik Menggunakan AM-GM
Tinjau tiga suku positif: $\frac{x}{y}$, $\frac{y}{z}$, dan $\frac{z}{x}$.
Berdasarkan ketaksamaan AM-GM untuk 3 suku: $$\frac{\frac{x}{y} + \frac{y}{z} + \frac{z}{x}}{3} \ge \sqrt[3]{\frac{x}{y} \cdot \frac{y}{z} \cdot \frac{z}{x}}$$ Perhatikan bahwa hasil kali ketiga suku tersebut saling menghilangkan secara siklik (*telescoping product*): $$\frac{x}{y} \cdot \frac{y}{z} \cdot \frac{z}{x} = 1$$ Sehingga: $$\frac{\frac{x}{y} + \frac{y}{z} + \frac{z}{x}}{3} \ge \sqrt[3]{1} = 1$$ Kalikan kedua ruas dengan $3$: $$\frac{x}{y} + \frac{y}{z} + \frac{z}{x} \ge 3 \quad \text{(Terbukti)}$$ Kesamaan tepat terjadi jika dan hanya jika ketiga suku bernilai sama: $$\frac{x}{y} = \frac{y}{z} = \frac{z}{x} = 1 \iff x = y = z$$
a) Nilai maksimum dari $a^2 b^3 c$ adalah 6.912 (tercapai di $a=4, b=6, c=2$).
b) Terbukti bahwa $\frac{x}{y} + \frac{y}{z} + \frac{z}{x} \ge 3$, dengan kesamaan tercapai di $x = y = z$.
