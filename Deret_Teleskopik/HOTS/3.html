Berikut adalah soal tingkat ... materi Deret Teleskopik

Misalkan $$a = \frac{1^2}{1} + \frac{2^2}{3} + \frac{3^2}{5} + \cdots + \frac{1001^2}{2001} \quad\text{dan}\quad b = \frac{1^2}{3} + \frac{2^2}{5} + \frac{3^2}{7} + \cdots + \frac{1001^2}{2003}.$$ Tentukan bilangan bulat yang nilainya paling dekat ke $a - b$.
Sumber: OSK SMA 2002 (No. 19)
Pembahasan:

Pasangkan suku-suku berpenyebut sama dari $a$ dan $b$:

$$a - b = \frac{1^2}{1} + \sum_{k=1}^{1000} \frac{(k + 1)^2 - k^2}{2k + 1} - \frac{1001^2}{2003}$$

Karena $(k+1)^2 - k^2 = 2k + 1$, setiap suku di dalam sigma bernilai tepat $1$, sehingga ada $1 + 1000 = 1001$ suku bernilai $1$:

$$a - b = 1001 - \frac{1001^2}{2003} = \frac{1001(2003 - 1001)}{2003} = \frac{1001 \times 1002}{2003} = 500 + \frac{1502}{2003} \approx 500{,}75$$

Bilangan bulat yang paling dekat dengan $500{,}75$ adalah $501$.

Jadi, bilangan bulat terdekatnya adalah $501$.
