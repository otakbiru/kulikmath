Jika x1 dan x2 adalah akar-akar persamaan kuadrat x2 + x − 3 = 0 maka hasil dari 4x12 + 3x22 + 2x1 + x2 adalah
  1. 20
  2. 21
  3. 22
  4. 23
  5. 24
Sumber: Grup WhatsApp
Pembahasan:
\(\begin{aligned} x_1+x_2&=-\dfrac{b}a\\[8pt] &=-\dfrac11\\ &=-1 \end{aligned}\)

\(\begin{aligned} x_1x_2&=\dfrac{c}a\\[8pt] &=\dfrac{-3}1\\ &=-3 \end{aligned}\)

\(\begin{aligned} x^2+x-3&=0\\ x^2+x&=3 \end{aligned}\)

\(\begin{aligned} 4{x_1}^2+3{x_2}^2+2x_1+x_2&=2{x_1}^2+2{x_1}^2+2{x_2}^2+{x_2}^2+2x_1+x_2\\ &=2{x_1}^2+2{x_2}^2+2{x_1}^2+2x_1+{x_2}^2+x_2\\ &=2\left({x_1}^2+{x_2}^2\right)+2\left({x_1}^2+x_1\right)+{x_2}^2+x_2\\ &=2\left(\left({x_1}+{x_2}\right)^2-2x_1x_2\right)+2\left({x_1}^2+x_1\right)+{x_2}^2+x_2\\ &=2\left(\left(-1\right)^2-2(-3)\right)+2\left(3\right)+3\\ &=2\left(1+6\right)+6+3\\ &=2\left(7\right)+9\\ &=14+9\\ &=\boxed{\boxed{23}} \end{aligned}\)
Jadi, hasil dari 4x12 + 3x22 + 2x1 + x2 adalah 23.

Misalkan dua persamaan kuadrat mempunyai satu akar yang sama, yaitu 1 dan akar-akar lainnya berkebalikan. Jika salah satu persamaan itu adalah x2 − ax + 5 = 0, maka persamaan kuadrat lainnya adalah
  1. 6x2 + 5x + 1 = 0
  2. 6x2 − 5x − 1 = 0
  3. 6x2 − 5x + 1 = 0
  4. 5x2 − 6x + 2 = 0
  5. 5x2 − 6x + 1 = 0
Sumber: Grup WhatsApp
Pembahasan:
\(\begin{aligned} x^2-ax+5&=0\\ 1^2-a(1)+5&=0\\ 1-a+5&=0\\ 6-a&=0\\ a&=6 \end{aligned}\)

\(\begin{aligned} x^2-6x+5&=0\\ (x-1)(x-5)&=0 \end{aligned}\)
x = 1 dan x = 5

Persamaan kedua mempunyai akar 1 dan \(\dfrac15\).

\(\begin{aligned} (x-1)\left(x-\dfrac15\right)&=0&\color{red}{\times5}\\ (x-1)(5x-1)&=0\\ 5x^2-6x+1&=0 \end{aligned}\)
Jadi, persamaan kuadrat lainnya adalah 5x2 − 6x + 1 = 0.

Jika x1 dan x2 adalah akar-akar persamaan kuadrat x2 + 2x − 2 = 0 , maka nilai x13x2 + x1x23 adalah
  1. −12
  2. −14
  3. −16
  4. −18
  5. −20
Sumber: SKMP September 2020
Pembahasan:
a = 1, b = 2, c = −2

\(\begin{aligned} x_1+x_2&=\dfrac{-b}a\\ &=\dfrac{-2}1\\ &=-2 \end{aligned}\)

\(\begin{aligned} x_1x_2&=\dfrac{c}a\\ &=\dfrac{-2}1\\ &=-2 \end{aligned}\)
\(\begin{aligned} {x_1}^3x_2 + x_1{x_2}^3&=x_1x_2\left({x_1}^2+{x_2}^2\right)\\ &=x_1x_2\left(\left(x_1+x_2\right)^2-2x_1x_2\right)\\ &=-2\left(\left(-2\right)^2-2(-2)\right)\\ &=-2\left(4+4\right)\\ &=-2(8)\\ &=\boxed{\boxed{-16}} \end{aligned}\)
Jadi, x13x2 + x1x23 = −16 .

Diketahui akar-akar persamaan x2 + ax + (1 − a) = 0 adalah x1 dan x2. Jika \(\dfrac1{x_1}+\dfrac1{x_2}=\dfrac54\), maka nilai (a + 3)(a + 7) adalah
  1. 104
  2. 102
  3. 112
  4. 98
  5. 96
Sumber: SKMP Juli 2020
Pembahasan:
\(x_1+x_2=\dfrac{-a}1=-a\)

\(x_1x_2=\dfrac{1-a}1=1-a\)

\(\begin{aligned} \dfrac1{x_1}+\dfrac1{x_2}&=\dfrac54\\ \dfrac{x_1+x_2}{x_1x_2}&=\dfrac54\\ \dfrac{-a}{1-a}&=\dfrac54\\ -4a&=5-5a\\ a&=5 \end{aligned}\)
\(\begin{aligned} (a+3)(a+7)&=(5+3)(5+7)\\ &=(8)(12)\\ &=\boxed{\boxed{96}} \end{aligned}\)
Jadi, (a + 3)(a + 7) = 96.

Diketahui $x^2-x-2=0$ dan $2xy+3y=7$.
P Q
$x_1\cdot x_2$ $y_1\cdot y_2$
Manakah hubungan yang benar antara kuantitas P dan Q berdasarkan informasi yang diberikan?
  1. Kuantitas P lebih besar daripada kuantitas Q
  2. Kuantitas P lebih kecil daripada kuantitas Q
  3. Kuantitas P sama dengan kuantitas Q
  4. Informasi yang diberikan tidak cukup untuk memutuskan hubungan kuantitas P dan Q.
Sumber: UTBK 2020
Pembahasan:
$\begin{aligned} P&=x_1\cdot x_2\\[8pt] &=\dfrac{-2}1\\[8pt] &=-2 \end{aligned}$

$\begin{aligned} x^2-x-2&=0\\ (x-2)(x+1)&=0 \end{aligned}$
didapat $x_1=2$ dan $x_2=-1$

Untuk $x_1=2$ didapat $2(2)y+3y=7$ sehingga $7y=7$ dan $y_1=1$
Untuk $x_2=-1$ didapat $2(-1)y+3y=7$ sehingga $y_2=-7$

$\begin{aligned} Q&=y_1\cdot y_2\\[8pt] &=1\cdot(-7)\\[8pt] &=-7 \end{aligned}$

Karena $P=-2$ dan $Q=-7$, maka $P>Q$
Jadi, kuantitas P lebih besar daripada kuantitas Q.

Jika $x_1$ dan $x_2$ adalah akar-akar $2x^2-(2c-1)x-c^3+4=0$, maka nilai maksimum dari $x_1^2+x_2^2$ adalah ....
SNBT 2014
Pembahasan:
Diketahui persamaan kuadrat: $$2x^2 - (2c - 1)x - c^3 + 4 = 0$$ Identifikasi koefisien persamaan kuadrat ($Ax^2 + Bx + C = 0$):
  • $a = 2$
  • $b = -(2c - 1)$
  • $c_{\text{konstanta}} = -c^3 + 4$
Langkah 1: Menggunakan Teorema Vieta
Berdasarkan rumus jumlah dan hasil kali akar-akar persamaan kuadrat: $$\begin{aligned} x_1 + x_2 &= -\frac{b}{a} = \frac{2c - 1}{2} \\[6pt] x_1 \cdot x_2 &= \frac{c_{\text{konstanta}}}{a} = \frac{-c^3 + 4}{2} \end{aligned}$$
Langkah 2: Menjabarkan bentuk $x_1^2 + x_2^2$
Gunakan identitas aljabar: $$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2(x_1 \cdot x_2)$$ Substitusikan nilai dari Teorema Vieta: $$\begin{aligned} x_1^2 + x_2^2 &= \left(\frac{2c - 1}{2}\right)^2 - 2\left(\frac{-c^3 + 4}{2}\right) \\[6pt] &= \frac{4c^2 - 4c + 1}{4} - (-c^3 + 4) \\[6pt] &= c^2 - c + \frac{1}{4} + c^3 - 4 \\[6pt] &= c^3 + c^2 - c - \frac{15}{4} \end{aligned}$$ Misalkan fungsi kuadrat akar-akar tersebut dinyatakan sebagai $f(c)$: $$f(c) = c^3 + c^2 - c - \frac{15}{4}$$
Langkah 3: Menentukan nilai stasioner dengan turunan pertama
Nilai ekstrim (stasioner) tercapai saat turunan pertama bernilai nol ($f'(c) = 0$): $$\begin{aligned} f'(c) &= 3c^2 + 2c - 1 = 0 \\ (3c - 1)(c + 1) &= 0 \end{aligned}$$ Diperoleh dua titik stasioner: $$c = \frac{1}{3} \quad \text{atau} \quad c = -1$$
Langkah 4: Menguji jenis titik stasioner (Uji Turunan Kedua)
Turunan kedua fungsi: $$f''(c) = 6c + 2$$
  • Untuk $c = -1$: $$f''(-1) = 6(-1) + 2 = -4 < 0 \implies \text{Titik balik maksimum lokal}$$
  • Untuk $c = \frac{1}{3}$: $$f''\left(\frac{1}{3}\right) = 6\left(\frac{1}{3}\right) + 2 = 4 > 0 \implies \text{Titik balik minimum lokal}$$
Langkah 5: Menghitung nilai maksimum
Substitusikan $c = -1$ ke dalam fungsi $f(c)$: $$\begin{aligned} f(-1) &= (-1)^3 + (-1)^2 - (-1) - \frac{15}{4} \\[6pt] &= -1 + 1 + 1 - \frac{15}{4} \\[6pt] &= 1 - \frac{15}{4} \\[6pt] &= \color{blue}\boxed{\boxed{\color{black}-\frac{11}{4}}} \quad \left(\text{atau } -2\frac{3}{4} = -2{,}75\right) \end{aligned}$$
Jadi, nilai maksimum dari $x_1^2 + x_2^2$ adalah $-\dfrac{11}{4}$ (atau $-2\dfrac{3}{4}$).
