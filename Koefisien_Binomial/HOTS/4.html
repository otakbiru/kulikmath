Berikut adalah soal tingkat ... materi Koefisien Binomial

Misalkan $S = (x - 2)^4 + 8(x - 2)^3 + 24(x - 2)^2 + 32(x - 2) + 16$. Apakah $S$ jika dituliskan dalam sesedikit mungkin suku penjumlahan?
Sumber: OSP SMA 2002 (Bagian Pertama - No. 3)
Pembahasan:

Perhatikan pola koefisien binomial $(a + b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4$ dengan $a = x - 2$ dan $b = 2$:

$$S = (x - 2)^4 + 4(x - 2)^3(2) + 6(x - 2)^2(2^2) + 4(x - 2)(2^3) + 2^4 = \big((x - 2) + 2\big)^4 = x^4$$
Jadi, bentuk paling sederhana dari $S$ adalah $x^4$.
