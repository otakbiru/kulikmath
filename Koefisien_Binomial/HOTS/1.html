Misalkan \(S = (x - 2)^4 + 8(x - 2)^3 + 24(x - 2)^2 + 32(x - 2) + 16\). Apakah bentuk \(S\) jika dituliskan dalam sesedikit mungkin suku penjumlahan?

OSP SMA 2002
Pembahasan:

Ingat kembali ekspansi binomial Newton untuk pangkat \(4\): \[ (a + b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4 \]

Perhatikan koefisien dan pola pada bentuk aljabar \(S\): \[ \begin{aligned} S &= (x - 2)^4 + 8(x - 2)^3 + 24(x - 2)^2 + 32(x - 2) + 16 \\[6pt] &= (x - 2)^4 + 4 \cdot 2(x - 2)^3 + 6 \cdot 2^2(x - 2)^2 + 4 \cdot 2^3(x - 2) + 2^4 \end{aligned} \]

Dengan mengambil \(a = (x - 2)\) dan \(b = 2\), bentuk tersebut tepat mengikuti ekspansi \((a + b)^4\): \[ \begin{aligned} S &= \bigl((x - 2) + 2\bigr)^4 \\[6pt] &= (x)^4 \\[6pt] &= x^4 \end{aligned} \]

Jadi, bentuk \(S\) jika dituliskan dalam sesedikit mungkin suku penjumlahan adalah \(x^4\).

Tentukan nilai dari penjumlahan deret koefisien binomial berikut: \[ \sum_{i=0}^{2011} (-1)^i \binom{2011}{i} \]

Pembahasan:

Berdasarkan Teorema Binomial, bentuk ekspansi \((x + y)^n\) dinyatakan oleh rumus: \[ (x + y)^n = \sum_{i=0}^{n} \binom{n}{i} x^i y^{n - i} \]

Jika kita substitusikan nilai \(n = 2011\), \(x = -1\), dan \(y = 1\), maka diperoleh: \[ \begin{aligned} (-1 + 1)^{2011} &= \sum_{i=0}^{2011} \binom{2011}{i} (-1)^i (1)^{2011 - i} \\[6pt] 0^{2011} &= \sum_{i=0}^{2011} \binom{2011}{i} (-1)^i (1) \\[6pt] 0 &= \sum_{i=0}^{2011} (-1)^i \binom{2011}{i} \end{aligned} \]

Jadi, nilai dari \(\displaystyle \sum_{i=0}^{2011} (-1)^i \binom{2011}{i} = 0\).
Suku konstanta pada ekspansi $\left(2x^2 - \dfrac{1}{x}\right)^9$ adalah $\cdots$
Sumber: OSP SMA 2007 (Bagian 1 • No. 11)
Pembahasan:

Suku umum ekspansi binomial $\left(2x^2 - \dfrac{1}{x}\right)^9$ adalah:

$$T_{k+1} = \binom{9}{k} (2x^2)^k \left(-\frac{1}{x}\right)^{9-k} = \binom{9}{k} 2^k (-1)^{9-k} x^{2k - (9-k)} = \binom{9}{k} 2^k (-1)^{9-k} x^{3k - 9}$$

Untuk suku konstanta, pangkat $x$ harus sama dengan nol:

$$3k - 9 = 0 \implies k = 3$$

Substitusikan $k = 3$:

$$T_4 = \binom{9}{3} \cdot 2^3 \cdot (-1)^6 = 84 \cdot 8 \cdot 1 = 672$$
Jadi, suku konstantanya adalah $672$.
Koefisien $x^4$ dari penjabaran $(1 + 2x + 3x^2)^{10}$ adalah $\cdots$
Sumber: OSK SMA 2011 (No. 16)
Pembahasan:

Dengan teorema multinomial, suku umum $(1 + 2x + 3x^2)^{10}$ adalah:

$$\frac{10!}{a!\,b!\,c!} (1)^a (2x)^b (3x^2)^c = \frac{10!}{a!\,b!\,c!} 2^b 3^c \, x^{b + 2c}$$

dengan $a + b + c = 10$ dan $a, b, c \ge 0$. Agar pangkat $x$ sama dengan $4$, haruslah $b + 2c = 4$:

  • $c = 2, b = 0, a = 8$: $\dfrac{10!}{8!\,0!\,2!} \cdot 2^0 \cdot 3^2 = 45 \times 9 = 405$.
  • $c = 1, b = 2, a = 7$: $\dfrac{10!}{7!\,2!\,1!} \cdot 2^2 \cdot 3^1 = 360 \times 4 \times 3 = 4320$.
  • $c = 0, b = 4, a = 6$: $\dfrac{10!}{6!\,4!\,0!} \cdot 2^4 \cdot 3^0 = 210 \times 16 = 3360$.

Total koefisien $x^4$ adalah $405 + 4320 + 3360 = 8085$.

Jadi, koefisien $x^4$ adalah $8085$.
Misalkan $S = (x - 2)^4 + 8(x - 2)^3 + 24(x - 2)^2 + 32(x - 2) + 16$. Apakah $S$ jika dituliskan dalam sesedikit mungkin suku penjumlahan?
Sumber: OSP SMA 2002 (Bagian Pertama - No. 3)
Pembahasan:

Perhatikan pola koefisien binomial $(a + b)^4 = a^4 + 4a^3b + 6a^2b^2 + 4ab^3 + b^4$ dengan $a = x - 2$ dan $b = 2$:

$$S = (x - 2)^4 + 4(x - 2)^3(2) + 6(x - 2)^2(2^2) + 4(x - 2)(2^3) + 2^4 = \big((x - 2) + 2\big)^4 = x^4$$
Jadi, bentuk paling sederhana dari $S$ adalah $x^4$.
