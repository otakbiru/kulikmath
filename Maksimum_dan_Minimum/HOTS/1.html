Nilai maksimum dari \({\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\) dengan x,y,z ∈ [0, 2021] adalah ....
  1. \(\sqrt{6063}\)
  2. \(2\sqrt{2021}\)
  3. \(\sqrt{4042}+\sqrt{2021}\)
  4. \(2\sqrt{2021}+\sqrt{4042}\)
  5. \(2021\sqrt{2}+2021\)
SUMBER
Pembahasan:
Misalkan x ≥ y ≥ z dan \({P=\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\). P bisa kita tulis menjadi,
\({P=\sqrt{x-y}+\sqrt{y-z}+\sqrt{x-z}}\)

Nilai P akan semakin besar jika nilai x semakin besar dan nilai z semakin kecil. Didapat x = 2021 dan z = 0. Substitusikan ke P menjadi
\({P=\sqrt{2021-y}+\sqrt{y}+\sqrt{2021}}\)

Dengan menggunakan ketaksamaan Cauchy-Schwarz didapat,
\(\begin{aligned} \left(\sqrt{2021-y}\cdot1+\sqrt{y}\cdot1\right)^2&\leq \left(\left(\sqrt{2021-y}\right)^2+\left(\sqrt{y}\right)^2\right)\left(1^2+1^2\right)\\ \left(\sqrt{2021-y}+\sqrt{y}\right)^2&\leq \left(2021-y+y\right)\left(2\right)\\ \left(\sqrt{2021-y}+\sqrt{y}\right)^2&\leq 4042\\ \sqrt{2021-y}+\sqrt{y}&\leq \sqrt{4042}\\ \sqrt{2021-y}+\sqrt{y}+\sqrt{2021}&\leq \sqrt{4042}+\sqrt{2021} \end{aligned}\)
Jadi, nilai maksimum dari \({\sqrt{\left|x-y\right|}+\sqrt{\left|y-z\right|}+\sqrt{\left|z-x\right|}}\) dengan x,y,z ∈ [0, 2021] adalah \(\sqrt{4042}+\sqrt{2021}\).

Nilai maksimum dari \(y=x\sqrt{2-x^2}\) adalah ....
  1. 0
  2. 1
  3. 1 dan 0
  4. −2 dan 0
  5. 2 dan 0
Grup Matematika Idhamdaz
Pembahasan:
\(\begin{aligned} y&=x\sqrt{2-x^2}\\ y^2&=x^2\left(2-x^2\right)\\ &=2x^2-x^4 \end{aligned}\)

y mencapai maksimum saat \(\dfrac{dy}{dx}=0\)
\(\begin{aligned} 2y\ dy&=\left(4x-4x^3\right)\ dx\\ 2y\dfrac{dy}{dx}&=4x-4x^3\\ 2y(0)&=4x-4x^3\\ 4x^3-4x&=0\\ 4x(x+1)(x-1)&=0 \end{aligned}\)
x = 0, x = −1, x = 1

x = 0 ⟶ y = 0
x = −1 ⟶ y = −1
x = 1 ⟶ y = 1
Jadi, nilai maksimum dari \(y=x\sqrt{2-x^2}\) adalah 1.

Diberikan bilangan real x dan y sehingga memenuhi persamaan 4x2 + y2 = 4x − 2y + 7. Jika diketahui nilai maksimum dan minimum dari 5x + 6y adalah berturut-turut A dan B, maka carilah nilai |A| + |B| (|x| menyatakan nilai muthlak dari x)
SUMBER
Pembahasan:
\(\begin{aligned} 4x^2+y^2&=4x-2y+7\\ 4x^2-4x+y^2+2y&=7\\ (2x-1)^2+(y+1)^2&=3^2 \end{aligned}\)
Misal
\(2x-1=a\longrightarrow x=\dfrac{a+1}2\)
\(y+1=b\longrightarrow y=b-1\)

\(\begin{aligned} 5x+6y&=5\cdot\dfrac{a+1}2+6(b-1)\\[3.8pt] &=\dfrac{5a+5}2+6b-6\\[3.8pt] &=\dfrac{5a+12b-7}2 \end{aligned}\)
\(\begin{aligned} (5a+12b)^2&\leq(5^2+12^2)(a^2+b^2)\\ &\leq(13^2)(3^2)\\ &\leq39^2 \end{aligned}\)
\(\begin{array}{rcccl} -39&\leq&5a+12b&\leq&39\\ -39&\leq&5(2x-1)+12(y+1)&\leq&39\\ -39&\leq&10x-5+12y+12&\leq&39\\ -39&\leq&10x+12y+7&\leq&39\\ -46&\leq&10x+12y&\leq&32\\ -23&\leq&5x+6y&\leq&16 \end{array}\)

\(\begin{aligned} |A|+|B|&=|16|+|-23|\\ &=\boxed{\boxed{39}} \end{aligned}\)
Jadi, |A| + |B| = 39.

KTOM April 2023
Pembahasan:
Dari persamaan pertama didapat bahwa 0 ≤ p,q ≤ 124
\(\begin{aligned} p+q&=124\\ q+r&=248&+\\\hline p+2q+r&=372\\ r+p&=372-2q \end{aligned}\)
Nilai maksimum dicapai saat q minimum (q = 0), dan nilai minimum dicapai saat q maksimum (q = 124).
\(\begin{aligned} M-m&=372-2(0)-\left(372-2(124)\right)\\ &=\boxed{\boxed{248}} \end{aligned}\)
Jadi, nilai dari M − m adalah 248.
Bilangan real positif \(x, y,\) dan \(z\) memenuhi persamaan-persamaan berikut: \[\begin{cases} xyz &= 3,\\ (x - y)(y - z)(z - x) &= 4,\\ (x + y)(y + z)(z + x) &= 40. \end{cases}\] Jika nilai minimum dari \(x^6\) dapat ditulis dalam bentuk \(\dfrac{p - \sqrt{q}}{r}\), dengan \(p, q,\) dan \(r\) bilangan bulat dan \(q\) tidak dapat dibagi oleh bilangan prima kuadrat manapun, tentukan nilai dari \(p + 2q + 3r\).
KTOM September 2026
Pembahasan:
Misalkan \(A = xy^2 + yz^2 + zx^2\) dan \(B = x^2y + y^2z + z^2x\). Perhatikan uraian aljabar berikut: \[\begin{aligned} (x + y)(y + z)(z + x) &= A + B + 2xyz \implies A + B = 40 - 2(3) = 34\\ (x - y)(y - z)(z - x) &= A - B \implies A - B = 4 \end{aligned}\] Dengan menjumlahkan dan mengurangkan kedua persamaan di atas, diperoleh: \[A = \frac{34 + 4}{2} = 19 \quad \text{dan} \quad B = \frac{34 - 4}{2} = 15\] Selanjutnya, definisikan: \[a = \frac{x}{y}, \quad b = \frac{y}{z}, \quad c = \frac{z}{x}\] Maka berlaku sistem persamaan simetris dasar terhadap \((a, b, c)\): \[\begin{aligned} abc &= \frac{x}{y}\cdot\frac{y}{z}\cdot\frac{z}{x} = 1\\[4pt] a + b + c &= \frac{x}{y} + \frac{y}{z} + \frac{z}{x} = \frac{xy^2 + yz^2 + zx^2}{xyz} = \frac{A}{3} = \frac{19}{3}\\[4pt] ab + bc + ca &= \frac{x}{z} + \frac{y}{x} + \frac{z}{y} = \frac{x^2y + y^2z + z^2x}{xyz} = \frac{B}{3} = \frac{15}{3} = 5 \end{aligned}\] Berdasarkan Teorema Vieta, \(a, b,\) dan \(c\) merupakan ketiga akar dari polinomial berderajat tiga: \[t^3 - \frac{19}{3}t^2 + 5t - 1 = 0 \iff 3t^3 - 19t^2 + 15t - 3 = 0\] Faktorkan polinomial tersebut: \[(3t - 1)(t^2 - 6t + 3) = 0 \implies t \in \left\{\frac{1}{3},\; 3 - \sqrt{6},\; 3 + \sqrt{6}\right\}\] Perhatikan bahwa \(\dfrac{a}{c} = \dfrac{x/y}{z/x} = \dfrac{x^2}{yz} = \dfrac{x^3}{xyz} = \dfrac{x^3}{3}\), sehingga \(x^3 = 3\cdot\dfrac{a}{c}\).

Agar \(x^6 = \left(x^3\right)^2\) mencapai nilai minimum (dengan \(x > 0\)), kita pilih nilai \(a\) terkecil dan nilai \(c\) terbesar dari ketiga akar di atas, yakni \(a = \dfrac{1}{3}\) dan \(c = 3 + \sqrt{6}\) (serta \(b = 3 - \sqrt{6}\)): \[x^3 = 3 \cdot \frac{1/3}{3 + \sqrt{6}} = \frac{1}{3 + \sqrt{6}} = \frac{3 - \sqrt{6}}{9 - 6} = \frac{3 - \sqrt{6}}{3}\] Kuadratkan kedua ruas untuk memperoleh nilai minimum \(x^6\): \[x^6 = \left(\frac{3 - \sqrt{6}}{3}\right)^2 = \frac{9 - 6\sqrt{6} + 6}{9} = \frac{15 - 6\sqrt{6}}{9} = \frac{5 - 2\sqrt{6}}{3} = \frac{5 - \sqrt{24}}{3}\] Dalam bentuk \(\dfrac{p - \sqrt{q}}{r}\) yang seprima (\(\gcd(p, r) = 1\)), diperoleh \(p = 5\), \(q = 24\), dan \(r = 3\), sehingga: \[p + 2q + 3r = 5 + 2(24) + 3(3) = 5 + 48 + 9 = \color{blue}\boxed{\boxed{\color{black}62}}\]
Jadi, nilai dari \(p + 2q + 3r\) adalah \(62\).
Diberikan bilangan real \(x\) dan \(y\) yang memenuhi \[x^2 - xy + y^2 = 9.\] Tentukan nilai minimum yang mungkin dari \((x^3 + y)(y^3 + x)\).
KTOM September 2026 (Bagian B No. 2)
Pembahasan:

Misalkan \(p = xy\). Dari persamaan \(x^2 - xy + y^2 = 9\), kita dapat menyatakan \(x^2 + y^2\) serta \((x + y)^2\) dalam \(p\):

\[\begin{aligned} x^2 + y^2 &= p + 9\\ (x + y)^2 &= (x^2 - xy + y^2) + 3xy = 9 + 3p = 3(p + 3) \end{aligned}\]

Karena \(x\) dan \(y\) adalah bilangan real, maka \((x + y)^2 \ge 0\), sehingga haruslah:

\[3(p + 3) \ge 0 \implies p \ge -3\]

Selanjutnya, kita hitung \(x^4 + y^4\) dalam variabel \(p\):

\[x^4 + y^4 = (x^2 + y^2)^2 - 2x^2y^2 = (p + 9)^2 - 2p^2 = -p^2 + 18p + 81\]

Uraikan ekspresi yang ingin diminimumkan:

\[\begin{aligned} (x^3 + y)(y^3 + x) &= x^3y^3 + (x^4 + y^4) + xy\\ &= p^3 + (-p^2 + 18p + 81) + p\\ &= p^3 - p^2 + 19p + 81 \end{aligned}\]

Untuk mencari nilai minimumnya pada domain \(p \ge -3\), kita faktorkan selisihnya terhadap nilai saat \(p = -3\) (yaitu \((-3)^3 - (-3)^2 + 19(-3) + 81 = -12\)):

\[\begin{aligned} (x^3 + y)(y^3 + x) &= (p^3 - p^2 + 19p + 93) - 12\\ &= (p + 3)(p^2 - 4p + 31) - 12\\ &= (p + 3)\big((p - 2)^2 + 27\big) - 12 \end{aligned}\]

Karena \(p + 3 \ge 0\) dan \((p - 2)^2 + 27 \ge 27 > 0\), maka suku pertama selalu bernilai tak-negatif:

\[(x^3 + y)(y^3 + x) = (p + 3)\big((p - 2)^2 + 27\big) - 12 \ge 0 - 12 = -12\]

Kesamaan tercapai jika dan hanya jika \(p = -3\), yakni ketika \(x + y = 0\) dan \(xy = -3\), yang dipenuhi oleh pasangan bilangan real \((x, y) = (\sqrt{3}, -\sqrt{3})\) atau \((-\sqrt{3}, \sqrt{3})\). Dengan demikian, nilai minimum yang mungkin adalah \(\color{blue}\boxed{\boxed{\color{black}-12}}\).

Jadi, nilai minimum yang mungkin dari \((x^3 + y)(y^3 + x)\) adalah \(-12\).
