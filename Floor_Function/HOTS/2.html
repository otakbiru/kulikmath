Berikut adalah soal tingkat ... materi Floor Function

Tentukan banyaknya bilangan real \(x\) yang memenuhi persamaan dan pertidaksamaan

\[\lfloor x \rfloor \cdot \lceil x \rceil = x^2 < 2026.\]
KTOM November 2026 (Bagian A No. 6)
Pembahasan:

Kita bagi analisis ke dalam dua kasus berdasarkan apakah \(x\) bilangan bulat atau bukan:

Kasus 1: \(x\) adalah bilangan bulat (\(x = k \in \mathbb{Z}\))
Jika \(x = k \in \mathbb{Z}\), maka \(\lfloor x \rfloor = k\) dan \(\lceil x \rceil = k\), sehingga persamaan \(\lfloor x \rfloor \cdot \lceil x \rceil = k^2 = x^2\) otomatis terpenuhi. Syarat \(x^2 < 2026\) memberikan:

\[k^2 < 2026 \iff -45 \le k \le 45 \qquad (\text{karena } 45^2 = 2025 < 2026 < 2116 = 46^2)\]

Banyaknya solusi bulat adalah \(45 - (-45) + 1 = 91\) bilangan.

Kasus 2: \(x\) bukan bilangan bulat (\(x \in \mathbb{R} \setminus \mathbb{Z}\))
Misalkan \(n = \lfloor x \rfloor \in \mathbb{Z}\), sehingga \(n < x < n + 1\) dan \(\lceil x \rceil = n + 1\). Persamaan menjadi:

\[x^2 = n(n + 1)\]
  • Jika \(n = 0\) atau \(n = -1\), maka \(n(n + 1) = 0 \implies x = 0 \in \mathbb{Z}\) (bukan di dalam interval buka \((n, n + 1)\)).
  • Untuk setiap bilangan bulat \(n \ge 1\), berlaku \(n^2 < n(n + 1) < (n + 1)^2\), sehingga terdapat tepat satu solusi real positif \(x = \sqrt{n(n + 1)} \in (n, n + 1)\). Syarat \(x^2 < 2026\) memberikan: \[n(n + 1) < 2026 \implies 1 \le n \le 44 \qquad (\text{karena } 44 \times 45 = 1980 < 2026 < 2070 = 45 \times 46)\] Diperoleh \(44\) solusi real positif tak-bulat.
  • Untuk setiap bilangan bulat \(n \le -2\), tulis \(n = -(m + 1)\) dengan \(m \ge 1\) (sehingga \(n + 1 = -m\)). Maka \(n(n + 1) = m(m + 1)\), dan terdapat tepat satu solusi real negatif \(x = -\sqrt{m(m + 1)} \in (-(m + 1), -m) = (n, n + 1)\). Syarat \(x^2 = m(m + 1) < 2026\) memberikan \(1 \le m \le 44\).
    Diperoleh \(44\) solusi real negatif tak-bulat.

Jumlahkan banyaknya solusi dari seluruh kasus:

\[\text{Total solusi} = 91 + 44 + 44 = \color{blue}\boxed{\boxed{\color{black}179}}\]
Jadi, banyaknya bilangan real \(x\) yang memenuhi adalah 179.
Untuk setiap bilangan real \(\alpha\), kita definisikan \(\lfloor \alpha \rfloor\) sebagai bilangan bulat yang kurang dari atau sama dengan \(\alpha\). Sebagai contoh \(\lfloor 4{,}9 \rfloor = 4\) dan \(\lfloor 7 \rfloor = 7\). Jika \(x\) dan \(y\) bilangan real sehingga \(\lfloor \sqrt{x} \rfloor = 9\) dan \(\lfloor \sqrt{y} \rfloor = 12\), maka nilai terkecil yang mungkin dicapai oleh \(\lfloor y - x \rfloor\) adalah ....
OSK SMA 2003 (Bagian II No. 18)
Pembahasan:

Berdasarkan definisi fungsi lantai (floor function), syarat \(\lfloor \sqrt{x} \rfloor = 9\) dan \(\lfloor \sqrt{y} \rfloor = 12\) ekuivalen dengan:

\[\begin{aligned} 9 \le \sqrt{x} < 10 &\implies 81 \le x < 100 \\ 12 \le \sqrt{y} < 13 &\implies 144 \le y < 169 \end{aligned}\]

Untuk mencari batas bawah dari \(y - x\), gunakan nilai minimum \(y\) dan batas atas \(x\):

\[y - x > 144 - 100 = 44\]

Karena \(y - x > 44\), maka bilangan bulat terbesar yang tidak melebihi \(y - x\) pasti memenuhi:

\[\lfloor y - x \rfloor \ge 44\]

Pemeriksaan ketercapaian: Karena \(x\) dan \(y\) merupakan bilangan real (tidak harus bulat), kita dapat memilih misalnya \(x = 99{,}5\) (sehingga \(\lfloor \sqrt{99{,}5} \rfloor = 9\)) dan \(y = 144\) (sehingga \(\lfloor \sqrt{144} \rfloor = 12\)). Untuk pasangan ini:

\[\lfloor y - x \rfloor = \lfloor 144 - 99{,}5 \rfloor = \lfloor 44{,}5 \rfloor = 44\]
Jadi, nilai terkecil yang mungkin dicapai oleh \(\lfloor y - x \rfloor\) adalah 44.
Tentukan semua solusi bilangan real persamaan \(\lfloor x^2 \rfloor + \lceil x^2 \rceil = 2003\).

[Catatan : Untuk sebarang bilangan real \(\alpha\), notasi \(\lfloor \alpha \rfloor\) menyatakan bilangan bulat terbesar yang lebih kecil atau sama dengan \(\alpha\), sedangkan \(\lceil \alpha \rceil\) menyatakan bilangan bulat terkecil yang lebih besar atau sama dengan \(\alpha\).]
OSN SMA 2003 (Hari I No. 3)
Pembahasan:

Misalkan \(y = x^2 \ge 0\), sehingga persamaan menjadi \(\lfloor y \rfloor + \lceil y \rceil = 2003\). Tinjau dua kemungkinan nilai \(y\):

  • Kasus 1: \(y\) adalah bilangan bulat (\(y \in \mathbb{Z}\)).
    Maka \(\lfloor y \rfloor = \lceil y \rceil = y\), sehingga \(y + y = 2003 \iff 2y = 2003\). Tidak ada solusi bilangan bulat \(y\) karena \(2003\) bernilai ganjil.
  • Kasus 2: \(y\) bukan bilangan bulat (\(y \notin \mathbb{Z}\)).
    Misalkan \(k = \lfloor y \rfloor \in \mathbb{Z}\). Karena \(y\) bukan bilangan bulat, berlaku \(k \lt y \lt k + 1\), akibatnya \(\lceil y \rceil = k + 1\). Substitusikan ke persamaan: \[k + (k + 1) = 2003 \iff 2k + 1 = 2003 \iff 2k = 2002 \iff k = 1001\] Dengan demikian, \(y = x^2\) harus memenuhi: \[1001 \lt x^2 \lt 1002\]

Karena \(1001 \gt 0\), pertidaksamaan kuadrat \(1001 \lt x^2 \lt 1002\) pada himpunan bilangan real ekuivalen dengan \(\sqrt{1001} \lt |x| \lt \sqrt{1002}\), yaitu:

\[-\sqrt{1002} \lt x \lt -\sqrt{1001} \qquad \text{atau} \qquad \sqrt{1001} \lt x \lt \sqrt{1002}\]
Jadi, semua solusi bilangan realnya adalah \(x \in (-\sqrt{1002}, -\sqrt{1001}) \cup (\sqrt{1001}, \sqrt{1002})\).
