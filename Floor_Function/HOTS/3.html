Misalkan $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang lebih kecil atau sama dengan $x$ dan $\lceil x \rceil$ menyatakan bilangan bulat terkecil yang lebih besar atau sama dengan $x$. Tentukan semua $x$ yang memenuhi $\lfloor x \rfloor + \lceil x \rceil = 5$.
Sumber: OSK SMA 2013 (No. 20)
Pembahasan:

Jika $x \in \mathbb{Z}$, $2x = 5$ tidak punya solusi. Jadi $x \notin \mathbb{Z}$, sehingga $\lceil x \rceil = \lfloor x \rfloor + 1$ dan $2\lfloor x \rfloor + 1 = 5 \implies \lfloor x \rfloor = 2 \implies 2 < x < 3$.

Jadi, semua nilai $x$ yang memenuhi adalah $2 < x < 3$.
No. 22
Untuk sebarang bilangan real $x$, didefinisikan $\lfloor x \rfloor$ sebagai bilangan bulat terbesar yang kurang dari atau sama dengan $x$. Tentukan banyak bilangan asli $n \le 1.000.000$ sehingga $$\sqrt{n} - \lfloor\sqrt{n}\rfloor < \frac{1}{2013}$$
Sumber: OSP SMA 2013
Pembahasan:

Tulis $n = k^2 + m$ dengan $k = \lfloor\sqrt{n}\rfloor \in \{1, 2, \dots, 1000\}$ dan $0 \le m \le 2k$ ($m = 0$ jika $k = 1000$).

Pertidaksamaan menjadi $\sqrt{k^2 + m} < k + \dfrac{1}{2013}$. Kuadratkan kedua ruas:

$$k^2 + m < k^2 + \frac{2k}{2013} + \frac{1}{2013^2} \implies m < \frac{2k}{2013} + \frac{1}{2013^2}$$

Karena $k \le 1000$, maka $\dfrac{2k}{2013} + \dfrac{1}{2013^2} \le \dfrac{2000}{2013} + \dfrac{1}{2013^2} < 1$. Oleh karena itu, satu-satunya bilangan bulat tak negatif $m$ yang memenuhi adalah $m = 0$.

Jadi $n = k^2$ untuk setiap $k = 1, 2, \dots, 1000$, yang semuanya memenuhi $0 < \dfrac{1}{2013}$.

Jadi, banyaknya bilangan asli $n \le 1.000.000$ adalah $1000$.
No. 23
Untuk sebarang bilangan real $x$, didefinisikan $\lfloor x \rfloor$ sebagai bilangan bulat terbesar yang kurang dari atau sama dengan $x$. Jumlah $2014$ digit terakhir dari $\left\lfloor \dfrac{60^{2014}}{7} \right\rfloor$ adalah $\cdots$
Sumber: OSP SMA 2014
Pembahasan:

Perhatikan bahwa $6^{2014} \equiv (-1)^{2014} = 1 \pmod 7$, sehingga $6^{2014} = 7k + 1$ untuk suatu $k \in \mathbb{Z}^+$. Maka:

$$X = \left\lfloor \frac{(7k + 1) \cdot 10^{2014}}{7} \right\rfloor = k \cdot 10^{2014} + \left\lfloor \frac{10^{2014}}{7} \right\rfloor$$

Jadi $2014$ digit terakhir dari $X$ sama dengan $2014$ digit di belakang koma dari $\dfrac{1}{7} = 0,\overline{142857}$. Karena $2014 = 335 \times 6 + 4$:

$$335 \times (1 + 4 + 2 + 8 + 5 + 7) + (1 + 4 + 2 + 8) = 335 \times 27 + 15 = 9060$$
Jadi, jumlah $2014$ digit terakhirnya adalah $9060$.
No. 24
Untuk bilangan real $x$, notasi $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang tidak lebih besar dari $x$; sedangkan $\lceil x \rceil$ menyatakan bilangan bulat terkecil yang tidak lebih kecil dari $x$. Bilangan real $x$ yang memenuhi $$\lfloor x \rfloor^2 - 3x + \lceil x \rceil = 0$$ adalah $\cdots$
Sumber: OSP SMA 2015 (No. 14)
Pembahasan:
  • Jika $x \in \mathbb{Z}$: $\lfloor x \rfloor = \lceil x \rceil = x \implies x^2 - 2x = 0 \implies x = 0$ atau $x = 2$.
  • Jika $x \notin \mathbb{Z}$: misalkan $k = \lfloor x \rfloor$, maka $\lceil x \rceil = k + 1$ dan $k < x < k + 1$. Persamaan memberi $x = \dfrac{k^2 + k + 1}{3}$, sehingga: $$k < \frac{k^2 + k + 1}{3} < k + 1 \implies 3k < k^2 + k + 1 < 3k + 3$$ Pertidaksamaan kanan $k^2 - 2k - 2 < 0 \implies k \in \{0, 1, 2\}$, sedangkan pertidaksamaan kiri $(k - 1)^2 > 0 \implies k \neq 1$.
    • $k = 0 \implies x = \dfrac{1}{3}$ (memenuhi).
    • $k = 2 \implies x = \dfrac{7}{3}$ (memenuhi).
Jadi, bilangan real $x$ yang memenuhi adalah $0, \dfrac{1}{3}, 2, \dfrac{7}{3}$.
No. 25
Banyaknya bilangan asli $n \in \{1, 2, 3, \dots, 1000\}$ sehingga terdapat bilangan real positif $x$ yang memenuhi $x^2 + \lfloor x \rfloor^2 = n$ adalah $\cdots$
Sumber: OSK SMA 2016 (No. 17)
Pembahasan:

Misalkan $k = \lfloor x \rfloor \ge 0$ (bilangan bulat) sehingga $k \le x < k + 1$. Maka $k^2 \le x^2 < (k+1)^2$, dan karena $x^2 = n - k^2$ harus bilangan bulat positif, nilai $x^2$ yang mungkin adalah $k^2 + m$ dengan $0 \le m \le 2k$ (jika $k = 0$ maka $x^2 = n \ge 1$ tidak mungkin karena $x^2 < 1$).

Untuk setiap $k \ge 1$ dan $0 \le m \le 2k$, diperoleh $n = 2k^2 + m$, yang berbeda-beda untuk tiap pasangan $(k, m)$ (karena $2k^2 + 2k < 2(k+1)^2$).

  • Untuk $k = 1, 2, \dots, 21$: semua $2k + 1$ nilai $m$ menghasilkan $n \le 2(21)^2 + 42 = 924 \le 1000$. Banyaknya adalah $\sum_{k=1}^{21} (2k + 1) = 22^2 - 1 = 483$.
  • Untuk $k = 22$: $2(22)^2 = 968$, sehingga $0 \le m \le 32$ ($n = 968, \dots, 1000$), ada $33$ nilai.
  • Untuk $k \ge 23$: $2k^2 \ge 1058 > 1000$.

Total nilai $n$ yang memenuhi adalah $483 + 33 = 516$.

Jadi, banyaknya bilangan asli $n$ adalah $516$.
No. 26
Untuk sebarang bilangan riil $x$, notasi $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang tidak lebih besar dari $x$. Hasil jumlah semua bilangan riil $x$ yang memenuhi $|8x - 1008| + \lfloor x \rfloor = 2016$ adalah $\cdots$
Sumber: OSP SMA 2016 (No. 14)
Pembahasan:

Misalkan $n = \lfloor x \rfloor \in \mathbb{Z}$, sehingga $n \le x < n + 1$.

  • Kasus 1 ($8x - 1008 \ge 0$, yakni $x \ge 126$): $8x - 1008 = 2016 - n \implies x = \dfrac{3024 - n}{8}$. Syarat $n \le \dfrac{3024 - n}{8} < n + 1$ memberi $335{,}11 \dots < n \le 336 \implies n = 336$, sehingga $x_1 = \dfrac{3024 - 336}{8} = 336$.
  • Kasus 2 ($8x - 1008 < 0$, yakni $x < 126$): $1008 - 8x = 2016 - n \implies x = \dfrac{n - 1008}{8}$. Syarat $n \le \dfrac{n - 1008}{8} < n + 1$ memberi $-145{,}14 \dots < n \le -144 \implies n \in \{-145, -144\}$. Diperoleh $x_2 = -\dfrac{1153}{8}$ dan $x_3 = -\dfrac{1152}{8} = -144$.

Jumlah semua solusi adalah $336 - \dfrac{1153}{8} - \dfrac{1152}{8} = \dfrac{2688 - 2305}{8} = \dfrac{383}{8}$.

Jadi, hasil jumlah semua bilangan riil $x$ adalah $\dfrac{383}{8}$.
No. 27
Untuk sebarang bilangan real $x$, notasi $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang tidak lebih besar daripada $x$. Diketahui $\{a_i\}_{i \ge 1}$ barisan bilangan real dengan $a_1 = 20{,}17$. Jika $a_1, a_2, \dots, a_{11}$ dan $\lfloor a_1 \rfloor, \lfloor a_2 \rfloor, \dots, \lfloor a_{10} \rfloor$ masing-masing merupakan barisan aritmetika, sedangkan $\lfloor a_1 \rfloor, \lfloor a_2 \rfloor, \dots, \lfloor a_{11} \rfloor$ bukan merupakan barisan aritmetika, maka nilai infimum (batas bawah terbesar) dari $a_2 - a_1 - \lfloor a_2 - a_1 \rfloor$ adalah $\cdots$
Sumber: OSP SMA 2017 (No. 17)
Pembahasan:

Misalkan beda $a_i$ adalah $b = d + \alpha$ dengan $d \in \mathbb{Z}$ dan $\alpha \in [0, 1)$, sehingga $\{b\} = a_2 - a_1 - \lfloor a_2 - a_1 \rfloor = \alpha$.

Karena $\lfloor a_i \rfloor$ membentuk barisan aritmetika hingga $i = 10$ dan berubah lompatan pada $i = 11$, beda barisan floor tersebut harus $d$ atau $d + 1$:

  • Kasus beda floor $= d$: $0{,}17 + 9\alpha < 1$ dan $0{,}17 + 10\alpha \ge 1 \implies \dfrac{0{,}83}{10} \le \alpha < \dfrac{0{,}83}{9}$, yakni $\alpha \ge 0{,}083$.
  • Kasus beda floor $= d + 1$: tulis $b = (d + 1) - \beta$ dengan $\beta = 1 - \alpha \in (0, 1]$. Agar $\lfloor a_i \rfloor = 20 + (i-1)(d+1)$ untuk $i \le 10$ dan gagal di $i = 11$, butuh $0{,}17 - 9\beta \ge 0$ dan $0{,}17 - 10\beta < 0 \implies \beta \le \dfrac{0{,}17}{9}$, sehingga $\alpha = 1 - \beta \ge 1 - \dfrac{0{,}17}{9} > 0{,}98$.

Jadi nilai minimumnya adalah $\alpha = 0{,}083 = \dfrac{83}{1000}$.

Jadi, nilai minimum yang dicari adalah $0{,}083$ (atau $\dfrac{83}{1000}$).
No. 28
Untuk setiap bilangan real $z$, $\lfloor z \rfloor$ menyatakan bilangan bulat terbesar yang lebih kecil dari atau sama dengan $z$. Jika diketahui $\lfloor x \rfloor + \lfloor y \rfloor + y = 43{,}8$ dan $x + y - \lfloor x \rfloor = 18{,}4$, maka nilai $10(x + y)$ adalah $\cdots$
Sumber: OSK SMA 2018 (No. 12)
Pembahasan:

Tulis $x = \lfloor x \rfloor + \{x\}$ dan $y = \lfloor y \rfloor + \{y\}$ dengan $0 \le \{x\}, \{y\} < 1$.

Dari persamaan pertama: $\lfloor x \rfloor + 2\lfloor y \rfloor + \{y\} = 43{,}8 \implies \{y\} = 0{,}8$ dan $\lfloor x \rfloor + 2\lfloor y \rfloor = 43$.

Dari persamaan kedua: $\{x\} + \lfloor y \rfloor + \{y\} = 18{,}4 \implies \lfloor y \rfloor + \{x\} = 17{,}6 \implies \{x\} = 0{,}6$ dan $\lfloor y \rfloor = 17$.

Maka $\lfloor x \rfloor = 43 - 2(17) = 9$, sehingga $x = 9{,}6$, $y = 17{,}8$, dan $10(x + y) = 10(27{,}4) = 274$.

Jadi, nilai $10(x + y)$ adalah $274$.
No. 29
Untuk sebarang bilangan real $x$, notasi $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang kurang dari atau sama dengan $x$, sedangkan $\lceil x \rceil$ menyatakan bilangan bulat terkecil yang lebih besar atau sama dengan $x$. Bilangan asli terbesar $n$ sehingga $$50\lfloor x \rfloor - \lfloor x\lfloor x \rfloor \rfloor = 100n - 27\lceil x \rceil$$ memiliki solusi real $x$ adalah $\cdots$
Sumber: OSP SMA 2018 (No. 20)
Pembahasan:

Misalkan $m = \lfloor x \rfloor \in \mathbb{Z}$ dan $x = m + \alpha$ ($0 \le \alpha < 1$). Tinjau $\lceil x \rceil$: bernilai $m$ jika $\alpha = 0$ dan $m + 1$ jika $\alpha > 0$.

  • Jika $m < 0$: $50m - \lfloor m^2 + m\alpha \rfloor + 27\lceil x \rceil \le 77m + 27 + (-m) - m^2 < 0$, sehingga tidak ada $n \ge 1$.
  • Jika $m \ge 0$: $\lfloor m^2 + m\alpha \rfloor = m^2 + k$ dengan $0 \le k \le \max(0, m - 1)$ dan $\lceil x \rceil \le m + 1$. Maka: $$100n = 50m - (m^2 + k) + 27\lceil x \rceil \le 77m + 27 - m^2$$ Nilai maksimum $77m + 27 - m^2$ pada bilangan bulat terjadi di $m = 38$ dan $m = 39$, sebesar $77(38) + 27 - 38^2 = 1509$. Jadi $100n \le 1509 \implies n \le 15$.

Untuk $n = 15$, pilih $m = 38$ dan $x = 38{,}25$: $\lfloor x \rfloor = 38$, $\lceil x \rceil = 39$, $\lfloor 38 \times 38{,}25 \rfloor = 1453$, dan $50(38) - 1453 = 447 = 100(15) - 27(39)$.

Jadi, bilangan asli terbesar $n$ adalah $15$.
No. 30
Untuk sebarang bilangan real $x$, simbol $\lfloor x \rfloor$ menyatakan bilangan bulat terbesar yang tidak lebih besar daripada $x$, sedangkan $\lceil x \rceil$ menyatakan bilangan bulat terkecil yang tidak lebih kecil dibanding $x$. Interval $(a, b)$ adalah himpunan semua bilangan real $x$ yang memenuhi $$\lfloor 2x \rfloor^2 = \lceil x \rceil + 7$$ Nilai $a \times b$ adalah $\cdots$
Sumber: OSK SMA 2019 (No. 10)
Pembahasan:

Misalkan $m = \lceil x \rceil \in \mathbb{Z}$, sehingga $m - 1 < x \le m$.

  • Jika $x = m$, maka $\lfloor 2x \rfloor = 2m$, sehingga $4m^2 = m + 7 \implies 4m^2 - m - 7 = 0$ (tidak punya akar bulat).
  • Jika $m - 1 < x \le m - \frac{1}{2}$, maka $2m - 2 < 2x \le 2m - 1$. Nilai $\lfloor 2x \rfloor$ adalah $2m - 2$ (untuk $x < m - \frac{1}{2}$) atau $2m - 1$ (untuk $x = m - \frac{1}{2}$). Persamaan $(2m - 2)^2 = m + 7 \iff 4m^2 - 9m - 3 = 0$ tidak punya akar bulat.
  • Jika $m - \frac{1}{2} \le x < m$, maka $2m - 1 \le 2x < 2m$, sehingga $\lfloor 2x \rfloor = 2m - 1$ dan $\lceil x \rceil = m$. Substitusi memberikan: $$(2m - 1)^2 = m + 7 \iff 4m^2 - 5m - 6 = 0 \iff (4m + 3)(m - 2) = 0$$ Karena $m \in \mathbb{Z}$, diperoleh $m = 2$.

Dengan $m = 2$, himpunan penyelesaiannya adalah $\frac{3}{2} \le x < 2$ (ujung interval terbuka/tertutup batasnya $a = \frac{3}{2}$ dan $b = 2$), sehingga $a \times b = \frac{3}{2} \times 2 = 3$.

Jadi, nilai $a \times b$ adalah $3$.
