Jika \(\sqrt[4]a+\sqrt[4]9=\dfrac1{2-\sqrt3}\), maka nilai a = ....
  1. 16
  2. 17
  3. 18
  4. 19
  5. 20
Sumber: Ganesha Operation
Pembahasan:
\(\begin{aligned} \sqrt[4]a+\sqrt[4]9&=\dfrac1{2-\sqrt3}\cdot\dfrac{2+\sqrt3}{2+\sqrt3}\\ \sqrt[4]a+\sqrt[4]{3^2}&=\dfrac{2+\sqrt3}{4-3}\\ \sqrt[4]a+\sqrt3&=\dfrac{2+\sqrt3}1\\ \sqrt[4]a+\sqrt3&=2+\sqrt3\\ \sqrt[4]a&=2\\ a&=2^4\\ &=\boxed{\boxed{16}} \end{aligned}\)
Jadi, a = 16.

Di antara semua solusi bilangan asli $(x, y)$ persamaan $\dfrac{x + y}{2} + \sqrt{xy} = 54$, solusi dengan $x$ terbesar adalah $(x, y) = \cdots$
Sumber: OSP SMA 2007 (Bagian 1 • No. 19)
Pembahasan:

Kalikan kedua ruas persamaan dengan $2$:

$$x + y + 2\sqrt{xy} = 108 \implies (\sqrt{x} + \sqrt{y})^2 = 108 \implies \sqrt{x} + \sqrt{y} = 6\sqrt{3}$$

Agar $x$ dan $y$ merupakan bilangan asli dengan $\sqrt{x} + \sqrt{y} = 6\sqrt{3}$, keduanya harus berbentuk $x = 3a^2$ dan $y = 3b^2$ untuk bilangan asli $a, b \ge 1$ dengan $a + b = 6$.

Agar $x = 3a^2$ sebesar mungkin, pilih $b$ sekecil mungkin yaitu $b = 1$, sehingga $a = 5$:

$$x = 3(5^2) = 75, \qquad y = 3(1^2) = 3$$
Jadi, solusi dengan $x$ terbesar adalah $(75, 3)$.
Dua bilangan real $x, y$ memenuhi $\left(x + \sqrt{x^2 + 1}\right)\left(y + \sqrt{y^2 + 1}\right) = 1$. Berapakah nilai $x + y$?
Sumber: OSP SMA 2004 (Bagian Pertama - No. 16)
Pembahasan:

Karena $\left(\sqrt{x^2 + 1} + x\right)\left(\sqrt{x^2 + 1} - x\right) = 1$, maka dari persamaan soal diperoleh:

$$y + \sqrt{y^2 + 1} = \frac{1}{x + \sqrt{x^2 + 1}} = \sqrt{x^2 + 1} - x \iff x + y = \sqrt{x^2 + 1} - \sqrt{y^2 + 1}$$

Secara simetris, $x + \sqrt{x^2 + 1} = \sqrt{y^2 + 1} - y \iff x + y = \sqrt{y^2 + 1} - \sqrt{x^2 + 1}$. Jumlahkan kedua persamaan tersebut:

$$2(x + y) = 0 \implies x + y = 0$$
Jadi, nilai $x + y$ adalah $0$.
No. 6
Hasil kali semua akar real dari persamaan $2x^2 + 3x + 4 = 2\sqrt{2x^2 + 3x + 12}$ adalah $\cdots$
Sumber: OSK SMA 2014
Pembahasan:

Misalkan $u = \sqrt{2x^2 + 3x + 12} \ge 0$, sehingga $2x^2 + 3x + 12 = u^2$ dan persamaan menjadi:

$$u^2 - 8 = 2u \iff u^2 - 2u - 8 = 0 \iff (u - 4)(u + 2) = 0$$

Karena $u \ge 0$, satu-satunya solusi adalah $u = 4$, sehingga:

$$2x^2 + 3x + 12 = 16 \iff 2x^2 + 3x - 4 = 0$$

Diskriminannya $D = 3^2 - 4(2)(-4) = 41 > 0$, sehingga kedua akarnya real dan berbeda. Dengan Teorema Vieta, hasil kali kedua akar realnya adalah $\dfrac{-4}{2} = -2$.

Jadi, hasil kali semua akar realnya adalah $-2$.
No. 7
Jumlah dari semua bilangan real $x$ yang memenuhi $$x^2 - 2x = 2 + x\sqrt{x^2 - 4x}$$ adalah $\cdots$
Sumber: OSP SMA 2015 (No. 1)
Pembahasan:

Syarat terdefinisi: $x^2 - 4x \ge 0 \iff x \le 0$ atau $x \ge 4$. Pindahkan $2$ ke ruas kiri dan kuadratkan:

$$(x^2 - 2x - 2)^2 = x^2(x^2 - 4x) \implies x^4 - 4x^3 + 8x + 4 = x^4 - 4x^3 \implies 8x + 4 = 0 \implies x = -\frac{1}{2}$$

Periksa ke persamaan awal: ruas kiri $\frac{1}{4} + 1 = \frac{5}{4}$, ruas kanan $2 - \frac{1}{2}\sqrt{\frac{1}{4} + 2} = 2 - \frac{3}{4} = \frac{5}{4}$ (memenuhi).

Jadi, jumlah semua bilangan real $x$ yang memenuhi adalah $-\dfrac{1}{2}$.
