Ringkasan dan penjelasan lengkap materi Persamaan Bentuk Akar

1. Pengertian Persamaan Bentuk Akar (Persamaan Irasional)

Persamaan Bentuk Akar (atau sering disebut Persamaan Irasional) adalah persamaan aljabar yang memuat variabel (peubah) di dalam tanda radikal (akar).

Contoh persamaan bentuk akar: $$\sqrt{3x + 4} = x, \quad \sqrt{2x - 1} = \sqrt{x + 3}, \quad x^2 - 3x - \sqrt{x^2 - 3x + 5} = 1$$

Konvensi Akar Utama (Principal Square Root):
Untuk setiap bilangan real $A \ge 0$, lambang radikal $\sqrt{A}$ didefinisikan secara tunggal sebagai bilangan real non-negatif yang jika dikuadratkan menghasilkan $A$. Artinya: $$\sqrt{A} \ge 0 \quad \text{untuk seluruh } A \ge 0$$ Sebagai contoh, $\sqrt{9} = +3$ (bukan $\pm 3$). Nilai negatif hanya muncul jika di depan tanda radikal terdapat tanda minus, yaitu $-\sqrt{9} = -3$.

2. Mengapa Mengkuadratkan Memicu Akar Palsu (Extraneous Roots)?

Metode standar untuk menyelesaikan persamaan bentuk akar adalah mengkuadratkan kedua ruas untuk melenyapkan tanda radikal. Namun, operasi kuadrat merupakan implikasi satu arah, bukan hubungan kesetaraan ekuivalen ($\iff$): $$a = b \implies a^2 = b^2 \quad \text{(benar, tetapi sebaliknya belum tentu)}$$ $$a^2 = b^2 \centernot\implies a = b \quad \text{(karena bisa saja } a = -b \text{)}$$

Penjelasan Grafis: Kurva Asli vs Parabola Bayangan

Perhatikan persamaan dasar: $$\sqrt{3x + 4} = x$$ Jika kedua ruas dikuadratkan: $$3x + 4 = x^2 \iff x^2 - 3x - 4 = 0 \iff (x - 4)(x + 1) = 0$$ Secara aljabar, kita mendapatkan dua calon akar: $x = 4$ dan $x = -1$.

Mari kita uji kedua nilai tersebut ke persamaan awal:

  • Untuk $x = 4$: $\sqrt{3(4) + 4} = \sqrt{16} = 4 = x$  (BENAR / Sah).
  • Untuk $x = -1$: $\sqrt{3(-1) + 4} = \sqrt{1} = 1 \neq -1$  (SALAH / Akar Palsu).

Mengapa $x = -1$ muncul?
Grafik $y^2 = 3x + 4$ membentuk parabola horizontal utuh. Kurva fungsi asli hanya berupa separuh cabang atas $y = \sqrt{3x + 4}$ ($y \ge 0$). Saat dikuadratkan, kita secara tidak sengaja mengikutsertakan cabang bawah bayangan $y = -\sqrt{3x + 4}$ yang berpotongan dengan garis $y = x$ di titik $(-1, -1)$.

3. Hubungan Geometris: Bentuk Akar & Teorema Pythagoras

Dalam geometri Euclidean, bentuk akar kuadrat $\sqrt{x^2 + a^2}$ merepresentasikan panjang hipotenusa (sisi miring) dari sebuah segitiga siku-siku dengan panjang sisi tegak $x$ dan $a$.

Berdasarkan Teorema Pythagoras: $$c^2 = a^2 + b^2 \iff c = \sqrt{a^2 + b^2}$$ Konsep ini mendasari rumus jarak antara dua titik koordinat pada bidang Kartesius: $$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$ Oleh karena itu, penyelesaian persamaan bentuk akar sering kali dapat diartikan sebagai pencarian posisi titik yang memiliki jarak tertentu ke titik acuan geometri.

4. Syarat Keharusan & Prinsip Ekuivalensi Persamaan Akar

Agar tidak terjebak oleh akar palsu, setiap persamaan bentuk akar wajib diselesaikan dengan memperhatikan himpunan semesta syarat berikut:

Bentuk Persamaan Syarat Keharusan (Domain & Jangkauan) Sistem Ekuivalen
$\sqrt{f(x)} = c$  $(c \in \mathbb{R})$ $c \ge 0$  (jika $c < 0$, himpunan penyelesaian adalah $\emptyset$) $f(x) = c^2$
$\sqrt{f(x)} = g(x)$ $g(x) \ge 0$  (Syarat non-negatif ruas kanan) $\begin{cases} g(x) \ge 0 \\ f(x) = [g(x)]^2 \end{cases}$
$\sqrt{f(x)} = \sqrt{g(x)}$ $f(x) \ge 0$ dan $g(x) \ge 0$  (Irisan domain) $\begin{cases} f(x) \ge 0 \\ f(x) = g(x) \end{cases}$
$\sqrt{f(x)} + \sqrt{g(x)} = h(x)$ $f(x) \ge 0$, $g(x) \ge 0$, dan $h(x) \ge 0$ Isolasi satu akar: $\sqrt{f(x)} = h(x) - \sqrt{g(x)}$, lalu kuadratkan

Visualisasi Domain Bersama: $\sqrt{x + 2} = \sqrt{6 - x}$

Pada persamaan dengan dua bentuk akar $\sqrt{f(x)} = \sqrt{g(x)}$, solusi hanya boleh berada di dalam irisan domain kedua fungsi:

  • Syarat fungsi 1: $x + 2 \ge 0 \implies x \ge -2$
  • Syarat fungsi 2: $6 - x \ge 0 \implies x \le 6$
  • Domain gabungan: $x \in [-2, 6]$

Ketika kedua ruas dikuadratkan: $$x + 2 = 6 - x \iff 2x = 4 \iff x = 2$$ Karena $x = 2 \in [-2, 6]$, maka $x = 2$ merupakan solusi valid tunggal. Pada grafik di samping, terlihat kedua kurva bertemu tepat di titik $(2, 2)$.

5. Strategi Penyelesaian Lanjutan: Substitusi Variabel Pembantu

Persamaan bentuk akar yang memuat bentuk kuadrat berulang atau bertingkat (sering keluar di SNBT dan ujian masuk perguruan tinggi) dapat diselesaikan dengan sangat cepat menggunakan pemisalan variabel baru ($u = \sqrt{\dots}$):

  1. Identifikasi ekspresi berulang $f(x)$ di luar dan di dalam tanda akar.
  2. Misalkan $u = \sqrt{f(x) + c}$ dengan syarat mutlak: $$u \ge 0$$
  3. Ubah persamaan awal menjadi persamaan polinomial sederhana dalam variabel $u$.
  4. Selesaikan nilai $u$, pilih hanya $u \ge 0$, lalu substitusikan kembali untuk mendapatkan nilai $x$.

6. Contoh Soal & Pembahasan Bertingkat

Contoh 1: Persamaan Dasar & Eliminasi Akar Palsu (Tingkat Dasar)
Tentukan himpunan penyelesaian dari persamaan bentuk akar berikut: $$\sqrt{2x + 9} = x - 3$$
Pembahasan:
Langkah 1: Tentukan syarat non-negatif ruas kanan
Karena $\sqrt{2x + 9} \ge 0$, maka ruas kanan wajib memenuhi: $$x - 3 \ge 0 \implies x \ge 3$$
Langkah 2: Kuadratkan kedua ruas
$$\begin{aligned} (\sqrt{2x + 9})^2 &= (x - 3)^2 \\ 2x + 9 &= x^2 - 6x + 9 \\ x^2 - 8x &= 0 \\ x(x - 8) &= 0 \end{aligned}$$ Diperoleh calon akar: $x = 0$ atau $x = 8$.

Langkah 3: Uji syarat batas ($x \ge 3$)
  • $x = 0$ tidak memenuhi syarat $x \ge 3$ ($\sqrt{2(0)+9} = 3 \neq 0 - 3 = -3$, akar palsu).
  • $x = 8$ memenuhi syarat $x \ge 3$ ($\sqrt{2(8)+9} = \sqrt{25} = 5 = 8 - 3$, sah).
Jadi, himpunan penyelesaian dari persamaan tersebut adalah $\{8\}$.
Contoh 2: Substitusi Variabel Kuadrat Berulang (Tingkat SNBT)
Tentukan jumlah semua nilai $x$ yang memenuhi persamaan aljabar berikut: $$x^2 - 3x - \sqrt{x^2 - 3x + 5} = 1$$
Pembahasan:
Perhatikan pola berulang $x^2 - 3x$ di luar dan di dalam akar.
Misalkan: $$u = \sqrt{x^2 - 3x + 5} \quad \text{dengan syarat } u \ge 0$$ Kuadratkan kedua sisi: $$u^2 = x^2 - 3x + 5 \implies x^2 - 3x = u^2 - 5$$ Substitusikan ke persamaan awal: $$\begin{aligned} (u^2 - 5) - u &= 1 \\ u^2 - u - 6 &= 0 \\ (u - 3)(u + 2) &= 0 \end{aligned}$$ Diperoleh $u = 3$ atau $u = -2$.
Karena syarat mutlak $u \ge 0$, maka $u = -2$ gugur. Kita hanya menggunakan $u = 3$.

Kembalikan ke variabel $x$: $$\begin{aligned} \sqrt{x^2 - 3x + 5} &= 3 \\ x^2 - 3x + 5 &= 9 \\ x^2 - 3x - 4 &= 0 \\ (x - 4)(x + 1) &= 0 \end{aligned}$$ Diperoleh akar-akar real: $x_1 = 4$ dan $x_2 = -1$.
Jumlah seluruh nilai $x$ yang memenuhi adalah: $$x_1 + x_2 = 4 + (-1) = 3$$
Jadi, jumlah semua nilai $x$ yang memenuhi persamaan adalah $3$.
Contoh 3: Persamaan Dua Tanda Akar & Pemfaktoran Konjugat (Tingkat HOTS)
Selesaikan persamaan bentuk akar berikut untuk nilai real $x$: $$\sqrt{2x + 3} - \sqrt{x + 1} = 1$$
Pembahasan:
Langkah 1: Syarat domain radikand $$\begin{aligned} 2x + 3 &\ge 0 \implies x \ge -\frac{3}{2} \\ x + 1 &\ge 0 \implies x \ge -1 \end{aligned}$$ Irisan domain awal: $x \ge -1$.

Langkah 2: Isolasi salah satu bentuk akar
Pindahkan $-\sqrt{x + 1}$ ke ruas kanan agar kedua ruas bernilai positif: $$\sqrt{2x + 3} = 1 + \sqrt{x + 1}$$ Kuadratkan kedua ruas: $$\begin{aligned} (\sqrt{2x + 3})^2 &= (1 + \sqrt{x + 1})^2 \\ 2x + 3 &= 1 + 2\sqrt{x + 1} + (x + 1) \\ 2x + 3 &= x + 2 + 2\sqrt{x + 1} \\ x + 1 &= 2\sqrt{x + 1} \end{aligned}$$ Bawa seluruh suku ke satu ruas: $$(x + 1) - 2\sqrt{x + 1} = 0$$ Faktorkan dengan mengeluarkan faktor $\sqrt{x + 1}$: $$\sqrt{x + 1}\left(\sqrt{x + 1} - 2\right) = 0$$ Diperoleh dua kemungkinan:
  1. $\sqrt{x + 1} = 0 \implies x + 1 = 0 \implies x = -1$
  2. $\sqrt{x + 1} - 2 = 0 \implies \sqrt{x + 1} = 2 \implies x + 1 = 4 \implies x = 3$
Langkah 3: Uji verifikasi
  • Uji $x = -1$: $\sqrt{2(-1)+3} - \sqrt{-1+1} = \sqrt{1} - 0 = 1$  (Memenuhi).
  • Uji $x = 3$: $\sqrt{2(3)+3} - \sqrt{3+1} = \sqrt{9} - \sqrt{4} = 3 - 2 = 1$  (Memenuhi).
Jadi, himpunan penyelesaian dari persamaan tersebut adalah $x = -1$ atau $x = 3$.
