Berikut adalah soal tingkat ... materi Pertidaksamaan Logaritma

Himpunan semua nilai bilangan real $x$ yang memenuhi pertidaksamaan logaritma dengan basis peubah $$\log_x(2x^2 - 5x + 3) \le 1$$ adalah ....
  1. $0 < x \le \dfrac{3 - \sqrt{3}}{2}$ atau $\dfrac{3}{2} < x \le \dfrac{3 + \sqrt{3}}{2}$
  2. $\dfrac{3 - \sqrt{3}}{2} \le x < 1$ atau $x \ge \dfrac{3 + \sqrt{3}}{2}$
  3. $0 < x < 1$ atau $x > \dfrac{3}{2}$
  4. $\dfrac{3}{2} < x \le \dfrac{3 + \sqrt{3}}{2}$
  5. $x \le \dfrac{3 - \sqrt{3}}{2}$ atau $x \ge \dfrac{3 + \sqrt{3}}{2}$
Pembahasan:
Diberikan pertidaksamaan $\log_x(2x^2 - 5x + 3) \le 1$.

1. Syarat Keberadaan Logaritma:
  • Syarat Basis: $x > 0$ dan $x \ne 1$.
  • Syarat Numerus: $$2x^2 - 5x + 3 > 0$$ $$(2x - 3)(x - 1) > 0 \iff x < 1 \quad \text{atau} \quad x > \frac{3}{2}$$
Menggabungkan syarat basis dan numerus diperoleh interval valid: $$x \in (0, 1) \cup \left(\frac{3}{2}, \infty\right)$$ 2. Penyelesaian Berdasarkan Nilai Basis $x$:
Perhatikan bahwa $1 = \log_x(x)$.

• Kasus 1: Untuk $0 < x < 1$ (Basis di antara 0 dan 1)
Karena basis pecahan $0 < x < 1$, maka tanda pertidaksamaan berbalik arah: $$2x^2 - 5x + 3 \ge x$$ $$2x^2 - 6x + 3 \ge 0$$ Akar-akar dari $2x^2 - 6x + 3 = 0$ menggunakan rumus kuadrat: $$x = \frac{6 \pm \sqrt{(-6)^2 - 4(2)(3)}}{2(2)} = \frac{6 \pm \sqrt{12}}{4} = \frac{3 \pm \sqrt{3}}{2}$$ Sehingga penyelesaian pertidaksamaan kuadrat adalah: $$x \le \frac{3 - \sqrt{3}}{2} \quad \text{atau} \quad x \ge \frac{3 + \sqrt{3}}{2}$$ Nilai $\frac{3 - \sqrt{3}}{2} \approx \frac{3 - 1{,}732}{2} = 0{,}634$ berada pada interval $(0, 1)$.
Irisan dengan interval kasus $0 < x < 1$ adalah: $$0 < x \le \frac{3 - \sqrt{3}}{2}$$ • Kasus 2: Untuk $x > 1$ (Basis lebih dari 1)
Dari syarat numerus, domain yang memenuhi adalah $x > \frac{3}{2}$. Karena $x > 1$, tanda pertidaksamaan tetap: $$2x^2 - 5x + 3 \le x$$ $$2x^2 - 6x + 3 \le 0$$ Penyelesaian pertidaksamaan kuadrat: $$\frac{3 - \sqrt{3}}{2} \le x \le \frac{3 + \sqrt{3}}{2}$$ Nilai $\frac{3 + \sqrt{3}}{2} \approx \frac{3 + 1{,}732}{2} = 2{,}366$, yang lebih besar dari $\frac{3}{2} = 1{,}5$.
Irisan dengan interval $x > \frac{3}{2}$ adalah: $$\frac{3}{2} < x \le \frac{3 + \sqrt{3}}{2}$$ 3. Gabungan Himpunan Penyelesaian:
Menggabungkan hasil dari Kasus 1 dan Kasus 2: $$0 < x \le \frac{3 - \sqrt{3}}{2} \quad \text{atau} \quad \frac{3}{2} < x \le \frac{3 + \sqrt{3}}{2}$$
Jadi, himpunan penyelesaiannya adalah $0 < x \le \dfrac{3 - \sqrt{3}}{2}$ atau $\dfrac{3}{2} < x \le \dfrac{3 + \sqrt{3}}{2}$.
